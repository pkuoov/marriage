# Intelligence Intake

This directory stores abstracted source material for future story packs. It must not store copied real cases, names, handles, screenshots, exact amounts, exact timelines, or traceable quotes.

Use each entry as a pressure system:

- What object appears on mic?
- Why does it exist tonight?
- Which edge is missing?
- What does the caller gain by telling it this way?
- What does the other side gain by leaving it incomplete?
- Which third pressure source pushes the conflict?
- What can be confirmed, what was edited, and what remains unknowable?

`plot-template-pool.json` is not runtime content. It is a production pool for showrunner selection before a case is written as a complete call and moved into `content/packs/<pack-id>/cases/*.json`.
