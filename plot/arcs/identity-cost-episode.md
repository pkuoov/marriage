# 好听身份的成本

## Dramatic Question

当“体面”“自己人”“条件”“主责”变成要求别人付款、带客、交出流水或垫款的理由时，谁应该为实际成本负责？

## Movement

1. 第一幕把感情压力落到信用卡和工资时间线。
2. 第二幕把专属感落到会员、客户资源和投店资金。
3. 第三幕让来电人也成为被审视者，失去单向控诉的安全位置。
4. 第四幕把同一种结构迁移到职场流程，完成主题合拢。

## Resolution Rule

结尾不能说成“所有好听话都是假的”。好听词本身无罪；利用它遮住钱、资源或责任入口的动作才需要被指出。
