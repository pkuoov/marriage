# 好听身份的成本

## Dramatic Question

当“体面”“自己人”“条件”“主责”变成要求别人付款、带客、多出彩礼或垫款的理由时，谁应该为实际成本负责？

## Movement

1. 第一幕让女方把十四个月半薪与房租当成自己的固定收入并几乎花完，也让男方把二十四万五累计给付误算成她至少还有十五万；八万元请求因此有了动机，但信用卡、借款与信托责任仍按签字、受益和去向拆开。
2. 第二幕先让何用特殊作息遮住酒吧营销工作；强光、敲门和借口物业留下开放边。第二夜玩家从民警来访问出她的职业与客户资源，再把 Tony 给她的专属感落到会员、带客和投店资金。
3. 第三幕让玩家从“男方已经说拿不出，女方为何仍要求流水”问出女方父母的财力误判，再拆开“女方不信—男方只交工资账户”的互相防备；男方随后用高额礼物闯进直播，双方第一次直接争到二十八万八彩礼、工资账户二十八万六、未提供的其他账户和女方家尚未到期的宸直三十万元，来电人也失去单向控诉的安全位置。
4. 第四幕把同一种结构迁移到职场流程，完成主题合拢。

## Resolution Rule

结尾不能说成“所有好听话都是假的”。好听词本身无罪；利用它遮住钱、资源或责任入口的动作才需要被指出。
