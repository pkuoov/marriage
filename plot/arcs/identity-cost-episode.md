# 好听身份的成本

## Dramatic Question

当“体面”“自己人”“条件”“负责人”变成要求别人付款、带客、多出彩礼或垫款的理由时，谁应该为实际成本负责？

## Movement

1. 第一幕先让女方以“我不转是不是不讲情分”索取公开支持，再用约五千男装追问男方怎么花钱。主播从两千多一件大衣问回约四万共同排场，其中一万二的设备就是买给她的；第二天银行流水再露出三月、五月各一万元双月房租，玩家追问后才知道住房成本也由男方承担。她把十四个月半薪和自己的工资几乎花完，男方则把二十四万五累计给付误算成她至少还有十五万。八万元请求因此有了动机，但信用卡缺口、借款与信托责任仍按签字、受益和去向拆开。
2. 第二幕先让何用特殊作息遮住酒吧营销工作；强光、敲门和借口物业留下开放边。第二夜玩家从民警来访问出她的职业与客户资源，再把 Tony 给她的专属感落到十四个月十八次消费、四万六千三百八十元营业额、七名联系人和四名到店顾客。她要求全额退款时，玩家必须拆开已完成服务与姓名、手机号、客源能力被擅用这两种性质不同的损失。
3. 第三幕让玩家从“男方已经说拿不出，女方为何仍要求流水”问出女方父母的财力误判，再拆开“女方不信—男方只交工资账户”的互相防备；男方随后用高额礼物闯进直播，双方第一次直接争到二十八万八领证前进入女方个人账户、婚宴首饰另算、工资账户二十八万六、未提供的其他账户、女方领证后才准备拿出的六万元，以及父母留给女儿个人的未来二十万元。来电人失去单向审查男方家底的安全位置。
4. 第四幕把同一种结构迁移到职场流程。陈把“公司一直不给我报销”打进群，却想同时保住负责人署名；玩家按五层口径追出她主动抢活、看过流程、用九天后的通知替当天解释、把审批页当付款、又想用“月底一起办”省掉留痕。结案不靠她说懂了，而靠她把消息改成个人刷卡、尚未收到报销和索要凭证的准确文字，完成主题合拢。

## Resolution Rule

结尾不能说成“所有好听话都是假的”。好听词本身无罪；利用它遮住钱、资源或责任入口的动作才需要被指出。
