# 好听身份的成本

## Dramatic Question

当“体面”“负责人”“条件”“自己人”变成要求别人付款、背责、多出彩礼或带客的理由时，谁应该为实际成本负责？

## Movement

1. 第一幕先让女方以“我不转是不是不讲情分”索取公开支持，再用约五千元男装追问男方怎么花钱。主播从两千多一件大衣问回约四万元共同排场，其中一万二的设备就是买给她的；第二天银行流水再露出三月、五月各一万元双月房租。玩家若追问，可以提前确认住房成本也由男方承担；没走这条路线，男方第二夜发来的催款消息也会明确房租受益人。她把十四个月半薪和自己的工资几乎花完，男方则把二十四万五累计给付误算成她至少还有十五万。八万元请求因此有了动机，但信用卡缺口、借款与信托责任仍按签字、受益和去向拆开。
2. 第二幕先把同一种结构迁移到职场流程。陈把“公司一直不给我报销”打进群，却想同时保住负责人署名；玩家按五层口径追出她主动抢活、看过流程、用九天后的通知替当天解释、把审批页当付款、又想用“月底一起办”省掉留痕。平台强制贴片第一次让公开原话付出可见代价，职场案的程序性也让整晚在此换气。
3. 第三幕让玩家从“男方已经说拿不出，女方为何仍要求流水”问出女方父母的财力误判，再拆开“女方不信—男方只交工资账户”的互相防备；男方随后用高额礼物闯进直播，双方第一次直接争到二十八万八领证前进入女方个人账户、婚宴首饰另算、工资账户二十八万六、未提供的其他账户、女方领证后才准备拿出的六万元，以及父母留给女儿个人的未来二十万元。来电人失去单向审查男方家底的安全位置。
4. 第四幕让何用特殊作息遮住酒吧营销工作，也把完整名单裁成只剩姓名、亲密度和下次约。强光、拉帘和敲门留下开放边；第二夜玩家从警方上门问出她借过涉案高利贷放款人的钱，再沿酒吧消息源与完整名单问到一百万门槛、十二万转账和走他户。结案把这笔钱与第二幕的六万八并排：前者只有转账和提交页，后者至少有公司抬头发票。同样是追钱，证据不能混算。

## Resolution Rule

结尾不能说成“所有好听话都是假的”。好听词本身无罪；利用它遮住钱、资源或责任入口的动作才需要被指出。
