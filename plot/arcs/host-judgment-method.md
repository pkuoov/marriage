# 林旭阳的判断方法

## Wound

两年前，他曾被一张剪过的账单带着误判。因此他既怕再次伤人，也怕节目因为不够刺激被平台放弃。

## Arc

- 第一幕：从接住委屈，进到查看钱流。
- 第二幕：从审批截图追到正式报销入口；强制贴片压下来时，玩家第一次知道让一句原话留在直播里会丢掉推荐位。
- 第三幕：高额礼物让拒绝插麦变难；玩家亲手决定怎样处理礼物和连麦申请，再由他问清双方各自授权到哪里，把询问权对准来电人的条件与修剪。
- 第四幕：不靠名单给关系定罪，而是拆分真实照顾、主动代投和资金原件；再把只有转账与提交页的十二万，同第二幕至少有公司抬头发票的六万八并排。
- 咖啡厅序章：开播前与赵律师同行处理离婚谈判，也是玩家第一次亲手并看、出示材料的操作入口。双方只约好先录，公开范围仍要当场确认；玩家负责问材料、收镜头，赵负责把离婚、财产和亲子诉求压回可提交的程序。妻子带孩子离开后，赵指出亲子异议由男方提出、怀疑依据也得由他先拿，并让他先联系正规机构，判断共同住所里遗留的旧物是否可用。两条线交给专业人后才进入夜间直播，个人委托初检的结果放在四幕热线后兑付。

## Player Expression

固定的是林旭阳为什么怕误判，开放的是他今晚怎样做。每个关键选择都必须能翻译成一个主播台前的动作，而不是编剧分类：从哪句话追、要不要静音、向谁求助、带哪页材料回麦上。按钮按下后，NPC 要回应林旭阳刚做的事，不能只让数值变化。

白天线不授予侦查权。来电人授权的遮名材料、对方主动发来的回复、节目顾问在职业边界内的解读，以及愿意见面的第三人，构成林旭阳能触及的全部范围。

## End State

他没有变成判官，只形成一套可重复的方法：复述已知、追问主语、把材料边界说清、把未知项留下。咖啡厅先让玩家看见这套方法离开直播台也能成立；当晚的四通热线再让他为同一种坚持付出看得见的平台代价。
