# 林旭阳的判断方法

## Wound

两年前，他曾被一张剪过的账单带着误判。因此他既怕再次伤人，也怕节目因为不够刺激被平台放弃。

## Arc

- 第一幕：从接住委屈，进到查看钱流。
- 第二幕：从批评暧昧，进到辨认情绪劳动如何转化资源。
- 第三幕：把询问权对准来电人的条件与修剪。
- 第四幕：不靠“谁更坏”收尾，而是拆分主责、付款、返款和审批。

## End State

他没有变成判官，只形成一套可重复的方法：复述已知、追问主语、把材料边界说清、把未知项留下。
