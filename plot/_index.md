# Plot Structure

## Story Structure

**Model:** 起—承—转—合四幕结构

```text
体面 → 自己人 → 条件 → 主责
短债 → 亲密转化 → 反查来电人 → 公共流程入口
```

每一幕都必须完成一个独立案件，同时改变玩家下一幕的听法。第四幕不是同题材加码，而是把前三幕形成的方法迁移到职场。

## Escalation Contract

| 幕 | 玩家最容易先信什么 | 本幕校准 | 离场钩子 |
|---|---|---|---|
| 一 | 失业与体面值得先心疼 | 情绪能接，账不能代接 | 亲密照顾是否也能变成消费入口 |
| 二 | “自己人”代表专属关系 | 看它是否接着办卡、带客和投店 | 来电人自己有没有包装和筛选 |
| 三 | 只要资料有假，就只需审对方 | 双方的修剪都要有主语 | 离开婚恋后，这套话术是否仍成立 |
| 四 | 有审批截图就等于责任清楚 | 追付款、返款和主责各自的入口 | 四个好听词共同把成本推给了谁 |
