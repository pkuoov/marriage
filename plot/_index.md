# Plot Structure

## Story Structure

**Model:** 起—承—转—合四幕结构

```text
体面 → 自己人 → 条件 → 主责
短债 → 亲密转化 → 反查来电人 → 公共流程入口
```

每一幕都必须完成一个独立案件，同时改变玩家下一幕的听法。第二幕用较安静的职场流程换气，第三幕用双人连麦升压，第四幕再用突然挂断、警方回拨和商务函收束。

每案的发动机固定为“求助问题 + 当夜压力 + 被保护的利益 + 重大隐瞒”。来电人可以问一件事为什么发生，也可以要求主播帮自己作决定或争取结果；玩家揭开的事实必须足以改变对这项求助的答复，否则该隐瞒不承担主反转。

四案重复的证词墙、材料选择和正式指认是契约仪式，不再作为同模板缺陷处理。节奏变奏写在佯攻层：首案只做 Tier 1-2 的如约兑付和玩家亲手出招；第二案起允许主播眨眼；Tier 4 只能在第二案结案以后出现。每次发债最迟在下一场付息，六十行以上的连续对质在场内另插一次小承认或弹幕败退。
