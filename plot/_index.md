# Plot Structure

## Story Structure

**Model:** 起—承—转—合四幕结构

```text
体面 → 自己人 → 条件 → 主责
短债 → 亲密转化 → 反查来电人 → 公共流程入口
```

每一幕都必须完成一个独立案件，同时改变玩家下一幕的听法。第四幕不是同题材加码，而是把前三幕形成的方法迁移到职场。
