# 中国式婚恋：十年一梦

中国式恋爱、相亲、结婚、生子主题的视觉小说 / 关系选择游戏原型。

当前公开首版为男主线。玩家从婚介相亲或自由恋爱开局，在十年关系里经历约会、见朋友、见父母、谈婚事、婚礼、婚后磨合、房贷压力、育儿与入学等阶段。每个周目都会随机生成候选人的隐藏动机、性格爆发倾向、家庭态度和现实事件，玩家需要在暧昧、压力、利益和边界之间做选择。

## 游戏宗旨

《中国式婚恋：十年一梦》使用“周目”和“随机事件”作为游戏表达，并不是为了说现实可以重开，而是为了让玩家在安全的虚构环境里练习观察、判断、沟通、止损和承担后果。游戏里的重开是一种学习工具，现实里的每一次选择才是真正要认真对待的东西。

## 作者想说的话

人生不是肉鸽游戏，人生也不能重来。大多数人并不是完美无限或是十恶不赦，他们都有他们的利益考量，他们也有他们的诉求。我不能改变随机的事和随机的人，我只能关注我自己的每一次选择。

欢迎大家提出创作意见，也欢迎分享自己或者知道的故事。我们可以把这些故事抽象、改写、融合进游戏里，让更多的人享受幸福，也让更多的人提前避坑。

## 如何游玩

### 在线运行本地版本

本项目是纯前端原型，不需要后端服务。

```bash
npm run dev
```

然后在浏览器打开：

```text
http://127.0.0.1:5174
```

如果 5174 端口被占用，也可以直接用 Python 指定其他端口：

```bash
python3 -m http.server 5175
```

然后打开：

```text
http://127.0.0.1:5175
```

### 开始一局

1. 进入标题页后点击开始。
2. 公开首版只开放男主线，女主线会作为后续大版本单独制作。
3. 你有 25 点机动点数，可以分配到个人财富、家庭背景、外貌、学历和情商，每项最高 10 点。
4. 选择进入婚介相亲线，或选择自由恋爱开局。
5. 在每个事件中阅读对话，选择回应方式。选择会影响关系温度、边界感、现实压力、父母态度、对方隐藏动机爆发概率等状态。
6. 留意右侧的关系手账。它不会像 debug 面板一样暴露精确内部数值，而是用更接近游戏内观察的方式提示当前关系状态。
7. 在关键章节中，你可以继续推进、止损离开，或在某些条件下切换到备选关系。
8. 周目结束后会获得永久机动点。前几轮成长更快，用来鼓励玩家尝试不同判断路径。

## 当前内容

- 男主线公开首版。
- 25 点自由加点，属性包括财富、家庭、外貌、学历、情商。
- 婚介相亲与自由恋爱两种开局。
- 多名女性候选人，包含不同家庭结构、消费观、亲密关系模式和隐藏动机。
- NPC 每局会随机生成隐藏底色，包括真诚、利己、图钱、控制、回避、NPD 倾向等。
- 随机事件库会在不同阶段插入现实压力，例如失业、升职、住院、父母催促、礼物要求、彩礼谈判、房贷压力、育儿分工等。
- 黄色信号和红色信号会受情商、当前关系状态和动机爆发值影响。
- 第 3 章之后存在关系止损、换线和不同阶段结局。
- 无语音，使用轻量音效和立绘 / 背景图营造橙光式互动体验。

## 内容边界

本作是虚构游戏，不提供法律、心理、婚恋咨询结论。游戏中的案例、角色和事件会参考中文互联网常见婚恋讨论、律师普法内容、相亲博主叙事和现实关系矛盾，但会进行抽象、改写和混合，不对应任何单一真实人物或具体案件。

游戏的核心不是审判某一类人，而是呈现婚恋关系里常见的利益、压力、误判、投射和边界问题。玩家可以在游戏中练习识别风险，也可以看到“并非坏人但不适合”的关系如何一步步走向不同结局。
