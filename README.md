# 深夜热线：直播间侦探

一款以匿名情感连麦为舞台的现实向剧情推理游戏。

你将作为直播间主播，听来电人讲述感情、金钱与工作的纠纷，再从前后改口、聊天记录和账目材料里找到被省略的事实。玩家只选择怀疑的方向，完整问句由主播说出；证据能确认到哪里，判断就停在哪里。

## 玩法

- 先听完整陈述，再逐句回放并指出可疑之处。
- 在有限耐心内追问；问偏会消耗机会，关键回答会改变对方口径。
- 收麦后选择调查地点和材料，第二次连线会回应你的选择。
- 区分已经确认、仍需核对和无法证明的内容，不靠猜测补齐真相。

## 当前试玩版

`steam-demo-01` 包含四个连续主案和两个直播快案。主案会跨两晚推进，并由一条共同暗线串联；快案更接近短局质证，重点是从一段话里抓住破绽。

项目仍在开发中。浏览器试玩、离线包、Electron 桌面版和 Windows 便携版流程已经接通，正式发行前仍会继续调整剧情、演出、语音和实机体验。

## 本地运行

需要 Node.js 22.12 或更高版本。

```bash
npm ci
npm start
```

`npm start` 会从新进度启动游戏并自动打开浏览器。

常用命令：

```bash
npm run test:local      # 本地检查与核心路线回放
npm run build:playable  # 生成离线浏览器版
npm run build:desktop   # 生成 Electron 桌面版
```

Windows 打包必须在原生 Windows 环境验收，具体步骤见 [Windows EXE 制作与验包手册](docs/windows-exe-build-guide.md)。
