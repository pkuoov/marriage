# 婚恋侦探局

中国式恋爱、相亲、结婚、生子主题的反诈防骗防坑视觉小说 / 关系选择游戏原型。

当前版本转为婚恋侦探 / 律师顾问视角。玩家不再亲自下场相亲，也不再主动给主角加点。每周目由系统后台随机生成三起婚恋案件：一个婚前 case、一个婚后 case、一个告解模式。玩家在当事人连线中听男方或女方诉苦，复盘当时场景，追问证词里的提示，判断 TA 是真受害者、半真半假、恶人先告状，还是在自己的告解里自欺。

## 游戏宗旨

《婚恋侦探局》使用“周目”和“随机事件”作为游戏表达，并不是为了说现实可以重开，而是为了让玩家在安全的虚构环境里练习观察、判断、沟通、止损和承担后果。游戏里的重开是一种学习工具，现实里的每一次选择才是真正要认真对待的东西。

本作更接近一款婚恋风险识别游戏，而不是甜宠恋爱模拟。你要识别的坑包括情感诈骗、财务共债、房产边界、彩礼婚礼消耗、父母越界、前任未断、情绪价值过度索取、关心不足导致的关系外包、择偶资料包装、婚育史隐瞒、短择经历隐瞒，以及经济周期和投资决策对家庭的连锁影响。

案件不是线性破案。每个当事人都有预设立场，有些话是假话，有些话只是迷惑性含糊，有些事 TA 明明知道但不愿意说。场景复原也只是当事人的版本，不自动等于事实。玩家需要反复追问，找出迷惑点和矛盾点，证据不足时不能稳定指认。

## 作者想说的话

人生不是肉鸽游戏，人生也不能重来。大多数人并不是完美无限或是十恶不赦，他们都有他们的利益考量，他们也有他们的诉求。我不能改变随机的事和随机的人，我只能关注我自己的每一次选择。

欢迎大家提出创作意见，也欢迎分享自己或者知道的故事。我们可以把这些故事抽象、改写、融合进游戏里，让更多的人享受幸福，也让更多的人提前避坑。

## 如何游玩

### 在线运行本地版本

本项目是纯前端原型，不需要后端服务。

```bash
npm run dev
```

然后在浏览器打开：

```text
http://127.0.0.1:5174
```

如果 5174 端口被占用，也可以直接用 Python 指定其他端口：

```bash
python3 -m http.server 5175
```

然后打开：

```text
http://127.0.0.1:5175
```

### 开始一局

1. 进入标题页后点击开始。
2. 点击开始接案。
3. 系统会随机生成本场调查画像，不再由玩家手动加点。
4. 开案前选择本局侦探专长：财务审计型、情绪追踪型或证据核查型。
5. 系统会生成三桩后台共用案件：第一案婚前核验，第二案婚后共同生活，第三案告解模式。
6. 每案有有限追问/整理次数，重复试探、追问证词、比对现场和整理证据都会消耗资源。
7. 在每个事件中阅读对话，选择追问方式。选择会影响证据清晰度、舆论压力、叙事可信度、恶人先告状风险、对方隐藏动机爆发概率等状态。
8. 留意右侧的侦探手账。它不会像 debug 面板一样暴露精确内部数值，而是用更接近游戏内观察的方式提示当前案件状态。
9. 每案结案后会进入侦探局战况页，上一案的判断会影响声誉、舆论热度和下一案调查资源。
10. 三案总复盘后，进入当事人后续片段。旧案表现会影响谁被建议止损、谁被澄清、谁进入观察期。
11. 周目结束后会获得永久经验点。前几轮成长更快，用来鼓励玩家尝试不同判断路径。

- 婚恋侦探 / 律师顾问公开首版。
- 取消主动加点，改为系统随机生成本场调查画像。
- 新增侦探专长选择：财务审计型、情绪追踪型、证据核查型。
- 婚恋侦探 / 律师顾问视角。
- 后台案件库已接入 28 个抽象案型，会生成骗婚、化债、外遇、接盘、生育责任、择偶定位包装、彩礼短暂共同生活、恋爱转账借赠、杀猪盘、交友软件假账号、前任复联借钱、婚史/孩子/重大疾病隐瞒、房产加名、情侣创业股权、控制报备、同居装修代付等共用故事。
- 每周目固定三案：婚前 case 查承诺前的包装与止损点；婚后 case 查共同生活里的责任、账本与边界；告解模式让随机当事人自述经历，玩家扮演/贴近当事人视角查探关系里的坑、自欺和伤害。
- 每案加入追问配额，玩家不能把所有按钮无成本点完。
- 非线性调查流程：现场复原、证词追问、证据卡、阶段指认之间可以来回切换。
- 证据卡整理方式产生不同线索：时间线、钱和资源、动机和收益会暴露不同问题。
- 证据卡不只是实物证据，也包括当事人之前说过的话、直播录屏、微信截图、社媒存档、高级服装/护肤品图片、消费截图等直播间可展示材料。
- 证词追问中可以选择一张证据卡并对具体台词出示，命中会形成“出示证据”矛盾点，出示偏了会增加舆论压力。
- 结案复盘会对照你的指认方向、关键矛盾命中和错过的关键点。
- 新增案间战况页：声誉、舆论热度和上一案余波会影响下一案配额。
- 三案加入同周目牵连：上一案人物会作为旁证、舆论记忆或告解镜像影响下一案。
- 三案结束后进入压缩关系后续，旧案表现会转化为止损建议、澄清程度、观察期和后续风险。
- 旧版 1-10 章恋爱/婚后内容降级为素材库，不作为当前主流程展开。
- 告解模式改为时间线标注玩法，玩家需要把节点标成“被坑”“自欺”“可能伤了别人”。
- 证词包含假话、含糊话、不愿说完整、小承认掩护大隐瞒、真话但留白。
- 多名当事人，包含不同家庭结构、消费观、亲密关系模式和隐藏动机。
- NPC 每局会随机生成隐藏底色，包括真诚、利己、图钱、控制、回避、NPD 倾向等。
- 随机事件库会在不同阶段插入现实压力，例如失业、升职、住院、父母催促、礼物要求、彩礼谈判、房贷压力、育儿分工、经济下行、股市投资、前任回流、情绪供养和出轨风险等。
- 黄色信号和红色信号会受情商、当前关系状态和动机爆发值影响。
- 第 3 章之后存在关系止损、换线和不同阶段结局。
- 无语音，使用轻量音效和立绘 / 背景图营造橙光式互动体验。
- 元进度经验点开始影响下一局：5 点解锁每案额外追问次数，10 点解锁时间线追踪提示，15 点解锁开案提前预警。

## 内容边界

本作是虚构游戏，不提供法律、心理、婚恋咨询结论。游戏中的案例、角色和事件会参考中文互联网常见婚恋讨论、律师普法内容、相亲博主叙事和现实关系矛盾，但会进行抽象、改写和混合，不对应任何单一真实人物或具体案件。

游戏的核心不是审判某一类人，而是呈现婚恋关系里常见的利益、压力、误判、投射和边界问题。玩家可以在游戏中练习识别风险，也可以看到“并非坏人但不适合”的关系如何一步步走向不同结局。
