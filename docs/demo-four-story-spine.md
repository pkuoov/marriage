# 试玩四案整体剧情骨架

生成时间：2026-06-29

本稿按 `story-architect` 的 premise / designing principle / character web / moral argument 方法整理，用来约束试玩版四个故事。目标不是把四案写成连续剧，而是让玩家玩完以后觉得：这四通电话是在追同一个现实问题。

## Premise

主播接到四通看似无关的匿名来电，逐渐发现真正要判断的不是谁说话更委屈，而是好听的身份、关系和流程词，最后把钱、责任和边界落到了谁身上。

## Designing Principle

每案都从一个“听起来正当的词”开始：

- 体面
- 自己人
- 条件
- 主责

这些词本身不坏。戏剧性来自它们后面接了具体要求：垫钱、办卡带客、交换流水、背付款入口。玩家追问的是它们落到谁的账户、谁的客户资源、谁的工作风险里。

## 整体结构选择

试玩版更适合用 **Kishotenketsu 四幕结构**，而不是普通单元剧：

```text
起：第一案建立玩法和主题。好听的体面后面接了信用卡还款。
承：第二案把同一问题换到服务和暧昧边界。好听的自己人后面接了办卡、带客和投店。
转：第三案反转玩家站位。来电人也在包装条件、借家里口风问收入。
合：第四案离开婚恋语境。主责、流程、审批这些职场词也能转嫁成本。
```

这样四案不是“同类案件合集”，而是一集直播里的四次校准：

- 第一案让玩家学会别被情绪直接推去买单。
- 第二案让玩家学会把亲密话术拆成资源转化。
- 第三案让玩家失去舒服的审判位置，开始反问来电人。
- 第四案证明这个判断方法不是婚恋专用，而是公共生活里的通用防线。

整集真正的悬疑不是“谁是坏人”，而是：

```text
为什么四个完全不同场景里，都有人用一个好听身份，把成本挪给别人？
```

## 主播弧线

玩家扮演的主播也要有一条暗线。四案结束时，玩家感觉到的不是“我做完四道题”，而是“我学会了一种听电话的方法”。

| 案件 | 主播一开始容易怎么听 | 本案迫使主播怎么变 |
|---|---|---|
| 第一案：体面 | 先心疼失业和自尊 | 情绪可以接住，账单不能替人接。 |
| 第二案：自己人 | 先骂暧昧不清 | 亲密词要落到办卡、带客和投店。 |
| 第三案：条件 | 先查男方材料真假 | 来电人的筛选和包装也要被问出来。 |
| 第四案：主责 | 先骂同事卡钱 | 要拆流程入口，也要承认来电人想要机会。 |

这个弧线决定了结尾不能像总结课。尾声要像主播终于摸清了这一晚的规律：好听词不是罪，拿好听词转嫁成本才是问题。

## 四案之间的钩子

每案结尾都要抛出一个能带到下一案的问题：

| 结束案 | 带出的下一问 | 下一案如何接住 |
|---|---|---|
| 体面 | 如果不是借钱，而是“自己人”带来的照顾呢？ | 进入理发店排班表和办卡节奏。 |
| 自己人 | 如果不只是对方会包装，来电人自己也在筛别人呢？ | 进入存款证明和收入流水。 |
| 条件 | 如果离开婚恋，身份词还会不会转嫁成本？ | 进入职场主责和报销入口。 |
| 主责 | 四案共同指向什么？ | 尾声生成玩家路线和评论区审判墙。 |

## Moral Choice

主播每次都要在两种接法之间选择：

- 接住情绪和体面，让来电人继续讲顺口的版本。
- 把话落到证据、钱流、流程和边界上，让双方难听的半句都露出来。

主播不替某一方撑腰。主播保护愿意说实话、愿意承担责任的人，也把撒谎、操控、转嫁成本的动作指出来。

## 四案顺序

| 顺序 | 案件 | 本案词 | 功能 |
|---|---|---|---|
| 1 | 8 万信用卡周转 | 体面 | 最容易让玩家先心疼，训练“情绪不等于债务”。 |
| 2 | 理发店排班表 | 自己人 | 把亲密称呼推进到办卡、带客和投店资源。 |
| 3 | 存款证明 | 条件 | 反过来查来电人的筛选、收入诉求和自我修剪。 |
| 4 | 职场报销截图 | 主责 | 离开婚恋语境，证明同一套判断能处理公共事件。 |

## 压缩 22 步

1. 自我问题：主播容易被“谁更委屈”带节奏。
2. 世界：直播间、截图、账单、合同和群聊都是真假混在一起的材料。
3. 弱点：玩家如果只听态度，会漏掉谁在承担成本。
4. 引爆：第一通来电把信用卡账单递到面前。
5. 欲望：主播想在每通电话里把一句好听话问实。
6. 盟友：观众评论和来电原话提供压力，也会误导。
7. 对手：不是单个坏人，而是“关系词替责任背书”的系统。
8. 假盟友：截图、合同、审批图看起来像证据，其实可能省掉最要紧的一页。
9. 第一揭示：体面消费背后是断缴和最低还款。
10. 计划：主播开始每段只抓一个问题问下去。
11. 反击：对方用心疼、自己人、条件稳定、主责这些词把问题推回情绪。
12. 推进：玩家逐案学会看钱流、名义、账户和流程入口。
13. 观众攻击：评论区会催你站队，甚至把问题拉回性别和身份。
14. 低点：第三案揭示来电人自己也在修剪事实，玩家不能舒服地只当审判者。
15. 第二揭示：四案不是同类人问题，是同一种成本转移机制。
16. 观众先知：玩家开始从标题就怀疑“好听词后面接了什么要求”。
17. 第三揭示：职场案证明玩法不靠婚恋矛盾，也能成立。
18. 门槛：最后总结不问“谁坏”，问“谁把责任落到了别人身上”。
19. Battle：评论区审判墙根据玩家路线生成，不替玩家讲大道理。
20. 自我揭示：主播意识到自己不是选边站，而是在保护事实落地。
21. 道德决定：下一次接话，先让证据、钱和边界说话。
22. 新平衡：试玩结束，但正式内容可以继续扩展到消费、租房、平台交易和熟人借贷。

## 编剧约束

- 每案都必须有一个生活触发，不允许关键证据像系统发牌。
- 每案都必须让来电人也暴露一点自我保护或自我修剪。
- 四案里的“坏行为”不能落成性别标签，要落成具体动作。
- 总结页不写课文，用玩家已经听过的原话把四案串起来。
