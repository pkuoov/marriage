# 第 23 批·温情与尾巴执行单(人文关怀线 + 正式版钩子)

你是本仓库的实施工程师。设计判决:①全包缺"关系变化量与互惠"——NPC 只给不收,主播只判不被照顾,来电人用完即弃;②尾巴全是躺在「今晚定不了」里的未决事实,没有活性钩子(钩子=再来动因+信物+兑现形态)。本单以一个新表面(收播后·后台未读)加三条温情弧线解决,并把赵的案卷升级为正式版主线钩子。

## 铁律

1. **台词逐字使用**;未列出的台词一律不动;「(拍)」为分句停顿,不进字面。
2. 未读消息属"打字面":半角标点、打字风(书面纹理律)。
3. 未读内容只许生活与关系,**不许出现任何新事实、新证据、新指认**;3301/王**/老规矩谱系等未决事项保持原状。
4. 新台词已避开禁语表;全量校验同前批:`content:index && check && verify:pack && smoke:browser && content:script`。

## A. 每案收麦「今晚最后一句」(玩家关怀动词,三选,不判分)

引擎:每案正式结案前新增一拍,玩家三选一,记 `careChoice`(pragmatic/affirm/accompany),进收麦余味与未读回声。台词逐字:

- **务实**·「回去先把转账页关了。饭吃了吗?没吃煮个面。」→ 她:「……嗯。我现在就关。」(拍)「面看心情。」

### 案 2

- **务实**·「年卡别办,号先留着。头发该剪还得剪——换家店。」→ 她:「……嗯。楼下新开了家,十五块快剪。就是不聊天。」(拍)「不聊挺好。」

- **陪伴**·「群里的事不急。想不好,就来节目里想。」→ 她:「行。想不好我就再打。」

### 案 3

- **务实**·「两个人谈的时候,把你那张表带上。别念,放包里就行。」→ 她:「带表……你不是让我别发后台吗。」**林旭阳:**「放包里,不是放台上。」她:「……嗯。」
- **肯定**·「你查得不过分。想看清楚一个人,不丢人。」→ 她:「……谢谢。这句,我妈应该听听。」
- **陪伴**·「谈完什么结果,都可以来说一声。不用带材料。」→ 她:「不带材料。」(拍)「好。我试试。」

### 案 4

- **务实**·「明天上班,先补报备,再提回单号。一件一件来。」→ 她:「呃,我记下了。报备,回单。」(拍)「像考试划重点。」

## F. Skill 立法(`case-scriptwriting/SKILL.md` 新增「温情与尾巴法条」节,逐字)

- **互惠律**:每包主角至少被照顾 2 次,其中 1 次来自声纹最意想不到的表面;关怀须有物件载体(汤/水/便签),物件要走完整弧线(留下→在场→收尾,≥3 拍)。只给不收的关系网视同道具,不算关系。
- **回访律**:结案不等于人物结束。尾声必须让每案传回一条非案件信息(未读),内容只许生活与关系,不许携带新事实、新证据、新指认。
- **关怀动词律**:玩家每案至少一个非侦探动词(最后一句三选),不判分,但必须有回声——未读措辞随选择变化。没有回声的关怀选项视同装饰,不许写。
- **破例即温情条款**:声纹破例是最强温情载体,每包 ≤1 次,破例者须是全包声纹最窄的角色;破例后立刻回归原声纹。
- **活性尾巴律**:钩子=再来动因+信物+兑现形态,三件齐才算;只进未决清单的不算钩子。每包 ≥3 根活性尾巴 + 1 根主线尾巴(案卷级)。尾巴只约定形态(专场/再谈/再打),不约定未设计的答案;不许为悬念透支未来案件的真相。
