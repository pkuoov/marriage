改写法则：
1. 分类算术留给材料卡/documents；人物嘴里只留「我认这些 / 不认那些」+ 情绪短句。
2. stageJudgement：最多钉 1–2 个物件结论，禁止连报 ≥4 个金额的对账单。
   坏例（01）：「不到三万…一万五…三万五…二十万…两笔十万…五万…49800」
   好方向：「这八万先别转。你收过的可以谈；没说清的，不能先垫。」（流水另场再说一句即可）
3. deepFollowup：先问人，再提桶；不要主播先替她算完再提问。
4. 咨询者禁止复述主播分析框架（「不到三万 / 一万五 / 三万五」干净三连）；改成卡壳、认一段、拒一段。
5. 同一专业结论只允许最符合职业声纹的人完整说一次。案4保留周会计的「审批、付款、到账，是三张纸」，V哥、主播和结案不再复述；「先给身份，再让人掏钱」这类跨案母题句删除。
   → 其他角色改成当场可说的一句，指向具体页、具体行或具体原话。
6. crossCaseEchoes / 弹幕若直接说破包主题（「先给身份再掏钱」「好听身份换工装」）→ 删或改成跑偏/器物反应，主题留给玩家品。
7. V哥类提示禁止「按失业前后切一刀」解题腔 → 改成一句人话或删。

保留：信用卡三桶事实、documents 行、truthBoundary、能证明/不能证明的边界含义（可留在材料/顾问专业场，别塞进情绪通话主通道）。
