# 《直播间大侦探》Steam 试玩版剧本梗概

版本：2026-06-30  
故事集：`steam-demo-01`  
集名：好听的身份，最后让谁买单

## 剧本定位

这不是四个随机案件，而是一集四通匿名直播来电。主播坐在直播间里，面对的不是“谁更委屈”，而是四个听起来都正当的词：

```text
体面
一家人
条件好
主责
```

这些词本身不坏。问题在于，它们后面接了很具体的要求：替人还款、共同还贷、交换收入透明、背工作付款入口。

玩家扮演主播。每段来电先可以问一句普通询问，确认情绪、背景或可能的善意解释；然后必须选一句关键追问，把话落到钱、材料、流程或责任上。四案结束后，玩家得到的不只是“谁对谁错”，而是一条主播路线：你习惯先相信人、先拆截图、先追钱流，还是先反问来电人自己。

## 主要人物

**主播 / 玩家**

直播间里的主持侦探。没有上帝视角，也不能把另一方直接拉上麦。主播只能通过咨询者的口述、转述、截图、账单、合同和群聊，判断哪句话没说全。

主播的弱点是容易被“谁更委屈”带走。试玩版的四通电话，会逼主播学会一件事：好价值观不是替某一边撑腰，而是保护愿意说实话、愿意承担责任的人，同时把撒谎、操控、转嫁成本的行为指出来。

**咨询者**

每案只有一个匿名咨询者上麦。TA 不一定是坏人，但也不一定完全可靠。TA 可能害怕被看轻、怕家里翻脸、怕承认自己也想要好处，或者怕说出自己的真实诉求后关系直接停掉。

**缺席的另一方**

不会上麦，只通过咨询者念出的原话、截图、合同、账单、审批图、群聊或回拨内容出现。缺席感是本作的关键：玩家永远不能舒服地“审判两个人”，只能在半截材料里把问题问实。

**弹幕 / 评论区**

不是单纯气氛组。弹幕会催主播站队，也会把问题带偏。故事集结尾的评论区审判墙，会根据玩家四案路线生成不同复盘。

## 整集结构

```text
序幕：主播开播，四案故事集主题出现。
第一案：体面。恋爱消费和 8 万信用卡周转。
第二案：一家人。婚前房、共同账户和婚后还贷。
第三案：条件。学历收入材料、流水和婚后管钱预设。
第四案：主责。职场报销截图、项目署名和付款入口。
尾声：四案收麦，评论区审判墙生成。
```

## 序幕

**内景｜直播间｜夜**

屏幕亮起。主播坐在桌前，麦克风旁边摆着几张看不清内容的材料照片：信用卡账单、购房合同、存款证明、报销审批图。

弹幕滚动。

```text
弹幕 A：今天又是什么瓜？
弹幕 B：先说好别上来就判。
弹幕 C：截图都发了还不算锤？
```

主播没有急着立场。

```text
主播：今晚四通来电，先别急着判谁好谁坏。
主播：听见好听的话，先问它后面接了什么要求。
```

标题出现：

```text
好听的身份，最后让谁买单
```

## 第一案：体面

**案名：8 万信用卡周转**  
**本案词：体面**  
**功能：最容易让玩家心软，训练“情绪不等于债务”。**

### 开场

**内景｜直播间｜夜**

咨询者接入，声音压得很低。

```text
咨询者：主播你好，我想问下我男朋友的事。
咨询者：我们谈了半年，之前约会一直挺体面。
咨询者：可他突然让我先垫 8 万信用卡。
咨询者：那周我们还去了很贵的纪念日晚餐，我还发了朋友圈。
咨询者：我当时以为他只是奖金晚发，也没想承认自己其实很吃那种体面。

主播：晚上好，这事听着不只是手头紧。
主播：TA 第一次提钱时，原话怎么说？
```

### 第一段：体面和失业时间

咨询者说，对方让她帮忙看一张办材料用的社保截图，她才看到社保已经断缴两个月。可在这两个月里，对方仍然订餐厅、买礼物、维持体面约会。

**询问对话，可以先问：**

```text
主播：你当时有没有起疑心？
咨询者：一开始没有。我第一反应是他是不是压力太大，想先把人稳住。可后来再看，失业到底从什么时候开始，他一直没讲。
```

**关键追问，只能选一句：**

```text
主播：他开口借钱之前，有没有跟你说过工作最近不稳定？
咨询者：没有。TA 只说最近忙。那张社保截图还是他让我帮忙看材料时露出来的，上面两个月前就断缴了。
```

**揭示：**失业不是突然发生，体面消费和资金缺口同时存在。

### 第二段：账单用途

咨询者翻出信用卡账单，最大几笔不是房租、医疗或刚需，而是餐厅、礼物和短视频平台分期。

**询问对话：**

```text
主播：有没有可能这些消费是他在硬撑？
咨询者：可能。可我卡住的是，硬撑出来的账单，最后为什么变成我要先帮他补上。
```

**关键追问：**

```text
主播：这几笔账，哪些是在他没工作以后花的？
咨询者：纪念日晚餐、礼物分期和两次酒店都在断缴之后。
```

**揭示：**账单不只是困难，而包含维持恋爱体面的消费成本。

### 第三段：被说急的还款日

咨询者对日期，发现第一次开口周转时，账单其实还有三天才到期。对方先说“今晚就要”，后来又改成“这几天都行”。

**询问对话：**

```text
主播：有没有可能他自己也慌了，才把时间说乱？
咨询者：可能。他确实慌。但慌不等于可以把时间说成今晚，让我在没看清账单时先转钱。
```

**关键追问：**

```text
主播：他为什么把三天后的期限说成今晚？
咨询者：我问了，他说怕我拖着不管。但那一刻我心里咯噔一下：他更怕的可能是我把账单翻明白。
```

**揭示：**“着急”可能是真慌，也可能是在压缩咨询者核对账单的时间。

### 第四段：怕你离开

对方发来一句：“我只是怕你知道我失业后就离开我。”紧接着又问能不能先转最低还款。

**询问对话：**

```text
主播：那他下个月准备怎么还？
咨询者：他开始讲下个月会有办法，可说来说去，失业多久、债务怎么形成，还是没接上。
```

**关键追问：**

```text
主播：他说怕你离开，那最低还款为什么要你先转？
咨询者：我当时确实被那句“怕你离开”拽住了。可下一句就是让我先转最低还款，我才反应过来：他难受，我也要掏钱。
```

**揭示：**情绪脆弱是真的，但不能自动把债务转给另一方。

### 第五段：结婚压力

咨询者补充，对方说如果这次不帮，以后可能就不敢谈结婚，会一直觉得低她一头。她停了一下，又承认自己前面也没说全：她跟朋友一直把对方讲得挺体面，突然承认他失业欠账，就像承认自己看走眼。

**询问对话：**

```text
主播：那你为什么一直绕着说要看账单？
咨询者：我怕被说嫌贫爱富。我也怕别人觉得我找了个撑不住场面的人。所以我一直绕着说要看账单，不敢直接说我不想接这笔债。
```

**关键追问：**

```text
主播：他把你不垫钱和结婚联系起来，是怎么说的？
咨询者：他说最难的时候我都不站在他这边，以后结婚他也抬不起头。我听完很难受，好像不转这笔钱，就成了我不爱他。
```

**揭示：**个人债务被包装成关系忠诚测试；咨询者也不愿承认自己被体面吸引。

### 满格深问

```text
主播：那我多问一句，社保断缴和信用卡还款都摆出来以后，你最怕失去的是钱，还是这段关系原来看起来很体面的样子？
咨询者：我最怕承认的是，我也被那个体面打动过。朋友都觉得他工作稳定、出手大方，我不垫这笔信用卡还款，就像亲手把这层撕开。可撕开归撕开，账还是不能变成我的。
```

### 收麦原话

玩家最后从四句原话里选一句往下接：

```text
“我只是怕你知道我失业后就离开我。”
“我也怕别人觉得我找了个撑不住场面的人。”
“账单其实还有三天才到期。”
“以后他可能就不敢跟我谈结婚了。”
```

**本案落点：**  
这案别只问穷不穷。社保断缴没说，信用卡花销没停；她也被那层体面吸引过，所以才迟迟不敢把账单和面子分开。心疼归心疼，账单不能自动换人。

### 案间桥：短债到长债

```text
弹幕：8 万都这样了，那房贷这种几十年的怎么办？
主播：所以第二通，先别听“像不像一家人”，先看钱从哪个账户出去，最后算在谁名下。
```

## 第二案：一家人

**案名：婚前房与共同还贷**  
**本案词：一家人**  
**功能：把短期垫钱推进到长期资产和家庭压力。**

### 开场

```text
咨询者：主播你好，我不是非要房子。
咨询者：婚前房写 TA 父母名下，可婚后又说我们一起还贷才像一家人。

主播：晚上好。合同上写谁、家里怎么说还贷，你从这两处讲。
```

### 第一段：权属和还贷

咨询者说，她不是非要加名，只想知道婚后还进去的钱算什么。对方一直说，正常夫妻不会算这么细。

**询问对话：**

```text
主播：他说一起还贷时，怎么把“一家人”带出来的？
咨询者：他说婚后一起还贷才像一家人。我当时听着挺暖，回头看才发现，房本是一套话，还贷是另一套话。
```

**关键追问：**

```text
主播：你慢点说，首付谁出、房本写谁、婚后谁还？
咨询者：首付和登记都在对方父母名下，婚后还贷计划却要从共同账户走。
```

**揭示：**权属归父母，现金流却要小家庭承担。

### 第二段：共同账户支出表

合同照片是对方母亲发到小群里的，买受人写的是对方父母。后面又补了一张婚后共同账户支出表，房贷也在里面。

**询问对话：**

```text
主播：如果只留每月流水，这事能不能先谈下去？
咨询者：可能能谈下去一点，但补偿和退出规则还是被推迟了。流水有了，钱算什么没说清。
```

**关键追问：**

```text
主播：这张表里，房贷和装修是怎么写进家庭开销的？
咨询者：房贷和装修被列成每月固定支出，旁边没有写份额，也没有写以后分开怎么补。
```

**揭示：**共同支出表没有对应还贷份额和退出补偿。

### 第三段：每月转账

对方母亲说装修不用女方家出大头，但希望咨询者每月从工资里转一笔到共同账户，这样“新家才像一起过”。

**询问对话：**

```text
主播：她说不用你家出大头，是不是也算退让？
咨询者：听起来像退让。但我每月固定转进去，长期下来也不是小钱，只是没有一次性说得那么刺耳。
```

**关键追问：**

```text
主播：这笔每月转账有没有写用途和归属？
咨询者：没有。她只说放共同账户好看点。我一问用途，她就说房贷、装修、生活都在里面，反正别分那么清。
```

**揭示：**钱被包装成共同生活投入，但产权与补偿仍不对应。

### 第四段：轻方案也被拒

咨询者提出，不加名，只把婚后还贷和装修按流水留个确认。但她补了一句，这个说法是她妈妈帮她改过的。妈妈原话是“最好能有个位置”，怕她直接说加名太难听，才让她先说投入确认。对方说这比加名还伤感情，因为说明她随时准备撤。

**询问对话：**

```text
主播：如果他愿意留流水，不签协议，你能不能接受？
咨询者：只能让我没那么慌。流水能证明我出了钱，但这钱以后算什么，还是没人认。
```

**关键追问：**

```text
主播：你提的是加名，还是只确认婚后投入？
咨询者：嘴上是只确认投入。我还特意说不碰他父母首付和产权。可我妈那句“最好能有个位置”确实在我心里，我没有直接说出来。
```

**揭示：**咨询者把“最好能有个位置”的诉求包装成投入确认；对方连不加名的投入确认也拒绝。

### 第五段：不写才像一家人

咨询者念出对方原话：“房子放父母名下是家里安排，不影响我们过日子。不写才像一家人，你要协议，就是不信我。”

**询问对话：**

```text
主播：你要不要先只谈装修钱，房贷这块晚点再说？
咨询者：装修钱容易谈，但房贷才是长期流出的那笔。话题一缩小，核心现金流就滑过去了。
```

**关键追问：**

```text
主播：不写清楚的话，你还进去的钱算什么？
咨询者：我就卡在这里。如果不写份额，那我婚后还贷的钱算借款、赠与，还是家庭支出？
```

**揭示：**“像一家人”不能替共同还贷签字。

### 满格深问

```text
主播：那我多问一句，你自己心里最想要的是投入补偿，还是这套房里有一个能被看见的位置？
咨询者：我想要能被看见的位置。这句话我没在直播开头讲，因为讲出来就像我要房。可如果婚后每月还贷、装修、共同账户都进去，我又不想最后只剩几张流水。
```

### 收麦原话

```text
“买受人写的是对方父母。”
“最好能有个位置。”
“正常夫妻不会算这么细。”
“不写才像一家人。”
```

**本案落点：**  
婚前房不加名可以谈，父母出资也可以尊重。但如果婚后要一起还贷、装修、转共同账户，就得提前说清这些钱以后算什么。她也别把“想有个位置”全包成投入确认，这句话难听，但不说出来更容易把人推到互相猜。

### 案间桥：从对方家到自己家

```text
弹幕：前两通都是别人拿好听话压人。
主播：不一定。下一通反过来听，来电人自己也可能拿家里的口风，去问自己想问但不好听的问题。
```

## 第三案：条件

**案名：存款证明**  
**本案词：条件好**  
**功能：反过来查来电人的筛选、收入诉求和自我修剪。**

### 开场

```text
咨询者：主播你好，我想问下我男朋友的事。

主播：晚上好。你们怎么认识的，现在聊到哪一步了？

咨询者：我们是相亲认识的，最近聊到见父母。
咨询者：我之前跟家里说过他名校毕业、条件不错，所以我妈问得比我想象中细。

主播：她问细到哪一步了？

咨询者：学校、工作、收入、有没有存款，后来还绕到流水。
咨询者：我也知道见父母前问这么细有点过，可我当时没拦住。
```

### 第一段：材料什么时候出现

咨询者说，正式见父母前，家里就问到学校、收入、存款和流水。她自己也觉得尺度不像普通见家长。

**询问对话：**

```text
主播：问到流水的时候，你有没有拦过？
咨询者：有。我还跟我妈说，第一次见面就问存款和流水不太好听。可她说我已经把话说在前面了，现在不问，饭桌上更尴尬。
```

**关键追问：**

```text
主播：这些截图是什么时候发的，发之前你们怎么说到材料的？
咨询者：我没有直接说“你发截图”。我妈说，见一面可以，但你前面把他学校和收入说得都不错，总得知道实不实在。我转述得比较含糊，只说家里可能会问细，让他别被问住。第二天他就发了几张图。
```

**揭示：**女方家在见面前就开始核对择偶条件。

### 第二段：好看版本怎么被放大

咨询者补充，介绍人一开始就把男方讲得很好，说“学校好、收入稳、家里也省心”。她后来跟家里说的时候，也顺着这个版本说下去了。

**询问对话：**

```text
主播：你后来为什么没有跟家里改口？
咨询者：我前面已经说他条件不错了，后面再改口，就像我自己也没看清。
```

**关键追问：**

```text
主播：这个好看的版本，是他一个人说出来的吗？
咨询者：不是。介绍人先铺了一层，我又跟家里复述了一层。他自己也没有把 MBA、本科和收入构成一次讲清。
```

**揭示：**体面标签被介绍人、男方和咨询者共同放大。

### 第三段：MBA 和本科

男方说的名校毕业不是全假，具体是读过名校 MBA 项目。他本科普通，这段一开始没主动说。

**询问对话：**

```text
主播：你知道本科之后，跟家里说了吗？
咨询者：没有。我只说他学校那边确实是真的。因为我前面已经把“名校毕业”讲得很好听了，再补一句本科很普通，我怕我妈立刻变脸。
```

**关键追问：**

```text
主播：那张学校图少了哪一边，少的是本科、项目还是学制？
咨询者：能看到校名和项目，确实不是瞎编。但本科、项目性质、学制没有一起摆出来。他一直说名校毕业，别人很容易听成一路名校；细问才说是 MBA。
```

**揭示：**男方用真标签保留了别人误会的空间；女方知道落差后也没完整告诉家里。

### 第四段：收入和花销

咨询者开始不踏实，是因为男方口头收入不错，平时花销却对不上。他不是没钱那种，但特别会算。

**询问对话：**

```text
主播：哪次花销让你觉得不对？
咨询者：有次他说这个月奖金刚到，结果吃饭时又反复算团购券，还提醒我停车费能不能 AA。不是不能 AA，是和他说的收入状态放一起有点别扭。
```

**关键追问：**

```text
主播：你问流水，是想确认他到底赚多少？
咨询者：是。我嘴上说家里想看稳定，其实我自己也想知道。他到底是收入没那么高，还是钱花到别处去了。
```

**揭示：**流水追问不只是求安心，也在确认真实收入和婚后钱怎么落地。

### 第五段：工资卡

男方反问：“再问下去，是不是工资卡也要交出来？”咨询者当时没接住。但她妈妈确实说过，结婚以后钱最好放一起管。

**询问对话：**

```text
主播：那他拒绝流水是不是就一定心虚？
咨询者：也不一定。见父母前就问到流水和工资怎么管，换谁都会不舒服。可是我确实想知道，他说的收入能不能落到以后的小家里。
```

**关键追问：**

```text
主播：这句你有没有转给他？
咨询者：没有。我只说我妈想确认稳定。我要是原样说“以后钱放一起管”，这顿饭可能直接不用吃了。
```

**揭示：**女方把工资管理的要求包装成了确认稳定。

### 满格深问

```text
主播：那我多问一句，你自己的家庭经济状况怎么样？你自己一个月工资多少，够花吗？
咨询者：我自己也不是特别宽裕，所以我才更在意他收入到底落不落地。我嘴上说家里想看稳定，其实我也想知道以后这笔钱是不是能进小家。
```

### 收麦原话

```text
“他一直说名校毕业，细问才说是 MBA。”
“我只说他学校那边确实是真的。”
“再问下去，是不是工资卡也要交出来？”
“结婚以后钱最好放一起管。”
```

**本案落点：**  
男方不是整套假资料，MBA、收入、存款都有真东西；女方也不只是求个安心，她想看的其实是以后这笔收入能不能进小家。两边都把难听的话包起来了。

### 案间桥：离开婚恋

```text
弹幕：所以这还是婚恋题吧？
主播：不只。只要一个好听身份能换来别人先承担成本，事情就会在任何地方重演。
```

## 第四案：主责

**案名：职场报销截图**  
**本案词：主责**  
**功能：离开婚恋语境，证明同一套判断能处理公共事件。**

### 开场

```text
咨询者：主播你好，我想问一件公司里的事。
咨询者：上个月部门做客户答谢会，同事让我先垫了场地和礼品钱。

主播：晚上好。你先说清楚，为什么是你垫，报销截图又是什么时候发来的？

咨询者：他说流程来不及，让我先刷卡，活动署名会写我负责。
咨询者：后来他发了审批通过截图，说财务批了，但钱一直没回我。
```

### 第一段：署名和垫款

咨询者承认自己不是完全被迫。她刚进项目组，确实想借这次客户答谢会让老板看到自己。更难听一点，她先跟老板说过这次自己可以主责，所以听到“署名写你负责”，就先垫了。

**询问对话：**

```text
主播：他说主责署名的时候，你为什么先答应垫？
咨询者：我也确实想要这个主责，所以没有第一时间追垫款流程。可想表现不等于默认钱可以一直卡着。
```

**关键追问：**

```text
主播：他让你垫钱时，原话有没有提署名和老板？
咨询者：有。他说这次活动缺个执行负责人，如果我先顶上，复盘材料里可以写我主责。我当时没有说的是，我前面已经跟老板表过态。
```

**揭示：**咨询者先想要主责曝光，同事再把垫付款包装成机会，资金风险被弱化。

### 第二段：绕开公开预算

活动前，同事让她别在大群里问预算，说客户答谢会临时调整太多，先私下办成，复盘再补流程。她也怕在大群问预算，会显得前面说能主责是嘴硬。

**询问对话：**

```text
主播：你如果当时在群里问，会不会真的影响观感？
咨询者：可能会显得我不够爽快。但至少钱是谁批、谁还、谁对接供应商，会留下记录。
```

**关键追问：**

```text
主播：他为什么不让你在大群确认预算？
咨询者：他说问多了显得我不担事，老板会觉得我推活。现在想想，这句话把我想表现的心理拿住了。
```

**揭示：**流程先被挪到私下，后续风险开始失去公开记录。

### 第三段：审批截图缺边

同事发来的图抬头是“报销审批通过”。咨询者以为等于钱已经到账，仔细看才发现下面没有付款流水，也没有收款账户。

**询问对话：**

```text
主播：他有没有可能只是财务慢，不是故意拖？
咨询者：有可能。所以我才没一上来撕破脸。但如果只是财务慢，他完全可以给我看付款状态，或者让我问财务，而不是一直拿审批截图挡。
```

**关键追问：**

```text
主播：这张审批图少了哪一边，是付款状态还是收款账户？
咨询者：下面少了付款状态这一边，收款账户也没露出来。只能证明审批通过，不能证明财务已经把钱打到谁的账户。
```

**揭示：**审批通过不等于钱已到账。

### 第四段：供应商返款入口

咨询者翻供应商报价单，发现礼品那项有一个“服务协调费”。供应商群里又提到返款统一打给对接人，而对接人是同事。

**询问对话：**

```text
主播：你问过这笔服务协调费是不是正常报价吗？
咨询者：问过。他说可能就是正常报价。可他不让我问财务，也不说返款怎么处理，我就没法只按正常报价理解。
```

**关键追问：**

```text
主播：供应商返款打给谁，和你的垫付款是不是同一条钱路？
咨询者：供应商群里写的是统一打给对接人，对接人是他。我的垫付款、公司报销、那笔返款，最后都要经过他。
```

**揭示：**同事同时控制报销入口和供应商返款入口。

### 第五段：主责和付款入口分离

复盘材料出来后，主责那栏确实写了咨询者。但付款对接人和供应商确认人仍然是同事。出问题时她像负责人，拿钱时入口却不在她手里。

**询问对话：**

```text
主播：主责写了你以后，你为什么反而更慌？
咨询者：一开始我觉得也算值。可钱没回来以后，主责反而像风险，出了问题大家会先问我为什么私下垫。
```

**关键追问：**

```text
主播：主责署名和付款入口，最后在同一个人手里吗？
咨询者：不在。复盘写我主责，可付款对接、供应商确认、返款入口都在他那边。
```

**揭示：**项目责任和资金入口被拆给不同人。

### 满格深问

```text
主播：那我多问一句，如果今天不只是钱没回来，你最怕这件事在公司里被说成什么？
咨询者：我最怕他们说我是为了抢署名才私下垫款，流程不规范。我先跟老板说能主责，我也确实想要这个主责；但他用这个让我先刷卡、又拿审批截图挡我，也是真的。
```

### 收麦原话

```text
“报销审批通过了。”
“我也确实想要这个主责。”
“返款统一打给对接人。”
“先私下把事办成，复盘再补流程。”
```

**本案落点：**  
职场截图也会只截好看的半张。她想拿表现，所以先垫了；同事拿着审批图和供应商入口不放，所以钱一直回不来。两件事要分开说。

## 尾声：故事集收麦

**内景｜直播间｜深夜**

四通电话结束。屏幕上的四个词重新出现：

```text
体面
一家人
条件好
主责
```

```text

```

```text
主播：愿意说实话、愿意承担责任的人，要保护。
主播：拿体面、家人、条件、流程去转嫁成本的人，要问到底。
```
