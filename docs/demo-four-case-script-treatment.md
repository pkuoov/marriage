# 《直播间大侦探》Steam 试玩版剧本梗概

版本：2026-06-30  
故事集：`steam-demo-01`  
集名：好听的身份，最后让谁买单

## 剧本定位

四通匿名来电在同一晚接进直播间。主播坐在麦前，听见四个听起来都正当的词：

```text
体面
自己人
条件
主责
```

这些词本身不坏。问题在于，它们后面接了很具体的要求：替人还款、办卡带客、交换收入透明、背工作付款入口。

玩家扮演主播。每段来电先可以问一句普通询问，确认情绪、背景或可能的善意解释；然后必须选一句关键追问，把话落到钱、材料、流程或责任上。四案结束后，玩家会留下自己的主播路线：先相信人、先拆截图、先追钱流，还是先反问来电人自己。

## 主要人物

**主播 / 玩家**

林旭阳，男，三十三岁。以前在互联网大厂做法务，失业后阴差阳错做了个人主播，不温不火地播了两年半。没有上帝视角，也不能把另一方直接拉上麦；他只能通过咨询者的口述、转述、截图、账单、合同和群聊，判断哪句话没说全。

主播的弱点是容易被“谁更委屈”带走。试玩版四通电话会把主播往回拽：谁愿意说实话、谁愿意承担责任，谁在撒谎、操控、转嫁成本，都得落到具体话和具体钱上。

**咨询者**

每案只有一个匿名咨询者上麦。TA 不一定是坏人，但也不一定完全可靠。TA 可能害怕被看轻、怕家里翻脸、怕承认自己也想要好处，或者怕说出自己的真实诉求后关系直接停掉。

**缺席的另一方**

不会上麦，只通过咨询者念出的原话、截图、合同、账单、审批图、群聊或回拨内容出现。缺席感是本作的关键：玩家永远不能舒服地“审判两个人”，只能在半截材料里把问题问实。

**弹幕 / 评论区**

弹幕会催主播站队，也会把问题带偏。故事集结尾的评论区审判墙，会根据玩家四案路线生成不同复盘。

## 整集结构

```text
序幕：主播开播，热线接入。
第一案：体面。恋爱消费和 8 万信用卡周转。
第二案：自己人。理发店排班表、熟客话术和办卡投店。
第三案：条件。学历收入材料、流水和婚后管钱预设。
第四案：主责。职场报销截图、项目署名和付款入口。
尾声：四案收麦，评论区审判墙生成。
```

## 序幕

**内景｜直播间｜夜**

```text
林旭阳（旁白）：我叫林旭阳，三十三岁。以前在一家互联网大厂做法务。失业以后，阴差阳错开了这个直播间。不温不火，也做了两年半。
```

屏幕亮起。主播坐在桌前，麦克风旁边摆着几张看不清内容的材料照片：信用卡账单、理发店表格、存款证明、报销审批图。

弹幕滚动。

```text
弹幕 A：今天又是什么瓜？
弹幕 B：先说好别上来就判。
弹幕 C：截图都发了还不算锤？
```

主播没有急着立场。

```text
主播：今晚热线开着。
主播：话好听不好听，等人说完。
```

标题出现：

```text
好听的身份，最后让谁买单
```

## 第一案：体面

**案名：8 万信用卡周转**  
**本案词：体面**  
**功能：最容易让玩家心软，训练“情绪不等于债务”。**

### 开场

**内景｜直播间｜夜**

咨询者接入，声音压得很低。

```text
咨询者：主播你好，我想问下我男朋友的事。
咨询者：我们谈了半年，之前约会一直挺体面。
咨询者：可他突然让我先垫 8 万信用卡。
咨询者：那周我们还去了很贵的纪念日晚餐，我还发了朋友圈。
咨询者：我当时以为他只是奖金晚发，也没想承认自己其实很吃那种体面。

主播：晚上好，这事听着不只是手头紧。
主播：TA 第一次提钱时，原话怎么说？
```

### 第一段：体面和失业时间

咨询者说，对方让她帮忙看一张办材料用的社保截图，她才看到社保已经断缴两个月。可在这两个月里，对方仍然订餐厅、买礼物、维持体面约会。

**询问对话，可以先问：**

```text
主播：你当时有没有起疑心？
咨询者：一开始没有。我第一反应是他是不是压力太大，想先把人稳住。可后来再看，失业到底从什么时候开始，他一直没讲。
```

**关键追问，只能选一句：**

```text
主播：他开口借钱之前，有没有跟你说过工作最近不稳定？
咨询者：没有。TA 只说最近忙。那张社保截图还是他让我帮忙看材料时露出来的，上面两个月前就断缴了。
```

**揭示：**失业不是突然发生，体面消费和资金缺口同时存在。

### 第二段：账单用途

咨询者翻出信用卡账单。与两人有关的餐厅、酒店、礼物和短视频设备不到三万；后面还有数笔男装，合计约一万五，都是男方自己的尺码和常买品牌。

**询问对话：**

```text
主播：有没有可能这些消费是他在硬撑？
咨询者：可能。我纳闷的是，这些钱是他自己硬撑出来的，怎么到最后变成我先替他补。
```

**关键追问：**

```text
主播：这几笔账，哪些是在他没工作以后花的？
咨询者：纪念日晚餐、礼物分期、两次酒店都在。男装也是，一万五左右。那些衣服是他的。
```

**揭示：**账单里既有两人共同享受的排场，也有男方失业后仍在维持的个人排场，不能把八万全说成“为她花的”。

### 第三段：一万二的灯和稳定器

账单里有一笔一万二的分期，买的是拍视频用的灯和稳定器。咨询者说，对方当时把这套东西叫作“投资”，她一直以为那是对方全款买来送她的。

**第一夜追问：**

```text
主播：那套灯和稳定器，买完以后送到谁那里了？
咨询者：送到我这儿了，东西也一直是我在用。可他当时说的是支持我做探店号，我真以为那是他全款买来送我的。分期不是我签的，我也没答应过要替他还。
```

第一夜不再为了排剧情硬藏设备去向。她承认收货和使用，同时坚持自己当时不知道对方办了分期。

**第二夜追问：**

```text
主播：昨晚你已经说了，设备在你家，也是你在用。为什么没告诉我们，开箱那晚你们就一起拍了第一条视频？
咨询者：我怕一说拍到凌晨，你们就会觉得分期是我们俩一起商量的。可我真没跟他商量过。他说买来送我，我就当礼物收了。视频是一起拍的，这个我认。分期怎么开的，我当时确实不知道。
```

**揭示：**设备由她使用、两人共同拍摄，与她是否知情并同意办理分期是两件事。第二夜深化的是她主动参与到什么程度，不再重复揭示设备归属。

### 第四段：三只桶和被说急的还款日

咨询者重新加总：与她有关的消费不到三万，男方自己的男装约一万五，八万出头里仍有至少三万五没有说明。她再对日期，发现第一次开口周转时，账单其实还有三天才到期。对方先说“今晚就要”，后来又改成“这几天都行”。

**询问对话：**

```text
主播：有没有可能他自己也慌了，才把时间说乱？
咨询者：可能。他确实慌。可还有三天，他一直催我当晚转，我就觉得这事不太对。
```

**关键追问：**

```text
主播：跟你们俩有关的不到三万，他自己的男装一万五左右，剩下那三万五你问过是什么吗？
咨询者：问过一次。他当时愣了一下，说“反正不是乱来的钱”。然后我再问，他就把话岔到“别拖，今晚先转”上去了。
```

**揭示：**“着急”可能是真慌，也可能是在压缩咨询者核对账单的时间；无论哪一种，都没有说明信用卡里剩余三万五的用途。

### 第五段：怕你离开

对方发来一句：“我只是怕你知道我失业后就离开我。”紧接着又问能不能先转最低还款。

**询问对话：**

```text
主播：那他下个月准备怎么还？
咨询者：他开始讲下个月会有办法，可说来说去，失业多久、债务怎么形成，还是没接上。
```

**关键追问：**

```text
主播：他说怕你离开，那最低还款为什么要你先转？
咨询者：我当时确实被那句“怕你离开”拽住了。可下一句就是让我先转最低还款，我才反应过来：他难受，我也要掏钱。
```

**揭示：**情绪脆弱是真的，但不能自动把债务转给另一方。

### 第六段：结婚压力

咨询者补充，对方说如果这次不帮，以后可能就不敢谈结婚，会一直觉得低她一头。她停了一下，又承认自己前面也没说全：她跟朋友一直把对方讲得挺体面，突然承认他失业欠账，就像承认自己看走眼。

**询问对话：**

```text
主播：那你为什么一直绕着说要看账单？
咨询者：我怕被说嫌贫爱富。我也怕别人觉得我找了个撑不住场面的人。所以我一直绕着说要看账单，不敢直接说我不想接这笔债。
```

**关键追问：**

```text
主播：他把你不垫钱和结婚联系起来，是怎么说的？
咨询者：他说最难的时候我都不站在他这边，以后结婚他也抬不起头。我听完很难受，好像不转这笔钱，就成了我不爱他。
```

**揭示：**个人债务被包装成关系忠诚测试；咨询者也不愿承认自己被体面吸引。

### 满格深问

```text
主播：我把这张信用卡明细重新分了一遍。餐厅、酒店、礼物和设备分期，不到三万，都和你有关；一万五左右的男装，是他自己买的；还剩至少三万五没说清。你可以反驳我。先说前面不到三万：有哪一笔，你觉得跟你没有关系？
咨询者：……没有。餐厅有我挑的，酒店是一起住的，礼物我收了，设备也在我屋里。我得认，我也享受过他花钱撑出来的日子。可我认的是这些，不是八万全该我还。
```

### 收麦原话

玩家最后从四句原话里选一句往下接：

```text
“我只是怕你知道我失业后就离开我。”
“我也怕别人觉得我找了个撑不住场面的人。”
“账单其实还有三天才到期。”
“以后他可能就不敢跟我谈结婚了。”
```

**本案落点：**  
这案不是“他为她花了八万”或“她跟八万完全无关”的二选一。她要认自己享受过不到三万的约会和设备；他要认失业以后还花一万五买男装撑场面；至少三万五仍没说明。银行流水里五万贷款与 49,800 转出是另一张单子的两行，不能拿来替信用卡缺口编答案。

### 第一案小尾声与案间桥

```text
赵律师：我要是也这么爱面子、讲排场，花钱没数，你会不会打肿脸充胖子，什么都给我买？
林旭阳：真那样的话，我们俩大概一开始就看不上对方。
【林旭阳笑了一下。赵律师把热水推过去。音乐慢慢起来。第一案完。】
【后台收到下一通的理发店表格。】
```

## 第二案：自己人

**案名：理发店排班表**
**本案词：自己人**
**功能：把亲密话术拆成办卡、带客和投店资源。**

### 开场

```text
咨询者：主播你好，我想问理发店 Tony 的事。
咨询者：他一直叫我自己人，说跟别人不一样。
咨询者：后来我看到店里的排班表，才发现“自己人”不止我一个。

主播：晚上好。先说你为什么会看到那张表。
```

### 第一段：自己人

咨询者说，对方平时会留晚一点的时间给她，剪完头发还会陪她聊天。她知道这不算正式关系，但一直顺着“自己人”往下接。

**询问对话：**

```text
主播：你们有没有把关系说死？
咨询者：没有。这也是我后面难受的地方。我明知道没说死，却一直按“他对我不一样”来理解。
```

**关键追问：**

```text
主播：他说你是自己人后，后面接过什么具体要求？
咨询者：一开始是办护理卡，后来是让我带朋友来，再后来聊到他想开分店，说以后可以一起做点事。
```

**揭示：**自己人不只是亲密称呼，后面接着办卡、带客和资源推进。

### 第二段：同款话术

咨询者翻到店内聊天记录，发现对方也对别的顾客说“你跟别人不一样”。她当时第一反应是生气，但又怕自己显得太认真。

**询问对话：**

```text
主播：有没有可能他只是嘴甜，服务行业都这么说？
咨询者：可能。可如果只是嘴甜，就不会每次甜话后面都接到办卡、带客和投店。
```

**关键追问：**

```text
主播：这些话后面接的事，是不是也很像？
咨询者：像。一个人是“你最懂我”，后面接年卡；一个人是“以后店开起来你就是老板娘”，后面接投店；到我这里就是带朋友来。
```

**揭示：**亲密话术被复制，并和具体消费转化相连。

### 第三段：排班表

咨询者看到一张店内表格。表格看起来像排班，但备注里写着“稳情绪”“能办卡”“能投店”“带客”。

**询问对话：**

```text
主播：表上有你的名字，就能证明他骗你吗？
咨询者：只看名字还不够。真正让我不舒服的是，名字后面跟着怎么推进。
```

**关键追问：**

```text
主播：这张表是在排员工，还是在排你们这些人下一步怎么推进？
咨询者：现在看，表里排的不是员工，是人。谁适合办卡，谁能带客，谁可能投店，都写在后面。
```

**揭示：**表格不是普通排班，而是熟客资源推进表。

### 第四段：来电人的自我修剪

咨询者承认自己也没把关系说清。她享受“自己人”的优待，也没有在对方第一次接办卡、带客时停下来问边界。

**询问对话：**

```text
主播：现在回头看，你当时为什么愿意帮他转活动、带朋友去店里？
咨询者：剪头不要钱，满号也能插，带闺蜜去还有六折。我嘴上说是顺手帮忙，心里真把自己当成了店里的人。他让我转活动，我就转；朋友要剪头，我就往那儿带。表上后来把这叫“带客”，可我当时真觉得是在帮我们。连他提投店，我第一反应都是，他是不是认真把我算进以后。我不敢问关系，他也一直不说。只要那句“自己人”还在，我就愿意继续帮。
```

**关键追问：**

```text
主播：你一直顺着“自己人”往下接，是不是也在等他把话说死？
咨询者：是。我没有明说自己想要什么，也没有在他提办卡、带客的时候停下来。后面看到表，才发现我以为的暧昧可能只是他很熟的一套。
```

**揭示：**咨询者不是纯被动，她也在用模糊关系保留期待。

### 第五段：投店

对方最后提到以后开分店，话说得很漂亮：“自己人我才跟你说，以后店开起来，你就是老板娘。”咨询者后来才发现，另一位顾客也收到过类似说法。

**询问对话：**

```text
主播：他说老板娘这句话，是不是也可能只是开玩笑？
咨询者：可能是玩笑。但如果后面接的是投店和分红，就不能只当玩笑听。
```

**关键追问：**

```text
主播：他把“老板娘”和投店放在一起说，是怎么说的？
咨询者：他说以后店开起来，自己人可以一起做，投一点钱也算有份。我当时听着像未来，现在看更像把关系往投资上接。
```

**揭示：**暧昧称呼被接到商业转化上。

### 满格深问

```text
主播：那我多问一句，你最难受的是他骗你感情，还是你发现自己也被那句“自己人”带着往消费和投资上走？
咨询者：都有。我不想承认的是，我确实因为“自己人”这三个字松过口，也替他带过朋友。可如果这套话对谁都能说，那我就得把关系和生意分开看。
```

### 收麦原话

```text
“你跟别人不一样。”
“自己人我才这么跟你说。”
“你带朋友来，我肯定给你安排最好的。”
“以后店开起来，你就是老板娘。”
```

**本案落点：**  
一个人会聊天不等于有问题。但如果同一套“你最懂我”分别发给几个人，后面还接办卡、带客、投店，那就不是普通暧昧了。咨询者也要承认，她一直没逼对方把关系说死，是因为自己也舍不得那句“自己人”。

### 第二案小尾声与案间桥

```text
老方（语音）：他店里那个六折，我现在去还算数吗？
林旭阳：你真想剪就正常约。别为了六折，顺便认个自己人。
老方（语音）：那算了。别把我加群里。
【老方撤回预约截图。第二案完。下一通的存款证明到了后台。】
```

## 第三案：条件

**案名：存款证明**  
**本案词：条件**
**功能：反过来查来电人的筛选、收入诉求和自我修剪。**

### 开场

```text
咨询者：主播你好，我想问下我男朋友的事。

主播：晚上好。你们怎么认识的，现在聊到哪一步了？

咨询者：我们是相亲认识的，最近聊到见父母。
咨询者：我之前跟家里说过他名校毕业、条件不错，所以我妈问得比我想象中细。

主播：她问细到哪一步了？

咨询者：学校、工作、收入、有没有存款，后来还绕到流水。
咨询者：我也知道见父母前问这么细有点过，可我当时没拦住。
```

### 第一段：材料什么时候出现

咨询者说，正式见父母前，家里就问到学校、收入、存款和流水。她自己也觉得尺度不像普通见家长。

**询问对话：**

```text
主播：问到流水的时候，你有没有拦过？
咨询者：有。我还跟我妈说，第一次见面就问存款和流水不太好听。可她说我已经把话说在前面了，现在不问，饭桌上更尴尬。
```

**关键追问：**

```text
主播：这些截图是什么时候发的，发之前你们怎么说到材料的？
咨询者：我没有直接说“你发截图”。我妈说，见一面可以，但你前面把他学校和收入说得都不错，总得知道实不实在。我转述得比较含糊，只说家里可能会问细，让他别被问住。第二天他就发了几张图。
```

**揭示：**女方家在见面前就开始核对择偶条件。

### 第二段：好看版本怎么被放大

咨询者补充，介绍人一开始就把男方讲得很好，说“学校好、收入稳、家里也省心”。她后来跟家里说的时候，也顺着这个版本说下去了。

**询问对话：**

```text
主播：你后来为什么没有跟家里改口？
咨询者：我前面已经说他条件不错了，后面再改口，就像我自己也没看清。
```

**关键追问：**

```text
主播：这个好看的版本，是他一个人说出来的吗？
咨询者：不是。介绍人先铺了一层，我又跟家里复述了一层。他自己也没有把 MBA、本科和收入构成一次讲清。
```

**揭示：**体面标签被介绍人、男方和咨询者共同放大。

### 第三段：MBA 和本科

咨询者家里一直按“名校毕业”理解。真问到本科时，男方先回“也算吧，MBA”，后来才说明自己读的是名校 MBA 项目，本科不是那所学校。

**询问对话：**

```text
主播：你知道本科之后，跟家里说了吗？
咨询者：没有。我只说他学校那边确实是真的。因为我前面已经把“名校毕业”讲得很好听了，再补一句本科很普通，我怕我妈立刻变脸。
```

**关键追问：**

```text
主播：那张学校图少了哪一边，少的是本科、项目还是学制？
咨询者：能看到校名和项目，确实不是瞎编。但本科、项目性质、学制没有一起摆出来。“名校毕业”是我回家说满的，他那句“也算吧，MBA”也确实没把本科说明白。
```

**揭示：**男方用含混回答保留了误解空间；咨询者则把“学校好”主动说成了“名校毕业”，知道落差后仍没完整告诉家里。

### 第四段：收入和花销

咨询者开始不踏实，是因为男方口头收入不错，平时花销却对不上。他不是没钱那种，但特别会算。

**询问对话：**

```text
主播：哪次花销让你觉得不对？
咨询者：有次他说这个月奖金刚到，结果吃饭时又反复算团购券，还提醒我停车费能不能 AA。不是不能 AA，是和他说的收入状态放一起有点别扭。
```

**关键追问：**

```text
主播：你问流水，是想确认他到底赚多少？
咨询者：是。我嘴上说家里想看稳定，其实我自己也想知道。他到底是收入没那么高，还是钱花到别处去了。
```

**揭示：**流水追问不只是求安心，也在确认真实收入和婚后钱怎么落地。

### 第五段：工资卡

男方反问：“再问下去，是不是工资卡也要交出来？”咨询者当时没接住。但她妈妈确实说过，结婚以后钱最好放一起管。

**询问对话：**

```text
主播：那他拒绝流水是不是就一定心虚？
咨询者：也不一定。见父母前就问到流水和工资怎么管，换谁都会不舒服。可是我确实想知道，他说的收入能不能落到以后的小家里。
```

**关键追问：**

```text
主播：这句你有没有转给他？
咨询者：没有。我只说我妈想确认稳定。我要是原样说“以后钱放一起管”，这顿饭可能直接不用吃了。
```

**揭示：**女方把工资管理的要求包装成了确认稳定。

### 满格深问

```text
主播：那我多问一句，你自己的家庭经济状况怎么样？你自己一个月工资多少，够花吗？
咨询者：我自己也不是特别宽裕，所以我才更在意他收入到底落不落地。我嘴上说家里想看稳定，其实我也想知道以后这笔钱是不是能进小家。
```

### 收麦原话

```text
“也算吧，MBA。”
“我只说他学校那边确实是真的。”
“再问下去，是不是工资卡也要交出来？”
“结婚以后钱最好放一起管。”
```

**本案落点：**  
男方不是整套假资料，MBA、收入、存款都有真东西；女方也不只是求个安心，她想看的其实是以后这笔收入能不能进小家。两边都把难听的话包起来了。

### 第三案小尾声与案间桥

```text
赵律师（语音）：第一次去我家，我妈也问过你存款。你当时怎么没走？
林旭阳：你在桌子底下踢了我一脚。
赵律师（语音）：我那是让你别报数。
林旭阳：所以我没报。饭还是吃完了。
【热过的汤又凉了。第三案完。下一通的审批截图到了后台。】
```

## 第四案：主责

**案名：职场报销截图**  
**本案词：主责**  
**功能：离开婚恋语境，证明同一套判断能处理公共事件。**

### 开场

```text
咨询者：主播你好，我想问一件公司里的事。
咨询者：上个月部门做客户答谢会，同事让我先垫了场地和礼品钱。

主播：晚上好。你先说清楚，为什么是你垫，报销截图又是什么时候发来的？

咨询者：他说流程来不及，让我先刷卡，活动署名会写我负责。
咨询者：后来他发了审批通过截图，说财务批了，但钱一直没回我。
```

### 第一段：署名和垫款

咨询者承认自己不是完全被迫。刚进项目组，确实想借这次客户答谢会让老板看到自己。更难听一点，咨询者先跟老板说过这次自己可以主责，所以听到“署名写你负责”，就先垫了。

**询问对话：**

```text
主播：他说主责署名的时候，你为什么先答应垫？
咨询者：我也确实想要这个主责，所以没有第一时间追垫款流程。可想表现不等于默认钱可以一直卡着。
```

**关键追问：**

```text
主播：他让你垫钱时，原话有没有提署名和老板？
咨询者：有。他说这次活动缺个执行负责人，如果我先顶上，复盘材料里可以写我主责。我当时没有说的是，我前面已经跟老板表过态。
```

**揭示：**咨询者先想要主责曝光，同事再把垫付款包装成机会，资金风险被弱化。

### 第二段：绕开公开预算

活动前，同事让她别在大群里问预算，说客户答谢会临时调整太多，先私下办成，复盘再补流程。她也怕在大群问预算，会显得前面说能主责是嘴硬。

**询问对话：**

```text
主播：你如果当时在群里问，会不会真的影响观感？
咨询者：可能会显得我不够爽快。但至少钱是谁批、谁还、谁对接供应商，会留下记录。
```

**关键追问：**

```text
主播：他为什么不让你在大群确认预算？
咨询者：他说问多了显得我不担事，老板会觉得我推活。现在想想，这句话把我想表现的心理拿住了。
```

**揭示：**流程先被挪到私下，后续风险开始失去公开记录。

### 第三段：审批截图缺边

同事发来的图抬头是“报销审批通过”。咨询者以为等于钱已经到账，仔细看才发现下面没有付款流水，也没有收款账户。

**询问对话：**

```text
主播：他有没有可能只是财务慢，不是故意拖？
咨询者：有可能。所以我才没一上来撕破脸。但如果只是财务慢，他完全可以给我看付款状态，或者让我问财务，而不是一直拿审批截图挡。
```

**关键追问：**

```text
主播：这张审批图少了哪一边，是付款状态还是收款账户？
咨询者：下面少了付款状态这一边，收款账户也没露出来。只能证明审批通过，不能证明财务已经把钱打到谁的账户。
```

**揭示：**审批通过不等于钱已到账。

### 第四段：供应商返款入口

咨询者翻供应商报价单，发现礼品那项有一个“服务协调费”。供应商群里又提到返款统一打给对接人，而对接人是同事。

**询问对话：**

```text
主播：你问过这笔服务协调费是不是正常报价吗？
咨询者：问过。他说可能就是正常报价。可他不让我问财务，也不说返款怎么处理，我就没法只按正常报价理解。
```

**关键追问：**

```text
主播：供应商返款打给谁，和你的垫付款是不是同一条钱路？
咨询者：供应商群里写的是统一打给对接人，对接人是他。我的垫付款、公司报销、那笔返款，最后都要经过他。
```

**揭示：**同事同时控制报销入口和供应商返款入口。

### 第五段：主责和付款入口分离

复盘材料出来后，主责那栏确实写了咨询者。但付款对接人和供应商确认人仍然是同事。出问题时她像负责人，拿钱时入口却不在她手里。

**询问对话：**

```text
主播：主责写了你以后，你为什么反而更慌？
咨询者：一开始我觉得也算值。可钱没回来以后，主责反而像风险，出了问题大家会先问我为什么私下垫。
```

**关键追问：**

```text
主播：主责署名和付款入口，最后在同一个人手里吗？
咨询者：不在。复盘写我主责，可付款对接、供应商确认、返款入口都在他那边。
```

**揭示：**项目责任和资金入口被拆给不同人。

### 满格深问

```text
主播：那我多问一句，如果今天不只是钱没回来，你最怕这件事在公司里被说成什么？
咨询者：我最怕他们说我是为了抢署名才私下垫款，流程不规范。我先跟老板说能主责，我也确实想要这个主责；但他用这个让我先刷卡、又拿审批截图挡我，也是真的。
```

### 收麦原话

```text
“报销审批通过了。”
“我也确实想要这个主责。”
“返款统一打给对接人。”
“先私下把事办成，复盘再补流程。”
```

**本案落点：**  
职场截图也会只截好看的半张。咨询者想拿表现，所以先垫了；同事拿着审批图和供应商入口不放，所以钱一直回不来。两件事要分开说。

### 第四案小尾声

```text
赵律师：今晚这些杯子，谁主责？
林旭阳：我洗。你复核。
赵律师：我不复核。我在门口等你。
【林旭阳把备用线缠好，收进桌下的盒子，又端起桌上的杯子。屏幕右上角的“直播中”灭了。第四案完。】
```

## 尾声：故事集收麦

**内景｜直播间｜深夜**

四通电话结束。屏幕上的四个词重新出现：

```text
体面
自己人
条件
主责
```

这一次，词后面多了四个落点：

```text
体面 -> 最低还款
自己人 -> 办卡带客
条件 -> 工资卡
主责 -> 付款入口
```

主播看向弹幕。

```text
主播：今晚四通麦，难听话都藏在好听词后面。
主播：有人把账单递过来，有人把表格发错，有人把流水换成“稳定”，有人拿审批截图挡钱。
主播：谁愿意把话说全，谁就还有得谈。谁拿好听话省掉钱和责任，就继续问。
```

评论区审判墙生成，内容根据玩家路线变化。

```text
你这一集最常问：钱从哪来，最后落到谁手里。
```

```text

```

**反向追问路线：**

```text

```

**外围听感路线：**

```text
你这一集听到了情绪，但几句最要紧的话还没问出来。
```
