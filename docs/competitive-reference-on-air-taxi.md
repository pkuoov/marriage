# 竞品参考：On Air! Taxi Detective Casebook DEMO

参考对象：[On Air! Taxi Detective Casebook DEMO](https://store.steampowered.com/app/4256330/)。

这份记录只用于校准《直播间大侦探》的 Steam 试玩方向，不作为新分支。当前结论是：不要同时追“出租车职业模拟”“AI 自由问答”“影游多分支”三条路；只吸收它证明有效的部分，收束成我们的“直播控场系统”。

## 竞品有效点

- 玩家身份有强机制理由：玩家是车内 AI，司机是前台，天然解释了“幕后推理、前台发声”。
- 场景职业化：出租车夜班让乘客故事、评分、路线、收入和情绪压力同时存在。
- 文本不只是读：玩家要扫描乘客发言里的关键词，把票据、录音、时间戳等碎片变成线索。
- 引导有伪装：玩家不能直接说推理，要用广播、交通提示等方式间接推动事件。
- 失败压力是场景内的：乘客心情、平台评分、机会损失都属于出租车职业本身。

## 我们不照搬

- 不做出租车式移动场景。我们的场景是直播间，职业压力来自弹幕、连线人防备、平台边界和收麦节奏。
- 不把“AI”放到玩家身份前台。玩家体验仍是主播控场；AI 只可作为后续受控 intent router 或内部编剧工具。
- 不把案件奇谈化。我们的核心优势是中文互联网现实事件：截图、账单、话术、关系边界和责任转移。
- 不新增多线职业模拟。收入、路线、开车这些不属于本项目，照搬会稀释产品。

## 可学习但必须翻译成直播间语言

| 竞品机制 | 本项目翻译 |
| --- | --- |
| 车内 AI 暗中推理 | 主播/导播在直播间控场 |
| 司机平台评分 | 直播热度、听众耐心、主播口碑 |
| 乘客心情 | 连线人防备值 |
| 关键词扫描 | 原话标记、截图圈点、时间线排序 |
| 广播伪装提示 | 主播选择追问方式、压弹幕、换话头 |
| 绕路/收入风险 | 错问导致弹幕跑偏、连线人闭麦、忍耐下降 |

## 单一优化方向

当前不要新开多个方向。竞品学习只落到一个方向：

**直播控场系统：玩家作为主播，在听众耐心、连线人防备和材料缺口之间做选择。**

这个系统只包含三件事：

1. 资料操作：截图、账单、表格不再只是文字选项，而是可圈点、可标记、可回看。
2. 现场压力：错问、重复问、太急问会影响听众耐心和连线人防备；命中问题不扣。
3. 收麦结果：结果页回收玩家控场路线，而不是展示教程式评分。

## 当前实施顺序

1. 保持昨天的两项架构支撑：内容包骨架、路线运行时拆分。
2. 下一步只做资料操作模型，不同时做 AI 问答、桌面壳和新剧情扩写。
3. 资料操作模型完成后，再把听众耐心和连线人防备统一成一个现场压力模型。
4. 等直播控场系统成立，再考虑桌面壳和受控自由追问。

## 成功标准

- 玩家能用一句话说清自己在做什么：我在直播间控场，把来电人话里的缺口问出来。
- 每案至少有一个“我亲手圈出来”的材料动作，而不是只读选项。
- 错误不是“选错答案”，而是现场被带偏：弹幕散、来电人防备、时间被消耗。
- 结果页不教育玩家，只回看这晚怎么控场、哪句原话被接住、哪处材料被圈出。
