# 第 11 批·剧情扩容框架（story expansion pass 11）

日期：2026-07-07
性质：框架与蓝图文档（非执行单）。来源：Codex 自我复盘的"剧情扩容 pass"提案。本文档先裁定提案、把配额合规化，再给四案蓝图；执行按 11-engine → 11a → 11b → 11c → 11d 切分，每案单出执行单。

## 一、对 Codex 复盘的裁定

| 提案 | 裁定 | 说明 |
| --- | --- | --- |
| 场景太单一，缺第二/第三现场 | **采纳，改写** | "现场"不是新地点渲染，是来电人**还原现场的叙述拍＋该现场的材料包**。扩容与幕结构、材料板中置同批落地，否则纯加文本会加重"十分钟读完"问题 |
| NPC 只是信息源，应有立场 | **采纳，改写** | NPC 永不上麦（单连线人契约），"下场"=其立场/遮掩/利益写进他们的**材料、回流、留言、顾问单**——每个具名麦外声音立三行卡：立场／遮掩／利益。只证明主线的声音是道具，砍掉或武装它 |
| 证据链太直，应三段式 | **全盘采纳** | 支持来电人 → 推翻一部分 → 把双方拖进灰区。规则化进 coupling-review |
| 矛盾太早说透，缺中段误判 | **全盘采纳，配新机制** | "误判拍"：中段设一次**立场快照**（无惩罚的阶段性判断，被记录、可被推翻，终局照出你的弧线）。误判必须由证据喂出来，不许靠隐瞒信息骗 |
| 每案一次难受的自我暴露 | 已达标 | 四案深问/证言更新已覆盖，扩容中保持 |
| 一句话讲不完的未知缺口 | **采纳** | 案 1 的"8 号还入"已是标杆；案 2-4 的 unknown 升级成"有形状的刀刃" |
| 案 1-4 的主题重定向 | **部分驳回** | 案 1"共同人设＋成本转嫁"、案 4"利用表现欲拆开责任与钱路"——**这已是现行出货主题**（第 7/8 批落地），不需要重定向，需要的是加厚。案 4 的"中段怀疑她抢主责"是真增量，采纳 |

## 二、配额的合规化定义（每案达标线）

1. **+2 现场拍**：场景数 5→6-7。每个现场拍 = 来电人还原一个麦外现场（饭局/店内/拍摄夜/财务流转）＋该现场至少一件新材料；随幕结构分幕，幕间是材料板或委托的锚点。manifest 难度、耐心预算、`runtimeLengthPlan` 同步。
2. **+2 有立场的麦外声音**：立场/遮掩/利益三行卡进角色圣经；投放面限于既有合法表面（材料、回流、respondent-note——扩容包每案放宽至 2 条、顾问单、幕间委托回单）；每个声音的传感器契约先审后写。
3. **三段证据链**：三件材料互相 revalue（支持→部分推翻→拖入灰区），伏笔账本里连线可查。
4. **1 次中段误判（立场快照）**：幕 2 末新交互——"现在这通麦你站哪边"（三选：他的问题/她也有份/还听不出来），记录不判分；被后续证据推翻是设计目标；终局回看展示你的判断弧线。误判方向必须有真证据喂养。
5. **1 次自我暴露**：保持现有水准，扩容不得稀释。
6. **1 个有形未知**：能被一句具体的问题命名、但今晚无法回答的缺口；禁止"感情真不真"这类灰尘级未知。

## 三、四案扩容蓝图

### 案 1（信用卡）——已最深，轻扩

- 现场拍 ×2：纪念日晚餐夜（会员号订座、谁点的酒、发圈那一刻）；设备开箱/首拍夜（"我来投资你"的完整语境）。
- 声音 ×2：**闺蜜**（升级现有 DM——立场：当初起哄"他真大方"，现在急着撇清自己当过人设观众；遮掩：删过自己的起哄评论；利益：友情里的面子）；**男方前同事**（新回流——立场：欠过他人情；只肯说"他阔过，阔得早"；遮掩：不说钱的去向——**不得触碰 8 号谜底**，他的价值恰是"知道点什么但不说"）。
- 三段链：账单（支持她）→ 往期账单（推翻一半：供血史）→ 会员记录＋朋友圈（拖她入灰）。已成形，账本补连线。
- 中段误判：幕 2 末（她的线峰值处）快照——诱导"双方互坑，她占的便宜不小"；板 2 的 8 号还入翻回"他早有洞，借她填"。
- 有形未知：8 号还入（已达标）。

### 案 2（理发店）——中扩

- 现场拍 ×2：办卡那天的店内（店长在场，话术围观，小妹喊"嫂子"的完整语境）；她带闺蜜去剪头那次（折扣发生现场）。
- 声音 ×2：**店长**（第三方 note 或回流——立场：业绩压死人，话术是我教的没错；遮掩：把他的私加列说成"年轻人自己上进"；利益：店的口碑与指标）；**另一位女客升级**（现有 DM 深化——立场：不想当受害者，想合伙讨说法；与来电人目标冲突：一个要说法，一个要止损——两个"受害者"不同路，本身就是戏）。
- 三段链：排班表（支持她：他有问题）→ 店长培训话术＋会员系统记录（部分推翻：模板真存在，指标全店都背）→ 私加列＋她的带客折扣（双方入灰）。
- 中段误判：快照设在"行业就这样"峰值（店长声音进场后）；私加列翻回个人猎场。
- 自我暴露硬化：带客折扣从"没好意思问"落成实据，她当场不舒服。
- 有形未知：「同款表他做过几张，今晚只见过两张。」

### 案 3（存款证明）——中扩

- 现场拍 ×2：第一次见面饭局（谁问了什么、冷场十几秒、服务员解围的完整还原）；介绍链（介绍人对两边各说了什么——双面话术拍）。
- 声音 ×2：**介绍人**（回流或 note——立场：两头做人；遮掩：各报高价；利益：谢媒人情）；**男方表姐**（note——立场：护短＋家里催婚；关键句：资料是全家帮着整理的——协作沉默显形，东方快车结构落地）。
- 三段链：学历图（支持她：他包装）→ 家里群＋她先提流水（推翻一半：她家也在生产版本）→ 介绍人双面原话（整条介绍链拖入灰：人人都在替婚恋市场做一个好看版本）。
- 中段误判：快照设在"他就是婚骗"峰值（学历＋存款抢答之后）；介绍链证据翻成共谋图景。
- 有形未知：「他那份 MBA 的学费当年是谁出的——今晚没人答得了。」
- 红线：表姐与前同事类声音**不得证实收入构成**（那是本案该活着离场的 unknown）。

### 案 4（报销）——重扩（Codex 判断正确：最适合多方结构）

- 现场拍 ×2：预算沟通现场（部门助理发流程那天，他插进来说"来不及"）；复盘会现场（领导点名夸她的完整语境——夸奖如何变成套牢）。
- 声音 ×2（在既有同事 note、供应商匿名话之上）：**领导**（回流：他在复盘里的批注原文——立场：只要结果；遮掩：对"老规矩"选择性眼盲；利益：部门数据）；**部门助理**（回流：正常流程的样本记录——立场：按规矩办事的人，最清楚这单哪里绕开了她）。
- 三段链：审批图（支持假解：流程真慢）→ 预算沟通记录＋延后通知日期差（推翻：借口早于证据，绕流程是他主动——**启用第 10 批入账的候选转折**）→ 复盘署名＋返点话术（拖入灰：她的表态被利用，领导默许结构）。
- 中段误判（本包最强）：幕 2 弹幕带节奏「她自己先表态要主责的，垫钱博署名怪谁」——**直播间中段倒向指责她**，快照诱导玩家跟风；后续证据逼玩家在"不豁免她"的前提下把矛头拨回钱路控制。包级元反转（她先自认）在这里被武器化第二次。
- 有形未知：「"老规矩"从哪一年开始、还有谁拿过——今晚只看得见这一单。」

## 四、执行切分与依赖

- **11-engine**（先行）：幕结构锚点＋材料板中置（`afterScene`）＋立场快照（新交互，记录不判分）＋note 每案配额放宽至 2＋场景数解锁（manifest/plan/耐心预算联动）。证据委托（P2.5）可与 11a 同批试点于案 4。
- **11a=案 4**（试点，最大增量）→ **11b=案 2** → **11c=案 3** → **11d=案 1**（最轻，收尾）。每案独立执行单、独立 playtest 快查后再进下一案。
- 全程铁律不变：单连线人、感知带宽、效力/侦查线、双源、留白配额、真相账本先行（每案扩容前先把新账算完）。
