# 人物出场来源与目的修订

本轮承接揭露顺序审读，修正主播随时找到知情人、知情人一到场就负责补线索的问题。原则已写入 `project-skills/case-scriptwriting/references/current-project-direction.md`：每个提供信息的人都需要接触渠道、此时出场的缘由、愿意开口的个人目的；这些必须在可玩剧情里交代。主播没有传唤、进入单位或查看内部系统的默认权限，来电人的同意也不能代替第三人自己的意愿。

| 案件 | 出场因果与信息边界 |
| --- | --- |
| 信用卡 | 主播请一直帮工作室记账的周会计看男方提供的记录；会计不掌握额外账户。旧朋友圈由认识来电人的观众听到“只去过一次”后补来，要求匿名。 |
| 职场 | 小陈想找人帮腔，自己联系本次礼品供货方和已离职的部门助理，牵线私聊。供货方不愿背虚报价的责任，前同事不愿背漏发通知的责任。供货方后续向自家财务找到回执，遮去账号后经陈转来；前同事只能讲任职时通知与经手记录。公司工作群通知也由陈转发。删除没有独立作用的仓管出场，通用财务解释交给已有关系的周会计。 |
| 彩礼 | 来电人把连线发给亲属、介绍人和男方，想找支持。介绍人被两家埋怨，主动约谈澄清传话；男方表姐经男方牵线，只在私下语音解释自己参与的选卡过程，不接受上播。女方表妹因同在家群、听到片面说法而补截图，材料先留后台，沿用后续公开授权环节。 |
| Tony | 小何把回放发到美发预约群要求回应，才引来店长、熟客和周女士。店长要说明门店业务范围，熟客不愿被算作女友，周要追自己的钱。朋友由小何约来，先澄清自己没有劝买；机构人员通过公开咨询电话只答通用规则；店外片段发生在店长约见之前的等候中，不能据此认定具体交易。 |

上一场主办的旧结算也补齐来由：陈向他索要以前展示过的到账记录，想证明先垫确实能拿回；对方要求实支页一起展示，不愿被说成没有花钱白拿。没有再让主播直接联系一个只负责发材料的人。

人物可以拒绝、只说自己经手的部分，也可能带着推责目的提供真实片段。信息来源成立不等于内容已经全部证实。原有核心诉求与分夜揭露顺序保留；旧场景、材料身份键保留以兼容存档，旧的上门叙述同步清除。

角色档案、声音参考、连续台本与 playable 已同步。浏览器回归新增核对：日间场景的来源说明必须实际显示。`npm run check`、案一完整路线及 `six-review` 路线通过；后者覆盖职场、彩礼、Tony 和三宗快案。主案从各自入口定点开始，检查两夜推进、材料、重载与收麦，不把它表述为从序章到片尾连续游玩。
