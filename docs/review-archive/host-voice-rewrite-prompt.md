# 主播声音重写执行单（双寄存器 + 夜班弧，治"一本正经"）

你是本仓库的实施工程师。设计依据：`docs/host-voice-redesign.md`（已批准）。目标：把主播林旭阳从"中性提问机"改成"平时风趣调侃、碰真相就步步紧逼"的活人。**只改主播的说话方式（交付层），不动任何来电人台词、事实、路线轴、案件真相、收窄阶梯、计策铁律、公平机制。**

分三阶段，**B（案1竖切）改完必须停下等真人朗读**——风趣是 AI 写作最容易写假的一类，主角的声音必须先由人耳锁定，再铺开。

## 全局铁律

1. **只重写主播（林旭阳）台词的措辞**；来电人、对方、顾问、旁白、舞台指示一律不动（除非同一 lines 内主播行的因果桥需要，且不改其信息）。
2. **不碰承重层**：事实分拣、双源、留白结尾、不预判、路线轴、真相、收窄阶梯、阳谋不阴谋——一条不松。风趣只进"怎么说"，不进"判什么"。
3. **保住 verify-pack 现有主播约束**：主播行必须署名林旭阳（不许裸"你"）；`hostLine`/`entryQuestion` 仍是单问回合（不许一句塞两问）；`nightStructure.hangup.hostLine` 仍等于 `overnightStructure.hostHoldLine`；`hostDisclosure` 不许替玩家点位置（禁"圈/那一栏/哪一块"）。
4. **接话节奏不破**：每次转下一条线索仍要"先复述刚听到的、再说为什么问下一件"（因果桥）。新声音是给这套桥**加暖/加锋**，不是省掉桥。禁区仍禁：一句开场塞全关系+异常+证据+金额；用"好/先别解释"办案指令代替反应。
5. 全量校验：`npm run content:index && npm run content:script && npm run check && npm run verify:pack -- steam-demo-01 && npm run smoke:browser`。**改动了 smoke 里 pin 的主播原句，必须在同一提交同步更新 pin**（见 B4）。

## 去 AI 味 · 风趣专项约束（最重要）

风趣写假 = 全盘皆输。落笔守：

- **干、淡、随口**，不俏皮、不金句、不 punchline。AI 味的风趣 = 对仗工整的俏皮话、漂亮收尾的一句。对照 `spoken-corpus-patterns.md` 禁写清单：不对仗、不句句承重、不用漂亮短句收尾、不装深刻。**干冷的顺口吐槽 > 抖机灵。**
- **风趣 ≠ 金句**。金句配额律照旧（≤3/案，只在深问/结案）；风趣是**没营养的随口话、自嘲、翻白眼**，恰恰不该抖成可截图的漂亮句。两者别混。
- **不许拿脆弱来电人当笑料**：可以自损、损套路、损对方、跟老方贫；对正在难受的来电人只暖不损。
- 不触发 `verify-logic` 库存 AI 用语正则；`npm run test:logic` 绿。
- 判据：念出来像一个人缘好的前法务在深夜档随口说的，不像编剧写的俏皮台词。

## B. 案1竖切（主角声音锁定，改完**停下等真人朗读**）

对案1所有主播台词做双寄存器重写。目标配额（案1处夜班弧起点：**精神、话多、爱贫**）：

- **默认档·风趣** ≥4 拍：开场接线、老方来消息、顾问插话/过场、来电人跑题或生活噪声处。
- **专业档·步步紧逼** ≥4 拍：矛盾露头、来电人闪躲、流水核对、关键追问、深问、结案。
- **收笑变脸切换** ≥1 处可见：正松着 → 破绽一露 → 笑一收、声音沉下去（同一段里能看见切换）。
- **钉完回暖** ≥1 处：结案钉死真相后软回来给台阶。

### B1 签名拍（方向示意，**非最终逐字**；最终按上面风趣约束写，写完人耳过）

- **老方来消息**：主播打趣着躲，不焦虑——把"不上进赚钱 + 有正义感"一次带出（他是真不在乎数据、懒得迎合，不是苦大仇深）。示意方向："数据不好看归不好看，这通我还是想听完"这类干冷、不焦虑的躲，别写成励志宣言。
- **收笑变脸**：案1流水/账单矛盾处，前一句还在松着接她，后一句咬住不放（"等等——你刚说他两周前订的座？"这类，把松切成紧）。
- **深问/结案**：保留现有锋利（truth 咬字狠），钉完补一拍回暖。

### B2 因果桥保留

每处专业追问仍先复述再问，只是把原来干巴的"八万。好，先别解释"这类换成有反应、有温度或有锋的过渡。信息、顺序、路线轴不变。

### B3 不动清单（案1内）

来电人沈的所有台词、V哥、顾问原话、旁白/舞台指示、流水文档行、真相边界、路线轴、收窄阶梯——一律不动。

### B4 smoke pin 同步（硬要求）

改这两句就改 pin；不改就别动这两句。改完 `npm run smoke:browser` 必须绿。
