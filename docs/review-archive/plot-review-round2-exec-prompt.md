## P0-1 案1：第一夜账单自打脸（旧 P0-1，仍在）

**位置：** `01-credit.json`（纯台本 133 / 193 / 905 行）。

- 133：她第一夜主动念全「餐厅礼物酒店设备约四万 + 男装五千」。

**验收：** 第一夜→重述→结案卡三处口径一致：她先控叙事，被逼才认四万。

## P1-2 案2：Tony 留言的自保逻辑（旧 P1-2 升级）

**位置：** `02-tony.json` 约 1372 行对方留言。

**问题：** 他主动认了最重的事（女客十万先转买宸直），却对已被民警坐实、更轻的「未经同意写进项目介绍」一字不提。自辩的人不会这么挑。

**做：** 留言内加一句他对项目介绍的说法（可辩不可赖）：如「项目介绍里写她，是我想着她客源熟，没先问她，这是我不对」或「对方要看联络人，我填了最常带客的号码」。禁止改成「她书面同意过」，禁止否认姓名手机号在介绍里。

**验收：** 结案三角里身份轨有对手方回应；他的认账顺序符合自保逻辑（轻的先认）。
