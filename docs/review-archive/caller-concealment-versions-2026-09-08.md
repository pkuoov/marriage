## 先分清三本账

- **作者知道的底层事实**：发生过什么，角色自己知道什么、故意压下什么。用户已给出的底层设定继续保留，不能因为主播未能证明，就在作者账里一并删除。
- **现稿人物实际说过／玩家能够取得的内容**：注明陈述、对质、材料、留言及分支。内部 `deceptionChain` 不是实机已播放的证据。
- **下一轮拟补内容**：还缺的动作、承诺、材料或最后一套说辞。列出供重构使用，不伪装成已发生。

人物可能真相信自己的解释，也可能随压力改口。误判、价值观、隐私拒答与已知事实的隐瞒分开写。每次松口以后，他仍想保住什么，才是下一问的入口。

| 第四套：这些是私事，找个人品好的人就行 | 三个点被问过后重新讲要求：四五千、没房也行 | 普通候选人与原贷九十万、工资剩余、前任分手放在一起 | 补出想接触经营稳定、能分担房贷的人，承认前任也为钱争执。Q14、Q15 |
| 第五套：我没让他养，住在一起帮一点正常 | 原稿已用住我的房子解释分担；下一稿须进一步说清具体支付分工 | 问生活费、月供、房屋归属及资助关系哪些需要向对象说明 | 让她维护自己的分类，不轻易改成我要求太高了；新增具体金额／持续资助须先补作者账 |
| 最后的请求：你先替我说可靠，后面我自己聊 | 要主播为她争取见面，但拒绝把重大关系和依赖说透 | 主播追问凭什么用信誉替她说话 | 她仍把推荐说成一句好话、不用保证一辈子；完成 Q11 与 Q15 的回收，不能让说好话小梗取代经济与关系主线 |

**信息顺序固定，结论分轮叠加：** 说好话 → 爸爸 → 生育顾虑 → 她再讲一版自己 → 重新问对象条件 → 月供、前任与推荐请求合起来看。不是第一轮就让她交出完整隐藏经历。

## 7. 快案二·周女士

**她来要什么：** 留住一个经济条件与婚姻意愿都合适的对象，同时继续把自己放在只要求理解、对方却过分追究的位置。

| 隐瞒 ID | 要压住的内容 | 状态 |
| --- | --- | --- |
| Q21 | 她享受花、包、车及朋友羡慕带来的满足 | 现稿花是自己要求、动态是自己发的，第一轮陈述已说。后问才说包是谁送；不能把所有礼物都登记为晚揭秘密 |
| Q22 | 23:52 回还行时已经不舒服，并非直到漏掉消息才突然失联 | 现稿当事人承认；漏回消息本身不等于蓄意失联 |
| Q23 | 不止妹妹，桌上还有一名男性朋友；解释时也是说漏后才补出 | 对主播与对男方分别省略，两个披露时间不可混成一次 |
| Q24 | 八号已去 KTV，九号又去清吧；很久没出去是按她自己的分类 | 现稿截图与本人回答落实，分类辩护是主要笑点 |
| Q25 | 十号道歉同时发八号照片，未标日期，却期待对方理解完整时间线 | 现稿落实；男方究竟看完哪些旧图仍未说明 |
| Q26 | 末尾要的可能不只是表达歉意，而是让男方主动回头哄她 | 本轮完整收尾已接入：她要求男方也为说话重道歉，话术又不能显得自己求人 |

| 整体版本 | 她怎样讲这件事 | 触发点 | 最小改口与仍保留的说法 |
| --- | --- | --- | --- |
| 第一套：问题在于他不懂我的感受 | 用歌没聊下去、花送了却不懂自己解释失联 | 自己晒图、收包与朋友羡慕，使物质与展示也进入对话 | 承认喜欢这些，仍可合理坚持有礼物也要交流；这层不能独自定罪。Q21 |
| 第二套：不过是跟妹妹出去，漏了一条消息 | 把事情压成一次偶然、一次回复问题 | 六分钟前还回还行，之后吐到记不清 | 承认当时不舒服，把缩小说成不想让他担心。Q22 |
| 第三套：有人在，但不是我叫来的，后来也解释了 | 先只说别人点酒，再说妹妹的朋友 | 追谁在场、男方怎样知道第三人 | 承认男性在场及解释时说漏，继续强调不熟、不是专门见他。Q23 |
| 第四套：聚会不算出去玩，旧图也不算继续玩 | 八九号连着玩与十号动态都被摆出 | 她用八号旧图自证，反而露出前一晚也去过；截图还显示多次深夜活动 | 改定义：生日毕业不算、没醉不算；照片修好了不发浪费。Q24、Q25 |
| 现稿收尾：那你给我一句，我照着发 | 承认对方条件合适，仍想挽回 | 主播不能保证对方回消息 | 她很快转为再想想，缺少目标继续暴露的一拍 |
| 拟补最后一套：要联系回来，但别让我显得有错 | 当主播建议发完整经过，她嫌像认错、像自己追着他 | 让她实际拒绝或改写一版消息 | 本轮已演出她拒绝继续解释，改要一句不显得求人的话；Q26 成立 |

**保留她的自圆其说。** 日期说清以后，不要把她改成承认自己不该出去玩的人；她应继续认为每个例外都正当，却要求对方自动明白这些例外。

## 9. 快案三的两位公开发言者

这里没有来电人。作者的文章是一次公开叙述，四段阅读顺序不等于他在直播里被戳穿四次。

### 顾：长文作者

**要得到：** 退回自己声称的三千万，同时让对方撤声明、承认全文，保住自己版本的权威。

**要压下：** 金额与私事主要来自自己单方叙述；较大的五千万美元未转；中间人是否获女方授权未落实；撤声明、认全文超出了自己所说的诉状金额争议。

**现有包装顺序：** 我公开受委屈的经历 → 大额钱款显示她只看钱 → 她急着找人来谈，似乎说明她认了 → 我只要退钱和恢复名誉 → 条件实际还有撤声明、认全文。文末虚构从开头就给玩家看见，结尾用于回看，不假装最后才出现。

**隐瞒性质：** 不是他把未转的钱明说成已转，而是排列方式诱导观众把大数字当成同一份损失；不是已证实她授权后他撒谎，而是他把缺了一环的转述讲得很满。判断落在他公开写法和要求上。

**拟重构的冲突：** 让玩家把自己可退回虚构、对方必须认全文直接并看，保留一个尖锐短事件；若要设计真正的第二套说辞，必须新写他后续公开回应，不能让主播替他编反驳。

### 被点名的女演员

**现稿能确认：** 回应强调没有为钱出卖爱情，没有具体回答三千万。她的名誉与工作有现实利害，但没有来电或进一步公开材料。

**不能提前写死的秘密：** 款项实际性质、是否确有文中所述安排、是否本人授权中间人。现有“没回答”是一处回避，不足以编出她三套完整谎言。

**待补方向：** 若她需要成为真正的对手，就给一份针对金额或条件的新回应，且能改变作者下一步行动；否则保留单次回应，不靠主播反复猜动机凑层数。

## 本轮找出的旧记录误差

1. **主题清单被写成改口链。** 收入、房产、工作、检查四项信息依次出现，不等于角色为了同一目标连续修补了四套说辞。
2. **已说出的事继续登记成隐瞒。** 陈开场已说活动是争来的；何开场已说要钱；周女士第一轮已说主动要花、发图；林开场已说问过其他账户。后面要追的是动机、范围和被省去的部分。
3. **误判被登记成谎话。** 陈猜别人手续不全、何把提交当成交，与她们明知分配名目、明知裁图不同。缺少知情材料就不能拿前者替代后者作为大反转。
4. **作者秘密被玩家证据边界吞掉。** 罗的长期供养是用户给的底层方向；当前未铺出持续往来，不代表作者无需确定。下一稿先补底层事实，再决定她承认多少、主播能判断多少。
5. **麦外短留言冒充完整攻防。** 男友、主管、Tony 目前都不具备现场同等长度的改口过程。扩写要有追问送达与回复来源，不能在评审里写成已经演过。
6. **最后一套说辞缺失。** 揭事实后应继续看角色怎样保收益、保名声或换一个请求。信用卡、Tony、两个来电快案都还需要这一拍；彩礼刚补了取消理由争夺。

## 后续改稿使用方式

配合 [当事人诉求主线](caller-request-spines-2026-09-08.md) 使用：隐瞒账解释她为什么修剪故事，诉求线解释她希望主播采取什么行动。揭事实以后，继续写她如何争取结果，不把所有来电归成同一种求背书。

实际段落是否服务上述目标、找补要接在哪个具体取舍之后，见 [逐段匹配续审](case-goal-dialogue-alignment-2026-09-08.md)。

先选一个人物的共同目标，再确定要补哪一个隐藏 ID。每个版本标记：谁已听过、哪份材料已到、她此刻最少必须认什么、还拒绝什么、这会让谁改变下一步。固定主线承担关键改口，可选支线加深背景。不得把本表里“拟补”的说辞直接登记为现稿真相。
