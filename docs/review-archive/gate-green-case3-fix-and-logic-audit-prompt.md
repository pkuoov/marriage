4. 改写句走去 AI 味约束,不触 `verify-logic` 禁语表。

## Part 0|先把行为闸门弄绿(阻塞项,最先)

本轮改了案1场景(删 sitIn/加房租场景/换 opener 与流水行)+ 大量 UI(对白与快案对齐、continue 锚定、决策点暴露材料、宽屏、滚轮不开案卷)。smoke 可能因此**挂住**或**pin 漂移**。诊断三分法:

1. **先定位卡点**:`npm run smoke:browser`,看它停在哪个 route/viewport(smoke 会逐路线打进度)。若长时间无任何回放输出、进程还活着→**回放挂住**(多半在等一个被 UI 改动改掉的 selector);若抛 `Error:`→**断言失败**(pin 漂移或真回归);若只是慢→等它跑完。
2. **挂住**:找到卡住那一步等待的 selector/元素,对照本轮 UI 改动(continue 锚定/材料暴露/对白对齐)判断是**选择器改了名**(更新 smoke 里的选择器)还是**流程真的断了**(UI 回归,修 UI)。真回归停下报告。
3. **pin 漂移**:案1 opener/流水行/场景名被重写,smoke 里 pin 的 `openerText`/`assertVisibleText`/route 的 `opener`/`dayScenes` 名等按当前内容逐条更新(去台本/JSON 找现文)。已知需核对:案1 已删 sitIn 相关 opener(旁听/订座与灯/五万或三万五拒答)、白天场景改为 `day-support-payments`(把两笔房租圈出来)、流水行加了 r01a/r01b/r04a/r04b/r06a——凡 smoke 引用到旧名/旧句处全部对齐。
4. 反复到 `smoke:browser` 全绿。**不许靠删断言/删路线蒙混**;断言意图要保留,只对齐名字与位置。

Part 0 绿之前不做 Part 1/2。

## Part 1|修案3「算进婚礼」硬矛盾(逐字)

**位置**:`manifest.json` → `nightShell.interludes[2].lines[3].text`(案3广告间隙,林旭阳对赵律师)。

原文:
```
她家已经把九月底的钱算进婚礼了。希望到时候真能回来吧。
```

**为什么错**:案3反复钉死女方家那二十万是「留给女儿自己,不是拿来付婚宴和首饰」;林旭阳自己的结案说「不把那二十万元算成可用资金」;同 manifest 的表妹尾声说「宸直那笔钱也不算进预算」。这句"算进婚礼"把女儿对男方撒的谎当成她家事实,与案身/结案/尾声三重打架。

改为(逐字):
```
她家那二十万还压在宸直里，能不能按时兑，谁也说不准。
```

不动同 interlude 其它行、不动表妹尾声。改完 `content:script` 重生成,确认案3小尾声与结案/尾声一致、无"算进婚礼"残留。

## Part 2|四案系统性逻辑审计(报告优先)

对纯文字剧本全文(`docs/generated/steam-demo-01-pure-story-script.md`,必要时回 JSON)逐案跑三类检查,产出报告 `docs/review-archive/logic-audit-2026-08-11.md`:

- **检查一·总结句 vs 案身事实**(最高优先,与 Part 1 同型):比对每案的小尾声/尾声未读/结案卡/能确认·仍未知清单/材料卡里的**概括句**是否把案身已确立事实说反或说漏。**正确值唯一的矛盾可直接修**(离群句回案身,同 Part 1);有歧义只报告。
- **检查二·数字/日期/时长闭合**:每案金额/日期/时长/比例列成账核自洽(案1:35000 月薪、17500×14=245000、余额11600+、他以为15万、房租2×10000、七月停转、20万澄川/20万宸直/5万新阳/49800→3301、"一年半"与"第五个月起十四个月"是否闭合,以及**失业后五、六月仍转17500半薪+房租的资金从哪来**是否需要一句交代;案2:18次/46380、7人4到店、十万→宸直;案3:28.8/28.6/23.8/18.8/30万宸直含20万留女儿/8.4万愿拿6万/领证前进卡;案4:6.8万、14:05/14:22/九天后、报销与返利两条钱路)。**任何不闭合只报告,不自行改数。**
- **检查三·知识账本**:逐拍核说话人此刻能否知道所引信息(案3男方"我从头听到现在"已补锚,核其余各处、含本轮新房租场景的追问)。命中只报告。

报告每条:`案N | 位置 | 类别 | 问题一句话 | 案身正确版本或存疑点 | 已修/待定`。
