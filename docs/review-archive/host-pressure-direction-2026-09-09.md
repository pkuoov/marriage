# 主播主动识别与追问：人物及对白修订

用户方向：主播比多数对话人更有经验，能看穿连线人及其相关人员的谎言、动机和套路。发现疑点即可发问，含糊、绕答与辩解中漏掉的细节都能继续追。连线游戏通过话术和反应呈现最可能的真相，不等待法庭式证明，也不把口播写成边界说明。

## 续改：追着诉求问，点破后留出反弹

后续人工方向已接入：来电人始终有所求。无关绕答可以打断叫回来说事；话里露出目的即可先下局部判断，用它引出找补、反咬、迁怒或断线。允许有脾气的点评和挂断后的喜剧，不要求谈完都接受教育。

赵律师继续提供法律意见，主播负责麦上的关系、利益和话术判断。这里调整角色分工说明，不修改对话框配色。

## 播放回归发现的流程遗漏

第一案在纪念日与借款流水两场后插入现场反应，打断结束直接进入下一场，漏掉对应的场后材料检视。已修正 `liveCounterScreens.js`：同位置的打断按顺序播完后，先回到尚未完成的材料；材料已经完成时才继续下一场。补充实际事件回调测试，验证未完成与已完成两种情况。另补显式的 `flowGroupHtml` 导入，消除该屏幕对浏览器全局函数的隐式依赖。

浏览器回归脚本也补上材料阶段识别，避免在已有圈点结果的复查页误等原句回放按钮。仍保留四处场后材料必须全部经过的检查，未通过削弱断言掩盖漏播。
