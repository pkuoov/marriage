## 已更正的执行单问题

- `ensureNight` / `ensureOvernight` 会写状态；sceneWith 系列并不全是纯函数。
- `nightShellGoodEnding` 间接依赖 normalizedDailyResult 及当前局结果，仅加 state 参数不足以完成下沉。
- URL 函数默认读取浏览器上下文，fresh 还会写 history，不能称“纯解析器 / 零风险”。
- 竖屏根因须看最终层叠规则，不能只修改早期 680px 或已不生效的 grid 行布局。
- hex 批量替换必须避开变量自身定义，防止自引用；相近 RGB 不等于误写，alpha 等价拼写也不等于视觉变化。
- 删除会吞掉开始按钮失败的验收示例，要求核对真实场景、稳定视口、舞台矩形及滚动性。app 容器满高、负 gap 都不能单独证明布局正确。
- 去掉硬性 1200 行门槛；对白框缩高、隐藏阅读按钮和批量令牌化留为独立设计/重构，不归入本轮 bug 修复。
