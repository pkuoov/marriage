本次仅处理新清单 G1，不修改对白、金额、问询、快案分叉或鉴定进入条件。

## 定位与修改

在 `bae1487` 的源码版和重新构建的离线版中，片尾按钮读完对白后可以正常点击；播放期间父容器被 `hidden` 隐藏，按钮测得 0×0。此次给片尾操作区保留位置：对白播放时按钮可见但禁用，读完后启用。没有用 CSS 强制显示所有隐藏选项，也不允许提前跳过对白。

序章原件上次已移出隐藏选项容器，本次没有再次复现其弹层 0×0。聊天与酒店原件均实际打开、核对正文、关闭并返回问询；保留现有实现。

## 实际验证

- 专用浏览器上下文，不重置用户存档。分别检查本地开发服务和 `dist/playable/index.html`。
- 1280×720、1366×768、1280×800、1920×1080：序章两份原件打开、阅读、关闭；片尾打开未读、逐条下一条、信封页出口均实点通过。
- 1280×720 的未读按钮为 160×48；原件弹层为 920×633.59；老来客按钮为 585.5×48。其余尺寸同样大于 0 且主操作在视口内。
- 回归脚本补充从第 0 条未读逐条推进，验证按钮非零、未读完时不能提前点击、读完后继续，原先只从完成的信封页跳过该段。
- `npm run build:playable`、`npm run check`、`node scripts/smoke-browser-replay.js --target=cafe-prologue` 通过。后者覆盖四个 PC 尺寸。

截图位于 `output/playwright/G1-*`，包括原件、首条未读和信封页。定点恢复仅用于到达待查拍点，不代表重玩全部主案。
