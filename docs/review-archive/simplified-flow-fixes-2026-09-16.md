| F1 序章旧配对 | 两轮争议均直接显示现场材料与完整问句。选中即问，删除必经的原句选择、选材料和出示确认。原件仍可展开。 |

| F5 选项质量 | 四主案七幕的错误方向改为金额约定、催款期限、审批经手、提交先后、婚宴安排及退款办理等有依据的相邻问题，回答说明当前争议尚未解决。没有新增配对、预算或惩罚。 |
| F6 重复接话 | 职场第二幕只问一次财务知情依据，陈推给主管后直接接下周是否再垫、如何向财务说明，保留发出两条消息的实际行动。 |
| F7 阅读与验收 | 连续阅读稿使用现行问答；序章不再导出旧配对步骤；已在麦上完成的审批问答不再作为幕间重复出现。重试测试立即检查当前问法，禁止自动点完重播来掩盖问题。 |
