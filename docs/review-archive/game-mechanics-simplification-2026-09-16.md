## 当前玩法

读对白和当前材料 → 有实际分歧时选择完整问句 → 听回应 → 问清后继续。普通交流按玩家阅读速度翻页；问错留在当前段换个问法。

| M2 材料与原句配对 | 四主案七幕关键证据问询改用完整问句，相关材料与当前原话同页展示；删除当前路径的材料下拉框、逐句出示和组合操作。 |
| M3 隐藏解锁 | Tony 必要诉求放入必经对白，直接进入问法选择，不再逐句 PRESS 解锁。 |
| M4 耐心与次数 | 现行主案、来电快案问错不扣耐心、不限次数、不挂断重开；读完错误回应留在本段。旧失败存档回到当前问询，已完成交流及历史预算保留。 |

| M6 HUD 负担 | 隐藏耐心、伪进度和空材料占位；保留当前夜次、已收到的材料及其原件入口。 |
| M7 状态确认 | 合并唯一问句确认、问清状态页和证据命中演出确认；保留真实对白、时间地点转场与阅读翻页。 |

证据问询通过 `acts[].inquiry` 保存开场、完整问句和回应。错问选择单独存档，读档后继续回应；旧材料选择页跳转当前问询。旧 statements／decisivePresent 等字段用于材料来源、稳定 ID、结果记录和兼容，不再作为当前配对规则。

布局按对白、材料、选项纵向排列。修复旧悬浮选项遮住材料、窄按钮造成无效换行，以及选择出现后旧规则把原话抬出阅读区的问题；矮窗口允许滚动核对。
