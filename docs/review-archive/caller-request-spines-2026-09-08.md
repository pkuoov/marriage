## 诉求怎样贯穿一通电话

先写清当事人希望主播做什么：听自己诉苦、替自己说句话、介绍一个人、提供一段能发出去的话，或帮忙解决眼前的问题。一个人可以同时有几种需要，但每案应有一个最牵动她下一步行动的主诉求。

“隐瞒部分信息来求助”是求助方式，不是另一种目的。真委屈、真需要帮助与有意省略可以同时存在。揭开省略后，要改变帮助的内容或条件，不能把所有来电都改成主播抓坏人，也不能让人物忽然放弃原先想要的东西。

| 写作时区分的需要 | 主播被要求交付什么 | 本轮主要落点 |
| --- | --- | --- |
| 情绪支持 | 愿意听、承认难受、帮助理解对方反应 | 快案二；Tony 案的感情受挫 |
| 判断与话术 | 一个立场、一句可转发的话、一段能拿去谈判的说法 | 信用卡、彩礼、快案二后段 |
| 现实解决 | 催款办法、下一步动作、找到能处理事情的人 | 职场、Tony |
| 资源与信用 | 候选对象、介绍机会、主播的一句推荐 | 快案一 |

`helpRequest.kind` 现有 `explanation / interest` 分类继续兼容使用，不为本轮设计新增枚举。丰富人物需要写进请求、行动和对白，不能只多填几个标签。

每次改稿按下面顺序检查，缺哪项补哪项：

1. 写一句她希望今晚带走的东西，再写为什么找这个主播、为什么现在来。来电时点没有素材支持就标待补，不凭空加催款期限或私人消息。
2. 接上人物隐瞒 ID：哪项事实会让主播改变答复？她为什么觉得先不说更容易得到帮助？
3. 把每段陈述记成“她刚受到什么压力，所以换怎样的说法，仍想让主播做什么”。不能只有事实升级，没有请求的延续。
4. 设计一个回应来检验诉求：主播愿意帮其中一部分，却需要她说明一件事、接受一个条件，或承认对方有权拒绝。她下一句选择保哪一头，戏才继续。
5. 写最后还在争的具体结果。可以拿到有限帮助、谈崩、换一个要求或暂不决定，不要求被说服、道歉、接受作业。
6. 连读时检查：主播为什么还在问、她为什么还不挂、下一段为何接得上。拿掉这段若不影响她争取结果，也不改变判断，就考虑合并。

以下保留初稿的拟补方向；实际接入部分见页首最新记录，其余口语示意仍不视为定稿台词。

## 主案一｜沈：把共同储备说成自愿供养，能继续拿就拿

最新作者事实：她以未来共同生活、替两人存钱为理由索取每月一半工资，男方另付房租。她后来花掉这笔钱，来电却强调是对方自愿养她。供养可继续就继续拿，转账停了情感投入就撤，拿不出才找理由切断。恢复给付是托辞或试探，不是与退出互斥的真感情目标。以 [最新主线](credit-mainline-2026-09-08.md) 为准。

| 阶段 | 她要主播支持什么 | 对应反转／状态 |
| --- | --- | --- |
| 开场 | 旧钱不退、新八万不出，理由是自愿给她花 | 现稿已有拒付；需强化她对半薪名目的说法 |
| 房租另付 | 承认两人过日子也花钱，继续淡化代存 | 另付房租是追半薪用途的入口，不等确认后才允许问 |
| 原约定揭出 | 钱曾说留给共同生活，但也不能一分不花 | 作者已定代存名目，正式问答及原始聊天待补 |
| 关系去留 | 能恢复付款就留口子；不能就让主播帮她把分手说得有理 | 同一个获益目标的条件性策略，不能机械禁止恢复给付话术 |
| 最后 | 想只带走不退钱、可分手的结论，省去存钱约定 | 主播拒绝替她改写收钱理由，按已问出的动作点明供养与退出 |

高潮是共同储备被改说成纯供养，余额是承诺落空的结果。原先写成男方纯凭空估计、双方从没谈过用途的理解撤回；十五万具体数仍是男方估计。尾声关于男方借钱理财维系供养及“恐怕兜比脸干净”的方向保留。

## 主案二｜陈：钱帮我催回来，后面的活动还得给我

**主诉求：拿回六万八，尽量保住主办机会。** 她还想留下过去靠垫款分成获利的路。来电不是求一堂职场课，而是找一种不惹主管、还能把钱催到手的办法。

现稿已有信用卡账单出来、报销未到这一压力。她不敢在公司群公开问，找主播是希望得到比自己直接催问更有用的办法。

| 阶段 | 她此刻最想解决什么 | 请求怎样随剧情变化 |
| --- | --- | --- |
| 第一夜开场 | 催回真垫款，同时不影响继续分活动 | 希望主播帮自己判断怎么开口，先把主管当必须维护的关系 |
| 谁垫谁办、往年多报揭开 | 保住主办与四千收益的合理性 | 把多拿解释为忙活动的回报，仍希望主管优先处理自己这单；W1、W2 |
| 第二夜发现其他部门也被欠 | 确认自己的钱还能不能拿到 | 她对流程的信任动摇；未知的公司欠款不能倒算成她一直知情 |
| 包干草单与虚列费用揭开 | 放弃四千，先救六万八 | 请求收窄，但不能借放弃未到手分成抹掉 W3 的参与 |
| 案后扩大到经营与押金 | 等待真实垫款的处理结果 | 调查主线超出她个人所知，靠多处材料推进；不能让她替集团交代真相 |

**保留的看点：** 她对实际欠款有正当要求，又希望解决问题时不损失原来的获利渠道。主播的帮助变得更具体，事情却更难办了，不能写成揭穿私心后就没有欠款问题。

**改稿重点：** 第二夜开头继续带着“能否先还我这笔”的焦急。宏观线索出现后，仍交代她这笔钱的状态；不虚构已经到账，也不靠一段金融讲解代替她的反应。

## 主案三｜林：替我证明他没诚意；谈不成，也别让我难看

**主诉求：拿到支持现有付款条件的理由，借主播把压力施加给男方。** 她问“是不是没诚意”，真正影响周末行动的是：男方是否按她的条件付钱、两家还见不见。

周末饭局给了现成的来电时点。主播公开判断比她继续和男方争更有分量；临时同麦使她从索取评价转为要求主播当场推动男方让步。

| 阶段 | 她向主播要什么 | 保住什么、转嫁什么 |
| --- | --- | --- |
| 开场 | 判断男方是不是隐瞒家底、没有诚意 | 先把自己放在父母与男方中间，少承担报价主动性；P1、P2 |
| 第一轮说法被追问 | 支持普通家境的男方应多给保障 | 承认自己赞同条件，仍拿母亲先报价作退路 |
| 第二夜对出资 | 让男方先付到个人卡，认可她家以后也出 | 用两家都会出遮掉时间、账户、用途差别；P3、P4、P5 |
| 男方提出共同安排 | 继续追男方还有多少钱，争取保持原条件 | 不肯把自己的保障资金按同样方式交出，试图把话题拉回他的诚意 |
| 取消饭局 | 让男方配合说忙，保留自己对母亲和介绍人的解释 | 金额没争下来，转而争取消原因；P6 已接入，双方未和解 |

现有取消理由争夺可作为完整样本：她输掉一个结果后换了请求，人物并没有被问成没主意的人。后续朗读重点是这些请求之间是否自然接上，不再追加同义的“你到底同不同意妈妈”。

### 同麦男方：让我把拒绝讲完，不接受条件不等于差两千

他需要在被公开判断家底、诚意之后取得答复机会。先交工资卡有选择性；同麦后应亲口澄清“拿不出”里还有“不接受这个安排”，不能让主播全替他说。

他的请求由纠正学校和账户范围，进入提出共同用途，再到取消饭局并照实解释原因。可以拒绝公开全部资产，也得承担早先含混表达引出的争执。最终要保住的是拒绝付款条件和拒绝替她编理由的权利，不必另造一项坏事来平衡女方。

## 主案四｜何：承认我被伤害，再帮我把十二万要回来

**主诉求：追回钱。** 情绪上想确认自己不是自作多情；策略上希望主播按恋爱被骗公开施压。三者彼此借力，也会在名单和代投事实露出后冲突。

现稿求助发生在听说产品可能出事、翻出并裁剪名单之后。她选主播，是希望公开说法能迫使 Tony 回应；强光和敲门发生在来电过程中，不倒写成她预先求助的唯一原因。

| 阶段 | 她希望得到的帮助 | 请求如何保留或转向 |
| --- | --- | --- |
| 第一夜 | 认定 Tony 把感情当工具，支持要回十二万 | 给亲密经历和半张名单，希望主播顺着养鱼骗钱去讲；T1、T2 |
| 裁图与高息被问到 | 即便我想赚利息，也请你承认他利用了我 | 尽量保住感情受害的解释，不愿让主动性覆盖 Tony 的行为 |
| 第二夜代投揭开 | 我确实求他买，但钱在他那里，你帮我问 | 追钱目的不变，帮助路径转到收款后的真实履行；T3、T5、T6 |
| 凭据仍不齐 | 让 Tony 交代我这笔，而不只是继续拖 | 可取得要求本人回应和提交材料的具体帮助，不能用已提交替代成功认购 |
| 拟补的最后争取 | 材料可以补，你还能不能替我公开把钱催回来 | 给她一次讨价还价：愿意交完整聊天，却仍想让节目使用更有压力的说法 |

**现稿缺口：** 结尾容易退成合同清单。应把“拿到东西之后，我的钱怎么办”接回她本人；不能裁图一揭开，她的受伤与追款就全消失。另一人回单的反转仍是 [前轮重构提案](dramatic-stakes-rebuild-2026-09-08.md)，不能在本轮当成现成证据。

## 快案一｜罗：给我介绍，但要按我后面补的条件替我筛

**主诉求：取得合适男性的实际介绍机会。** 后段进一步索取主播的推荐信用。她找林旭阳，是因为他手里确实有登记候选人；这条资源关系要在前面说清。现稿没有必须当晚解决的期限，普通来电机会已够，不补催婚倒计时。

| 阶段 | 她想拿到什么 | 对应的前后说法 |
| --- | --- | --- |
| 初述 | 凭低要求、能独立生活的形象进入候选名单 | 先让主播觉得容易介绍，别一上来报完整筛选表 |
| 说好话、爸爸、生育依次被追问 | 澄清到足以继续获得介绍 | 分别改口，不因不愿说明私人经历就自动被写成撒谎；用户指定的揭露顺序保留 |
| 主播重问要求 | 更稳的经济条件、可接受生育顾虑、分担房贷的对象 | 将第二轮要求叠到前轮说辞上，才看见她想解决的现实生活问题 |
| 尾段 | 主播先向候选人说她可靠、替她降低接触门槛 | 一开始不愿好好说话，求推荐时却会恭维；想拿推荐，又不愿说清会影响介绍的信息 |

**作者方向保留：** 长期被经济供养、生育顾虑、继续需要生活费用。具体持续往来和负担尚待确定；主播能判断到哪一步，要靠后续实际铺设。不能只因非亲生“爸爸”或检查经历直接判定全部关系。

**现稿缺口：** `helpRequest` 只写介绍对象，未写实际筛选与推荐责任。下一稿集中在她拒绝哪种符合口头条件的候选、希望别人具体承担什么，缩短找人过程。她要的是能成的介绍，不是专程来跟主播吵架；这是与未来快案四的区别。

## 快案二｜周女士：先告诉我没那么差，再帮我让他回来

**前段主诉求：理解男方为什么退出，得到情绪支持。后段转为修复关系的话术。** 她确实喜欢对方条件，也确实可能因为被退出而难受，不把难受全写成策略。

现有时点由男方突然退出触发。她需要主播这个旁观者解释，并希望借较小版本的事件获得有利判断。她没有直接承认自己要“骗他回来”，不能让作者旁白代她承认。

| 阶段 | 她希望听到什么或得到什么 | 怎样继续维护请求 |
| --- | --- | --- |
| 开场 | 一次没及时回，不该否定我的认真 | 把退出压缩成消息事件，希望有人理解委屈 |
| 聚会和时间线展开 | 这些事都有理由，仍不能说明我不认真 | 用生日、毕业、不喝醉等分类缩小出去玩的次数 |
| 截图与同场人物被问 | 别把这段关系全判没救 | 修补当晚情况，但男方实际看到哪些内容仍不能代填 |
| 现稿最后请求 | 帮我想一句，我照着发 | 从求解释转向争取恢复联系，认可男方条件合适 |
| 拟补的尾段 | 能挽回，同时别让我把责任全揽下 | 面对一段承认具体遗漏、不给对方压力的消息，她对哪句不愿发，才显出仍想保住的面子 |

**下一稿不要预设她必定要男方道歉。** “想让对方回来并先低头”可作为强化方案，但现稿只确认求一句消息。先写她对具体消息的修改意见，若确实要求对方先认错，再把这个目的落实到人物嘴里。

结尾可保留犹豫。主播愿意帮她组织诚实的表达，却无法提供一条保证对方回来的话。不要用“等一等、我再想想”直接跳过她对建议的反应。

## 快案三｜公开长文双方：分别争什么，不伪造来电

| 人物 | 现有公开诉求 | 需要保留的冲突 |
| --- | --- | --- |
| 顾，长文作者 | 退回声称已付的三千万，撤声明、认全文 | 财产请求延伸到要求对方认证私事叙述；自己保留虚构标注，却要对方替全文负责 |
| 被点名女演员 | 公开否认自己为了钱出卖爱情 | 回应维护感情与名誉形象，却没有具体答三千万；款项性质和中间人授权仍未落实 |

这里写的是他们向对方和公众提出的要求，并非向主播求助。女演员维护工作和名誉可以作为作者动机分析，不写成她已来电请求主播压新闻。

`helpRequest.request` 目前混入玩家如何点评的玩法说明。后续整理内容元数据时，应把节目本次要讨论的问题，与公开人物要达成的结果分开。阅读四段文章不会凭空让作者产生四次现场改口。

## 麦外人物怎样牵动来电诉求

沿用人物隐瞒账，补清其对主线的作用；不为短留言硬造完整回合。

- 信用卡男友向沈要八万，提供摘录是想催她转。被发现失业与投资后仍有还款压力，但节目不替他把“她应当有存款”变成已确认余额。
- 职场主管要活动有人垫款、有余款可分，又不想自己扛催款责任。他的回复要让陈面临实际取舍，不能只重复流程在走。
- Tony 目前坚持私下提供材料、拒绝上麦。合理请求是别替未明事实定性；是否借此拖延履行要由具体回应判断，不提前坐实钱已被他吞掉。
- 彩礼介绍人与父母的表述影响林的筹码，但成交利益、家庭期望与林自己的加工分开登记。没有当面请求的部分，不写成他们已经委托主播促婚。
