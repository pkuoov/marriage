# 六案剧情与对白修订记录

日期：2026-09-07。依据：[六案复审](six-case-story-review-2026-09-07.md)及用户本轮接入授权。四个主案、快案二与快案三已修改；快案一的人工作业不在本轮改动范围，BGM 未调整。

本轮先修实际发生的事、各方知情和可玩顺序，再改接话与口气。保留人物的答偏、反复和歪理，不把所有案件套成“两轮认错”。这里的“已处理”表示已落实本轮修改方向，仍需人工听读判断效果。

## 可直接审阅的稿件

- [连续故事台本](../generated/steam-demo-01-continuous-story-script.md)：主案沿一条合法路线连读，适合检查因果；未选旁路在附录。
- [两个快案的编号对白稿](quick-dialogue-revision-review-2026-09-07.md)：剔除制作字段，可直接用段号批注；单人口播的三选一点评并排备审。
- [纯剧情台本](../generated/steam-demo-01-pure-story-script.md)：主案各路线的对白，适合逐句改口气。
- [完整台本](../generated/steam-demo-01-full-readable-script.md)：独立快案在“独立模式：直播快案”部分，按每轮陈述、可选追问和结尾阅读；也可核对其他选项与制作字段。

## 同步和回归

案件 JSON 是真源，人物卡、意图合同、相邻问答锚点、幕间交接、章节与时间线已随改动同步。旧主线审计保留为历史记录并加修订入口，不能继续用已退役台词覆盖新版。

旧测试中强制某句话、认错方式、收尾页数和旧排序的部分已按本次因果改动更新。金额、材料边界、授权、追问入口与实际推进的检查仍保留；额外补了两组行为回归：

- 快案二 8 条有效点击路线（含同一问题的不同原句入口），快案三 243 种三选一组合，逐条检查当前可见锚点、来源不越过未来轮次、对话进入及结案。
- Tony 警方与转款陈述分开；彩礼取消饭局晚于出资；案一回放诉求必须在证词墙后真正播放。

快案沿用原有流程指纹：旧顺序的中途进度回到入口重听，同版进度保留。主案沿用原有内容刷新；此次没有增加存档机制，旧流程跨版本中途跳转的全部历史状态未穷举，人工审新稿宜从该案开头进入。
