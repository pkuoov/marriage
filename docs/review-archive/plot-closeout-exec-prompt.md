## P0-1 案1：第一夜账单「只挑男装」与重述对齐

**文件：** `content/packs/steam-demo-01/cases/01-credit.json`

**问题：**

- 某 claim 的 `version`（约「我先看见右上角那个数…餐厅、礼物…设备…四万…男装五千」）已把共同消费念全。
- 同段 `revisedVersion`（「……我刚才光说他买衣服…」）与上一句同夜矛盾。
- 夜B 设备追问仍写「你开场只说他买了五千左右的衣服，为什么没提这一万二…」（约 `question` 字段），与第一夜已提设备冲突。

**作者意图（必须恢复）：** 她先咬约五千男装控叙事；约四万共同消费是被追问/`revisedVersion` 才认；设备「买给我」的受益承认更晚。

**做：**

1. 改第一夜账单 `version`：第一眼/主动叙述**只强调男装约五千、大衣两千多**；对餐厅/酒店/礼物/设备最多一笔带过「后面还有好几页我没细看」或完全不报四万结构——**禁止**在 `version` 里主动报出「差不多四万」。
2. 保留或微调 `revisedVersion`：在被材料/追问逼出后，才承认四万与她有关；「刚才光说衣服」必须对得上改后的 `version`。
3. 同步 `contradiction` / `selfServingOmission` / `callerStake` 里「念卡时只盯男装」的描述，避免作者备注与台词反向。
4. 改夜B 设备追问：不要说「开场/昨晚没提一万二设备」；改为「为什么**先咬五千衣服**、把设备说成跟你无关」或「为什么**弱化这一万二是给你买的**」——与第一夜实际台词一致。
5. 若有 helperHint / 板书「还差至少三万五」依赖她已报四万：改为由**主播拆账**或玩家追问后才出现，不要依赖她主动报四万。

**验收：** 单路径通读第一夜→重述→夜B 设备问，无「她刚说完又假装没说」；纯台本重生后 P0 自打脸消失。

## P0-2 案1：房租受益人必须可挣得 + 有反应

**文件：** `01-credit.json`（流水 `case1-bank-flow` / `r01b` 等行追问已有「这是他自己住的地方？」→「不是，是我住的」）

**问题：** JSON 有追问，但纯台本主路径几乎看不到麦上确认；男友短信「房租另外算」后她无反应，发现链像作者剧透。

**做：**

1. **验证可玩性：** 白天圈选房租行后，该 Q&A 必能触发；若被 `gate`/可见性挡住，修门槛（仍要求玩家先见流水，禁止自动吐真相）。
2. **夜B：** 男友短信出现「房租另外算」后，加 1 句咨询者短反应（愣/换话题/「他不该在这说」），并确保若白天未问房租，此处可被主播追问补上「是我住的」；若白天已问过，则改为羞愧确认而非整段重演。
3. 赵律师广告/结案若提「房租还没算」，须默认建立在玩家已挣得或夜B 已公开之后——不要在玩家零追问时用旁白替她承认。

**验收：** spine「房租须追问才成立」在 playable + 纯台本主路径可见；男友揭房租时她不是哑巴。

## P0-3 案1：订座「白天已认」不再整段重演

**文件：** `01-credit.json` → 白天带回 `餐厅拒绝核对` / `常客的轮订规律` 的 `firstConflict`，以及夜B **固定**纪念日/订座叙述块（含「他说两周前订的」一类）。

**问题：** 条件分支已承认订座在自己手机 /「只为我」是自己加的，固定块仍让她再谎一次。

**做：**

- 已带回上述物件时：跳过「他说两周前订的」完整撒谎段，或改为主播一句「你下午才认过，别再改口」+ 她短承认。
- 未带回时：保留完整撒谎→拆穿。
- 检查 `both_performed` 类并置文案，避免与单一分支互斥。

**验收：** 强调查路径夜B 不因订座二次撒谎出戏。

## P0-4 跨案：收播新闻防「连载阴谋」误读

**文件：** `content/packs/steam-demo-01/manifest.json` → 收播新闻（约 `headline`:「宸直信托全部产品暂停兑付…」）及紧邻旁白/主播反应。

**做：**

- 在新闻 `body` 或紧随其后的主播/旁白**加一句 framing**（口语、一句即可）：四通来电**不共享当事人网络**；宸直是社会背景风险，**不能倒推**任一案「钱已经没了」或「同人同案」。
- 不删暴雷新闻；不削弱案1/2/3 各自边界句。

**验收：** 纯台本收播段读完，不会合理推出「今晚四人都是宸直受害者同盟」。

## P1-1 案3：广告句撤回「算进婚礼 / 希望回来」

**文件：** `manifest.json` → `afterCaseId: "03-profile"` 广告间隙，林旭阳句：

> 她家已经把九月底的钱算进婚礼了。希望到时候真能回来吧。

**做：**

- 改为符合结案纪律：父亲原话是**留给女儿本人**；**未到期不能算可用婚礼资金**；不要「希望回来」预支兑付。
- 示例方向：「她把九月底那个日子说得很满，可父亲原话是留给她本人，而且这页也不能保证到期能取。」（可改写，勿照抄成 AI 腔）

**验收：** 与案3 `caseClosing.nextStep`、表妹尾声「不算进婚礼预算」、赵律师「不能说拿不回来」同向。

## P1-2 案2：Tony 结案留言补身份轨

**文件：** `02-tony.json` → 对方后台留言（约「她那边酒局多…不能就说我吞了钱。」）

**做：**

- 在现有认账（酒桌/花/不确认恋爱/十万宸直话术）之外，**加一句对项目介绍的明确态度**（三选一即可，保持可恨可辩，勿变纯反派独白）：
  - 承认擅自写入「方便谈客源」；或
  - 称「她口头说过可以帮忙带客人」；或
  - 推给「对方要看联络人，我填了常用联系方式」——但**不能**改成「她书面同意」，也不能否认姓名手机号出现在介绍里（事实已立）。
- 不坐实十万已吞；不推翻「十八次做完不自动全退」。

**验收：** 结案三角里身份轨有对手方回应，不只主播独白。
