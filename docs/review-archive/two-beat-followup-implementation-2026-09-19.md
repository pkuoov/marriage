# 两连问清单审读与实施

依据：`project-skills/case-scriptwriting/references/two-beat-followup-prompt.md`。总体方向成立，已在点名的对质处实施，未增加场景、材料、秘密或必经选项。

## 接入情况

- 信用卡：不信加班后追“以前转来的也不拿出来”；代存原话摊开后追“数和约定都认了，为什么变成给自己花”。停缴处取消上一单的二选一句式，改问工资到账有没有给看。余额未新增精确数字，指定台词保留。
- Tony：第一夜追早已听过高息却只肯讲名单；第二夜把省略代投的长评语收成两连问，由她反驳“我先要买，但恋爱关系也得说”。合同与退钱留到下一幕。
- 彩礼：第一夜追她同意加价却归给母亲开口；后段完整群聊已经出现，才把只报数字、隐去进卡时点和额外支出合成一拍追问。她自己的同意仍在回应中说清。
- 职场：两条有效材料问法都接到“财务没确认优先，还准备垫吗”。他先想等旧款回来再垫，收到主管原话后，再问“不垫下一场，这笔还能下来吗”，随后落到催款与拒绝再垫。没有重开四千盘问。
- 快案一：只在可选交流里追问何时告知，不说还要求介绍是否说得通；她反驳会在见面聊得来时说。生育仍不承担通关。
- 快案二：追“难受却回还行，还指望对方看懂吗”，保留她怕被追问、维护自己并未故意晾人的回应。
- 快案三：口播只对照名字照片与虚构标注，不借第二问提前评论代孕或热搜。

## 没有照抄的细节

1. Tony 开场原话是“昨晚看见名单”，不是“今晚刚被骗”。追问沿实际已播时间，不把听过高息等同于已知被骗。
2. 彩礼第一夜只已知母亲说“钱先在你手里”；具体领证前进个人卡还未揭开，因此此处不提前说破账户与付款时点。
3. 生育顾虑没有被她明确说成永远隐瞒，第二问用“要是一直不说”的条件句，允许她反驳，而非提前认定她拒绝告知。

所有两问都写在对质 `lines` 的 host，按钮 `question`、入口 `entryQuestion`、单句 `hostLine` 没有新增双问号。既有问句、选项、场景 ID 和必经顺序保持；未改存档模型。
