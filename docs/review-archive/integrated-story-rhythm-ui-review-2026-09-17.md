## 结论

操作简化已经落地（满句直选、错问留在本段、不扣耐心、原件只读）。现在的问题不是再加一套系统，而是三段接反了：

1. **夜里该密的戏被切碎。** 「先听完整段陈述」标签很多，内容常常一两句；随后一个指定反驳、一个「继续」。没有逆转那种「一段证词 → 集中开火 → 改口停顿」。
2. **揭露靠投喂，不靠出示。** 关键材料在主播刚好需要时由后台弹出；经营亏损和押金归集放到收播讲座。玩家很少得到「打中了」的停顿。
3. **该空的白天和收播过密，UI 还把碎戏再切一刀。** 案一白天是二十行流水表；案二关灯后才讲单柜亏五毛。每个短段之间再垫无动作的「继续」，朋友圈三选项挤在截图边上。

保留：直接选完整问句、唯一接话直接播放、错问当前段重选且不惩罚、不恢复配对／耐心／圈选。改的是段落任务、问句价值、挂断前态度，以及会挡戏的共享界面。

## 保留基线（改稿时不要动）

- 满句问询、错问不重播开场、材料与问句同页、原件只读。
- 序章酒店 → 转账两轮满句对质；酒店材料的来源、质疑与回应齐全，转账来源另行补齐。
- 案三第二夜共同账户、取消见面、条件不改却要对方说忙。
- 案四隔窗观察、敲门中断、「修刘海问两遍不嫌烦」。
- 跨案宸直线索各自独立，尾声通报只确认已追过的事。

不恢复：逐句回放、材料配对、PRESS 解锁、耐心血条、不可重试的收口考试。不要为「像逆转」加开庭皮肤或无用地图。

## 节奏：骨架像逆转，波形反了

对照是**信息何时密、何时空**，不是玩法皮肤。逆转一轮大约是：证人先把谎说完 → 玩家开火 → 改口／崩溃停顿 → 下午透气并捡到明天的弹药 → 再开庭一次打完。

| 段落 | 现密度 | 应承担 | 问题 |
| --- | --- | --- | --- |
| 序章咖啡厅 | 中→高 | 小型开庭 | 两轮出示成立；程序和法律交接偏长 |
| 案一第一夜 | 中，碎 | 第一场庭审 | 第一夜三个普通陈述阶段；打到她消费四万后压力转去男方 |
| 案一白天 | 过密·无戏 | 低压调查 | 周会计只报工资，未带来发现；借款认购三行无人点 |
| 案一第二夜 | 高，碎，无峰 | 高潮庭审 | 逐题到货；「主动赠与」后直接收麦 |
| 案一收播 | 中 | 舒缓 | 赵律师在此第一次讲清产品风险，讲座占了生活 |
| 案二第一夜 | 中，填空 | 庭审 | 回扣问出来了，公司怎么赚钱没上麦 |

各段按任务安排：夜里给足陈述、集中问询和反应，白天由发现推进后续问题；不设置出示、场次或信息峰值配额。收播只消化已问过的人，或只抛一个明天要查的钩子，不要讲新课。舒缓靠汤、面、工牌，不靠加地点。

## 剧情与问题逻辑

优先级按改稿顺序，不是按发现顺序。身份错误会污染所有后续台词，所以先统一人称。

### P0 身份

- **职场陈是男性。** 立绘为短发衬衫男；用户实机也按男性理解。玩家可见文本仍大量用「她」：`continueLabel`「听她说公司的安排」「听她接下来怎么说」，白天「看她的审批页」，财务朋友「她的发票」「让她问公司财务」，舞台「她停了一下」，以及共享默认标签「先听她说完」（`sceneScreens.js` 写死）。统一改指陈的「他」。不要全局替换，财务朋友、部门助理等女性角色保持「她」。
- **周会计前后矛盾。** 序章「转给她」，案一白天「你问他……他放下外套」。按同一人物设定改完两处及相关出场，不要各改一个字凑数。

### P1 案一／案二重排

- **完整陈述，再集中问。** 先让来电人把本场立场讲清（诉求、理由、有意省略），再集中问相关争议。案一第一夜有三个普通陈述阶段，全案两夜共五个；是否合并按接话断裂判断，不设每夜场数上限。陈述完整到能复述主张即可，不设句数配额，不错问后整段重听。
- **合理问题不是错题。** 职场「运营维修是否交得更晚」、Tony「催退款有没有答应日期」、案一「理财什么时候能取」、彩礼「男方领证前能给多少」都有依据，现在却不能推进。区分为：本段必要追问（推进）、可选补问（记录已问、回到本组、不播纠错口吻）、确实无依据的指控（短拒）。不要为凑三个按钮把有用问题判错。
- **案一立场与收口。** 第一夜后半段已见她挑男装、回避自己消费，主播却转去替她追男方三万五。三万五可以问，但要并上「你自己这一年花了多少」。第二夜在「主动赠与」之后必须接代存原话，挂机前当场指出她虚荣、要钱、只讲有利事实；给她一次抵抗、翻脸或主动挂断。判断在麦上，不恢复结案报表。男方失业可以说破，不要用它冲淡已经成立的女方问题。
- **收入→设备、报销残句。** 「花多少」之后先让她回避金额，再由主播点名账单里那一万二设备。餐厅回应收在「就是喜欢去那家嘛」，删「报销」。
- **材料要索取，不要按点到货。** 白天看见 r13–r15，只形成「用途要问本人」。代存原图、做脸聊天、离职通知：主播先点名缺口，再收到。不是新的换材料小游戏。
- **理财与公司经营前移。** 周会计顺着已看见的流水提「居然也买理财了」，主播当天查阅当前能看到的介绍，收播再研究「为什么有人愿意借钱也买」，不在案一讲完暴雷。案二第一夜问公司靠什么挣钱、铺这么大赚不赚；来电人只答自己知道的宣传。白天／收播用融资稿检验这句话，不当庭一次性讲完资金链。
- **序章三笔流水补来源。** 酒店截图已有平板同步和质疑。转账材料要有取得过程，并与「这两个月不让我看账户」相容。不能因为酒店来自平板就默认银行材料同一来源。

### P2 案三／案四／快案／尾声

- 案三：合并学历／「学费≠余额」；压短接麦确认、礼物退款、重复同意。表妹截图反应保留，不要拆成一串确认页。表姐的新信息应引出「为什么给工资卡时不说明范围」；其他账户和付款条件已问过，不再重复盘问余额。
- 案四：前夜并成一段亲密经历＋裁图动机；夜二从完整转账进入合同／认购／退款。平台函件放到高潮前或融入对话，不要打断「修刘海」。不要再让她为了题目断言「已提交就是买成了」。
- 快案一：生育顾虑保持普通交流，不要做成拆穿胜利。末组问清房贷和背书后拒绝即可。
- 快案二：合并「谁在场／怎样解释」；结尾明确指出「你漏说，却要对方先道歉」与挽回冲突。
- 快案三：保持口播，不要伪装对质。不同点评角度要带出不同观察。
- 总尾声：通报拆成可阅读的拍点；四案回信各只交代变化；鉴定结果后给当事人反应，不要立刻改问手续。片尾「维护基本的道德底线是每个人都应该做的」仍在；案内去说教不授权删这条已批准字幕，若改需单独决定。
- 「某直／宸直」统一为已有的宸直，不为避讳加平台禁词支线。

### 不采纳

- 挂断前错问不许重试、带错结案。
- 把历史 `stageJudgement` 金句当现行证据机械搬回（案一当前现场句是「就想在我这讨个说辞糊弄人家」，不是「这通回放可没那么好剪」）。
- 用旧「下个月还抢吗——会吧」覆盖案二已经作出的「下周不垫」。

## UI（本轮截图＋源码）

证据范围：1280×720 巡屏实机（序章→案一第一夜→白天朋友圈，之后脚本误点「返回追问」空转，**未进入第二夜**）；9 月 16 日 `output/playwright/simple-mechanics` 七幕问询截图；`sceneScreens.js` / `testimonyWallScreens.js` / `evidenceView.js` / `70-dialogue-stage.css`。上一轮 `.focused-evidence-inquiry` 尺寸测试通过，**不能**代替朋友圈页和普通陈述页。

### 已证实

**U1｜朋友圈三选项挤在截图右侧（笔记 2）**\
入口：第一夜挂断后白天「查看匿名私信」，不是连麦当中。1280 宽屏把朋友圈和工作台做成两列，右侧 `evidence-target` 最小高度 68px、三道长句竖叠，看起来叠成一坨；正确项描边压在另外两项上。底部仍写「这张补图里，最该圈的是哪一处？」——圈选已经取消，提示还在用旧话。\
改：选项改到截图下方通栏，拉开间距；提示改成可说出口的问法，不要「圈哪一处」。按这张朋友圈材料从挂断后走进去复验，不能用七幕问询截图代替。

**U2｜无动作「继续」垫在每个短段之间（笔记 1）**\
`renderStatementStageReview` 在 `focusedInquiry` 下仍渲染主键「继续」才打开本段（`data-scene-open-replay`）。舞台角标默认「先听她说完」。对话框是 `position: absolute` 贴在舞台底部，选择层 `z-index: 24` 盖在立绘上。短陈述越多，这种空继续越多，把碎戏再切一刀。序章空景也出现过整屏只剩右下角大「继续」（巡屏 `030.png`）。\
改：唯一下一步且没有真正选择时直接进陈述／问句，不要单独确认页。保留：阅读翻页、多问句选择、打开原件、改变剧情的行动。不能改成强制自动播放。

**U3｜问询页角标与人名牌打架（笔记 7 的同类）**\
案一第二夜材料问询截图：舞台角标「接着问」和说话人名牌「咨询者」叠在原话框左上角。`testimonyWallScreens.js` 的 `frame({ label: "接着问" })` 与名牌抢同一角。这是与用户反馈相近的遮挡；本轮未进第二夜连麦句，但同组件已在问询截图上出现。\
改：角标与名牌错开，或问询页只保留人名牌。

**U4｜原话显示与截图时机需要分开核验**\
既有 Tony、职场第二幕截图在开场尚未读完时拍摄，不能证明错问重选后为空。独立核验首次开场完整播放，以及错问后争议原话是否仍可对照。\
改：重选时保留本段争议原话供对照，或无字时收起该框。

**U5｜共享文案默认女性**\
「先听她说完」写死在陈述舞台。职场案再叠加案内「听她接着说」。改稿时按说话人性别生成，不要只替换职场三个 `continueLabel`。

### 问询主布局（对照，不是本轮主伤）

七幕问询在 1280×720：原话、材料卡、满宽问句纵向排列，主体可读。四张材料时 3+1 换行略参差。这不能证明朋友圈页和普通陈述页同样干净。

### 尚未实机走到

- 第二夜连麦进行中「主播接着问」是否还有第二层遮挡（笔记 7 的原场景）。应用 U3 的修法后，从夜一走进夜二再看一次。
- 窄于 1280 或 1920 的朋友圈页。修完 U1 后补 1280×720、1366×768、1280×800、1920×1080。
- 从用户自己的存档恢复到朋友圈／夜二，不用清用户进度。

巡屏在朋友圈后误点顶栏「返回追问」，在夜一空转约 2600 张图。`output/ui-walk/shots/` 里除朋友圈附近外无新信息；作为历史证据保留。

## 改稿顺序（可直接当执行 prompt）

建议修改范围（用户后续已授权本批实施）：按本文件改 `steam-demo-01` 剧情、问句和共享 UI。不恢复配对、耐心、圈选、逐句必经回放。不改用户现行存档。现行 S1/S6 的「集中问询」包含完整陈述与连续攻防；S8 短收麦不等于禁止挂机前判断——**先改内容，标准另开一小段澄清，不要先改 skill 再找戏。**

1. **人称。** 职场陈→他；周会计按同一设定改序章和案一；共享「先听她说完／听她接着说」按说话人生成。
2. **序章流水来源**一句话交代清楚。
3. **重排案一、案二段落。** 先定每夜：完整陈述 / 集中问哪些 / 挂断前什么态度 / 白天带回哪一个发现。再写台词。理财线与栖行盈利一起安排，避免各案补完又改接头。
4. **重写问句价值。** 必要核实可自动接话；真正判断让玩家选；有用补问记录已问，不判错。问询改变眼前信息：先索取，再收到。
5. **案三、案四定向压缩。** 保共同账户对质、不再垫款的群消息、「修刘海」；删重复确认和函件抢戏。
6. **快案和序尾章**按 P2，不统一愤怒口吻。同步清理阅读稿生成器的 `documentMarks` 与虚假标注输出，删除内容中的无效标注配置；保留必要存档兼容。
7. **共享 UI：** 取消无选择的阶段「继续」；朋友圈选项改通栏；问询角标与名牌错开；错问保留原话或收起空框。用隔离浏览器从挂断前走进朋友圈，再从夜一走进夜二；覆盖 1280×720、1366×768、1280×800、1920×1080。跑 `npm run check`，以及 `focused-credit`、`six-review`。完整通关不能代替：陈述能否复述、选项是否有区别、回答是否接所问、出示后是否改口或行动、高潮是否在跳转前完成、按钮是否还压台词。

验收时连读每个完整交换，不要只看自动点完。
