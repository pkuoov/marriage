## 〇、诊断结论（先读，改时对照）

当前台本表层去 AI 味已较好（几乎无疗愈腔/论文腔；物件与金额具体）。细读仍会被挂上的问题：

1. **证人陈述式流畅**：慌/羞/被追问时仍输出完整、因果清晰、信息齐全的多句回答。
2. **「不是 X，是 Y」节拍过密**（全稿约 24 处）：模型最爱的漂亮反转。
3. **高压坦白认领过干净**：立刻「是我的问题 / 好处我认」，缺否认→抢解释→甩锅→勉强认的中间段。
4. **四案声线在「整理账」时合流**：都变成「我把…翻了一遍」的冷静复盘 intern。
5. **结案卡书面腔**：`不会因此占理 / 这个支持拿不到 / 轻轻带过` 像 LLM 影评。
6. **防备变体像压缩版正确答案**：只变短，不变脏、不变躲。

**目标分数**：词汇层保持 ≥8；节奏层从 ~5 提到 ≥7.5；情绪层从 ~4.5 提到 ≥7；声线分化从 ~5 提到 ≥7。

## 〇.5、硬约束

1. **不改事实**：金额、日期、材料可见性、谁签了什么、仍未知清单，全部不动。
2. **不改结构**：节点顺序、追问树、可选补问集合、闯入事件触发点，不增删分支（除非同一节点内拆成两口气）。
3. **不加可见数值条 / 不写系统提示进玩家可见台词**。
4. **主播声线保持**：林旭阳仍是程序感、克制、偶尔漏私事；不要变成鸡汤主持。
5. **禁止回潮的 AI 词**：边界感、内耗、情绪价值、原生家庭、自我成长、某种程度上、值得注意的是、深刻共鸣、交织、归根结底、本质上、真正的问题是。
6. **语气词有配额，禁止洒胡椒面**：每段高情绪节点 1–3 处即可；禁止连续三句都「啊/呢/吧」。
7. **防备变体必须换情绪策略，不能只删字**。

## 一、六条改写技法（全案通用）

### T1｜三段式抵赖（被戳穿时）

否认半句 → 抢解释/甩锅 → 才勉强认。
禁止一上来「是我的问题」。

### T2｜数字结巴 / 改口

金额、次数、日期先说错或含糊，再自己纠正。保留已有好例子：`一万……一万一千六百多`。

### T3｜撒谎前先拖延

问句后先：反问 /「你等一下」/ 重复问题 / 答旁边的事，再进入正文。

### T4｜删自我注释，留动作

删：`我的意思是 / 我想说的是 / 换句话说`。
留：卡顿、重复、突然改话题、把手机扣上再翻回来。

### T5｜按人设分配「乱法」（声线分化）

| 角色 | 乱法 | 语气词偏好 | 禁止变成 |
|---|---|---|---|
| 案1 沈 | 数数改口、爱把消费说成「一起的」 | ……、啊、反正 | 冷静会计 |
| 案2 何 | 先骂半句再收回、横、护短 | 啊、凭什么、行吗 | 条理投诉专员 |
| 案3 林 | 绕回妈/介绍人、怕家里听见 | ……、那个、我妈说 | 婚恋分析师 |
| 案4 陈 | 先背流程词再崩、怕被说蠢 | 呃、那个、对账 | 合规复盘 intern |
| 男方/对方 | 短、防、推责但不演讲 | 怎么了、凭什么 | 反思小作文 |
| 第三方（介绍人/助理等） | 甩锅边界清晰、少抒情 | 我认、别问我 | 全知旁白 |

### T6｜结案卡去编辑腔

把影评句改成：**主播能当场说出口的短句** + 三条短事实。保留「能确认 / 仍未知 / 下一步」结构，但导语段落必须能朗读。

## 三、防备变体专项规则

每个【若咨询者已经起了防备】节点，改写时必须满足至少两条：

1. **少给数字**（用「一笔」「一年多」「说了有」替代精确复述）
2. **多给拒绝**（「你别问那么细」「先问别的」「我说了不想讲」）
3. **情绪不等于默认线的缩写**：烦 / 怕 / 横 / 累，四选一写进语气
4. **禁止**只是把默认线删到一半字数后粘贴

## 四、改写示例（照这个手感，不要照抄到不相关节点）

**会员被戳穿（案1）**

- 现稿：「……有。会员是我的。跟他在一起以前就办了。那晚，也是我用自己的号订的。」
- 目标：「……不是，那家店是真的难订——你等一下，我不是那个意思。会员是我的。号、号也是我订的。我刚才就是……说顺了。」

**收麦「不是我不说」**

- 现稿：「那三万五不是我不说，是他不说。」
- 目标：「三万五……我不是不说。他不说啊。我今晚再问。问到原话我再来。」

**「是我的问题」（案3）**

- 现稿：「这些我都没告诉你，是我的问题。」
- 目标：「进我卡、婚宴另算、还有那二十万……我都没跟你说。你别——行，是我没说。」

**结案卡导语（案1）**

- 现稿：「……并不会因此占理……这个支持拿不到……轻轻带过。」
- 目标：「八万今天别转。债在他名下，去向他也没说清。她来问过，不等于她没事。十四个月半薪她基本花完了；跟她有关的那四万排场，她也才刚肯讲。」

## 六、验收标准（写作圈细读也能过）

1. 词汇层：无疗愈腔/论文腔回潮。
2. 节奏层：长答（≥55字）在高压节点至少一半带卡顿、改口、拒答或半句。
3. 情绪层：每个案至少 2 处「被戳穿」走三段式抵赖，而不是一句认领。
4. 声线层：沈数数、何护短、林绕妈、陈背流程——乱法可辨。
5. 结案卡：导语可当主播口播朗读，无「占理/支持拿不到/轻轻带过」类编辑词。
6. 事实层：与 spine / 材料结论零冲突。
