# 剥雾节奏：一段一层

日期：2026-09-18。用户要求：剧情矛盾以小见大，逐层剥开；每一段集中询问发现本对话的一个核心问题；几层拼成全貌；最后归纳。现行节奏仍碎、仍抢层。

## 为什么现在没有节奏

不是缺反转，是层序反了，或一段里塞了好几层。

1. **小切口还没打中，大词先出门。** 案一夜二先问云栖，职场夜一先讲押金和宸直，快案三第一段口播代孕和三千万。听众还没握住眼前那块碎片，节目已经在讲全案。
2. **一段里同时打好几层。** 快案一第一轮自动打柜台，第三轮自动打检查，标题上的低要求和一百万都往后挤。快案二第一轮自动打包。玩家不知道「这一段赢的是哪一层」。
3. **碎问答代替剥雾。** 夜里多次「先听完整段陈述」只有一两句，打一下换题，没有「听完这一层说法 → 集中打一个点 → 她改口或停住 → 下一层」。
4. **收麦不拼图。** 要么关灯后补课（职场押金讲座），要么各层散着结束，没有把已经揭开的两三个核心收成一句判断。

正确波形：来电人把**这一层**的说法讲完 → 玩家用一个小切口打中 → 新的迷雾露头（改口、补人、补材料）→ 进入下一层。白天只带回下一层要用的一条弹药。收麦只归纳已经剥开的层。

## 改稿时怎么验收一段

改完一段，只问三句：

1. 听众能不能用一句话说出「这一层揭开了什么」？说不出，就是还在散点问答。
2. 本段有没有提前使用后一层的大词？有，就是抢层。
3. 收麦那句能不能点名已经剥开的层、不再添新事实？不能，就是讲座或报表。

唯一有效接话自动播放仍按 S1。自动播放的必须是**本层**那一个核心，不能是旁支。
