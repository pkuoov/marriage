# 第 32 批·案3 补上男方上麦的"知识来源"锚点(单点逻辑修复)

你是本仓库的实施工程师。判决来源:反转细节冷读(2026-08-04,聚焦逻辑严密/反转清晰)。案3唯一一处逻辑破绽:**男方上麦第一句就展示了只有直播里才有的知识,但"他在看直播"的交代来得比他展示知识晚十几拍。**

## 诊断(已核实)

- 位置:`content/packs/steam-demo-01/cases/03-profile.json` → `overnightStructure.liveCounterBeats[1]`(id `profile-gift-mic-request`,kind `interruptToast`)→ `lines[1]`(role caller,speaker 男方)。
- 男方上麦第一句:「我是她说的那个人。礼物你先收着。我只想问一句:她家开口二十八万八的时候,有没有告诉她,**那三十万还在宸直,眼下根本拿不出来**?」
- 「三十万在宸直、眼下拿不出」是来电人**刚在麦上对主播说的**(麦外无人知道)。男方送礼物只证明他此刻在看,不证明他听见了早先那句。
- 而"男方家也看了直播"这个知识来源,要等到后面介绍人那句「他们也看了直播」才补上——**justification 晚于 demonstration**,初见玩家在男方上麦那一刻会卡一下"他怎么知道的?"。
- 结案已单独总结过"两边都拿不出"(`stageJudgement` 含「你自己的存款和家里那笔还没到期的钱,也是今晚才告诉他」),故**不需要**再加澄清句;本单只补知识来源锚点这一处。

## 修复(逐字,单点)

`liveCounterBeats[1].lines[1].text` 原文:

```
我是她说的那个人。礼物你先收着。我只想问一句：她家开口二十八万八的时候，有没有告诉她，那三十万还在宸直，眼下根本拿不出来？
```

改为(在礼物之后、质问之前插入"我一直在听"的锚点):

```
我是她说的那个人。礼物你先收着——你们说了半天，我从头听到现在。我只想问一句：她家开口二十八万八的时候，有没有告诉她，那三十万还在宸直，眼下根本拿不出来？
```

这一句既补上知识来源(他从头在听,所以知道麦上说过的宸直),又和案1「他在听」的监视母题形成呼应。**只改这一行,同 beat 其余行、后续介绍人「他们也看了直播」一律不动**(那句现在变成对已知信息的确认,不冲突)。
