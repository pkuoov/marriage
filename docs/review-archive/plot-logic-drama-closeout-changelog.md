## 去 AI 味复审

- 男方、Tony 的后台留言删去整齐的自我审判，改成防守、承认一层、保留一层。
- 案二主播判词拆成可逐句说出的处理、批评和未知，不再把结案卡压成一个复句。
- 案三删除“我们把两件事当成一件”的作者总结，改为母亲怎样算、她怎样顺着算，以及学费已经花掉的当场改口。
- 案四删除“我一直拿通知替他解释”式心理注释，改成她真的把通知截给朋友并说过的话；日期错位改为现场认错。
- 最终扫尾继续删掉“我不能替他说”“只能到这里”这类角色自带审查报告的句式，改成直接说看见了什么、哪一栏为空、自己确实不知道什么。
- 材料问句中的“正常入口”改成“公司的正常流程”，避免产品和流程设计腔进入主播台词。
- 对白邻接锚点、证据门禁和剧情锁随新文案同步更新，测试不再强迫台词退回旧的总结腔。
