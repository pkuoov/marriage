## 去 AI 味复审

- 男方、Tony 的后台留言删去整齐的自我审判，改成防守、承认一层、保留一层。
- 案二主播判词拆成可逐句说出的处理、批评和未知，不再把结案卡压成一个复句。
- 案三删除“我们把两件事当成一件”的作者总结，改为母亲怎样算、她怎样顺着算，以及学费已经花掉的当场改口。
- 案四删除“我一直拿通知替他解释”式心理注释，改成她真的把通知截给朋友并说过的话；日期错位改为现场认错。
- 最终扫尾继续删掉“我不能替他说”“只能到这里”这类角色自带审查报告的句式，改成直接说看见了什么、哪一栏为空、自己确实不知道什么。
- 材料问句中的“正常入口”改成“公司的正常流程”，避免产品和流程设计腔进入主播台词。
- 对白邻接锚点、证据门禁和剧情锁随新文案同步更新，测试不再强迫台词退回旧的总结腔。

## 2026-08-13 补充收口

本轮重新对照任务书与现行真源，只执行仍未落地或落得不稳的部分：

- **案一证据来源**：离职结算通知改为第一夜收麦后已发给咨询者。她因害怕只看见文件名，没有打开；男方第二夜同意遮名展示后，通知才进入直播。由此删掉“第二夜临时准备好关键文件”的便利感。
- **案一判词**：删除“虚荣作祟”“花不起的日子硬撑”等抽象总评，改用约四万元共同消费、一万二设备、固定转账、另付房租和实际余额当面对账；主播仍明确拒绝替咨询者省掉解释。
- **案二首场**：首段只保留外表吸引、晚档、替她说过一句和深夜语音；职业玩笑原话与 Tony 的关系顾虑留给玩家追问。警务线原本已在第二夜首场出现，本轮不重复前移。
- **案二判词**：删去“把贪心改成被骗”的概念标签，改为已完成服务、真实特殊待遇、身份擅用和十万元原始记录四项具体责任。
- **案三主矛盾防漏**：修正男方台词中的错误指代，并让插麦第一句固定并排追问“二十八万八领证前进女方卡”与“女方家三十万元九月底以后留给女儿”。即使玩家跳过可选追问，时间与用途不对称仍会进入主线。
