# 一、案 2（`02-tony.json`）：资金池、名单夸大与「她也不是白莲花」

## 1.1 新作者真相（锁定）

**Tony 的真相：凑单吃息差。**信托按档位给息（示例：50 万起年化 7%，凑到 300 万档 9%+，数字定死）。Tony 把熟客的钱凑成大单、以自己名义买高档位（**宸直系产品**），给出资人承诺中间利率，自己吃差价。

- **信息食物链（新增源头）**：最早是她在夜店陪桌时听喝酒的「大佬」吹这款理财收益好——大佬们够得着高档位门槛，小人物只能靠 Tony 拼单摸到那个收益率。小姐妹圈子由此入局，**Tony 是渠道，不是源头**；这层阶级质感（同一款产品，大佬直投、小人物拼单加价）写进材料与台词的底色；
- 「下一次推进」名单 = 资金源 CRM：「能投店」「带客」「可稳情绪」都是出资潜力/维护策略标注；
- 「开店项目」= 收钱的包装；免单、留号、「自己人」= 维护资金网络的成本；
- 另一个女生的十万：名义「一起开新店」，实进信托池——保留为**针对 Tony 的独立执法线**（背景推进，不再是民警上她家门的原因）；
- **民警上她家门的原因改写**：她借了「高利贷」（民间借贷/网贷）去买理财——放贷那伙人被查，民警按借款人名单上门核实。她那晚的慌由此完全自洽：不是因为名单，不是因为 Tony，是她瞒着所有人借的钱；
- Tony 道德灰色而非纯骗子：利息真付过、手艺没坑过人、对她可能有过真实好感（留白，不定论）。

**来电人（何）的五层隐瞒**（洋葱，只能按序挤出）：

| 层 | 内容 | 揭出方式 |
|---|---|---|
| L1 | 「他把我当客源养」，退 4.6 万 + 删名单 | 第一夜自述（保留现状） |
| L2 | 名单是真的，但她念给直播间的条目里**掺了自己加的一句**（定死是哪句，建议最具煽动性那条） | 主播拿她自己交的原表当场对照 →「你念的那条，表里没有。」→ 三段式 →「我加了。不加的话，你们会说这就是普通办卡。」 |
| L3 | 池子里的钱不止自有两万——**还有三万是借的「高利贷」**（数字定死）：利息每天在走，信托那头却拖延无法变现，两头绞 | 民警线逼出：民警是按放贷团伙的借款人名单找上门的。「我没做违法的事」获得第二重含义（借款人不违法，但她瞒着所有人） |
| L4 | 劝她投钱的一直是闺蜜（闺蜜在池子里、利息到过账）；源头是夜店大佬的酒桌吹嘘；表发错前一周她刚答应**再加三万**（正是那笔高利贷） | 随 L3 带出。主播：「劝你投钱的不是 Tony，你为什么只找他退？」→「闺蜜我还要处的啊。」 |
| L5 | 她平时去夜店点男模，台费门儿清；对 Tony 是贪图外貌、想要短期关系，主动推进过（生日花、单独吃饭是她约的） | 她为证明 4.6 万自己上传的支付记录里混着男模台费类目，忘了遮。主播安静问起 → 峰值坦白场 |

**动机重写**：「我们到底算什么」一半是给退钱做的表演，一半是真的（L5 解释为什么）；「只想拿回钱」= 4.6 万 + 池子里的两万；把一切简化成「Tony 骗我」最省事——闺蜜要处，自己的贪心不想认。被问「你想跟他在一起吗」的诚实版：「……在一起倒说不上。他那张脸，谁不想多看两眼。我没想过那种长远的。」

## 1.2 结构改写点

- **C1（P0）第一夜**：现有骨架全保留（发错的表、退钱诉求、酒吧隐瞒、敲门收麦）；她念名单时埋 L2 加料；「我没做违法的事」原句保留，含义后翻。
- **C2（P0）白天材料线**：开店朋友对照旧表保留，新增行业证词（拼单拉客户钱的说法她见过别家做）；她上传的支付记录混入 2–3 条夜店/台费类目（遮名但类目可辨，玩家先看到、看不懂）；新增材料：**拼单利息表**——闺蜜转给她的宣传口径（「到 300 万档多 2 个点」），来源标注她本人提交（交出来是为了证明「不全怪我」，本身就是 L4 裂缝）。
- **C3（P0）第二夜·抓包场**：条目与原表并排 → 三段式（「我记错了吧」→「那表那么乱谁看得清」→「……我加了」）→ 动机吐实。**主播的代价时刻**：当场公开纠正第一夜播出内容（掉热度）/淡化处理（违方法论、弹幕留痕）——无安全选项，可接 drama-depth 机制。
- **C4（P0）民警线含义重写**：民警上门的直接原因 = 她在放贷团伙的借款人名单上（借钱买理财，被上门核实）；另一个女生的十万报案保留为针对 Tony 的独立执法线，**两条执法线不要混成一条**。此处逼出 L3/L4：借的三万、利息在走、信托拖延无法变现、闺蜜劝投、源头是夜店大佬。她的「只想拿回钱」由此变成两头绞的绝望——退不出的理财 + 停不下的利息。闺蜜声线：不是坏人，「利息真的到账过」是她的全部逻辑。
- **C5（P1）Tony 真相拼图**：档位利息 + 凑单 + 中间利率承诺，由行业证词 + 拼单利息表 + 十万去向边界拼出。**不给 Tony 定罪名**：结案卡只写「资金流向与承诺利率有证据，定性是执法的事」。执法信息只透边界内的量。
- **C6（P0）峰值坦白场（L5）**：三段式（「那是陪客人」→「我们那行就这样」→ 停顿）→ 「男模多少钱一小时，我清楚得很。台费、房费、开一支酒多少，我都门儿清。他不收我钱……我以为那是不一样的。」**设计红线：不是荡妇羞辱，是定价觉醒**——最懂付费注意力价格的人，在免单上当了真；发现自己在名单上 = 发现以为无价的东西也标着价。她要退的不是 4.6 万，是那句「自己人」。
- **C7（P0）结案·账人两分**：
  - 账：4.6 万服务已完成、退款站不住多少；名单冒名与资金池归执法；她的两万按合同谈退出；那句加料要不要公开收回（她扬言公开那张表——现在公开对她自己也危险）；
  - 人：「你要退的到底是钱，还是那句自己人？」对闺蜜怎么办（加投的三万叫停）；
  - Tony 结案留言（冷而半有理）：「息差我吃了，利息我也真给过，她的钱翻过一轮，她没亏。名单那句是我写的，可她带来的四个朋友，办卡我没多收一分。要退，按合同来。」
  - 【仍未知】保留：Tony 对她有没有过真实好感；池子总规模；定性结果。
- **C8（P1）跨案**：Tony 池子 = 宸直系 → 终幕「延迟兑付、无法变现」摆上桌后，「按合同来」自动成为全案最狠讽刺（合同写着的到期日，谁也兑不出来）；赵律师广告间隙可加半句「最近来问延迟兑付的咨询多了，什么人都在替他们凑单」，不点破，玩家自己连线。

# 二、案 3（`03-profile.json`）：步步加价的彩礼与户口本里的亲弟弟

## 2.1 新作者真相（锁定）

**家庭的隐藏经济学**：父母不是没钱，是流动性锁死——三十万在宸直未到期（九月底），弟弟婚房首付缺口迫在眉睫，此前已向小舅家借过一轮。女儿的彩礼是全家唯一能立刻变现的活钱。彩礼计划用途：**还借款（弟弟首付）+ 一部分再进理财**。

**最大的雷**：早年父母生过二胎，**亲弟弟户口落在小舅舅家**（计划生育年代的操作），对外是「小舅家的表弟」。她和这个「表弟」关系特别好，有经济往来（借过钱给他付定金）。爸那句「宸直到期拿二十万给她」是谈判话术——那笔钱的真实去向是弟弟。

**报价时间线**（每次涨价紧跟男方财力暴露，理由全是包装）：

| 级 | 数字 | 触发 | 包装理由 |
|---|---|---|---|
| 基准 | 18.8 万 | 表姐当年的数（仅作参照） | — |
| 初报 | 28.8 万 | 听说 MBA 学费 23.8 万自费 | 本地规矩 |
| 转折 | 工资卡 28.6 万曝光 | 「拿不出」被读成「有钱装穷」 | 「差两千就够，说明他不是不肯」 |
| 二报 | 车可以少，现金 48.8 万 | 认定总资产远超工资卡 | 「我们家不图物质」 |
| 终报 | 68.8 万 | 男方家托介绍人试探底线 | 「我们陪嫁也有二十万」（实为弟弟的钱） |

「车可以少，钱不能少」的真实逻辑：车留在小家庭，现金进父母口袋、可自由支配。

**女儿的共谋**（三层，按序挤出）：轻——把工资卡转给妈时加了句「你看，他还说拿不出」；中——知道「车可以少」的真实原因，替家里包装成「不图物质」；重——知道「表弟」是亲弟、知道首付缺口，瞒着男方。心里话（只在峰值坦白场说出）：「爸妈养我这么大，帮弟弟怎么了？」

## 2.2 揭雷链（核心修订：侦探权全程在主播手里）

**三步链，一步不许跳：**

1. **第一夜·主播闻出「急得不对劲」**：她用「家里有笔理财没到期，手头紧」解释要现金的急（家人的官方口径，真实但不充分）。主播追：「就算理财九月底到期，差两个月都等不了？彩礼非要领证前现金到账？」她答不上/硬答。【玩家怀疑：为什么这么急】节点成立——急迫本身成为第一条线索。
2. **第二天白天·男方主动联系节目**（**固定事件**，不占「下午最多处理两处」的名额——本案高潮不可错过）：他困惑、委屈，不知道弟弟的存在。玩家问话三选二（对齐现有白天问话模式），可问出的蛛丝马迹：
   - **表弟的存在感异常**：交往中她多次接「表弟」电话，语气是姐姐训弟弟；说起舅舅家买房，比说自家的事还上心；
   - **经济往来**：他见过她给备注「弟」的账户转账；她提过「借给表弟两万，他买房定金差一截」；
   - **妈的口误**：饭局上妈说过「她跟她弟从小一块长大」，随即改口「表弟」——他当时没多想，现在越想越不对。
   - 表妹群截图边缘那半句「你弟那边还差」可保留为佐证材料（非承重，玩家可拼可不拼）。
3. **第二夜·当麦逼问**：主播把急迫 + 转账 + 「从小一块长大」+ 户口在小舅家并到一起：「表弟的首付，为什么是你家在凑？你借他的两万，又是什么钱？」→ 三段式（「亲戚间帮衬很正常」→「你别把我家说成……」→ 崩）→ **「……那不是表弟。是我弟。户口落在我小舅家。」** → 停顿 → 「爸妈养我这么大，帮弟弟怎么了。」弹幕炸，主播不判分。

**删除项**：男方家托人打听「你们家还有个儿子」的风声线——不采用，侦探活不外包给场外。

## 2.3 其余结构改写点

- **C1（P0）开场诉求**：男方在 68.8 万后放话「你们家这是钓鱼」，两家僵住；她来要背书：「他明明有钱，我们多要一点，真的过分吗？」（与案 1 沈要「一分不出」对称）。
- **C2（P0）第一夜**：学历误会、介绍人传话、23.8 万学费、「差两千」beat 全保留（含义由后续自动翻转）；她转述报价只说 28.8，主播追出「后来……有变化」；「车可以少」作为反常细节首次露头；加上 2.2 第 1 步的「急迫」节点。
- **C3（P0）白天·介绍人茶馆升级**：介绍人是报价时间线的活证人，产出「时间、数字、当时给的理由」三列材料表；玩家在字段检视里圈出「每次涨价都发生在他财力暴露之后」。
- **C4（P0）第二夜·妈进场**：表妹看直播 → 家里知道 → 妈打进来/被迫免提。妈是理直气壮的账房逻辑，不是泼妇：「他有一百个心眼装穷，我们多要点怎么了？我们又不是不陪嫁。」主播用时间线对质：理由换了三套，涨价的时点只跟他的钱走。**妈绝口不提弟弟**，被问「你们家用钱的地方」就挂断/岔开——挂断本身是证词。
- **C5（P1）男方连麦（保留，去掉打听线）**：立场是「我不是拿不出二十八万八，我是看见了你们涨价的样子」；对等条件（共同账户）可保留。**「跟你弟切割清楚」的条件移到结案留言**——他听完直播坦白之后才说得出这句。
- **C7（P0）结案·账人两分**：
  - 账：68.8 万当场拆开（规矩钱/理财钱/弟弟的首付）；「陪嫁二十万」标注未到期 + 去向存疑；她借给弟弟的两万列入她自己的账；
  - 人：婚前重大隐瞒不是钱的问题；最后选择三选一（不判分）：自己告诉男方全部 / 让爸妈去说 / 继续瞒；
  - 【仍未知】：男方总资产与去留；**弟弟本人知不知道姐姐的彩礼在给他凑首付**（留白不答）。
- **C8（P1）跨案**：宸直从彩蛋变根因（钱被锁死 → 只能挤彩礼）；爆雷新闻含义倍增（存量三十万蒸发 + 弟弟首付链条全塌）；案 1（男方隐瞒失业）与案 3（女方家隐瞒动机）成两性镜像。
- **降级项**：表姐攀比线只留 18.8 万基准数字；「饭局沉没成本」可留一句，不再是结案支点。

# 三、案 4（`04-workplace.json`）：逻辑修复与「非白莲花」核心

## 3.1 新核心（A0·P0）：她也跑冒滴漏、配合过领导吃拿卡要，这次是被挑中的炮灰

**作者真相**：小陈手不干净是部门半公开的事，也是同事选她垫款的原因——她新、想表现、且不敢闹（一闹先查她自己）。三层「不白」，从轻到重：

1. **轻**：打车/餐费报销习惯性凑整多报（现有台词「以前最多垫过打车，第二天就能报」翻新为伏笔：报得很熟练）；
2. **中**：收过本次活动供应商塞的购物卡（两三千）；
3. **重**：转正前后帮领导把两张私人消费发票走成部门招待费——领导让办的，她照办，当时还觉得是被信任。

**落点**：

- 第一夜只埋不揭：保留【流程词说得很顺】；对「来不及走流程」毫不惊讶本身是伏笔；
- 白天：供应商门市补部门文化证词（「你们公司来对接的人，伴手礼从来不少拿」）；财务窗口补半句（「你们部门备注『老规矩』的单子不少」）；
- **第二夜·羞耻点坦白场（峰值，对齐案 1 余额坦白）**：主播问「他为什么偏偏挑你垫？」→ 三段式（「因为我好说话」→ 追问 →「因为我……帮领导报过两张票。私人的。他知道。」）→ 购物卡在此层或防备变体带出；
- **对方结案留言改写**（防守 → 软威胁）：「六万八我认她垫过。真要走公开流程，就把部门这半年的单子都摊开——她知道那里面有什么。」；
- **领导批注一字不改**：「老规矩」「别让这点流程问题影响部门这季度的成绩」靠新语境自动变暗；
- 结案：群消息「发不发」成真两难（发 = 追账但引火烧身；不发 = 安全但六万八悬置），诚实记录不判分；主播收束账人两分：「六万八该追，这是账。你那两张发票和购物卡，得在别人翻出来之前自己处理，这是人。」
- 【能确认】增补：帮领导处理过私人发票、收过购物卡；【仍未知】保留：领导是否知情本次垫款、返利是否已支付；
- 主播私线呼应（可选一句）：「我做法务的时候，最后背锅的从来不是拿最多的，是最好用的。」

## 3.2 逻辑修复

- **A1（P0）审批截图硬洞**：那张「报销审批通过」挑明为**冒名顶替**——实为「活动立项审批」页。材料检视新增字段（审批类型/单据编号），玩家亲手圈出「单据类型对不上」。因果闭合：报销单从未被提交，回单号永远查不到；「同一张图发三次」落地为实锤——他不只拖延，是伪证。同步：审批截图材料卡、q04 行备注、财务窗口台词（经办一眼指出编号段不对更佳）。
- **A2（P1）同事动机链**（二选一，推荐①）：① 供应商报价是他定的、高于门市价，走对公要过财务比价，绕开财务视线才保得住高报价和返利（供应商线补半句证词「这单的价是他报的，比我们挂牌高」）；② 本季预算已被他挪用，先斩后奏把窟窿转到她卡上。与 A0 联动：选她，正因为她不敢闹。
- **A3（P1）现实性三补丁**（各一句话）：信用卡额度——她自己申请了临时提额（顺带加深「她多想做成」）；活动为什么急——客户方提前/领导临时加场；发票——财务窗口第一问改「发票抬头开的谁？」她答「公司抬头，在我这儿」。
- **A4（P2）领导责任配比**：结案卡增补——部门存在「先办事后补流程」惯例，绕流程不是她发明的；她的问题是垫了钱不敢问 + 自己手上不干净，不是单纯「没报备」。
