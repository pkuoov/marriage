# 六案戏剧性复审与重构（2026-09-08）

依据：用户指出剧情须有能撑戏的“既要又要／前后矛盾”，或像垫付报销案那样有层层改变判断的复杂事件。本稿修正上一轮把连贯性通过视为剧情完成的判断。

## 问题出在哪里

上一轮处理了顺序、重复和越界推断，却把若干案件收成了“解释误会—承认一点—听建议—办手续”。人物欲望写在作者备注里，麦上却很容易接受拆账、列清单和暂停。主播承担了大部分推理和收束，其他人没有继续争取利益。技术检查通过只能说明流程可走，不能说明戏好看。

“既要又要”须落到同一件事上的两套待遇：要求谁付什么，自己拒绝付什么，被给出可以执行的办法后又为什么不接受。普通偏好、独处需要、拒绝对象或隐私本身撑不起指认。复杂案要让新证据改变前面的人物关系、行动或责任理解，不能只增加未解释的账户和来历不明的钱。

## 先执行：彩礼案退出见面后的第二次争夺

### 固定事实与人物目的

- 已发生：母亲提出二十八万八，来电人赞成领证前进入个人账户；男方提出共同账户，她尚未接受。她自己的六万与父亲未来二十万有不同时间、用途。双方连麦已把这些条件讲开。
- 本段新增动作：男方提出取消周末饭局后，她要求对外说他忙；男方拒绝这个理由。没有新增账户、收入、亲属活动或替任何人补过去的承诺。
- 她仍想保住：自己的报价与个人保障、继续选择这个人的机会、在母亲与介绍人面前没有被条件劝退的说法。
- 他仍想保住：不被迫先打钱，也不替谈崩编一个自己忙的理由。他先前选择性提供工资卡的行为不因此被洗掉。
- 误导层：她将自己放在母亲先报价造成的夹缝里。后续并非只发现她赞成报价，还看见她要求对方配合控制对外解释。
- 线索与来源：母亲先报价来自开场；她认同付款条件来自固定连麦；不改条件却要求更换取消理由，直接发生在双方同麦，玩家能听见要求及拒绝。此处评价的是公开做出的要求，不假装核实她过去怎样对母亲说。

### 本段因果与落点

既有付款条件谈不拢 → 男方取消饭局并承担定金 → 她试图把取消包装成他临时忙 → 他拒绝 → 她仍不肯承认自己需要改条件。固定事件停止在饭局取消，人物没有因此和解。之后的材料问答只问她准备怎样向父母解释；可选深问保留她是否愿意再谈的抵抗，不让她忽然接受教育。

删改范围：`profile-weekend-dinner-cancelled` 固定收尾；相关末尾材料问答、深问、结案摘要和人物状态同步。学校、工资卡、宸直、金额、双人连麦入口和原有选择 ID 均沿用。

### 接入后的关键对白

男方：周末包间的定金我来认。我回去跟我爸妈说，你也跟你家里说。饭先取消吧。我不想带着二十八万八去见你父母。

咨询者：饭可以先不吃。可你跟介绍人别说是因为彩礼，就说你最近忙，往后放一放。

男方：我不忙。我不接受刚才那几条，为什么不能照实说？

咨询者：你这么一说，我妈肯定觉得是我没跟你谈好。你先把这次见面往后推，我再跟她说。

男方：那二十八万八进你卡这条，你准备改吗？

咨询者：我没说改。我只是让你别把话说得那么难听。

男方：条件没变，换我去说忙。以后不还是得谈这几条？

主播：那先别忙着约两家人了。

本段不靠主播宣布她“双标”完成。她要求什么、拒绝什么、要求男方替自己承担什么，都当场发生。

## 接下来按什么顺序重构

1. 信用卡第二幕：撤掉用银行缺转证明心理的弱出示，重新设计一项可听见、可拒绝的关系安排；先保住双方有利益的争执，再接余额反转。
2. Tony 后半程：先写清回单原件归谁、谁怎么取得、Tony 当时如何答复，再排白天核验与第二夜拆解。不能为了有反转临时塞一张假回单。
3. 快案一、二的最终请求：让人被问明白以后继续争取好处；删掉自动认错和照单办事。旧隐私线要服务当前要求，不能单独充谜团。
4. 快案三：重新决定短事件的长度与操作，避免把评论素材凑成多轮案件。

验收时先问：删掉最后那段主播总结，观众能否自己说出这个人的算盘，或者指出哪份新材料推翻了自己前半段的判断。两种都没有，这个案子还没写成。
