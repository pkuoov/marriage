## 新增法条·同情梯度守恒律（本单核心,入 SKILL.md）

主线深化后,来电人普遍更算计;叠加变凶的主播,全包有滑向"一连串扒皮、四案全冷"的风险。立法守住梯度:

1. **梯度定档(按审计主线的算计程度)**:
   - **案4 陈=同情锚点**:她是为出头担事的焦虑新人,天真不算计,更多是被同事利用。**主播最暖、加压最轻**;她可以慌、可以认自己冲动,但要读着让人心疼、想帮。**全包至少留她一个清晰的"值得帮"的人。**
   - **案2 何=居中**:她付费/转介绍(自利)但也真被冒用身份、惊动警方(受害)。主播两头都给:加压落在她**淡化自己投入规模**处,暖落在她**被冒用**处。
   - **案1 沈 / 案3 林=最冷**:算计型(瞒余额/想把对方现金变成自己保障)。主播加压最狠——**但仍必须每段收回暖 + 两头公平**(对方也瞒了大事:案1男友瞒失业/借款买信托,案3女方家的钱也留在自己边界内)。两冷可以,别把冷做成刻薄或活该。
2. **没有纯反派**:任何一案,来电人再算计,对方/环境也有各自的隐瞒或过错;结案必须两头都称量,不许把某案做成"来电人纯坏"或"对方纯坏"。
3. **每段加压必收回暖**(重申母单):撬开来电人的算计后,主播软下来给台阶;没有回暖的加压不许留。
4. **累积效应自查**:四案打完,玩家不该只剩"每个人都在骗我"。靠陈的可亲 + 每案两头公平 + 尾声温度托住情感底。
