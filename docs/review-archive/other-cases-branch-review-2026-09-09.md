# 其他案件：调查分支与线性化检查

本轮只检查并记录，不修改剧情、玩法或数值，不操作正在试玩的浏览器。检查三个主案的幕间、白天地点、地点内选择、回拨开场及固定后续，以及三个快案的轮次推进。核对了案件 JSON 与运行代码，并调用现有纯函数验证幕间奖励映射和未访问供应商的可回拨路线。

承接用户对案一的意见：没有足够剧情差异的调查，不必强制二选一；可全部处理并简化后续，不靠增加行动力额度解决。其他案件本轮仅提出建议，尚未实施。

## 总体结果

| 案件 | 当前限制 | 发现 | 建议 |
| --- | --- | --- | --- |
| 职场（主案二，`04-workplace`） | 幕间三选一，另有不耗时的领导通知；白天四选二 | 私聊与旧结算重读，部分地点内选择人为拆材料；可跳过供应商，固定后续却默认白天约过 | 合并旧材料短查；重要新调查按因果串联，保留是否继续垫款及现场回应等真正决定 |
| 彩礼（主案三，`03-profile`） | 幕间二选一；白天三选二 | 回放重复第一夜；同一群聊多处复述；“带整页／标两句”不必互斥 | 合并材料处理；以介绍人说法、双方出资、同麦冲突递进，保留读群聊引出的反弹 |
| Tony（主案四，`02-tony`） | 幕间三选一；白天四选二 | 门店说明入口接错完整名单并提前泄露；周的旧分支与当前态度冲突；部分观察价值弱 | 先修接线与时序，再把名单、门槛、收款去向串成主干；保留有信息差的观察与对抗选择 |
| 快案一、二 | 按轮追问、耐心机制，承重对质需完成 | 没有“花行动力只能查一份材料”的同类限制 | 保留原句追问、反驳和耐心反馈；不借这轮线性化删掉推理交互 |
| 快案三 | 每段几个成立的点评角度，选一项推进 | 是同一公开文本的点评取向，不是互斥调查地点 | 保留角度选择；不强制把每种近义点评再读一遍 |

共同问题：不少调查主要增加一个可选回拨开场。玩家最终只选一个开场，其他已读材料对应的现场问答可能不播放；后面又进入相同主干。路线统计、语气变化本身不等于有分量的剧情差异。但有些选择确实控制改口、反弹、主播说法或平台代价，不应统一删掉。

## Tony：先修接错与提前揭露

### T1｜P0｜“看门店说明”打开完整名单

- 位置：`nightStructure.interlude.actions.reopen-training`，指向 `evidenceChecks.tony-roster-column`。
- 按钮与奖励都叫门店说明，实际打开的标题却是“完整名单”。内容明确写“后台把第一夜截图与第二天补交的原图并排”，且已列出何的十二万、不够一百万起投、走 Tony 户，以及周的一百万、已买。
- 当前幕间在白天调查之前，因此既接错材料，也提前用上了第二天的原图。回拨还奖励“门店的说明”并说门店未安排收钱，所看页面并未交付这份说明。
- 建议：先确定门店说明是否承担独立事实；保留则接回真实对应材料，否则合并入口。完整名单按既定补交时点进入，不能把三个现有入口直接全部开放而扩大泄题。

### T2｜P1｜周已说不闹店，按钮仍让主播劝她别闹店

- 位置：`investigationHooks.tony-other-caller-dm`，以及“周发来的材料／先要回单”两个回拨开场。
- 当前材料中周明确说“不去店里闹，材料可以交警方”；回复却仍是“支持她拉人要说法／劝她先要回单别闹店”。其中后一项劝阻的是她已否定的行动。
- 回拨继续写她想拉人、何不去店门口、何取消预约；缺少幕间期间何如何得知和采取这些动作的交代。回复另直接改动何的防御／开放态度，与案一的跨人物情绪跳接同类。
- 建议：围绕当前真正不同的利益写攻防，例如周有回单、何只有提交页，两人各自希望公开或追回什么。不要沿用旧“闹店／劝退”站队按钮。

### T3｜P2｜部分调查可以合并，部分观察仍有用途

- 门槛从小姐妹与机构窗口两处出现，来源不同可互相核对，但无需只准选一个小问题；小姐妹“听到门槛时的反应／为什么后来翻手机”都服务主动代投主线，可以接着问。
- 门边“自己人”及熟客拒绝推销能改变何对亲密话术的理解，值得保留。
- 侧窗只看到 Tony 点手机、看不清内容，之后只回拨问有没有问过，信息和后果偏弱，可压成观察中的一句，不必独占一项取舍。
- 吹风机回放有声音体验和情感作用，可作为原语音回听，不必与读取关键材料互斥。

## 彩礼：多次读同一份材料

### P1｜P2｜饭局回放与群聊反复交付

- `profile-listen-dinner-pause` 的本科、MBA、自费二十三万八及添水停问，已在第一夜 `profile-dinner-pause` 出现。
- 群聊可在幕间 `profile-family-chat-late` 阅读，也在白天核验文档 p04，回拨“家里群原话”再念；固定第二夜 `profile-family-chat-origin.beforeVersion/version` 又会交代二十万九月底到期、自己留着、彩礼先进个人卡。
- 部分重复是为了补未走支线者的信息，但走完整材料路线的玩家会先知道答案，再被要求重新发现。
- 建议：让关键群聊按一个明确时点交付。后面直接追她为何省略、现在还要求男方付什么；回放只保留确实改变理解的片段。

### P2｜P2｜已经看到整段聊天，却被要求二选一带走

- 茶馆的 `keep-both-records / mark-added-claims`，分别是留完整聊天和标出未核实的两句话。现场两边说辞已经讲了，保存整页和圈出疑点可以在同一次操作中完成。
- 回拨的区别主要是换一种问法与来电人回答，随后回到同一个出资冲突。
- 建议：合并为看完整聊天、点出疑点，不限制只带其中一种结果。

### 需要保留的差异

- 读取群聊 p04 或选“家里群原话”，确实触发 `profile-family-chat-origin` 的改口以及 `profile-family-chat-blowup` 现场反弹。不是所有分支只有换开场。
- 男方插麦、礼物怎么处理、当事人是否继续，以及取消饭局后如何对家里解释，都影响人物关系与现场动作，可保留。
- 表姐说明工资卡如何被挑选、提醒为何没一起转发，对拆男方说辞有独立作用。可缩短拜访，不宜把这条调查事实删掉。

## 职场：既重复检查，又默认玩家调查过

### W1｜P1｜未访问供应商，固定后续仍说白天已约好

- 白天允许财务窗口与后台垫款记录这两个地点组合，纯函数确认可进入回拨，没有访问供应商。
- 固定第二夜 `work-split-ownership.beforeVersion` 却说：“供应商按白天约好的范围，补来已结批次的工作结算和去名回执。”随后使用三层返费材料。
- 这段不随是否到过供应商而替换。材料在这里展示了，问题是约定与送达的前因被省略，未访问路线像被当成访问过。
- 建议：将必要联系纳入固定调查链，或给未访问路线一个真实的接入过程；若采用用户的简洁线性方向，优先统一这一来源。

### W2｜P2｜旧结算、垫款私聊重复收费检查

- 幕间 `reopen-timeline` 再看 `work-budget-timeline`，该板已接在第一夜 `work-private-process` 后。
- `listen-pad` 回放“你先把场地和礼品费垫了，这场就交给你”，也是第一夜 `work-title-for-advance` 原话。
- 幕间、财务窗口与第二夜开场又多次确认立项页不等于费用受理、三次发的是旧图。
- 建议：旧材料随时可回看，不占调查额度；新剧情从查受理情况、发现多部门欠款和费用草单开始。

### W3｜P2｜同次询问拿到的材料被拆成互斥带回物

- 财务窗口：“核已提交费用／确认立项号不能查报销”；供应商：“返费三栏／返费原话”；助理：“费用附单／预算与填单人”。
- 这些是互补信息，多数已在共同对话出现。既无实际拿不到另一项的阻碍，也不必靠选一个名词制造调查策略。
- 建议：同次访问把必要信息一起拿回，主播在回拨时决定先追哪一处即可。

### 需要保留的差异

- 财务、供应商、部门助理回答的是不同环节，不是把三个地点内容全删掉；可以压缩空间切换、按垫款及费用流向串成固定调查。
- 领导继续安排新垫款，应接“还接不接”的真实取舍，不能只变成一个可能没选到的开场。
- 现场先读还款消息还是等广告之后、Tony 案继续公开问还是收窄店名等选择，已经有具体现场回应、问题变化或平台损失，保留。

## 共用实现问题

幕间 `evidencePass` 在首次圈选后调用 `completeInterludeAction`，清空 `activeActionId` 并返回调查台。这个路径也用于其他主案的看材料入口，沿用案一发现的结果页停留与返回问题；不应只在案一单独打补丁。已经读过的材料重开时状态可能不同，统一修订需分别验收首次操作与重看。

## 建议实施顺序

1. 修 Tony 错接／提前揭露，以及职场未走供应商路线的承接。
2. 取消缺少真实取舍的幕间材料互斥，不增加行动力额度；旧材料作为可回看内容。
3. 把主线必需调查按因果串联，压缩地点间跳转；已调查的信息在回拨必有用途，重复说明改为针对新说辞的追问。
4. 保留原句选择、材料圈选、追问与反驳、现场立场和有后果的决定。简化调查分支不等于把连线游戏改成自动播放。

本轮未运行整套游戏测试，也未新增测试；结论来自源内容、接线与纯函数核对。实施后才需要验证新顺序、首次检视／重看、各种现场回应与原有存档恢复。
