# AI 风规则复查与全量台词审读

本轮承接二次改稿清单，重点是清掉会把对白重新写成摘要、心理分析和标准答案的旧要求。审读对象为当前试玩内容；历史评审保留历史身份，不作为现行台词规范。

## 规则为什么还会把话写僵

问题不只在某个词。旧规则与人物说明仍会要求：开场先讲全诉求和经历、每轮点破再追问、收尾必须归纳判断、律师永远补免责、会计只说数字、婚介每次解释都护行业。这些要求叠起来，即使换成口语词，人物还是在轮流完成作者的论证。

已修改 `case-scriptwriting` 的入口、当前项目方向与二次改稿参考；同步清理 `cast.json`、主播卡、顾问卡、来电人卡和声线表。顾问选择页的四句口号也改为具体说话示例。保留职业和知识边界，取消强制的句式、总结和心理说明。

检查程序中残留的“每个话轮最多一个问号”、固定五句交锋、主播必须再报全部金额等要求也已删除。来源和数额继续验证：材料先到、人物后引用，累计金额仍能在材料中核对；不靠一段旧台词保证剧情成立。

| --- | --- | --- |
| 案一账单到餐厅 | 场尾和下场开头重复问以前是否去过 | 删除场尾的重复问句，保留下场正式进入的问题 |
| 案一借款到代存约定 | 两次宣布收到同一段旧聊天；原件出现后主播又解释一遍是什么 | 材料在相应问题中到场，直接接来电人的反应 |
| 案一十四个月转账 | 主播把月额、月份、合计、房租全念一遍 | 只核对当前有争议的部分，精确总额保留在材料里 |
| Tony 恋爱与名单 | 问完又用同一事实追问，逼来电人承认不能证明别人身份 | 改问有没有亲眼见过别人约会，让她继续抓称呼争辩，删除重复收尾 |
| Tony 第一夜 | 来电人主动预告自己还藏着后话 | 改成对当前追钱方向的不满，不替下一夜宣布秘密 |
| 相亲案学历与彩礼 | 已经答过的“不继续问”再问一次；来电人用标准答案承认自己想要 | 追她是否纠正家里的印象、当时怎样回母亲；她继续争辩谁先报数 |
| 相亲案介绍人 | 主播把两边聊天、收入、学历和彩礼重新总结一遍 | 改问介绍人没核实就替人答话，保留对方“见面以后就好谈”的辩解 |
| 职场案后半段 | 材料被逐项复述，结束时来电人替作者概括资金链 | 用她们是否缺材料、谁答应优先付款继续问；收在催款和拒绝再垫的行动上 |
| 三宗快案 | 重复对质、同义尾句、反复划分边界 | 删除重复交锋；保留问法与来电人的抵抗，口播案追具体中间人来源和公开行为 |
| 序章与尾声 | 转账方向说错；法律意见后习惯性补免责；旧回声仍称公开过余额 | 改为双方来往的三笔钱，程序放在具体申请上；尾声只回指“拿不出八万” |

例如，“约会是真的……能说明其他人都是女朋友吗”改成“名单上其他人，你见过谁跟他约会吗”；“要求男方支付的时间、账户和额外项目都很清楚……”改成“你爸的钱可以等九月底，为什么他的就得领证前给”。修改对象是交流方式，没有新增隐情，也没有要求人物认错。
