# 当前项目方向

适用《深夜热线：直播间侦探》，按 2026-09-14 用户要求维护。这里存放跨 skill 的现行共识；一次性修改记录、旧设计稿、语料标题和示例只提供背景。用户新要求改变方向时，修改这里及冲突的消费者，不在旧命令上继续叠“优先执行”的补丁。

## 创作

主播有逻辑但不死板，可直问、顺着聊、接梗或阴阳。暂时沿着对方理由接话能引出更多分享，但不是每段先共情再反问的固定程序。来电人被揭穿后继续保护自己的钱、面子、关系或诉求，承认事实不等于态度投降。

角色可以偏见、胡扯、逃避和误会；作者事实与系统确认仍需有依据。主播能提出有根据的猜测，不能凭空知道未出场的人和材料。对方确实解释得通时应允许判断改变，不把每次否认都写成有罪证据。

不替玩家讲应该看出什么、相信谁或怎样评价。对白、旁白、材料说明、反馈和收尾都不用价值观宣讲、防冒犯套话或逐项责任总结。必要操作标签和错误状态保留；它们不能解释解题方法或暗示正确项。此要求不把所有人物修成中性口吻。

好笑、亲近、换气和人物习惯本身有价值，不必贡献一条证据。不得强制每案若干层伪装、几个场景、一次误判、两处独立来源、若干金句或若干环境噪声。已有明确的玩法契约仍按对应模式实现；不能把当前某案的结构数字推广成普遍叙事规律。

## NPC 与世界

玩家是林旭阳。人物身份、亲属关系和知识范围以当前 `content/characters/cast.json`、`voice-bible.md` 和 `offmic-voices.md` 为准。角色卡有过时口吻时按用户要求同步修正，不能拿角色卡覆盖用户指示。

妻子、好友和业务伙伴首次出场有自然寒暄与接话，保留原设计中的生活关系和伏笔。后续见面接上旧约定，不重复自报身份。案件当事人的亲友不自动变成主播的朋友。熟人往来不需要用“拒绝、打断、二选一”配额证明价值。

节目是个人直播；不要凭空增加档案室、导播班组或全知后台。NPC提供消息要有实际来源；熟悉主播不能让他知道未看过的材料。专业身份不吞掉私人关系，赵律师不固定充当“不等于”与“谁主张谁举证”的播报器。

## 当前交互

当前四案的叙事问答、现场反应与收麦交流按已确认的事实顺序推进。按 2026-09-14 试玩反馈，单一选项不能称为关键选择；逐句回放每屏展示完整原句，提供“询问这句／不询问”，实际问法在点击后的对话中呈现。回答后回到逐句回放，不把尚未播放到的追问接成单选长链。材料问题由玩家点击材料发问。禁止恢复旧互斥事实、机会成本或“只能问一次”的教学文案。

顺序化前先消除退款／暂挂、发送／不发、静音／继续等互斥后果；后文承接已发生动作。物证选择、PRESS／PRESENT、可选材料访问和快案专用交互以当前运行时及任务范围为准，不能仅为这条叙事要求把所有按钮改成自动成功。新模式要由产品需求决定，不由旧 skill 的“线性禁令”决定。

并列的真实选项等权展示，不用“关键选择”标签暗示哪一句必问。重放和上一问只展示已经播过的内容，顺序问答的已听交流不能只剩最后一句。UI 优先适配 PC；材料阅读、结果对白和继续操作各有位置，不靠挤压文字解决遮挡。

## 案内连贯与隐瞒（2026-09-14）

每段按“上一句提供什么—此时为何问—回答承认或躲开什么—下一问由何而来”连读。已经说清的归属不能再当第一次发现；可跳过的追问不能成为固定续文唯一的信息来源。材料先交代取得过程，再由玩家查阅和发问。

人物为了保住钱、关系、面子或原诉求，可以迟疑、改词、省略主语或时间、把索取说成承诺、把支出说成投入。用“呃、这个……”时应有正在斟酌的具体事实，不能人人每句都结巴。春秋笔法要让前后原话与材料出现可追问的差异；语塞本身不是证据。事实藏不住后允许人物继续争解释、转移话题或反击，不自动变成完整自白。

## 收尾

收麦回应眼前最大问题，允许谈崩、挂断或一句带脾气的结束。无需认错、安慰、强制回暖和完整结案报告。内部 `caseClosing` 保留后续连续性所需事实，不代表必须强制展示一页。

试玩片尾遵循已批准的电影字幕方向：“故事未完待续”；“维护基本的道德底线是每个人都应该做的”；“主播将在正式版归来继续主持公道！”这是用户明确指定的片尾文字，不是让角色在案内普遍说教的依据。是否出现、顺序、动画与进度以当前片尾数据和实际播放验证，不能因通用去说教规则擅自删除指定字幕。

## 维护边界

局部修句不用先停工填满整套账本；只记录请求范围内尚缺的信息。审查只读、记录不改、接入修改按用户当次授权区分，不能把旧“尚待落稿”当成永远不许实施。

事实与运行时合同是硬约束；声纹、节奏、反转模型是有适用条件的写法。技术变化以代码和实测为依据，文档冲突必须修正源规则及相关测试。旧材料中的经验只能推广到确实成立的范围，不能用一例建立全局禁词、逗号数或情绪配额。

规则归属与历史状态见[项目标准索引](../../../docs/standards-index.md)。修改共性问题时检查源规则、技能默认提示词、文档入口及校验消费者；验收数字只约束已明确配置的机制，不把段数、轮数或短答次数当文学规律。

## 2026-09-15 试玩调整

案一采用集中问询：每段问清后推进，缺问就在当前段补问，不回到后段重复核查，不靠完成度解锁额外对白。材料与原话同页核对，取消材料试问与正式出示的双套入口。删掉弹幕插话。

案一男方始终不上麦。看到直播说法不对后，他直接向后台发聊天截图、流水和本人文字说明；匿名观众另发女方两年前在同一家餐厅的朋友圈。不要让女方主动转述男方对她不利的材料。酒水与高消费先问，之后问支出来源及余额；明确拒付态度后收麦，不反复问八万、不复述整案。
