# Livestream Game Flow Review

先读 [当前项目方向](../case-scriptwriting/references/current-project-direction.md)。本技能验证实际玩家看到的内容，不另维护一套写作规则。案一按集中问询验证：本段问清再推进，错问留在本段，不回到整段回放或结尾补完成度。其他仍使用逐句回放的场景保留完整原句和“询问这句／不询问”；不得把单一推进标作“关键选择”，也不恢复已取消的互斥分支。

## 开始前

核对目标版本、地址、构建、用户存档和当前任务范围。试玩使用隔离浏览器上下文或专用存档；URL 加查询参数不等于 localStorage 隔离。不要为了“从头测试”重置用户当前进度。用户要求试玩只记录时不修改游戏；已授权修改时修实际问题，不重复索要批准。

按需查阅 [待办](../../docs/unfinished-backlog.md) 和 [试玩记录模板](../../docs/playtest-report-template.md)。旧记录描述的是当时版本；其中路线、字句和配额须与当前内容核对，不自动升级为新需求。

剧情原因不清时转 [case-scriptwriting](../case-scriptwriting/SKILL.md)；发现链问题转 [detective-plot-coupling-review](../detective-plot-coupling-review/SKILL.md)。不要每次 UI 修复都强制重做案件结构。

## 实际检查

从受影响场景之前进入并走到后续，保存实际 DOM 文本和必要截图。结构错误可先读代码定位，但完成 UI 验收要看真实屏幕。

- 主播、来电人、对方和 NPC 的姓名、角色 ID、立绘与当前对白是否一致。多人现场依照该案实际许可和角色表，不把主案临时调解套进旧单人模板。
- 首次陈述、回放、追问回应、场尾是否按当前模式推进；回放不新增摘要、不泄漏未来句。
- 逐句回放是否每屏可询问或不询问，实际问题在对话中播放，回答后回到对应原句；中途返回和读档能否继续。上一问保留已听的整组交换，不能只剩最终答案。
- 是否仍出现旧分支的守备回答、退款后暂挂、已发送后再选发送等互斥内容。后续状态不能清掉先前付出的代价。
- 材料原件是否可读，数据、图片和热点是否真正加载；是否还有黑屏、索引代原件和查看按钮没反应。
- 材料标注、继续、名牌和气泡是否重叠；完整原句、反馈和按钮是否都在视口内。单一按钮不得包装成关键选择，选项颜色不推荐正确项。
- 操作反馈是否明确、简短，失败不泄正确组合；正常浏览不误扣耐心，误问读完只扣一次，耗尽不跳到下一案。
- 弹层是否接管焦点和 Enter／A，Esc 是否只关闭当前可关闭层；关闭后恢复位置，自动播放不穿透。
- 读档、设置重绘、窗口退出是否重复对白或音效，旧网页是否覆盖较新的存档。
- 夜次、背景、音乐、HUD和角色状态是否随真正场景改变；普通翻页不触发新夜转场。
- NPC是否按实际首次出场寒暄，后续是否凭空引用被删支线；标题、案间、收麦是否仍播放旧总结。
- 最终片尾的字幕顺序、样式、动画与已批准数据是否一致；不能因内部有结案字段强制增加总结页。

## 修复与验证

从源内容、实际消费者和迁移入口修复。不要用旧句正则或每次手动改缓存戳来识别内容版本；先查当前内容身份、revision及资源缓存机制。修改 skill、评审记录或生成报告不应刷新正在试玩的页面。

共享内容或流程改动运行 `npm run check`，构建 playable 后验证受影响案件。可用 `node scripts/smoke-browser-replay.js --target=script-reading` 核对台词和顺序恢复，`--target=testimony-reading` 核对证词墙；其他目标先确认脚本是否仍按现行模式执行，不为适配旧烟测恢复取消的分支。

键盘／手柄、打包、资源替换分别选择对应测试。纯剧情改动不强制重打 Windows 包；平台支持不能只凭纯函数测试宣称完成。桌面构建由现有脚本管理锁，不拆回互相踩目录的并行构建。

新回归验证可观察行为和数据关系，不固定文风、情绪配额或 skill 原句。搜索只用于定位旧副本；命中历史记录不等于游戏仍在显示它。通用经验只有在相同原因下再次成立才加入维护规范，并同时写清适用范围。

最终说明改了什么、验证了哪些案件／交互／尺寸，以及尚未覆盖的路径。自动定点载入、完整路径与人工通读分别报告。

PC 为主验收平台：1920×1080、1366×768、1280×800、1280×720，手机只作补充。DOM visible 不等于没有遮挡：同时检查容器边界、截图和实际点击。过场也须验证标题、正文、继续按钮及顶部状态；最后一次影响布局的改动后重测，不能沿用修改前的截图通过记录。环境阻塞记为未验证，不记为通过。
