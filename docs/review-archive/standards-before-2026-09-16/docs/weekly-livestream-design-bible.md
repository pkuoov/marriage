# 章节式案件包设计总纲

状态：现行概要，2026-09-14。详细创作和交互约定维护在 [当前项目方向](../project-skills/case-scriptwriting/references/current-project-direction.md)，本文件不覆盖该入口。

## 产品

《深夜热线：直播间侦探》是一款以个人直播为舞台的剧情推理游戏。玩家是林旭阳，通过听原话、选择询问和查看材料发现被省略的事实；对话也可以承担人物关系、喜剧和生活节奏。

当前试玩有四个连续主案和三个独立快案。四案各跨两晚，顺序以 manifest 为准：信用卡消费、职场垫款、相亲资料、Tony。主案与快案采用各自已实现的交互；daily 为兼容入口，不能把它的旧单人短案模板当成所有模式的限制。

不以固定段数估计时长，不因目标二十分钟添加重复问答。实际时长包含阅读、思考、材料操作和过场，需试玩记录。新包规模、夜次和结构按题材决定。

## 人物与发现

案件可以有真实受害、双方隐瞒、荒诞诉求或误会。作者保持事实一致，人物可偏见、答偏和修剪。不是每案都必须双方有错；不为“灰区”给受害者添过失。

隐藏事实要有维护钱、关系、面子或诉求的原因。玩家通过前后说法与材料差异追问，不能把迟疑直接当结论。对方可以改口后继续争辩，也可以解释成功。

材料与消息有可追溯的出现过程；主播是个人，不凭空获得全知后台。固定续文不能依赖可跳过的信息，已知事实再次出现时应有新的核实对象或问题。

## 交互与呈现

主案陈述回放每页完整原句，提供“询问这句／不询问”，问句在对话里说。顺序依赖不等于连续单选菜单；问后回到原句，不贴“关键选择”推荐标签。材料驱动的问题由点击材料发起。

材料阅读、结果对白与继续操作分阶段呈现。重大交易可做重点卡片，其他原始行保留查阅；时间线排错须重排。转场同步时间、背景和 HUD，不把日间标签带到夜间。

PC 优先，尤其检查 1280×720 的矮窗口。按钮存在或 Playwright 的 visible 判定不等于首屏可见；布局需测边界并查看实际截图。

## 包级接续与收尾

跨案弧线由人物往来、已种下的材料和时间变化承接，不强制每案追加主题提问。内部事实记录用于保持连续性，不要求人物朗读责任清单。片尾保留用户锁定的字幕与顺序。
