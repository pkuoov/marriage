# 项目技能、标准与工作流审计

日期：2026-09-14。依据本轮连续试玩反馈，检查旧规则是否仍会被编剧、生成脚本、测试或文档入口采用。现行入口：[标准索引](../standards-index.md)。

## 结论

确有仍在生效的旧规则。共享方向此前已经更新，但部分技能正文、默认提示词、设计文档和校验没有同步；候选案生成器还会把旧规则重新写进下一批素材。仅在旧文档开头追加“以新要求为准”无法解决这种回流，本轮同时修正源规则、消费者和入口。

UI 遮挡的直接原因仍是布局、容器与状态代码；旧标准主要影响怎样设计页面、生成剧情以及判定验收通过。下表中的“影响”是已找到的约束冲突与复发路径，不声称文档是每个历史 bug 的唯一成因。

## 范围与方法

- 逐项检查全部 7 个项目 `SKILL.md`、共享与专项 references、2 个 `agents/openai.yaml`。
- 扫描 README、story、docs 规则入口及其生产流程、Schema、人物设计、素材管线、测试说明；对命中旧指令的文件追实际引用和消费者。
- 检查 `verify-pack`、`verify-logic`、`verify-narrative-flow`、`verify-content-pipeline`、`check-all`、候选案生成器及相关回归测试；检查两份 GitHub workflow。`.claude/settings.json` 仅配置 permissions，没有额外技能或工作流 hook。
- 对照当前 manifest、四主案与三快案实际数据，区分当前机制合同、单案特例、创作建议、历史方案、专项交付要求。
- 保留进入本轮前的未提交修改。未改案件 JSON 和现有 UI；没有把本次静态检查算作之前 UI 修复的最终浏览器复验。

## 入口和历史处置

新增[现行标准索引](../standards-index.md)，同步文档目录、主案与快案说明、Schema、剧情总入口、工作流、QA 和技能引用。旧双夜、多场景、Demo 2、主播声线、侦探改进、调查循环、顾问、P1 盲测等 8 份方案原路径保留历史跳转；主播角色设计与情报台重写为现行说明，旧稿另存。共保留 10 份历史原稿，见[归档目录](standards-before-2026-09-14/README.md)。

候选生成器仍输出熟悉的字段以兼容既有审阅工具，但 `beatLadder` 是可选功能清单，`writersRoomPasses` 是审读角度，不能被当成强制场数或创建代理的指令。旧 `.local` 候选不会因改文档自动更新；本轮运行过生成器，并用独立临时夹具检查新输出，正式采用任何候选前仍须复核。

## 保留的约束与适用范围

- 固定人物关系、作者事实、稳定 ID、来源锚点、引用存在性、存档恢复和材料门槛不放宽。
- 当前主案的具体金额、角色、材料与剧情合同不因删除通用配额而改动。检查现稿某个已确认场面，与规定所有未来案件都采用同样数字，是两回事。
- 素材池目前的规模和题材比例校验属于素材池准备度，不是可玩案件数或单案结构要求。
- 音频格式、录音参考授权、像素资产、桌面构建、真实 Windows EXE 验收按其专项交付继续生效。GitHub 的行为与 Windows 工作流未因本轮文档清理削弱。
- 人物／场景／连续性投影不作为独立交互标准；与当前 JSON 和新要求冲突时须核对来源。历史评审和生成阅读稿不能恢复旧玩法。

## 验证与限制

- 7 个项目技能均通过 `quick_validate.py`；技能格式与本地引用测试通过。
- 完整 `npm run check` 中：索引与阅读稿同步、158 个 JS 文件语法、音频与素材管线、内容包校验、129 项逻辑测试、相关 Node 回归以及 8 个 daily 日期样本结构校验通过。
- 新增 5 项行为回归：场景／问法数量不作创作配额；缺文与错误出处仍失败；关键词仅作为审读候选；生活对白不受数量阈值；单素材生成及两种 CLI 参数写法正确。已接入 `check-all`。最后调整后的纹理和生成器再次通过对应测试与逻辑检查。
- 完整检查最后两项台词编辑器 HTTP 测试因 `listen EPERM: operation not permitted 127.0.0.1` 受阻；其余 11 项编辑器测试通过。未将这次完整检查写为全绿。
- 本轮没有修改浏览器布局，也没有重跑游戏全路线；此前第二夜过场最后一次布局改动的浏览器复验仍按[原修复记录](playtest-common-fixes-2026-09-14.md)保持待验证。

后续更新规则时，沿“用户要求 → 唯一源规则 → skill／生成器 → 校验与试玩”同步查冲突；不再只给旧命令叠一条更高优先级的补丁。
