# 机制修复与实际试玩记录 · 2026-09-12

对应要求：排查反复修订后仍出现陈旧内容的机制问题，并自行试玩、修复剧情、UI 和台词衔接。用户 5194 的存档保留；人工试玩使用 5205 独立进度及不写存档的场景入口。

## 已确认的原因与修复

| 原因 | 复现与处理 |
| --- | --- |
| 改源稿后只刷新页面，没更新运行索引 | 开发服务现在启动前生成索引；内容变化后串行生成，最后一次成功才刷新。失败显示明确提示，并以 503 阻止重新请求旧稿。生成采用原子替换，无变化不重写文件。 |
| 构建入口行为不一致 | 直接运行离线构建、桌面构建所调用的函数，以及静态构建，都会先更新内容索引；不再依赖调用者记得执行 npm 前置脚本。 |
| 存档迁移与真实存档格式脱节 | 实际保存会裁掉完整案件，旧迁移测试却一直传完整案件。现在保存不含台词的场景／选项身份表，迁移按身份处理，早期无身份表的摘要也会刷新可匹配的回答。 |
| 上一次提问焦点覆盖当前回放进度 | 人工复现：在第一案第二段刷新，退回第一段。现在只有正在回答问题时才恢复该焦点；场景重排时迁移回放位置。修复后同位置再次刷新，仍在第二段。 |
| 证词墙信任存档中的旧回应正文 | 显示时根据当前幕、陈述及材料重新解析回应；已删除的回应不再从缓存显示。 |
| 批量修改落错对白位置 | 第四案朋友竟回答“后来你们还聊过这个产品吗”，主播又提前知道她劝过别转。恢复朋友对当时反应的回答，由主播接着问后续联系；日间对白增加稳定 ID，更新接入流程。 |
| 人物卡仍在引导旧身份 | 财务朋友的角色卡仍写“窗口”“系统状态”“下一位”。同步为受邀到工作室看单据的外部财务朋友，保留旧表面名称兼容映射。 |
| 作者约束直接显示为台词式说明 | 14 个日间场景新增简短来源提示 `sourceNote`；原 `access` 保留供作者审查。界面及玩家阅读稿使用前者。 |
| UI 复用不区分阅读材料和播放对白 | 纯材料页去掉自动播放、字速控件，缩小背景占位，给材料阅读让出空间。 |
| 滚动恢复被延迟聚焦覆盖 | 点材料行后，默认焦点下一帧跳去“继续”，把页面拖走。现在恢复刚点的行，保留内外滚动位置；浏览器回归直接检查焦点与滚动。 |
| 自动测试保留旧交互要求 | 修正序章顺序调查、双线回告、材料入口重复数量、八万账单旧判词等过时断言；入场动画结束后才检查台词，不把尚未出现的页面报成空对白。 |

## 继续排查：句子与材料内部的旧状态

上一轮解决了场景和选项层面的身份迁移，继续检查发现内部句子及材料行仍存在按位置或旧缓存判断的路径。本次复现并修复：

| 复现 | 修复 |
| --- | --- |
| 旧回放问过第二句；正文在中间插入新句后，新句继承“已问”，原问题又出现 | 存档增加不含原文的句子指纹和问题 ID 对应表。读档按问题身份迁移已问记录，按句子指纹恢复回放位置；同位置的新问题不继承旧记录。 |
| 旧存档标满两行；源稿删掉其中一行，新行仍标不上 | 读档过滤失效材料、失效行、重复行及超出当前上限的标注，然后重建可问问题和回答状态。 |
| 组合问题的两行顺序交换，同一问题被当成未回答 | 有稳定 ID 时优先按 ID 匹配；兼容旧问题时比较行集合，不依赖数组排列。 |
| 现场已选项被删，恢复后整组选项仍变成不可点击的“已选”展示 | 当前界面只接受仍存在的选择。失效选择重新开放按钮，历史记录及已发生的结局影响保留。 |
| 两项旧材料测试只有问题，没有材料行，不能暴露隐藏标注占位 | 补全真实行结构，保留原有回答更新与迁移断言。 |

生成检查增加：材料 `rowId` 缺失／重复、日间场景重复、现场拍与选择重复、证词幕／证词句／材料卡重复、揭露目标不存在、决定性出示目标不存在、非法幕序号。标注组合的默认上限统一为运行时的 3 行。

专项机制测试由 10 项增至 15 项，覆盖真实存档往返和实际选择 HTML。新增场景包括插句、新问题替换旧问题、删行释放名额、组合行调序及删除现场选择。身份信息不足的早期存档，或原版／改口版句子对应不唯一时，会重新开放无法确认的可选问题、重置无法确认的句子位置；不会猜测新句已问，也不会退还或重复结算已存的耐心支出。
