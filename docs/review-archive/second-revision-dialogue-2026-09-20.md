# 二次改稿清单：审阅与接入

日期：2026-09-20。来源为用户本轮粘贴的《二次改稿总规范》。本记录说明取舍和实际改动；维护规则见[当前方向](../../project-skills/case-scriptwriting/references/current-project-direction.md)及[二次改稿方法](../../project-skills/case-scriptwriting/references/second-revision-dialogue.md)，不以本记录另立规范。

## 审阅结论

采用清单的核心判断：问题不是短句本身，而是摘要式压缩、角色替作者解释心理、一次自报不利事实、材料与人物重复播报，以及 NPC 开口交信息后立即退出。修复应检查玩家此刻所知和完整对话，不只替换单句。

以下建议调整后采用：

- “先反应再问”是可能的节奏，不固定成三拍，也不每次加“等等”。
- 六遍审稿、每场三件事实、超过三个不利事实强制拆分，不变成数量规则。事实拆开要靠当前争议推动。
- 短视频式金句、动作、正式职业语言不一概删除；看它在此处是否起作用。
- NPC 不统一增加利益纠纷、抱怨或自辩开场；保留合理来源，自己的处境由交流表现，不由旁白解释。
- Tony 第一夜只明确裁图及右边涉及钱，保留此前听过高收益的模糊传闻；具体产品栏目、起投金额与走户安排留到次日收到材料后。次日白天也是后续披露阶段，无需把已收到的资料硬扣到回拨时才让玩家看。
- 第二案已成立的押金经营逻辑继续在私下咨询内展开，几天后的直播仅公开回访结论；不为统一跨案模板撤销前轮要求补完的结尾。最后暴雷新闻仍是公开事件的回收，不能倒推每笔个案损失。

## 规范清理

- 新增二次改稿方法，接入 case-scriptwriting；现行方向补充自然语法、半句回答、材料与反应分工、NPC 处境和删场尾的方法。
- 将六份已完成的旧 prompt 收为简短接入记录，移除旧替换句、锁定句和过时诊断，历史原文由 Git 保存；谎盖谎原则不再路由回旧清单，也不按每场一个谎分配。
- 清掉片尾三句不可改、案一心理点破句不可改、短而具体作为统一声线等旧要求；更新舞台 skill、复审流程、标准索引及角色卡。
- 会计不再按卡片要求“只报金额／三项并列”；小陈按不熟悉流程、照搬主管说法表达。女方与男方的声音从自报数字、条列自证改为在争执中说明。

## 实际改动

| 段落 | 接入结果 |
| --- | --- |
| 序章 | 转账追问直接对准三笔钱；报告回告里的律师安慰回到刚拿到结果、没睡好的当前状态。保留正式鉴定意见。 |
| 第一案 | 删流程小结与重复报账；不再问“最想让我替你说哪句”。代存反驳改为她抱怨以前没被拦，主播只追花掉未告知的行为；不再宣读心理归因和“交代”判词。旧朋友圈只交代收件与认识关系。 |
| 第二案 | 删除“这点先记下”和三件事一次总结；催付围绕主管口头保证与下周是否还垫。供应商先拒绝替陈证明正常成本，被追问后才说谁来要费用，回执仍未拿齐。 |
| 第三案 | 开场不再一次报完本人全部资金安排。先说自己也出，问出八万四和六万，再由男方追父亲的钱，最后争婚宴。删除提前引用六万的场前台词。男方表达不耐烦，表姐既护家又埋怨表弟总把问题转给她。 |
| 第四案 | 第一夜不报产品栏目；删回拨与下一场相同的转账追问。小姐妹先担心被说成劝买，问到原话后才说明门槛。何围绕不想被骂争聊天怎么展示，不主动精确描述隐瞒策略；修刘海保留，场尾改为催合同和不再转钱。 |
| 片尾 | 只保留“故事未完待续”，删除两句宣讲。字幕淡入后停留，返回按钮跟随单屏节奏；减少动态效果时直接显示。 |

稳定案件、场景和选项 ID 保留；新增 NPC 话轮使用独立 ID。多人物实际播放仍以 lines 为准，兼容短答与原话锚点一起同步。生成台本从内容源重新导出。
