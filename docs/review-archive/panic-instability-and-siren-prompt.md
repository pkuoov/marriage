# 执行单·慌乱失稳（来电人）+ 抓破绽（主播加压）+ 案1警笛突兀修复

你是本仓库的实施工程师。三件事:①来电人在慌乱中前后语气/语调/逻辑失稳;②主播在追问这些失稳/破绽时更有攻击性、步步紧逼;③案1那句"报警"生活噪声突兀,替换。①②与 `docs/host-voice-rewrite-prompt.md`(主播双寄存器)**共用同一批高压场景,合并在案1竖切里一起做、一起停下等真人朗读**;③可立即独立做。

## 与既有设计的关系(先读)

①②不是新戏,是把**已存在的高压反转拍**从"她平顺地自述复杂"改成"她在压力下露馅、主播抓住露馅往死里追"。每案的急压时刻已存在,直接挂上去:

- 案1:对方消息突袭(「他在听」「你们都看着」)。
- 案2:民警来访揭露(「腿都软了」)、弹幕炸毛(「谁装了」)。
- 案3:表妹泄露家里群(「我要先给她打个电话」)、男方上麦对撞。
- 案4:弹幕说"蠢"(「我也想骂我自己」)、大群还款消息。

**慌乱失稳是让"她也有份"的反转由平顺自述变成当场露馅**——反转更清晰,主播的攻击性就是把馅撬开的工具。

## Part 1|慌乱失稳律（来电人,立法 + 挂到高压拍）

急压来临时(被抓矛盾、被硬真相砸中、被对方消息突袭、揭露拍),来电人的说话必须**失稳**,不是平顺升级:

1. **语气/语调跳档**:短程内在 防御↔求饶↔发冷↔过度解释↔突然闭嘴 之间跳,不是一条平滑弧线。慌的人不是一个调门。
2. **逻辑/细节露馅 ≥1 处/案**:高压下她说出与前面**自己的说法**不一致的一句(口径/主语/时间点在她的**粉饰**上滑动),而且**她自己没圆回来**——留给主播抓。
3. **失稳落在她的"自利删减/粉饰"上,不落在承重事实上**:露的是她原先的 spin 裂了(例如"他订的"松动成"我订的"这类既定反转),或一个**非承重细节**在慌里滑一下;**案件承重事实、真相边界、收窄阶梯、行-证言一致性一律不动**(verify:pack 仍须过)。不许制造会破坏案件解算或知识账本的真矛盾。

配额:每案 ≥1 段急压失稳(含跳档)+ ≥1 处被主播抓到的露馅。

## Part 2|抓破绽·主播加压（扩展 host 双寄存器的专业档）

来电人一露馅/含糊/前后不一,主播不再垫着接,**扑上去**——比他专业档基线更狠、更不留缓冲,直接把矛盾摁在台面:「等等,你刚说是他订的,这会儿又说是你订的——哪个?」逼到她圆不回去、只能认。要点与边界:

1. **攻击对象是那处矛盾/粉饰,不是她这个人。** 逼逻辑不逼人(守阳谋不阴谋):可以咬口径、咬前后不一、咬"这句你再说一遍",不许攻击她的脆弱、痛处、身份。
2. **攻击性是挣来的,不是欺负求助者。** 只在她**正在粉饰/露馅**处开火(那正是她藏"自己也有份"的地方,她不是纯受害者);对她真正无助的坦白只暖不逼。
3. **一段式,不是全程。** 撬开→她认/她崩一下→主播**回暖给台阶**(接 host 设计的"钉完回暖")。攻击是相位,不是底色;别把讨喜主播写成刻薄。
4. **接话节奏不破**:开场接线仍是风趣默认档、先接住;攻击性出现在**矛盾露头之后**,不是一上来就凶。

一句话:主播平时松、暖、爱贫;**她一露馅,他立刻较真、步步紧逼、不让糊弄过去,撬开了再软下来。** 这正是"专业上不马虎、步步紧逼追求真相"的兑现。

## Part 3|案1"报警"噪声突兀修复（可立即独立做）

位置:`content/packs/steam-demo-01/cases/01-credit.json` → `sceneVersions[0].afterVersion.lines[2]`(role caller,nonLoadBearing:true,无音频提示)。

原文:

```
……你等我一下，我把窗关了。楼下有车在报警，吵。
```

问题:「报警」既像"防盗器响"又像"报了警",而案2 才是真正的警察线(民警上门、`case2-distant-siren.ogg`)。案1这句无意间预呼应了案2的警笛/警察母题,显得突兀。

改为(逐字,换成不带"警/报警"联想的普通夜噪,保持 nonLoadBearing、口语、无 AI 味):

```
……你等我一下，我把窗关了。楼下大排档还没散，吵。
```

(若"大排档"与场景不合,可换其它无警灯/警笛/报警联想的普通噪声——楼下有人搬东西、隔壁在放剧——但不得用装修/电钻,案3已用。)

约束:仍 nonLoadBearing;确认该行**未挂任何 siren/报警类音频提示**(现无,勿新增);不动同场其它行。
