### A｜先听她想找什么样的人

A01 主播：行，那说回介绍对象。你想找个什么样的？

A02 来电人：一个月四五千也行，比我大五岁以内，没房也可以，先住我那儿。学历、长相我真不挑。合适就处一两年结婚。我下班晚，平时也没什么机会认识人。

A03 主播：我这儿有个登记过的听众，二十九，在物流公司做调度，一个月六千，没房。要不要先留个联系方式？

A04 来电人：先别急吧。我还不知道他人怎么样呢，加了不合适，再删也挺麻烦的。

A05 主播：那你想先了解什么？

A06 来电人：您跟他熟吗？最好找您认识久一点的，知道底细。要是自己做点生意，家里也省心，就更好了。能帮我减轻点房贷压力，那我肯定也高兴啊。

A07 主播：你那套房一共多少钱买的？

A08 来电人：两百万。

A09 主播：怎么想到找我来介绍？

A10 来电人：您做这个两年多了，看人肯定比我准。您先跟他说一句，我这人还可以，他至少愿意见一面。旭阳哥，您就帮我留意一下吧。

### B｜玩家追问：刚才那位，为什么先放着？

[此处才展开她的“找你帮忙，就想再挑挑”的想法。对应现有 hidden-standards 追问。]

B01 主播：刚才那个做调度的，你是想先问问他人怎么样，还是想再看看别人？

B03 主播：你刚还说四五千也行。

B04 来电人：是行啊，我也没说他不行。您要是有条件更好的，干嘛不先给我看看？

B05 主播：……所以六千的先放着。

B06 来电人：先放一下嘛。真喜欢了，少挣点也没事。可现在都还没认识，我多看看怎么了？

B07 主播：房贷呢？你想让对方帮着还，要是他不愿意？

B08 来电人：那我就自己还啊。有人帮着当然轻松点。我又不是今天打完电话，明天就让人给我转钱。

[可选弹幕，放在 B06 后：六千那位：那我先走？]

### C｜玩家追问：你要我怎么跟他说？

[对应现有 useful-soft-talk 追问。A10 已经交代她想要主播的一句好话。]

C01 主播：你让我跟他说，你这个人还可以。可咱俩今天才认识。

C02 来电人：所以我前面不都跟您说了嘛。工作、家里、房子，您还想问什么？

C03 主播：那他问我，跟你认识多久了呢？

C04 来电人：您就说直播间认识的。

C05 主播：今天认识的？

C06 来电人：您干嘛非加今天啊？

C07 主播：那我说哪天？

C08 来电人：不用说哪天。我也没让您说认识十年八年的。先让他愿意见一面，后面我自己聊。

C09 主播：你自己跟他聊，不也一样？

C10 来电人：那哪一样。您说我人还可以，他才肯加我。加都不加，我怎么跟他聊啊。

### 本段事实和发现顺序

| 项目 | 本轮处理 |
| --- | --- |
| 表面诉求 | 自己能生活，择偶要求不高，想让主播介绍。 |
| 直接依据 | 她先说四五千也行，后说希望主播认识久、条件更好的对象，再要主播先说一句好话。 |
| 容易误判的地方 | 不加一个陌生候选人，并不等于低收入的人一概不见。B06、B08 仍留下她愿意接受的可能。 |
| 她想得到什么 | 进入主播能接触的对象范围，让对方因为主播的介绍愿意见她。 |
| 她省掉什么 | 推荐时先不提主播只认识她一天；其他情况留到见面后自己说。 |
| 外部压力 | 候选人不在麦上。C03 只是主播设想对方可能追问，没有新增男方消息。 |
| 第一次变化 | “要求低”原来不妨碍她希望主播优先提供更好的选择。不是据此判她撒谎。 |
| 第二次变化 | 主播提出不熟悉的困难，她却马上替他想介绍措辞；“帮我说句好话”开始变成一件她能安排步骤的事。 |
| 眼前结果 | 主播没有答应介绍；她也没有认错或放弃期待。 |
