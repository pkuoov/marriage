# 案件时间线与尾声收口

本轮按用户要求把“四案依次呈现”和“日历连续发生”分开。最后的 Tony 案是当前最近发生的案件。2022 年主播误判与 2019 年旧账单仍是独立历史，不借它们给这四案定年。

| 事件 | 故事日期 |
| --- | --- |
| 信用卡案，两次通话 | 2024-07-15—07-16 |
| 职场案，直播与单独咨询 | 2024-07-25—07-26 |
| 职场案，三天后的公开回访 | 2024-07-29 |
| 相亲资料案，两次通话 | 2024-08-22—08-23 |
| 序章咖啡厅 | 2024-09-01 |
| Tony 案，最近两晚 | 2024-09-21—09-22 |
| 宸直正式暴雷新闻、旧案来信 | 2024-09-22 深夜 |
| 序章鉴定回告 | 2024-09-23 上午 |

源日历在 manifest.storyCalendar，各案 sessionDates 驱动通话 HUD；标题卡给出日期和相对间隔。第二案的公开回访移回自己的案尾。同步垫款时长、会议、饭局、第三四案材料日期及平台方案截止日。尾声旧案来信承认事情已经过去数周，不再把旧会议写成今天发生。

尾声的实际路径：最后一案收播 → 打开宸直新闻 → 几位旧来电人的近况 → 天亮的生活段落和旧文件袋 → 上午鉴定回告 → 家庭卡回单 → 三段已批准片尾。鉴定报告由男方收到并带来；男方请求再看一遍，赵介绍并视频接通张法医。结果为排除生物学父子关系，生父身份与妻子此前知情仍未揭露。

本轮发现的核心问题：

- 案件编号被误当作连续日期，导致跨案衔接、旧案回访和平台期限一起失真。日期调整必须检查所有“今天、明天、下周”的相对说法。
- 内容文件里已有尾声，不代表玩家能按正确顺序看到。必须沿实际按钮走到新闻、鉴定与片尾，不能只搜到文案就算完成。
- 鉴定结果卡原先在对白尚未播完时就出现，提前泄露答案。新增随对白结束显示的区域，初始及中途读档都隐藏，完成后才展开。
- 专家出场要通过已建立的人物关系和具体求助接入，不能一切场景就直接给专业结论；删除主播重复替所有人解释边界的口播。

验证：内容索引与四份台本等派生报告已重新生成；`npm run check`、`npm run build:playable`、`git diff --check` 通过。隔离浏览器从序章进入案间测试，定点衔接各案尾、近期 Tony 开场、新闻、来信、鉴定回告与三段片尾；覆盖 1920×1080、1366×768、1280×800、1280×720，检查截图。鉴定入口与中途读档不显示结果卡，读完后显示。第二、三案另在 1280×720 跑完整受影响流程，核查第二案私下咨询、公开回访、来源、旧存档进度恢复及紧凑收麦。

以上是源码顺序审读与隔离自动路线回归，不声称是无先验玩家从新游戏盲玩四案。
