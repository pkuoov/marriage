## A 部分：第四案（`04-workplace.json`）

### A0（P0·新核心）来电人不是白莲花——她也跑冒滴漏、配合过领导吃拿卡要，这次是被挑中的炮灰

**作者真相（写进 spine）**：小陈手不干净是部门公开的秘密，也是同事选她垫款的原因之一——她新、想表现、且不敢闹（一闹先查她自己）。她的三层「不白」，从轻到重：

1. **轻**：打车/餐费报销习惯性凑整多报（现有台词「以前最多垫过打车，第二天就能报」翻新为伏笔：报得很熟练）。
2. **中**：收过本次活动供应商塞的购物卡（小额，两三千）。
3. **重**：转正前后，帮领导把两张私人消费发票走成部门招待费——领导让办的，她照办，当时还觉得这是被信任。

**落点设计**：

- **第一夜**：只埋不揭。保留【流程词说得很顺】；「垫过打车」句加一丝过度熟练感。她对「来不及走流程」毫不惊讶，这个不惊讶本身是伏笔。
- **白天调查**：
  - 供应商门市补一句部门文化证词（如项目员随口：「你们公司来对接的人，伴手礼从来不少拿。」不点名）。
  - 财务窗口补半句：「你们部门备注『老规矩』的单子不少。」
- **第二夜·羞耻点坦白场（本案峰值，对齐案1余额坦白）**：主播问「他为什么偏偏挑你垫？」→ 三段式挤出：先「因为我好说话」→ 被追问 → 「因为我……帮领导报过两张票。私人的。他知道。」→ 购物卡也在此层或防备变体中带出。
- **对方结案留言改写**（从纯防守变软威胁）：「六万八我认她垫过。真要走公开流程，就把部门这半年的单子都摊开——她知道那里面有什么。」删掉现稿里过于讲理的自辩排版。
- **领导批注一字不改**：「老规矩」「别让这点流程问题影响部门这季度的成绩」在新语境下自动变暗，靠上下文完成含义翻转。
- **结案变化**：
  - 群消息「发不发」成为真两难：发 = 追账但可能引火烧身；不发 = 安全但六万八悬置。结案卡诚实记录她的选择，不判分。
  - 主播收束账人两分：「六万八该追，这是账。你那两张发票和购物卡，得在别人翻出来之前自己处理，这是人。」
  - 【能确认】增补：她帮领导处理过私人发票；收过供应商购物卡。【仍未知】保留：领导是否知情本次垫款；返利是否已支付。
- **主播私线呼应（可选一句）**：林旭阳前大厂法务背景——「我做法务的时候，最后背锅的从来不是拿最多的，是最好用的。」

### A1（P0）修复「报销审批截图」硬洞

现稿硬伤：「报销审批通过」= 系统里存在单据，她却查不到回单号，也从不自己登录系统查——一句追问就塌。

**改法**：把那张图挑明为**冒名顶替**——它是「活动立项审批」页，不是「报销审批」。材料检视新增字段（审批类型/单据编号），玩家亲手圈出「单据类型对不上」。因果闭合：报销单从未被提交（垫付未报备根本没有单），所以回单号永远查不到；「同一张图发三次」的既有暗示正好落地为实锤——他不只拖延，是伪证。同步更新：审批截图材料卡、q04 行备注、财务窗口台词（经办一眼指出「这不是报销单据的编号段」更佳）。

### A2（P1）补齐同事动机链

现稿断裂：无论走对公还是她垫款，他都是项目联系人、返利照拿——让她垫钱对他无必然好处。

**改法（二选一，推荐①）**：
1. **报价含水分**：供应商报价是他定的、高于门市价，走对公要过财务比价，高报价保不住、返利跟着缩。让她垫 = 绕开财务视线。白天供应商线补半句证词（「这单的价是他报的，比我们挂牌高」）。
2. **预算已被挪用**：本季预算他已用掉/挪走，先斩后奏，把资金窟窿转到她卡上。

与 A0 联动：选她当垫款人，正因为她不敢闹。

### A3（P1）现实性三补丁（各一句话）

1. **信用卡额度**：入职八个月的新人一次刷 6.8 万存疑 → 她自己申请了临时提额（顺带加深「她多想做成」）。
2. **活动为什么急**：前一天 14:05 才发流程表无解释 → 客户方把时间提前/领导临时加场，一句交代。
3. **发票**：全案未提 → 财务窗口第一问改为「发票抬头开的谁？」；她答「公司抬头，在我这儿」——报销前提成立，窗口戏更真。

### A4（P2）领导责任配比

结案卡增补一条：部门存在「先办事后补流程」惯例，绕流程不是她发明的；她的问题是垫了钱不敢问 + 自己手上不干净，不是单纯「没报备」。避免全案责任落点像替公司开脱。

## B 部分：第三案（`03-profile.json`）

### B0（P0）诊断锚点

对照前两案：案1有隐瞒失业+借贷（恶意行为），案2有冒名+民警（不可逆后果），案3只有一场没谈拢的条件——没人做坏事、没人失控、没有不可逆损失，饭局一取消就无痛收场；所有冲突都是转述的；真正的戏剧引擎（妈）从未上场。以下五项按序落。

### B1（P0）让妈进场——用已埋的表妹钩子

现有资产：「自称表妹的人发来家里群截图，来电人没同意公开」。让这条线炸开：

- 表妹在看直播 → 家里知道女儿在电台讲家事 → **第二夜妈的闯入**（打女儿手机被迫免提，或直接打进热线，二选一实现成本低的）。
- 妈必须自洽而非泼妇：「我要二十八万八不是卖女儿，是怕她被看轻。你表姐十八万八，婆家现在怎么使唤她，你们看不见？」——妈有她的道理，冲突才立得住。
- 来电人当场被夹在中间，主播面临现成的「无安全选项」时刻：帮女儿挡（越界）/让母女当场对质（数据涨、伤害真）/切广告（保护但悬置）。
- 【停顿】【背景里妈的声音】等舞台指示优先复用现有演出机制。

### B2（P0）给「没叫停」以不可逆代价

男方连麦时补一刀：家里群截图已在他家亲戚间传开（表妹泄露的连锁），他妈也看到了「差那么一点就够，说明他不是拿不出，是不愿意拿」这句。**隐私外泄收不回来**——取消饭局不再是无损收场，双方带伤离场。来电人的「是我没说」从道德认领变成有实感的悔。

### B3（P1）男方从防守转反击——冲突升级为「钱怎么摆」

男方连麦不只自辩，抛出对等条件：「二十八万八可以谈。同等金额写进共同账户；你家那二十万到期也进来。你们要的是保障，我要的也是。」把问题从「要不要给」升级成「双方的钱怎么摆」——可辩论的真两难，弹幕有站队空间，主播「只对账」立场更难守。她当场答不上来（她连二十万到期都没告诉过他），哑场即戏。

### B4（P1）激活表姐对照线

表姐或表妹后台留一句：「姑妈现在拿『二十八万八』去说我妈了，说我当年要少了。」攀比沿家族链传染，一句话让彩礼数字从个案变成一张网。放尾声回声或第二夜后台留言均可。

### B5（P2）「取消饭局」变成有代价的选择

前提改两处：饭店已订（定金五百）、双方父母都已通知。结案的「先取消」于是牵出「谁去说、用什么理由、妈的脸往哪放」——取消是一个决定，不是安全阀。结案卡【下一步】同步改写。

## 硬约束

1. **跨案事实不动**：宸直线（三十万、九月底到期、兑付纠纷）、澄川、四案顺序、尾声回声结构不变。
2. **玩家知识 ≠ 作者知识**：新增的「不白」事实必须经玩家追问/材料挤出，禁止来电人无因自曝。
3. 新台词全部走 case JSON 真源；材料字段改动同步 `scripts/verify-pack.js` 相关断言与 `contentCase.js` 字段白名单。
4. 语气与「去AI味」技法一致：坦白走三段式抵赖，忌「是我的问题」式一步认领；语气词按人设配额。
5. 新增闯入/连麦选择若产生状态分叉，接 `docs/drama-depth-design-exec-prompt.md` 的 guardLevel/材料可见性机制，不自造新系统。
6. 不加说教：妈、领导、同事都不获得道德判词；结案卡只记录。
