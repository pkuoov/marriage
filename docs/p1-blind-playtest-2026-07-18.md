# P1 盲玩验收单

日期：2026-07-18

状态：机器预检已完成；真人盲玩待现场执行。机器回放不能代替玩家是否看懂代价、听清语音和接受像素风的主观判断。

## 给测试者的唯一说明

> 这是一个深夜热线节目。请按你自己的判断完成试玩；遇到犹豫时直接说出你以为按钮会造成什么后果。

不要提前解释正确路线、忍耐算法、三态立绘、音频资产数量或关怀选择不计分。主持测试的人只记录，不提示。

## 开始前机器门槛

- `npm run check`
- `npm run verify:pack -- steam-demo-01`
- `npm run smoke:browser`
- 标题、低忍耐、直播棚、白天城市和吹风机回放五条 P1 音频均为 `ready`。
- 四案均能加载 `neutral / guarded / pause`，运行时图为 `1024x2048`，母版为 `256x512` 真透明 PNG。
- 所有会改变路线、资源或结局的按钮，在点击前显示资源损失、锁定或“不计分”。

## 单人场次

建议 45–70 分钟，全程不开设计文档。至少覆盖一条正常路线；时间允许时再用第二位测试者走材料误圈或外围追问路线。

| 观察点 | 主持人只问 | 通过标准 | 记录 |
| --- | --- | --- | --- |
| 关键追问 | “点下去前，你觉得会失去什么？” | 能说出未命中会掉耐心 | |
| 材料圈点 | “这一步能不能反悔？” | 知道圈偏有代价，不把按钮当普通翻页 | |
| 白天地点 | “为什么选这里？” | 知道地点占用一次走访，能表达取舍 | |
| 回拨开场 | “另一个还能不能再选？” | 知道选后锁定 | |
| 最终追问 | “点下去以后会发生什么？” | 知道会收麦，不把它当可返回预览 | |
| 关怀选择 | “你觉得这句算分吗？” | 知道不计分，仍愿意按角色态度选择 | |

## 音频观察

- 标题 BGM 是否在 30 秒内显得重复或抢字。
- 低忍耐压力层是否让玩家感到收紧，但没有误以为倒计时即将归零。
- 直播棚与白天城市切换是否可辨，循环接缝是否明显。
- “吹风机回放”第一次播放是否能听清“只有你能接住我”，同时听出背景噪声；逐字稿必须一直可见。
- 当前系统声线只用于试玩。若测试者首先评论“机器人声”，记录但不把它误判成台词问题；商业发布前必须换定向真人录音。

## 立绘观察

- 不告诉测试者“三态”。结束后再问：“你记得来电人姿势变过几次？”
- 三态应被感知为同一个人在防备、停顿或放松，不能像换了三个人。
- 三分之二侧脸和简化五官要维持匿名感；如果测试者主动猜测具体身份、职业或年龄，记录是哪一张图、哪个五官细节泄露了信息。常驻立绘不得靠眼部光带、遮罩或重阴影补救。
- 在 `390x844`、`1366x768` 与 Steam Deck 至少各看一次：人物不能压住对白、材料板或按钮代价。

## 立即返工条件

- 两名测试者中有一人连续两次误判同类按钮代价。
- 吹风机语音无法靠一次播放听清，或底噪遮住关键词。
- 任一案件三态被认为是不同人物。
- 移动端按钮代价换行后遮住标签，或主选项需要横向滚动。
- 音频关闭后仍自动播放，或语音播放时 BGM/环境音没有压低。
