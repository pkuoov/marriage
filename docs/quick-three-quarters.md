# 快案 03《四分之三》制作说明

内容真源：`content/packs/steam-demo-01/quick-cases/03-three-quarters.json`。角色真源：`content/characters/cast.json` 的 `quick3-caller-secretary`。本案从直播快案选择页进入，完成记录独立于主线。

## 已确定的故事事实

本案为用户提供并经 manager 同意的虚构故事。只由林旭阳与女秘书在麦上说话。老张、小张、初恋和孩子不作为发言角色出现；所有材料由女秘书主动提供，公开对白使用化名及匿名内容。

| 人物／物件 | 固定设定 |
| --- | --- |
| 老张 | 58 岁，丧偶，父母已去世；前妻遗产已处理。与女秘书交往三年，三周前因交通事故去世，无谋杀支线。 |
| 小张 | 29 岁，老张成年儿子，留学归来在邻市工作；与女秘书交往两年半，以为她只是父亲的秘书。 |
| 女秘书 | 32 岁，明知父子关系；在两地分别同居，未与任何一人登记。与老张说邻市出差，与小张说回公司工作。 |
| 孩子 | 18 个月，实际为老张之子、小张同父异母的弟弟；曾被女秘书说成小张之子。 |
| 初恋 | 从事医疗咨询转介，非出具鉴定的专业人员；不设第三种生父悬疑，也不进入通话。协助联系筛查、裁图，收八千元咨询加急费。 |
| 财产 | 双方暂认的清单为老张个人净财产四百万元；未发现遗嘱。主播不把女秘书提供的清单当成完成法律审查。 |

## 时间与利益账

故事发生在孩子一岁半时。去年四月孩子满月，五月满两个月；今年九月老张去世。日期在剧本中固定，不随电脑日期变化。

1. 去年四月十六日：老张与孩子的报告支持生物学父子关系。
2. 四月十七日：她向初恋复述这个结论，并问小张的筛查能否只留“有血缘”那行；对方明确说不能凭这认父子。
3. 五月十八日：小张与孩子的亲缘筛查出结果。她付八千元，转发裁掉限制说明的截图，让小张相信自己是父亲。
4. 此后：老张每月给一万元，小张每月三千元，备注“儿子奶粉钱”；她收下且未纠正。这里只固定月额，不凭孩子年龄倒算全部实收金额。
5. 老张去世后：她向小张承认孩子是其弟弟。小张结束关系，要求明天协商时带齐材料。她来电想取得支持母子拿三百万元的片段。

她的算法是：先以伴侣身份拿二百万元，再将余款分给两个儿子，孩子的一百万元由她管理，所以她可拿走三百万元。这是人物想推动的方案。

## 三轮剧本与线索回收

| 轮次／预计朗读与操作 | 原话与材料 | 对质结果 | 下一轮入口 |
| --- | --- | --- | --- |
| 第一轮／约 4–5 分钟 | 未领证、自己写的分配表；父亲在世时却采小张的样本 | 先分一半没有现成依据；小张当时要确认自己是不是父亲 | 她承认与小张交往 |
| 第二轮／约 4–5 分钟 | 两地同居；儿子奶粉钱；完整报告的父子判断限制 | 所谓自愿付钱有身份前提；真实字句被裁去关键上下文 | 她为了自证主动提出老张的另一份报告 |
| 第三轮／约 4–5 分钟 | 老张报告、四月十七日旧聊天、五月截图和费用 | 早已知情仍误导小张；裁图由她主动要求 | 拒绝提供支持三百万元的录音 |
| 收麦与复盘／约 2–3 分钟 | 已播六处对质 | 完整路线尖锐批评具体欺骗，保留孩子权益与真正待核实的事项 | 返回选案／重玩 |

上述时长为写作目标，实际随字速与玩家停留变化。每轮两处对质可任意先后，不得互相使用同轮另一处尚未问出的事实；进入下一轮必须完成两处。

最大反转是她在给小张截图以前就已知情。`revealTransition.lineIndex = 6`，紧接她承认“四月就知道了”之后，复用已有的通用反转提示。出报告日期本身不证明阅读日期，必须结合她次日发送的聊天和本人的承认。

普通信息包括照看孩子、钟点工、孩子乘车习惯、装报告的检查袋；这些只维持人物生活感，不作为品行或亲子证据。八千元只证明付款，不能独立证明故意误导。

完整结尾按用户要求，主播直接称她为“为了钱不择手段的骗子”，理由限定在早已知情、主动裁图、误导小张付钱和改变身份索取遗产。提前收案版本不泄露未问出的关系、报告和聊天，不出现该定性。

## 事实边界

- 问题报告设定为亲缘筛查，明确不能判断父子。不能写成正规亲子鉴定必然把半兄弟误判为父子。
- 亲子报告、聊天、转账在游戏中是她提供并讨论的材料。她对自己的行为作出承认；对报告的法定证明力与最终财产分配仍保留核实。
- 同居身份、财产权属、继承份额和监护管理不能相互替代；母亲欺骗不取消孩子的权益。
- 不说女秘书依法绝对一分钱都拿不到，不把均分当成任何情况下的固定结果，不替初恋或女秘书宣布具体罪名。

法律设定核对：[最高人民法院公报《中华人民共和国民法典（续）》](https://gongbao.court.gov.cn/Details/7f184078694d811fb3314f6af9accf.html)，婚姻登记及继承相关条文见第 1049、1127、1130、1131、1153 条；备查[最高人民检察院全文](https://www.spp.gov.cn/spp/zdgz/202006/t20200602_463886.shtml)。这里只约束虚构剧情，不构成个案裁判结论。
