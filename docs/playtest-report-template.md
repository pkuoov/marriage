剧情连读检查：上一句提供了什么、为何追问、人物认了或回避什么、下一句由何而来。区分刻意隐瞒、真实迟疑与作者断线；不按禁词、金句、打断或说辞层数评分。材料出现有来源，可跳过信息不成为固定续文的唯一前提。

集中问询检查：本段问题是否问清、错问是否本段重问、完成后是否直接推进；不强制回放或结尾补问。材料同页核对，动作标签明确，已听历史完整，未听内容不泄漏。口播任一有效点评推进。旧回放只记录兼容现状与待迁移项，不算新设计通过。

状态检查：普通浏览不扣耐心；误问按模式结算且只扣一次；保存、重载、返回后保持进度；仍受支持的旧排序入口保持结果一致，不新增排序关卡；材料和反应不因重绘重复入账。

PC 布局检查：1920×1080、1366×768、1280×800、1280×720 按影响范围覆盖，再补小屏。原句、名牌、反馈、操作与转场标题在实际窗口内；长材料提炼重点并保留原件访问；关闭案卷或材料后焦点和位置恢复；短提示及时消失。

截图验证：先检查矩形边界，再查看截图里的文字、遮挡与点击目标；`visible`、DOM 存在和脚本 PASS 都不能独自证明画面正确。记录截图对应的构建，最后一次布局修改后需复验该页面，不能沿用旧截图结论。

音频、键盘、手柄与发行只在涉及对应变更时追加测试。盲玩时问测试者实际理解，不预先宣称每个按钮都消耗资源或锁定路线。
