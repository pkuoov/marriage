# 大测试记录模板

每轮大测试先复制本模板，记录实际屏幕文字和操作路径。不要只写“感觉还行”；问题必须能回到具体页面、具体台词或具体按钮。

- 日期：

## 文本问题

| 位置 | 原文 | 问题类型 | 修改建议 |
| --- | --- | --- | --- |
| | | AI 味 / 说教 / 早剧透 / 替玩家决策 / 口吻不像主播 / 来电人不像活人 | |

固定检查：

- 是否出现“先看、关键点、结论更锋利、正确答案、最佳答案、放准了、放到了别处、让我停住的是、麦温”这类工作流或 AI 腔。
- 主播问题是否只基于已出现的信息。
- 来电人是否藏了对自己不利的信息，而不是只负责递线索。
- 结果页是否像余波，而不是评分表或教程。

## 玩法问题

| 位置 | 操作 | 预期风险 | 实际结果 | 是否需要进 backlog |
| --- | --- | --- | --- | --- |
| | | 忍耐消耗 / 信息损失 / 防备回答 / 事实边界错放 / 材料误指 | | |

固定检查：

- 当前节点只能选一次，选完必须推进，不允许扫完同一段剩余选项。
- 外围选项要有诱惑，不能一眼就是弱答案。
- 忍耐耗尽进入本案失败，不自动接下一路麦。
- 事实边界一次放置，错放不当场纠正，只影响回看和终局。

## UI 和视觉问题

| 位置 | 截图/描述 | 问题类型 | 修改建议 |
| --- | --- | --- | --- |
| | | 遮挡 / 字号溢出 / 按钮优先级误导 / 立绘僵硬 / 背景不贴题 / 控场台不像直播间 | |

固定检查：

- 主体内容、匿名来电区、按钮和上一问抽屉不能互相遮挡。
- 选择按钮视觉权重一致，不能暗示“推荐项”。
- 立绘表情和停顿只做表演，不给答案。
- 案内不能显示目录、案数、标题列表或故事集论点。

## P1 音频、像素立绘与按钮代价

本轮盲玩执行细则见 `docs/p1-blind-playtest-2026-07-18.md`。

- 不提示机制，点击前追问测试者：“你觉得会付出什么？”
- 检查关键追问、材料圈点、白天地点、回拨开场、最终追问与关怀选择的按钮级代价是否被正确理解。
- 记录五条 P1 音频的可听性、循环接缝和抢对白问题。
- 不预告三态立绘；结束后再问测试者是否察觉姿势变化，以及是否仍认为是同一个人。
