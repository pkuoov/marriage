# 婚恋侦探局案型来源说明

本案库不是照搬真实个案，也不对应任何单一真实人物。所有案型都从公开可见的律师普法、法院规则、社会事件、情感咨询叙事和婚恋诈骗研究中抽象而来，再改写成可复用的游戏结构。

## 已接入规模

当前 `src/caseEngine.js` 的 `LIVESTREAM_PLOT_LIBRARY` 共 28 个案型。

## 来源类型

- 法院与法律规则：彩礼返还、婚前重大疾病告知、恋爱转账借赠争议、亲子关系、夫妻债务、婚前房产等。
- 网络律师普法常见题：彩礼短暂共同生活、房产加名、婚史/孩子/债务隐瞒、共同创业、同居装修代付等。
- 情感咨询/情感博主常见叙事：前任借钱复联、同事情绪外包、控制报备、婚礼前临时加条件、资料包装等。
- 公开社会事件抽象：恋爱转账舆论反转、订婚后彩礼/房产/亲密关系冲突、亲子疑云和外情生子争议等。
- 婚恋诈骗研究：杀猪盘、交友软件假账号/会员诱导、虚假身份与投资平台。

## 抽象原则

- 不使用真实姓名、具体金额、可识别地点和原始细节。
- 每个案型必须能生成“先诉苦者版本、另一方版本、第三方/材料版本”。
- 每个案型必须包含可追问的迷惑点：假话、含糊话、不愿意说、小承认掩护大隐瞒、真话但留白。
- 每周目固定抽取一个婚前 case、一个婚后 case、一个告解模式；告解模式由随机当事人自述经历，重点查被坑、自欺、隐瞒、获益和伤害。
