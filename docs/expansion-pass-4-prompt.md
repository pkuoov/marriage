## 任务 1：闲聊层引擎（小改）

内容契约：

- 新字段 `sceneVersions[].casualQuestions: [{ "question": "", "answer": "" }]`（可选数组；条目可带可选 `guardedAnswer`）。
- 渲染：当某场景存在 `casualQuestions` 时，「普通提问」区**只**渲染它们，不再从 `questionOptions` 里过滤非核心项；「关键选择」区照旧渲染全部 `questionOptions`。无 `casualQuestions` 的场景保持旧行为（兼容未迁移案件）。
- 已问置灰、防备信号联动均沿用现有 dialogue 通道行为；`casualQuestions` 不带 `contradiction`，路线记录按现行 dialogue pick 逻辑走默认轴。
- `verify:pack` schema 允许该可选字段；`scripts/verify-logic.js` UI-001 补断言：存在 `casualQuestions` 时普通区按钮文本来自它、且不得与该场景任何 `questionOptions.question` 重复。
- `npm run smoke:browser` 的 outer 路线若点的是普通区按钮，改为点新的闲聊按钮。

## 任务 2：四案闲聊层内容（每场 2 条，共 40 条，逐字）

写作红线：闲聊回答只做人物、语感和已有伏笔的浇水——不新增承重事实、不带矛盾点、不暗示材料板答案。

### 案 1（01-credit.json）

场景 0：
- Q「你们平时谁管钱多一点？」A「各花各的。约会基本他出，我偶尔抢着买单，他不让，说“跟我你还客气什么”。」
- Q「他丢工作前，加班是什么样子？」A「天天说忙。几点回家我其实不清楚，我们没住一起，都是他说什么我听什么。」

场景 1：
- Q「那些餐厅是什么档次？」A「人均四五百吧。他老说“这家你肯定喜欢”，其实有两家是我收藏了很久的。」
- Q「礼物都送了些什么？」A「香水、一条项链。项链那次他发了朋友圈，配文“她值得”。我朋友都点赞了。」

场景 2：
- Q「他以前跟你开过口借钱吗？」A「没有。一次都没有，所以这次我才慌。他那个人，以前连打车钱都不让我掏。」
- Q「“怕你离开”那句，他是打字还是语音？」A「语音。声音很低，我听了三遍。……然后金额是打字发的，很整齐。」

场景 3：
- Q「探店号你做起来了吗？」A「发了十几条。最高一条八百多赞。他每条都转。」
- Q「那套设备现在还用吗？」A「灯上个月还开过。现在拍不动了，一开灯就想起这事。」

场景 4：
- Q「你朋友现在知道多少？」A「知道我们在闹别扭，不知道钱的事。我还没想好怎么开口。」
- Q「“低你一头”这话，他以前说过吗？」A「说过一次，喝了酒。那时候我当情话听的。」

### 案 2（02-tony.json）

场景 0：
- Q「你在他们店剪了多久头发？」A「一年多。最早是同事推荐的，后来就只找他。」
- Q「相亲那次是谁牵的线？」A「我姨。她就说人家手艺人踏实。现在想想，介绍完第二周，他就开始给我留最晚的号。」

场景 1：
- Q「店长骂他，他都怎么跟你说？」A「语音，叹气，说“这行就这样”。我每次都接一句“你手艺好，怕什么”。」
- Q「帮他转活动，你朋友什么反应？」A「有个闺蜜真去剪了，还说不错。后来她办没办卡，我没好意思问。」

场景 2：
- Q「那张表你存下来了吗？」A「截了图。当时手比脑子快，现在想想幸好截了。」
- Q「备注里“稳情绪”三个字，你第一眼什么感觉？」A「说不上来。就是觉得……我在他那儿是个项目。这话我没跟人说过。」

场景 3：
- Q「老板娘那句话之后，店里人怎么看你？」A「有个小妹叫过我一次“嫂子”。他没接话，也没否认。」
- Q「年卡多少钱？」A「三千八。我没办。不是舍不得，是那天刚好看到那张表。」

场景 4：
- Q「你现在还去那家店吗？」A「号还留着，人没去。头发长了，随便找了家快剪。」
- Q「那个开过店的朋友，怎么认识的？」A「大学室友。她开过两年美容店，后来累垮了转行。她看东西毒。」

### 案 3（03-profile.json）

场景 0：
- Q「你们相亲见了几次？」A「四次。两次饭，一次展，一次他接我下班。节奏不快不慢。」
- Q「你跟你妈平时什么都聊吗？」A「大事聊。她比我急。我 28 了，她逢人就说我“不挑”，其实是她挑。」

场景 1：
- Q「介绍人跟男方家什么关系？」A「他妈的老同事。所以话肯定挑好的说，这我懂。」
- Q「“家里省心”这话你怎么理解？」A「就是独生子、爸妈有退休金、不用他贴钱。相亲市场上这四个字值钱。」

场景 2：
- Q「他解释 MBA 的时候，语气什么样？」A「不躲。就是说得很顺，顺得像回答过很多遍。」
- Q「你自己学历怎么样？」A「普通一本。所以“名校”两个字我提的时候，其实也在给自己贴金。」

场景 3：
- Q「团购那顿饭，最后谁付的？」A「他。用了券，又用了会员积分。他算得很快，我坐对面看着，有点走神。」
- Q「你妈见过他照片吗？」A「见过。第一句问的是“个子多高”，第二句就是“做什么的”。」

场景 4：
- Q「工资卡那句，他说完你们冷场了多久？」A「十几秒吧。后来是服务员来加水解的围。」
- Q「你身边有婚后一起管钱的例子吗？」A「我表姐。管得挺好，但她挣得比姐夫多。这话我没跟我妈说过。」

### 案 4（04-workplace.json）

场景 0：
- Q「你进这家公司多久了？」A「八个月。试用期转正第二个月，就接了这个活。」
- Q「那位同事平时人缘怎么样？」A「好。谁都能聊两句，领导也喜欢。这种人你很难当面翻脸。」

场景 1：
- Q「大群里一般谁管预算？」A「部门助理发流程，财务出数。以前都这么走，就这次说来不及。」
- Q「老板对答谢会满意吗？」A「满意，会上还点了名。我那天挺高兴的。现在想想，高兴得有点早。」

场景 2：
- Q「垫的钱是多少？」A「……不方便说具体。我一张卡刷了大半额度，下个月账单要来了。」
- Q「财务那边你认识人吗？」A「不认识。入职培训见过一面。真要问，也得同事引荐，又绕回他。」

场景 3：
- Q「服务协调费，行价一般多少？」A「我查过。有的有，有的没有，查完更乱了。」
- Q「供应商是谁选的？」A「他定的，说合作过。我连对接人微信都没有。」

场景 4：
- Q「复盘材料是谁写？」A「我写初稿，他“把关”。把关俩字是他说的。」
- Q「如果重来一次，你还接这个活吗？」A「接。但会先在群里问一句预算。就一句，够了。」

## 任务 3：证言更新引擎（小改）

内容契约：

- 新字段：`sceneVersions[].revisedVersion`（可选字符串）；`evidenceChecks[].options[].revisesScene`（可选整数，场景下标，仅正确选项可带）。
- 触发与渲染：玩家圈中带 `revisesScene` 的正确选项后，先播该选项的 `reactionLine`，随后以「咨询者」气泡播放目标场景的 `revisedVersion`，再出现"继续"按钮。误圈不触发。
- 回看（上一问抽屉）要能看到这条更新，标注跟随普通来电人台词，不加任何"证言已更新"式系统文案。
- `verify:pack` 校验：`revisesScene` 指向的场景必须存在且带 `revisedVersion`；`verify-logic` 补一条渲染路径断言；smoke 的 perfect 路线补一步确认气泡出现。

## 不要做的事

- 闲聊回答不得新增承重事实、金额、日期或第三方（案 4"不方便说具体"是刻意保持金额未知，不要替她补数字）。
- 不给闲聊条目加 `contradiction`、不让闲聊触发矛盾记录。
- 不在 UI 上做"已更新/找不同"提示——差异让玩家自己听出来。
- 不动 `questionOptions` 现有内容；旧的 dialogue 过滤逻辑保留为无 `casualQuestions` 场景的回退。
- 不给案 2-4 写 `revisedVersion`。
