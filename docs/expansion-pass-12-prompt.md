你是本仓库的实施工程师。诊断：顾问团（主播的熟人）至今只是收麦后的读后感，未影响任何决定。本单实施 P2.5 证据委托（设计：`docs/advisor-npc-and-offmic-design.md`；规则：`case-scriptwriting` 的 Evidence delegation 节），其引擎依赖（幕结构锚点）已随第 11 批落地。台词与 JSON 逐字使用。

## 任务 0：守则修订（qa-report，逐字替换 8 号收口守则）

> **8 号收窄阶梯**：免费路径（场景、材料板、回流、弹幕、终局）止于前同事的拒答——「每月 8 号那笔是谁，我不说」。玩家主动委托挣来的深度可以多走一步：周会计的回单可以确认「不是工资入账，是私人转的」，到此为止。任何表面、任何深度，永不指认付款人；三读法（拆东墙／多线／化债）永远全活着离场。

## 任务 1：委托引擎

- 内容契约：案件可选字段
  `delegation: { "moment": "actBreak:2", "material": { "id", "label" }, "outcomes": { "<advisorId>": { "tone": "strong|partial|offDomain", "text" } } }`
- 流程：到达锚点进入后台委托屏——展示该案可委托材料（v1 每案一件，无材料选择）＋四位顾问名牌（姓名/领域/口头禅取注册表）；玩家选一位；回单在下一幕开头以顾问名牌＋文本到达，**必须早于选原话**。每案一次，不可跳过改为可跳过（「先不送」按钮，跳过不惩罚、终局不提）。
- 路线记录：选择记入路线轴（zhou=money-flow, zhao=process-responsibility→映射现有 process-control, lin=identity-wording, zhang=document-edge）。
- 校验：`verify:pack` 要求 outcomes 覆盖四位顾问；strong 每案至多 1；顾问文本过禁词与"圈/那一栏/哪一块"扫描；回单不得与该案 advisorNotes 重复整句。
- `smoke:browser` 补一条委托路线（perfect 路线中选 strong 配对）。

## 任务 2：四案委托矩阵（16 条回单，逐字）

### 案 1 material：往期账单页（label「往期账单那几页」）

- zhou（strong）：「工资入账都带代发抬头，这笔 8 号的还入没有——是私人转的。谁转的我看不见，但它不是工资，这一点看得死死的。钱只认路径，不认说法。」
- zhao（partial）：「按月固定还入，若是借的，就是新债养旧债；若是赠与，停了也不欠。两种在法律上是两个世界。具体看证据，我只说一般情况。」
- lin（partial）：「这个账单我看不出门道。但一个人肯按月替另一个人填窟窿，在我们行里，这叫'关系没断干净'。当笑话听吧。」
- zhang（offDomain）：「流水单不是我的领域。链条上说，银行流水造假成本极高，这几页大概率是真的——所以更值得认真对。」

### 案 2 material：那张表（label「他发错的那张表」）

- lin（strong）：「维护表我见过几百张。写到'下一次推进'这个细法的，不是新手上进，是老手养熟客——这一列的写法，行里叫'关系落袋'。他这个岁数写出这个列，不是店里教的，是有人带过或者自己悟的。」
- zhang（partial）：「截图链条完整，没有拼接痕迹。表是真表，字是一次录入——这张图本身干净，脏的不在图上。」
- zhou（partial）：「年卡三千八进的是店收银还是个人码，让她查下支付记录的商户名。进店的算业绩，进个人的算什么，她该想清楚。」
- zhao（offDomain）：「'老板娘'这种话在法律上一文不值。可它值三千八——这句不归我管，归她自己管。」

### 案 3 material：学历截图（label「他发来的学校图」）

- zhang（strong，法医首秀）：「图是原图，像素没动过——她验得对。但鉴定书只管图，不管图外之意：这类项目学位，学信网三分钟能验真伪。真问题从来不是图的真假，是口径——像素没动过，不等于话没动过。链条不全，报告就是纸。」
- zhao（partial）：「恋爱里把 MBA 说成名校毕业，不犯法；婚姻登记处也不查学历。法律管骗婚财，不管吹牛皮——所以这事只能在饭桌上算，算之前先把话留好底。」
- lin（partial）：「'名校毕业'这四个字在相亲市场上有牌价。他这么说，介绍人这么传，女方家这么听——三方都没吃亏，直到有人当真。行里的话，得翻译着听。」
- zhou（offDomain）：「图我不看。要看看流水——收入这种事，纸上写的都是形容词，到账的才是名词。」

### 案 4 material：审批截图（label「那张审批图」）

- zhou（strong）：「对公付款都有回单号。让她别问'钱怎么还没到'，就问财务要这单的付款回单号——报得出，是真在走；报不出，就是根本没付。一句话的事，比吵十次管用。」
- zhao（partial）：「群里'让我垫'的原话，加上她的转账记录，债权凭证已经够了。走不走那一步是她的事，但料要现在留好——口说的不算，落纸的算数。」
- zhang（partial）：「这张截图是完整截屏，底部没有裁切痕迹——它不是被剪过，它本来就只走到审批这一步。图没撒谎，撒谎的是拿图当回执用的人。」
- lin（offDomain）：「职场不是我的场。但'想表现'这个东西我熟——我们行里叫'客户自己想成交'，最好的销售从来不推销，只递台阶。」

## 验收

1. 每任务后 `npm run content:index && npm run check`；最后 `verify:pack -- steam-demo-01`＋`smoke:browser`（含新委托路线）。
2. `rg "delegation" content/` 命中四案；`rg "私人转的" content/` 只命中案 1 委托回单（收窄阶梯只此一处）。
3. 手动过案 1：幕间委托屏出现→选周会计→下一幕开头回单到达→选原话仍在其后；选「先不送」终局无提及。
4. 四案各自验证 strong 配对的回单不与该案 advisorNotes 重复整句。
5. 提交：`feat: evidence delegation makes advisors players`（引擎+矩阵）、`chore: advisor-host history and the matchmaker conflict`（任务 3-4）。

## 不要做的事

- 回单永不点向材料板正确项；案 1 周会计回单是 8 号线的最深处，之后任何批次不得再深。
- 张法医案 3 回单不得替玩家去学信网"查到结果"——他只说可以验、几分钟能验，验不验是玩家和来电人的事。
- offDomain 回单不空手、不嘲讽、不漏强线索。
- 委托屏不加倒计时、不加推荐标记——选谁是玩家的表达，不是测验。
