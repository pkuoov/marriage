# 剧情事实链去 AI 化审查

生成时间：2026-06-29

本轮按 `livestream-game-flow-review` 的 pressure-system / actor-consistency 方法审查，不从单句润色入手，而是先抽取每案的事实链，再回写到案件模板。

## 审查准则

- 关键材料不能像系统自动发牌，必须有生活触发：发错、转述、家庭群、办材料、报销流程、顺手截图。
- 每个材料必须回答：谁推出来、想省掉哪句话、如果说全会失去什么。
- 来电人不能只当受害者，也要有面子、机会、误判、默认或不想承认的部分。
- 对方不能只当谜底坏人，要能看出 TA 为什么此刻不说全。
- 结论不写成讲义，尽量像主播复述刚才电话里听到的事实。

## 8 万信用卡周转

- 生活触发：社保截图不再凭空出现，改为对方让咨询者帮忙看办材料用的截图时露出断缴。
- 事实链：体面约会 -> 社保断缴 -> 信用卡账单 -> 最低还款 -> 结婚压力。
- 去 AI 点：收麦不再只说“债务转嫁”，改成“社保断缴没说，信用卡花销没停，最低还款递到她面前”。

## 婚前房与共同还贷

- 生活触发：购房合同和共同账户表不再像案卷材料，改成对方母亲发到小群，说让女方家先了解。
- 事实链：父母名下房本 -> 婚后共同账户 -> 房贷装修列固定支出 -> 不写协议才像一家人。
- 去 AI 点：不再用“洗房边界”做主文案，改成房本、房贷、装修、分开补偿四句话一起听。

## 理发店排班表

- 生活触发：排班表改成对方本来要发预约时间，误发店里表格。
- 事实链：专属聊天 -> 发错预约表 -> 推进目标 -> 老板娘话术 -> 办卡/投店。
- 去 AI 点：不再写成“客户管理系统”，改成“表里排的不是班，是人”。

## 存款证明

- 生活触发：材料来自见父母前的转述压力：介绍人先说好，女方又向家里说满，男方顺势发图。
- 事实链：名校/收入好版本 -> 见面前问材料 -> MBA 本科缺边 -> 花销别扭 -> 工资卡/婚后管钱。
- 去 AI 点：保留双方都不坦诚，但不用“客观看/结构上”压结论，改成两边都把难听话包起来。

## 职场报销截图

- 生活触发：报销图来自同事用来挡催款；供应商返款来自群聊和报价单。
- 事实链：想拿主责署名 -> 私下垫款 -> 审批截图少付款页 -> 供应商返款入口 -> 主责和付款入口分离。
- 去 AI 点：不再抽象成“入口控制”，改成审批图、主责署名、垫付款、返款全挤在同一个人手里。
