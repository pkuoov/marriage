## 人物与本案声音

### 案三咨询者·林

- **性格 / 防御：** 数字化自保的理性派；省略主语，把自己的要求放进‘我妈’名下。
- **受压变化：** 更爱报精确数字、减少语气词；问到自己的工资时句子骤短。
- **跨幕：** 夜 A｜报次数、日期和金额，关键要求省掉主语，反复借“我妈”挡住自己的筛选。 白天｜逐句标出谁添了什么，承认自己转述过，却仍回避自己的工资。 夜 B｜第一人称主语回到句子里；说到自己的月薪时骤短，不再躲到母亲后面。 结案｜报出自己的数字和真正担心，仍不把未知收入说成已经造假。

### 案三咨询者表妹

- **性格 / 防御：** 替人递话的亲近晚辈；只转姐姐准她说的生活安排，不碰材料真假。
- **受压变化：** 越怕姐姐反悔，越用玩笑和催促把话说快。

### 案三相亲对象

- **性格 / 防御：** 受冒犯的条件维护者；用每个局部真实抵挡整体概括的问题。
- **受压变化：** 被质疑时按项目、余额、家里安排逐项举证，却避开连续收入。
- **跨幕：** 夜 A｜从咨询者转述中逐项强调项目、余额和家里安排都各有真实出处。 白天｜家人共同整理资料的事实浮出，但他不新增证词，也不替家人统一口径。 夜 B｜留言条列真实项，用“不够不等于假”反击，继续避开连续收入。 结案｜无法回答长期收入与学费来源，局部真实不再自动等于整体条件。

### 案三介绍人

- **性格 / 防御：** 嘴快、怕砸媒人的热心撮合者；先划掉不是自己说的那一句，再把没核实的话解释成“想让他们先见一面”。
- **受压变化：** 越被两家围攻，越急着翻聊天记录；被问到依据时，先辩一句，再认自己没核实的具体话。

### 案三男方表姐

- **性格 / 防御：** 护家的感性防守者；使用‘大家一起整理’稀释主导者。
- **受压变化：** 先拒答；确认只问资料整理后才给半句。
