- 入场方式：continue
- 入场承接：让我先顶上 / 这活我能接。从同事要求先垫，转入咨询者此前在小会上主动争取项目的具体动作。

- 入场承接：我没在群里问预算 / 只隔了十七分钟。公开群未提问之后，本段按时间接上十七分钟后的私聊劝阻。
- 场尾承接：母亲敲门只打断通话，不提供案件判断，任一路线后都能继续看审批页。

## 人工语义复审状态

四案的锚点合同均已登记；这不等于语义已锁定。每次试玩发现跳跃后，仍须回看前后至少两个话轮并重新生成本表。
