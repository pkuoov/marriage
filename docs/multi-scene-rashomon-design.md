# 多元场景与线下罗生门设计

日期：2026-07-14  
性质：场景语法立法 + 四案线下地图（非一次性全引擎交付）。  
关联：[demo2-rebuild-blueprint.md](demo2-rebuild-blueprint.md)、[two-call-night-design.md](two-call-night-design.md)

## 默认边界

- **直播铁律**：ON AIR 时只有来电人上麦；对方永不实时连线。
- **线下放开**：日间/收麦后主播可离开控台。
- **当面特许**：每包最多 1 次（试玩包落在案 1：咖啡厅旁听同席）。其余案用间接罗生门（同场不同桌、旁人转述、双份材料对读）。
- **同席 ≠ 上麦**：线下旁听/同席不算违反单连线人契约。

## 病根

案 1 已有 `overnightStructure.dayScenes`（档案室 / 餐厅 / 审流水），但白天偏「拿一句 earnedItem 回麦」：档案室像教具，餐厅两句旁白无冲突，流水虽强仍是控台独处。案 2–4 幕间贴在控台上。标题是直播间侦探，舞台却几乎只有直播间。

## 目标手感

```text
夜里审人（连线）→ 幕间拼板（控台）→ 白天走路（城市）→ 再夜里对账（回拨）
偶发：同场罗生门（特许）
```

主播用身体把证据带进别人的空间，而不是四通电话模拟器。

## 五类舞台

| 舞台 | 谁在场 | 玩家动词 | 产出 |
| --- | --- | --- | --- |
| **控台** | 主播±顾问短信 | 听、圈、委托、选框架 | 信息态、姿态 |
| **连线** | 主播+来电人+弹幕 | 追问、出示、选原话 | 证言修订 |
| **幕间** | 主播+顾问/回流 | 取舍行动 | inventory |
| **城市日间** | 主播+地点 NPC | 登门、观察、对表、拒答 | earnedItem → 回拨开场 |
| **特许同席** | 主播+来电人+第三方±对方（同场） | 选坐哪边、抛哪句、是否离场 | 双源死锁当场成立 |

推荐整晚节奏：

```text
夜A → 短幕间（1–2）→ 白天城市（预算 2 / 地点 ≥3）→ 夜B
```

避免「幕间选三次 + 白天再选两次」过碎。

## 立法（五条）

1. **场景配额**：每案至少 2 个非控台地点；包级至少 1 次特许同席。
2. **带回律**：日间每个地点必须产出可改变回拨第一句的东西（物件边 / 一句旁人原话 / 一张当场对不上的表）。纯氛围地点砍掉。
3. **罗生门律**：同席戏的目标不是问出标准答案，而是让两份剪辑当场咬住（她的一句 vs 他的半句 / 旁人的一句）。
4. **单连线人**仍只约束 ON AIR；线下同席不算上麦。
5. **预算**：白天地点 ≥3，`dayBudget < dayScenes.length`（取舍保留）。

## 引擎契约（dayScenes kinds）

既有：`studio` | `visit` | `home` | `lab` | `document`

新增：

| kind | 含义 |
| --- | --- |
| `observe` | 同场不同桌：观察对方/第三方，主播不介入对话 |
| `sitIn` | 特许旁听同席：来电人约了对方，主播不露脸旁听 |
| `doorstep` | 门口/窗边拒答戏：NPC 只给半句就关门 |

可选 `body` 字段：

- `cast[]`：在场角色名牌
- `beats[]`：`{ speaker, text }` 短对话序列
- `choice`：`{ prompt, options: [{ id, label, grantsEarnedItemId? }] }` — 选完才能「记下离开」
- 产出仍走 `earnedItemId` → `callbackOpeners`（与案 1 现网一致）

## 案 1 特许同席 · 逐字节拍（sitIn）

**地点 id**：`day-cafe-sitin`  
**label**：咖啡厅·旁听  
**backdropClass**：`day-cafe`  
**kind**：`sitIn`  
**earnedItemId**：`旁听笔记`

**开场 body.text**：

> 她发来定位：「我约了他，只对账。你坐隔壁，耳机戴上，别开口——开口我就不说了。」店里下午茶客不多。你背对那桌，耳机里是她手机的共享听筒。

**cast**：`["咨询者", "对方（隔壁）", "你（旁听）"]`

**beats**（逐字）：

1. 咨询者：「八万里，可见的吃住玩加分期不到三万。中间那五万多，你到底干什么用了。」
2. 对方：「不是乱来的钱。细节我不在这儿讲。」
3. 咨询者：「那订座呢？会员号是我的。你开口第一句还说都是你安排的。」
4. 对方：「……号是你的。灯是我真心买的。这两句我认。」
5. 咨询者：（停了很久）「真心买灯，和叫我垫八万，哪一句算数。」
6. 对方：「你要是只为了在直播间赢，我们没必要坐这儿。」

**choice.prompt**：旁听听到这里，你——

- `stay-note`：「把两句半话记进旁听笔记」→ grants 旁听笔记（默认 earned）
- `leave-early`：「先离开，今晚回拨再用」→ 仍得旁听笔记，但姿态更冷（可选 routeTone）

**callbackOpeners「旁听笔记」**：

> 「你昨天坐隔壁了？……他亲口说订座号是我的，灯是真心的。五万他仍不讲。你听着的时候，我手一直在抖。」

## 成功标准

- 每案玩家至少离开控台两次（体感）。
- 至少一案有「我听见两个人对同一物件说了两套话」的当场戏（案 1 sitIn）。
- 回拨第一句能明显来自日间地点。
- 直播单连线人契约 playtest 仍成立。
