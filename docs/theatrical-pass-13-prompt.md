你是本仓库的实施工程师。本单依据 `case-scriptwriting` 新增的「Theatrical License」规则，给四案注入预算内的戏剧性。前置：**第 12 批（证据委托）先行落地**——本单任务 5 修改它建立的关系线。台词与 JSON 逐字使用。本批不碰误判拍、不碰材料板、不碰判定。

## 任务 1：案 1「他一直在听」（轻引擎＋内容）

- 引擎契约：案件可选字段 `lurkerNote: { "presenceLine": "", "deletedFragment": "" }`。渲染于「麦外来信」页**最后一条**，样式为后台提示＋一条被删弹幕的残影；全案只出现一次；不进直播弹幕流、不进终局评论墙。
- 案 1 内容（逐字）：

```json
{ "presenceLine": "后台在线名单里，有个 ID 从第一分钟听到现在。刚才发了一条，两秒后自己删了。",
  "deletedFragment": "灯是我真心买的" }
```

- 铁线：不出现 ID 名；被删句永不触碰 8 号与五万多；**弹幕与评论墙不得讨论这个 ID**（后台在线名单只有主播看得到——感知带宽）；此人此后任何批次不得"再次出现"，一次就是全部。
- `verify:pack` 允许该可选字段；每包至多一个案子使用（特许预算）。
