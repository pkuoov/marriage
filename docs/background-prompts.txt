《直播间大侦探》场景背景 Prompt 包

用途：
单独交给专业作图 GPT / 图像模型，生成本游戏的视觉小说场景背景。

核心要求：
1. 16:9 横版背景，建议 1920x1080 或 2048x1152。
2. 无人物、无文字、无 Logo、无水印、无 UI。
3. 中间或右侧预留人物立绘区域。
4. 底部预留对话框区域，不要把重要物体放在画面最底部。
5. 现代中国都市生活质感，适合直播连线、职场、消费、租房、平台交易、熟人借贷、相亲见父母等现实公共生活事件。


====================
一、总风格 Prompt
====================

为一款中国都市直播连线公共事件题材的互动视觉小说游戏制作场景背景。整体风格：现代中国城市、轻现实主义、2D视觉小说背景、干净精致、情绪克制，有一点国产互动小说/AVG游戏质感，但不要模仿任何具体游戏或画师。画面要适合直播间问案、职场报销、消费维权、租房纠纷、平台交易、熟人借贷、相亲见父母等现实公共生活事件。

场景背景要求：16:9 横版，1920x1080 或 2048x1152，无人物，无文字，无水印，适合作为视觉小说背景。构图中间或右侧预留人物立绘区域，底部预留对话框区域，光影柔和，有现代中国生活细节。


====================
二、统一负面 Prompt
====================

不要人物、不要儿童、不要文字、不要可读标识、不要水印、不要Logo、不要签名、不要UI、不要菜单按钮、不要对话框、不要过度杂乱、不要欧美奇幻、不要古风、不要赛博朋克、不要恐怖氛围、不要厚涂油画感、不要强烈漫画夸张风格。
