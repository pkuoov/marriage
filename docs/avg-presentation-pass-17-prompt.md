# 第 17 批·AVG 标准表现层重制执行单(逆转裁判式)

你是本仓库的实施工程师。本单把对话/UI/流程重制为标准文字冒险(逆转裁判式)的呈现方式。**铁律:`content/` 目录零改动**——只改交互方式、UI 形式与对话展示;一切玩家可见文本仍来自现有内容字段,UI 装饰词(设置/案卷/自动等)是唯一新增文案。完成后 `git diff content/` 必须为空。

## 任务 1:逐句显示引擎(对话分级展示的核心)

- **自动分句**:现有 `version`/`answer`/`text` 等长段落在渲染层按句读切分(。！？……;引号内不切,「……。」整体为一句;省略号折行保留)。**存储内容不动,切分只发生在展示层。**
- **打字机逐字显现**:字符逐个出现(requestAnimationFrame,不用 setInterval 链);句中遇 、,——微停顿;正在显现时点击/按键=立即补全整句,已完成时=推进下一句。
- 推进方式:点击文本框、Space/Enter、手柄 A——三者等效(沿用现有 inputNavigation)。
- 句尾显示闪烁的继续指示符(▼),打字中隐藏。
- `prefers-reduced-motion` 时打字机降级为整句浮现(淡入 opacity 过渡,150ms)。

## 任务 2:对话框与舞台重制

- **底部固定对话框**:半透明深色底(不遮立绘主体),内容区最多 3 行,超出自动翻页(同一句被切成多页时页间同样点击推进)。
- **名牌**:框左上角小名牌,取现有 speaker 字段(咨询者/你/顾问名);主播发言名牌用「你」。
- **立绘舞台**:来电人立绘居中偏右,说话者亮、非说话者压暗 20%(现只有单立绘,预留双位);变体切换(neutral/guarded/pause)在句间切,不在打字中切。
- **HUD 收纳**:ON AIR 灯、耐心条、弹幕条缩为顶部一条细带;弹幕条改为每次只滚动展示当前一条(点击可暂停)。信息不减,占屏减半。
- 材料实物卡(showsCard)改为:对话框上方滑入的小卡,点击放大为覆盖层。

## 任务 3:选项呈现(逆转裁判式全屏打断)

- 关键选择:**暂停舞台,选项以居中大按钮纵列覆盖呈现**(2-4 个),背景压暗;标题「关键选择」与说明沿用现行文案。
- 普通提问:对话框右上角常驻小按钮「先聊聊」,点开为侧栏列表(已问置灰),问完自动收回对话流——不打断主舞台。
- 材料板圈选/边界分拣/时间线拼装:保持整屏专用界面,入场加 200ms 转场(淡入,compositor-friendly)。
- 现有 data-* 事件契约不变(smoke 依赖)。

## 任务 4:案卷(Court Record 等价物)

- 右上角常驻按钮「案卷」:随时打开覆盖层,分三栏页签——**材料**(已亮出的 showsCard 卡与已看板)/**文档**(已收到的行级文档,可重读但不可再圈)/**收获**(earnedItem、委托回单、已听回放)。
- 案卷内容全部来自存档已有状态,不新增信息;未获得的不显示占位(不剧透数量)。
- 快捷键 Tab/手柄 Y(沿用现有回看键位,原「上一问」并入案卷第四页签「对话记录」)。

## 任务 5:对话记录(Backlog 升级)

- 完整滚动历史:每句一行,带名牌;从案卷页签进入或滚轮上滑呼出。
- 严格只含已播句(现有回看防剧透规则原样继承:不含未播场景/深问/结局)。

## 任务 6:系统条

- 对话框右下角三个小控件:**自动**(句间停留可调 1-3 档)/**快进**(按住加速,松开停;仅加速已读过的句——本局内已见文本)/**字速**(慢/中/快/立即)。
- 设置持久化进 saveStore;键盘 A=自动切换。
- 这些是文字游戏的类型惯例控件,不违反"无教程"原则;但**不加**任何"跳过本案/直达选项"类功能。

## 任务 7:冲击表现(克制)

- 证言更新、回拨开场、圈中反应台词三类节拍:句前 120ms 白闪(opacity 层)+ 2px 震动(transform);`prefers-reduced-motion` 时全部禁用。
- 不做「异议!」式全屏气泡(没有配音配图前是廉价模仿);lurker 残影句用 60% 透明度+删除线样式呈现一次。

## 任务 8:回归与验收

1. **内容零改动验证:`git diff --stat content/` 为空**;`npm run content:index` 产物 diff 亦为空。
2. `smoke:browser` 全面重写推进逻辑(逐句点击),五条既有路线+隔夜/文档路线全部跑通;新增断言:打字中点击补全、句尾指示符存在、案卷可开合、自动模式推进一句。
3. 键盘/手柄全流程可玩(现有 INPUT 测试扩展逐句推进)。
4. `prefers-reduced-motion` 模拟下:无打字机、无震闪,流程完整。
5. 手动过案 1 完整夜班一遍:对话节奏、选项打断、案卷、回log、变体立绘切换。
6. 提交拆分:`feat: line-by-line dialogue engine with typewriter`、`feat: avg stage — textbox, nameplate, choice overlays`、`feat: court record and backlog`、`chore: smoke rewrite for per-line advance`。

## 不要做的事

- `content/` 一个字节都不改;分句只在渲染层。
- 不加音效、语音、文字音 blip(另行立项);不做「异议!」气泡。
- 不改任何判定、耐心、路线逻辑;data-* 契约不动。
- 弹幕条收纳但不删除——它是本作身份,不是杂音。
- 快进不得穿透未读文本与关键选择;自动模式在选项处必停。
