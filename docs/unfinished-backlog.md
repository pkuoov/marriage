本文件只记录尚未完成、确实会影响试玩或发行的工作。已完成批次、旧执行 Prompt 和一次性复审不再保留在 `docs/`；需要追溯时查看 Git 历史。

## P0｜试玩与发行门

### 真人盲测

- 按 [P1 盲玩验收单](p1-blind-playtest-2026-07-18.md) 完整试玩夜 A → 白天 → 夜 B → 结案。
- 记录每案用时、第一次卡点、材料错读、逐句切屏是否拖沓。V哥当前隐藏，不计求助次数。
- 至少覆盖一条正常路线；条件允许时补一条材料误圈或外围追问路线。
- 机器 smoke 只能证明流程可走，不能代替玩家是否看懂代价、接受立绘和听清语音。

### 声音资产

- 九个 BGM 槽位已有八个正式接入；仍缺 `epilogue-dawn`。制作参数见 [Udio BGM 制作单](udio-bgm-production-prompts-v2.md)。
- 用真人定向录音替换试玩系统声线。录制顺序、逐字稿与交付路径见 [音频录制交接单](audio-recording-handoff.md)。
- 地点环境底和非关键语音在真人录音与真机混音后排产，不能用环境底冒充缺失 BGM。
- 所有 WAV 入库后通过 [BGM 处理管线](bgm-processing-pipeline.md) 裁循环、归一并转为运行时格式。

### 真实设备

- Windows 干净机器：安装/启动、SmartScreen、窗口恢复、文件存档、暂停恢复和崩溃日志。
- Steam Deck / 标准控制器：方向键、摇杆、A/B/Y、焦点可见性和长时间操作手感。
- 手机与桌面：字体、材料板、按钮代价、三态立绘遮挡和音频暂停恢复。
- macOS 不产出“正式 Windows 验收包”；Windows 打包要求见 [桌面与 Steam 构建计划](desktop-steam-build-plan.md)。

### Steamworks 权限项

- App ID、depot、内部测试分支与上传验包。
- Steam Cloud、overlay、Steam Input。
- Windows 签名，或形成明确的不签名发布决策。

## P1｜只在实测证据出现后修改

- 案 3 开场厚度：只有真人计时或理解记录证明过薄时才扩写。
- 白天地点卡舞台感：只有玩家把它误读成配置表时才调整。
- 材料阅读节奏：只有连续错读、漏读或信息过载时才重排。
- 逐句对白舞台：问答仍要有上下承接，但演出时每页只显示当前一方台词；只有长台词才继续拆屏，不按字段数量机械拆分。
- 立绘与混音：只处理可复现的不一致、遮挡、抢字和听不清问题。

## P2｜试玩稳定后

- 扩充内容模板池和社区投稿管线，但新案必须通过内容包、角色声纹和证据边界校验。
- 受控 AI 只做已写好意图的路由，不生成新事实、证据或临场答案。
- 小程序原生适配、更多平台入口和正式章节包排在 Steam 试玩验收之后。
