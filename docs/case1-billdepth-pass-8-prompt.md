# 第 8 批·案 1 账单纵深执行单（往期账单与 8 号还入）

你是本仓库的实施工程师。本单在第 7 批（五万缺口）之上给案 1 加账单纵深：往期账单成为关键证据，主播的交往时间线追问上桌，"拆东墙补西墙 / 多线 / 化债目的交往"作为**有证据支撑但不落死的假设空间**进入案子。

前置：第 6 批、第 7 批均已落地。本单对第 7 批的两处字段有覆盖（见 §2、§3 的"覆盖声明"）。台词逐字使用。仅改 `content/packs/steam-demo-01/cases/01-credit.json` 与生成索引。

## 设计要点（执行前读完）

- 往期账单只呈现两类**纯事实**：交往之前也有同款体面消费；每月 8 号曾有一笔固定还入，三个月前停了。还入记录只证明"有钱按月进来"，**不证明是谁付的**——多线、拆东墙、化债三个读法由玩家自己搭，案 2 已确认多线交往，案 1 不得重复确认。
- 时间线咬合（写作依据，不直接播报）：交往约六个月 → 断缴约三个半月前 → 8 号还入停止约三个月前 → 前几天开口要八万。供血停止在先，开口在后。
- 承重层仍是时间诡计：全部新证据都是"两个日期摆在一起"。

- 不动 S0/S1/S3/S4、板 1、accusationChoices、quotePickCandidates、deepFollowup。
- 弹幕、顾问、对方回拨不得提前或事后点破假设空间；`dailyShareQuestion` 是唯一允许邀请猜测的位置。
