# 主播角色设计（The Host Is a Person）

日期：2026-07-07
性质：角色设计文档。目标：主播不再是中立客观的提问机器，而是有旧伤、有立场、有生计压力的活人——同时不让他的偏向污染事实层的公平竞赛。边界规则同步写入 `project-skills/case-scriptwriting/SKILL.md`。

## 设计模型：定死的过去 + 玩家表达的现在

代入感不靠空白人偶，靠"有身份的容器"（巫师的杰洛特模型）：主播的**过去和伤口是定死的**（写进角色圣经），他的**现在由玩家的选择表达**（现有路线轴画像——先信人/先拆图/先追钱/先反问来电人——本来就是"你是哪种主播"的答案）。两层各管各的，互不侵占。

## 户口：他已经存在的部分（从现有文本反推立卡）

- **签名句式**：「X 归 X，Y 是 Y」——四案收麦全在用（心疼归心疼／难看归难看／自认归自认／延后归延后）。这不是巧合，是他的思维方式：把搅在一起的东西掰开。立卡后所有主播新台词优先用这个模具。
- **纪律的来源（旧伤 A）**：两年前他还在做调解节目，一期里他顺着舆论把一个"渣男"钉死了，后来发现关键账单是剪辑过的——当事人丢了工作，节目照播。他离开老东家自己做深夜热线，"今晚定不了的就不定"是那次学的，不是职业操守，是赎罪。**这条伤解释了整个游戏的判定哲学**：事实边界分拣、双源规则、留白结尾，全部从人物动机里长出来。
- **私人的账（旧伤 B）**：他自己有一笔没要回来的钱——多年前借给当时的伴侣"周转"，分手后没再提。金额不大，但"先帮我挡几天"这句话他听过原版。案 1 的共鸣点。
- **生计**：深夜档数据不好看，平台催他改成"爽点判决"式节目——观众要站队，他偏不给。听众耐心条对他不是抽象计量，是这档节目还能不能活的问题。（表现层重构：耐心=生计，不改机制。）

## 性格底色：心热、嘴稳、手上使计

- **爱憎分明**：他不是端水的。听到操控和转嫁成本会真动气，见人被话术套住会真想帮——这份热是节目存在的理由，也是观众爱他的理由。表达面：揭示落定后的收麦咬字（现有 truth 的锋利本来就是他）、对来电人的暖（「这句你不用替他圆」）、对套路的冷（「这词他说得太熟了」）。
- **旧伤管时机不管温度**：爱憎随时在烧，判决必须等证据锁死——"打之前把证据拿齐"是他从冤案学来的唯一规矩。所以他的热不走判决，走**计策**。
- **爱憎会打错靶（与 `hostWoundHook` 咬合）**：每案前半段，他的恨可以冲向磁性读法（案 1 的"就是渣"、案 4 的"财务背锅"），和玩家一起被案子纠正。主播被纠正的时刻要写出来——活人认错比机器中立可爱得多。

## 奇正相生：计策系统（帮连线人拿证据）

正是直接问，奇是巧劲。全部在法律框架内，铁律是**阳谋不阴谋**：计策是试金石不是陷阱——它只让已经存在的真相显形，清白的人通过时毫发无伤；永不诱导新的过错、永不冒充公权、永不越录音/隐私的线。

四类基础计策（钓回来的反应都是预先创作的授权材料）：

1. **无害请求**（请君入瓮的合法版）：让来电人提一个清白者一张截图就能满足的请求——「你就说你妈想看完整那页，让他再发一次」。他怎么拒绝、再裁哪里，本身就是证据。
2. **静默回拨**（引蛇出洞）：设计一通回拨，对 X 只字不提，看对方主动补什么、绕什么——案 1 的回拨「问到五万多他就不接话」就是这个模具。
3. **顾问背书请求**（借力）：以顾问名义提正规要求（「让财务给个付款状态截图，正常公司当天就能给」），拖延模式即证据。
4. **激将半句**（敲山震虎，最谨慎的一档）：让来电人抛半句真话看反应——只许用已在台面上的事实，不许虚构筹码。

机制草案（v1，随幕结构立项）：幕间"怎么帮她拿下一块料"三选一（正攻／奇策／走顾问），各通往同一真相的不同侧面材料，风险与耐心代价不同；选择记入路线轴——**你帮人的手法，也是你是谁**。与证据委托（P2.5）互为姊妹：委托是送出去鉴定，计策是钓回来反应。

## 四个投放面（按成本排序）

### 1. 自曝时刻（每案一条，纯内容）

情感热线主播自曝是行业常态，天然合规。规则：**只给感受和经历，不给结论**（感知铁律延伸到主播）；每案至多一条；出现在该案伤口共鸣点上。四案备用台词（逐字）：

- 案 1（S2 审计拍后的衔接位）：「"先帮我挡几天"——这话我也听过一次，原版的。那笔钱我后来没再提。所以下面这句我问她，也问我自己当年为什么没问。」
- 案 2（回流后）：「我做节目这些年，最怕的就是"自己人"这三个字。它不收钱，收的都比钱贵。」
- 案 3（深问前）：「接下来这个问题有点冒犯。我先说一句：当年有人这么问过我，我恼了半年，后来谢了人家。」
- 案 4（收麦位）：「我上一份工作丢的时候，也是流程词最多的那个月。这案里谁在说流程词，各位都听见了。」

### 2. 伤口即误导（内容字段，配合诡计分层）

主播的旧伤会让某个读法对他**有磁性**——案 1 的"他就是渣"对一个自己被借过钱的人来说太顺口了。每案可声明 `hostWoundHook`（策划字段）：本案哪个读法被主播的伤加热。它是假解喂养的新来源：**误导不再只来自当事人，也来自你自己**。弹幕可以在玩家连续选攻击性追问时点破：「主播你今晚话里带刺啊」——现有 routeTone 连击数据就能驱动，不需要新判定。

### 3. 弹幕记得主播的历史（内容池，低成本）

直播间的人认识他两年了。评论池加入主播史弹幕：「主播又想起那期节目了吧」「他每次听到'挡几天'都停半秒」。规则：只指主播的过去，永不指向本案答案；每案至多一条；旧伤 A 的具体细节（节目名/当事人）永不出现——观众知道有这件事，不知道全貌，主播史本身也是留白。

### 4. 深夜档存亡线（B 线 runner，随 Playbook 方法 9 立项）

包级 B 线：平台通牒（数据/赞助/改版压力）在案间过场露头，终局按整晚表现给一条走向。是"主播参与其中"的结构化形态，留给第二个故事包或幕结构落地后实施，不混入当前包。

## 铁线（防止活人变成脏裁判）

1. 主播的偏向只许影响**语气、自曝与计策风味**，永不影响事实层：材料、边界、双源判定全部与主播情绪无关。
2. 自曝只给感受与经历，不给结论；不许在结算里替玩家定读法；「X 归 X」句式恰好是天然的防说教模具。
3. 旧伤 A 的细节永不完整披露；旧伤 B 不许升级成本案卷入（主播永不认识本案当事人——他卷入的是"同款话术"，不是同一件事）。
4. 弹幕的主播史梗永不点向本案答案。
5. 每案自曝 ≤1 条、主播史弹幕 ≤1 条；超编就是自恋，主角是来电人的事，不是主播的回忆录。

## 实施顺序

1. 角色圣经加第 9 张卡（主播），签名句式与两道旧伤入卡——随第 9 批的 `content/characters/` 一起落。
2. 四条自曝台词 + `hostWoundHook` 字段 + 主播史弹幕池——下一个内容批次。
3. 计策系统随幕结构立项（与证据委托 P2.5 同期设计，共享幕间锚点）；先在案 1 试一条静默回拨的显式化。
4. 深夜档 B 线随幕结构立项。
