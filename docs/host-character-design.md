# 主播角色设计（The Host Is a Person）

日期：2026-07-07
性质：角色设计文档。目标：主播不再是中立客观的提问机器，而是有旧伤、有立场、有生计压力的活人——同时不让他的偏向污染事实层的公平竞赛。边界规则同步写入 `project-skills/case-scriptwriting/SKILL.md`。

## 设计模型：定死的过去和声音 + 玩家表达的调查立场

代入感不靠空白人偶，靠"有身份的主角"（巫师的杰洛特模型）：主播的**过去、伤口和说话声音是定死的**（写进角色圣经），玩家决定他此刻先追哪条线、怎样处理压力节点。路线轴画像——先信人/先拆图/先追钱/先反问来电人——回答"你让林旭阳怎么查"，不改写"林旭阳是怎样的人、怎样说话"。两层各管各的，互不侵占。

运行时不再把玩家写成林旭阳背后的编辑。对白框署名林旭阳，是因为玩家此刻就是他；舞台动作、白天回访和按钮提示使用“你”。疑点方向只是玩家脑中先抓住的点，按下以后会变成自己说出口的完整问句。界面不得再写“由林旭阳开口”“主播怎么接”。

## 双寄存器：平时松，碰到真相就收紧

林旭阳的默认声音是松、暖、会随口损两句。他可以自嘲节目不赚钱，跟熟人贫一句，也会在来电人咳嗽、跑题或卡住时把气氛托住；笑点不指向正在难受的来电人，更不进入事实判断。

一旦矛盾露头、材料对不上或有人拿含糊话术遮掩，他会收笑，切进精准、咬住不放的专业寄存器。前法务的底子体现在追清原话、金额和证据边界，不体现在公文腔。逼的是逻辑，不是逼人认罪；钉住问题以后，他会软回来，给来电人一个能继续说话或行动的台阶。

两个寄存器的切换是他的签名。玩家可以选择追哪条真相线，不能把他选择成四种不同声线的中性主持人。

## 户口：他已经存在的部分（从现有文本反推立卡）

- **基本履历**：林旭阳，男，三十三岁。以前在互联网大厂做法务，失业后阴差阳错开始做个人主播，至今两年半。直播间不温不火，但一直没有停播。这个背景只在整个故事的第一次开篇向玩家介绍一次，不是他每晚对固定观众念的口播。
- **签名句式**：「X 归 X，Y 是 Y」——四案收麦全在用（心疼归心疼／难看归难看／自认归自认／延后归延后）。这不是巧合，是他的思维方式：把搅在一起的东西掰开。它属于主播收紧后的专业寄存器，只在需要拆开混说的事实时使用；默认寄存器不拿它当口头禅。
- **纪律的来源（旧伤 A）**：开播约半年后，也就是两年前，他曾顺着直播间舆论把一个“渣男”钉死，后来才发现关键账单被剪辑过，当事人也因此丢了工作。直播间没有停，他却从那以后不敢再拿一句好听或难听的话直接给人定罪。“今晚定不了的就不定”是那次学的，不是职业操守，是赎罪。**这条伤解释了整个游戏的判定哲学**：事实边界分拣、双源规则、留白结尾，全部从人物动机里长出来。
- **私人的账（旧伤 B）**：他自己有一笔没要回来的钱——多年前借给当时的伴侣"周转"，分手后没再提。金额不大，但"先帮我挡几天"这句话他听过原版。案 1 的共鸣点。
- **现在的关系**：赵律师是林旭阳的妻子，也是能当场纠正他的人。两个人不靠昂贵消费证明亲密，意见相左时先说证据和边界，照顾则落在热水、汤和等他收工这些小事上。案后尾声可以让关系进入生活，但不能把赵律师写成只负责夸主播的附属角色。
- **生计**：深夜档数据不好看，平台催他改成"爽点判决"式节目——观众要站队，他偏不给。听众耐心条对他不是抽象计量，是这档节目还能不能活的问题。（表现层重构：耐心=生计，不改机制。）

## 性格底色：心热、嘴稳、手上使计

- **爱憎分明**：他不是端水的。听到操控和转嫁成本会真动气，见人被话术套住会真想帮——这份热是节目存在的理由，也是观众爱他的理由。表达面：揭示落定后的收麦咬字（现有 truth 的锋利本来就是他）、对来电人的暖（「这句你不用替他圆」）、对套路的冷（「这词他说得太熟了」）。
- **旧伤管时机不管温度**：爱憎随时在烧，判决必须等证据锁死——"打之前把证据拿齐"是他从冤案学来的唯一规矩。所以他的热不走判决，走**计策**。
- **爱憎会打错靶（与 `hostWoundHook` 咬合）**：每案前半段，他的恨可以冲向磁性读法（案 1 的"就是渣"、案 4 的"财务背锅"），和玩家一起被案子纠正。主播被纠正的时刻要写出来——活人认错比机器中立可爱得多。

## 接话节奏：先把人接住，再把事实问清

林旭阳是情感热线主播，不是已经读完卷宗的审讯者。新来电必须先完成正常的接线过程：来电人问候并说明来意，主播回应，再让来电人交代最近发生的事。金额、日期、物件等关键信息要由主播听见上一个回答后逐步追问，不能为了尽快露出矛盾而塞进第一句话。

每次转向下一条线索，台词都要写出因果桥：主播先复述刚听到的具体信息，再说明自己为什么追问下一件事。比如听到“信用卡周转”后先问金额，听到“八万”后再问原话；不能写成“八万。好，先别解释”这种已经替对方定性的办案短句。

主播可以简短，但不能省略人类交流所需的反应。判断一句话是否合格时，把前后两句连起来朗读：后一问必须能由前一答直接生长出来。若中间需要作者解释“主播为什么突然问这个”，就说明台词里缺了一步。

以下写法列为禁区：

- 一句开场同时交代关系、异常、证据和爆点金额。
- 主播用“好”“先别解释”“这句留着”等办案指令代替真实反应。
- 来电人刚报出关键词，主播立刻跳到尚未被提及的物件或动机。
- 为了制造悬念，把正常人不会突然关心的问题硬塞给角色。

## 奇正相生：计策系统（帮连线人拿证据）

正是直接问，奇是巧劲。全部在法律框架内，铁律是**阳谋不阴谋**：计策是试金石不是陷阱——它只让已经存在的真相显形，清白的人通过时毫发无伤；永不诱导新的过错、永不冒充公权、永不越录音/隐私的线。

四类基础计策（钓回来的反应都是预先创作的授权材料）：

1. **无害请求**（请君入瓮的合法版）：让来电人提一个清白者一张截图就能满足的请求——「你就说你妈想看完整那页，让他再发一次」。他怎么拒绝、再裁哪里，本身就是证据。
2. **静默回拨**（引蛇出洞）：设计一通回拨，对 X 只字不提，看对方主动补什么、绕什么——案 1 的回拨「问到信用卡里剩下的三万五他就不接话」就是这个模具。
3. **顾问背书请求**（借力）：以顾问名义提正规要求（「让财务给个付款状态截图，正常公司当天就能给」），拖延模式即证据。
4. **激将半句**（敲山震虎，最谨慎的一档）：让来电人抛半句真话看反应——只许用已在台面上的事实，不许虚构筹码。

机制草案（v1，随幕结构立项）：幕间"怎么帮她拿下一块料"三选一（正攻／奇策／走顾问），各通往同一真相的不同侧面材料，风险与耐心代价不同；选择记入路线轴——**你帮人的手法，也是你是谁**。与证据委托（P2.5）互为姊妹：委托是送出去鉴定，计策是钓回来反应。

## 四个投放面（按成本排序）

### 1. 自曝时刻（每案一条，纯内容）

情感热线主播自曝是行业常态，天然合规。规则：**只给感受和经历，不给结论**（感知铁律延伸到主播）；每案至多一条；出现在该案伤口共鸣点上。四案备用台词（逐字）：

- 案 1（S2 审计拍后的衔接位）：「“先帮我挡几天”，以前也有人对我说过。那笔钱我没再问，也没要回来。你刚才一重复这句话，我手心还是会冒汗。」
- 案 2（回流后）：「“自己人”这三个字，我以前上班的时候也听过。通常下一句就是：“这次你先帮我。”所以你这张表，我还得往下问。」
- 案 3（深问前）：「这问题难听。我以前被人这么问过，当场把门摔了。后来有半年，我每次算房租都会想起这句话。」
- 案 4（收麦位）：「我上一份工作丢的那个月，办公室里也整天说流程。我刚才听到“老规矩”，先起了火。我停一下，喝口水。」

节目是林旭阳独立运营的个人直播。需要停顿时由他自己关麦、推远麦克风或喝水；不设置导播、耳返指令或控制室回话。

### 2. 伤口即误导（内容字段，配合诡计分层）

主播的旧伤会让某个读法对他**有磁性**——案 1 的"他就是渣"对一个自己被借过钱的人来说太顺口了。每案可声明 `hostWoundHook`（策划字段）：本案哪个读法被主播的伤加热。它是假解喂养的新来源：**误导不再只来自当事人，也来自你自己**。弹幕可以在玩家连续选攻击性追问时点破：「主播你今晚话里带刺啊」——现有 routeTone 连击数据就能驱动，不需要新判定。

### 3. 弹幕记得主播的历史（内容池，低成本）

直播间里有人从他开播不久就认识他，前后两年半。评论池加入主播史弹幕：「主播又想起那期节目了吧」「他每次听到'挡几天'都停半秒」。规则：只指主播的过去，永不指向本案答案；每案至多一条；旧伤 A 的具体细节（节目名/当事人）永不出现——观众知道有这件事，不知道全貌，主播史本身也是留白。

### 4. 深夜档存亡线（B 线 runner，随 Playbook 方法 9 立项）

包级 B 线：平台通牒（数据/赞助/改版压力）在案间过场露头，终局按整晚表现给一条走向。是"主播参与其中"的结构化形态，留给第二个故事包或幕结构落地后实施，不混入当前包。

## 玩家身份闭环

按五拍验收：整晚开播前先交代林旭阳正在承受的私人或生计压力，同一晚后续来电不重复履历或硬造新压力；每案的麦上选择能翻译成主播动作；白天每次约见和看材料都有可见授权；第二夜确实用到白天带回的内容；结案至少一次回声玩家怎样处理了人，而不只统计问对了多少。

礼物插麦、隐私泄露、来电人失控等压力拍不能全由固定台词替玩家解决。事实边界与最低保护线可以固定，退礼物、先问谁、是否静音、怎样取得公开同意，应至少交给玩家一次。NPC 随后要回应这个动作，回看或后续消息再回声一次。

压力拍有几个处理选项，就要为几个选项分别写回声。`recapAftertaste` 使用林旭阳的第一人称，不写“主播当时如何”；连续阅读版同样保留“你选择”，不能由生成器改回旁观视角。

林旭阳是主播，不是调查机关。白天行动只允许四类来源：来电人明确交给节目的遮名材料；当事人主动回复并划定的公开范围；节目顾问在职业边界内的通用解读；愿意见面的第三人对自己经手内容的有限说明。未经当事人同意的私人截图即使被第三方投进后台，也只能麦外看；若要回到直播，先让受影响的人决定撤下、静音或继续。每个白天场景在 `body.access` 写清来由和禁区，并直接显示给玩家。

## 铁线（防止活人变成脏裁判）

1. 主播的偏向只许影响**语气、自曝与计策风味**，永不影响事实层：材料、边界、双源判定全部与主播情绪无关。
2. 自曝只给感受与经历，不给结论；不许在结算里替玩家定读法；「X 归 X」句式恰好是天然的防说教模具。
3. 旧伤 A 的细节永不完整披露；旧伤 B 不许升级成本案卷入（主播永不认识本案当事人——他卷入的是"同款话术"，不是同一件事）。
4. 弹幕的主播史梗永不点向本案答案。
5. 每案自曝 ≤1 条、主播史弹幕 ≤1 条；超编就是自恋，主角是来电人的事，不是主播的回忆录。

## 实施顺序

1. 角色圣经加第 9 张卡（主播），签名句式与两道旧伤入卡——随第 9 批的 `content/characters/` 一起落。
2. 四条自曝台词 + `hostWoundHook` 字段 + 主播史弹幕池——下一个内容批次。
3. 计策系统随幕结构立项（与证据委托 P2.5 同期设计，共享幕间锚点）；先在案 1 试一条静默回拨的显式化。
4. 深夜档 B 线随幕结构立项。
