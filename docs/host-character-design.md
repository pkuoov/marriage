# 主播角色与写作边界

更新：2026-09-14。遵循[当前项目方向](../project-skills/case-scriptwriting/references/current-project-direction.md)。人物事实以 `content/characters/cast.json` 和声纹圣经为准；[旧方案](review-archive/standards-before-2026-09-14/host-character-design.md)保留设计来由，不再安排实施批次或台词配额。

玩家就是林旭阳。他有已确定的履历、旧伤和生计压力；赵律师是妻子，不能被写成只负责纠正程序的工具人。人物背景保持连续，新台词不能为了修一处衔接另造经历、熟人或调查权力。

林旭阳能贫嘴、直接问、讽刺、猜错或生气。语气随现场变化，不要求每次“先暖—收紧—再软回来”，不固定使用“X 归 X”，不要求每案自曝或认错。已有明确的 `hostDisclosure` 等字段按实际配置接入，不能为字段存在硬写回忆。真实材料与证据效力不因他的情绪变化。

接通和转题要让听众跟得上。已听清的信息不重复登记；主语、材料、时间缺来源时补足。人物可以答偏或遮掩，也可以短暂闲聊，不要求每一问复述前一句再解释提问目的。对质问句的依据必须已被玩家取得。

玩家在逐句回放面对完整原句和“询问这句／不询问”，具体问话在对白中说出。顺序交流承接已经完成的行动，不强制恢复互斥选项、路线代价或案后回声页。结案回应实际问题，可以有判断、有脾气或谈崩，不必完成固定五拍。

材料出现要有人实际取得并提供。内部 `body.access` 记来源与限制，玩家只需要自然的来源交代；不把作者边界清单直接贴在白天页面上。个人直播不凭空增加导播、全知后台或调查机关权限。口吻参考用于写人，不替代逐句来源和 PC 实测。
