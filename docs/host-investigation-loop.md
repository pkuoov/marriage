# 主播探索与证据回流设计

## 目标

扩大《直播间大侦探》的推理半径：玩家不只听一通电话、圈一份材料，还可以把已经发现的矛盾交给直播间后台去追，或在案后收到私信回流，从而获得新的相关性证据。

这不是开放世界调查，也不是 AI 自由生成事实。所有调查结果仍由编剧固定，玩家只决定先追哪条线、承担多少现场压力、最终看到哪类证据。

## 为什么需要

当前玩法的证据来源主要是：

- 咨询者口述。
- 咨询者拿出的材料。
- 玩家对材料缺口的圈点。
- 结尾原话选择。

这个结构稳定，但证据半径偏窄。复杂案件里，真正的反转往往来自第三处：旁观者私信、平台记录、同事补话、店员证词、消费流水补页、群聊截图、审批状态、介绍人前后说法。

新增探索环节能让案件更像直播间发生的事：主播一边控场，一边让后台去找人、翻记录、看私信。这样也能自然支撑每案 20 分钟体量。

## 核心原则

- 玩家先在通话中发现矛盾，再触发核实。不能先给调查按钮让玩家扫图鉴。
- 核实结果只来自已写好的证据池，不允许运行时生成新事实。
- 每案最多 1-2 次探索机会，避免主线被切碎。
- 探索不能替代主播追问。它必须由某个已听到的矛盾、材料缺口或原话触发。
- 核实可能带来新证据，也可能只确认“这条线没咬住”，但不能直接给正确答案。
- 另一方仍不能直接上麦对峙。其声音只能通过私信、截图、录音、转述、平台记录、第三人补充或线下问询结果出现。
- 私信回流要像直播间真实噪音：有用线索、情绪站队、误导信息、蹭热度投稿混在一起。

## 三种探索形态

### 1. 麦中后台核实

发生在当前通话还没结束时。玩家发现一个矛盾后，可以让后台去查一条具体线。

适合：

- 平台/店铺/公司流程能查到状态。
- 有截图缺页、账单补页、排班表原表、审批流后续状态。
- 不需要离开直播间，只需要后台翻材料或联系匿名来源。

例子：

- 信用卡案：后台对照社保断缴时间和账单消费时间。
- 理发店案：后台收到另一位女生的私信，表格里也有类似备注。
- 职场报销案：后台查到审批通过不等于付款完成，供应商群里还有返款入口。

### 2. 案后私信回流

发生在收麦后或案间过渡前。直播结束后，后台收到新私信或补充材料，作为下一通或本案回看的一部分。

适合：

- 不打断主线，但补强案件余味。
- 用来制造“刚才站早了”的体验。
- 连接案件包，让节目像同一晚连续发酵。

例子：

- 第一案收麦后，朋友私信说咨询者朋友圈当晚确实发过高消费照片。
- 第二案收麦后，另一个暧昧对象发来同款话术截图。
- 第四案收麦后，供应商匿名说“服务协调费”不是第一次出现。

### 3. 主播线下追问

发生在更大的故事集或正式版里。主播不是出门跑地图，而是在下一段直播前做一次明确问询：问介绍人、问店员、问同事、问平台客服、问共同朋友。

适合正式版，不适合当前最小试玩循环一次做太多。

限制：

- 不做可自由移动地图。
- 不出现长 NPC 访谈。
- 每次只回收一个问题：这条线证明什么、仍然不能证明什么。

## 推荐先落地的最小版本

先不做线下追问，只做“案后私信回流”：

1. 每案增加 1 个 `investigationHook`。
2. 触发条件来自玩家是否命中某个材料或核心追问。
3. 回流展示为一张可读材料板，继续使用现有材料检视 UI。
4. 玩家只圈一处，不新增菜单层。
5. 结果进入路线图和结算余味。

这样能复用现有材料操作台，也不会打乱当前线性通话。

## 编剧要求

每个探索证据必须回答四个问题：

- 来源是谁，为什么现在才出现。
- 它和玩家已经发现的哪条矛盾相关。
- 它能证明什么。
- 它仍然不能证明什么。

如果一个回流证据只是重复主线信息，就不要加。它必须改变玩家对某句话、某份材料或某个责任边界的理解。

## UI 语气

可用：

- 后台进来一条私信
- 有人补了一张图
- 这页刚翻出来
- 对方没上麦，只留了这句

避免：

- 证据链已完善
- 核验成功
- 新线索解锁
- 正确路线
- 关键证据出现

它要像直播间的动静，不像任务系统。
