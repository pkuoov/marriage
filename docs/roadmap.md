# 版本路线

## v0.14 GitHub 首版

公开首版只开放男主线。

原因：男版和女版不是候选人性别互换，而是完整体验不同：

- 候选人设定不同
- 玩家心态不同
- 家庭压力来源不同
- 恋爱和婚前风险点不同
- 同一个选择在男女主身上的社会反馈不同
- 止损条件、案例触发和状态语言也应不同

当前内容更适合作为男主线原型发布。女主线如果继续沿用同一组选项和同一套问题，会变成错位体验。

## 最大 TODO：女主线独立设计

女主线应单独设计：

- 女性玩家候选池
- 女性视角的婚恋市场压力
- 彩礼、婚房、怀孕、生育、职业中断、照护劳动等议题的权重
- 对方男性 NPC 的家庭脚本和风险模式
- 女性视角下的自由恋爱与相亲开局
- 独立状态面板文案和止损判断

完成后再开放建档页里的女主线入口。
