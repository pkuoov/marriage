# 版本路线

更新时间：2026-07-25

## 当前产品

《深夜热线：直播间侦探》当前是 Steam 优先的章节式案件包游戏。试玩包 `steam-demo-01` 包含四案，主循环是：

```text
夜 A 来电
→ 收麦调查
→ 白天两地取舍
→ 夜 B 回拨
→ 最终追问
→ 单案回看
→ 跨案伏笔回收
```

`daily` 保留为单案兼容入口和内容生产单元，不是主产品叙事。

## 已稳定的底座

- 四案玩家可见内容已进入 `content/packs/steam-demo-01/`，运行时不再依赖手写故事镜像。
- 标题页、过场、材料板、一问一答分页、白天地图、第二晚回拨、结案与终局均已接通。
- 角色性格、知识边界和声纹有固定真源；剧情结构同步到 `story.md`、`plot/`、`scenes/` 与 `continuity/`。
- Web 离线包、Electron 桌面壳、文件存档、键盘与基础手柄导航已经具备自动化回归。
- 八个 BGM 槽位已接入；音频、内容包、阅读稿和相邻问答均有确定性校验。

## 当前阶段：发行验收

当前不再并行扩写剧情和机制，只完成：

1. 真人盲测。
2. `epilogue-dawn` BGM 与真人语音替换。
3. Windows、手机、控制器和 Steam Deck 实机验收。
4. Steamworks Cloud、overlay、Input、depot 与签名决策。

逐项清单见 [未完成项目清单](unfinished-backlog.md)。

## 试玩通过后

1. 根据真人数据修正明确的节奏、误读或操作问题。
2. 冻结 `steam-demo-01`，建立下一章节包，不在旧包上无限叠加。
3. 扩充公共生活案件模板与社区投稿管线。
4. 最后评估受控 AI intent router 和更多平台适配。
