# 版本路线

## v0.16 婚恋侦探 / 律师视角

游戏形式从“玩家亲自相亲”改为“婚恋侦探局连环审案”。

已完成基础改造：

- 取消主动给主角加点，开局改为系统随机生成调查画像
- 新增每周目三案序列 `caseBriefs`
- 新增侦探案件库：骗婚、化债、外遇反咬、外情生子/接盘生子、大结果收割、择偶定位包装
- 游戏主循环改为连环案：开案、现场复盘、证词追问、证据整理、阶段指认、案件复盘
- 三案结构固定为婚前 case、婚后 case、告解模式；第三案不再固定为终案预谋，而是随机当事人自述经历并自查关系问题
- 状态面板改为侦探手账，展示后台案件标题、难度和表层冲突
- 新增证据清晰度、舆论压力、来访者可信度、恶人先告状风险等 flags
- 新增侦探专长、追问配额、证据整理差异、告解时间线标注
- 新增案间战况：声誉、舆论热度、下一案配额变化
- 三案结束后进入压缩关系后续，旧案表现会影响止损建议、澄清程度、观察期和后续风险

下一步优先级：

- 强化逆转裁判式章节：开案、调查、交叉追问、出示证据、阶段反转、最终指认
- 把旧恋爱章节拆成案件回忆、证词、直播证据卡和案后短片段，而不是长线恋爱模拟
- 深化“出示证据卡”系统，让玩家用当事人前后说过的话、微信截图、图片和消费记录戳破具体台词
- 增加章节级反转：真受害者反咬、恶人先告状、双方都有隐瞒、告解自欺

## v0.15 婚恋侦探局重定位

项目定位从“中国式婚恋长期模拟”升级为“婚恋反诈防骗防坑游戏”。十年关系推进仍然保留，但玩法核心改为风险识别、边界建立、资产保护、情绪安全和及时止损。

已完成基础设计：

- 标题统一为《婚恋侦探局》
- 文档新增婚恋避坑核心系统
- 文档新增大环境系统
- 文档新增股市与家庭投资系统
- 文档新增前任、暧昧与出轨风险系统
- 文档新增反诈防骗防坑案例池
- 代码新增宏观经济、投资、诈骗、前任、情绪价值和出轨风险 flags
- 案例事件库新增经济周期、股市投资、前任回流、情绪价值外包等事件种子

下一步优先级：

- 在章节正文中显式接入大环境开局播报
- 让股市与投资事件在第 4、6、7 章拥有可选择分支
- 扩写第 6、7、8、9 章的前任回流、情绪价值外包和出轨风险链
- 增加“反诈核验”按钮或事件选项，例如查资质、看合同、保留证据、拒绝借贷投资
- 增加止损结局：保住资产、识别骗局、延期婚礼、取消共同投资、关系修复失败但体面退出

## v0.14 GitHub 首版（历史形态）

这一版是旧的“玩家亲自相亲”形态，公开首版只开放男主线。v0.16 之后不再作为主玩法方向，只保留部分 NPC、案例因子和长期关系压力作为后台素材库。

原因：男版和女版不是候选人性别互换，而是完整体验不同：

- 候选人设定不同
- 玩家心态不同
- 家庭压力来源不同
- 恋爱和婚前风险点不同
- 同一个选择在男女主身上的社会反馈不同
- 止损条件、案例触发和状态语言也应不同

当前内容更适合作为男主线原型发布。女主线如果继续沿用同一组选项和同一套问题，会变成错位体验。
