## D. Skill 立法(`project-skills/case-scriptwriting/SKILL.md` 新增两条,逐字)

- **悬时校验律**:任何"跟上次一样／又是老样子／这套路我熟"式的回溯性台词，必须能在本案内指向一个已经播出的具体拍；指不出来就改成向前看的判断句（如"这我早该看出来"），不许暗示玩家没见过的过去事件。
