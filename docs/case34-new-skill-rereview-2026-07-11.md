# 案 3 / 案 4 新版 Skill 重审与重构稿

日期：2026-07-11  
适用内容：`03-profile.json`、`04-workplace.json` 及对应跨夜流程、NPC 场景、材料板、选项、回拨与收麦。  
执行标准：`case-scriptwriting`、`detective-plot-coupling-review`、`story-dialogue-staging`、`livestream-game-flow-review`。

## 一、重审结论

### 案 3 原结构问题

- “介绍人给两边说不同版本”在相邻两幕重复出现，删掉一幕也不影响因果，属于无转向重复。
- 开场一次装入学校、收入、存款、流水和母亲压力，戏剧物件虽多，发现顺序却不清楚。
- 设计稿要求周会计 / 小林老师二选一，运行时允许玩家在后台连做两三件，白天机会成本失效。
- 来电人的“我妈想看”主要靠后段自认，缺少能由玩家先看见的主语证据。
- “男方节俭”和“收入可疑”混在同一判断里，容易把团购、积分、AA 写成收入造假的旁证。

### 案 4 原结构问题

- 来电人直接把公司报销和供应商返款总结成“两条钱路”，替玩家完成覆盖检查。
- 三位 NPC 在设计稿中应公开冲突，运行时却主要表现为调查台菜单和两位顾问二选一。
- “财务延后”虽为真借口，但“来不及”早于延后通知九天的时间诡计没有成为主干。
- 主责、付款对接人、供应商确认人三个位置没有被设计成一次可读的主语核对。
- 若只强调来电人想拿主责，容易误写成“有野心就应自担垫款”；若只强调同事绕流程，又会把来电人写回无瑕受害者。

## 二、案 3《好条件的两面》

### 1. 案件账本

| 槽位 | 重构后内容 |
| --- | --- |
| 表面说法 | 男方在见父母前主动发来学校、工作、收入和存款证明；图都是真的，咨询者却越来越不安。 |
| 戏剧物件 | MBA 项目图、28.6 万当日存款证明、单月到账 3.1 万、家里群整页截图。 |
| 假解 | 男方只是怕饭桌上解释不清，所以把真实材料备得过分周到。 |
| 缺失边缘 | 学校图没有把本科、项目性质、学制放在一起；收入图没有连续月份；存款证明只站在开具当天。 |
| 利益路径 | 男方和家里想让见父母先过关；咨询者想让自己报给家里的“名校、收入不错”继续成立；介绍人想把这单促成。 |
| 来电人修剪 | 她把自己先发起的流水要求挂在母亲名下，又只向家里确认“学校是真的”。 |
| 第三压力 | 母亲催见父母、介绍人要还谢媒人情、男方家催婚。 |
| 实物—言语死锁 | 家里群最上面是她发的“要不要把流水也问了”，与她反复说“我妈想看”互相卡死；学校图缺本科口径，与“名校毕业”互相卡死。 |
| 反转 | 这不是一方拿假图骗过另一方，而是多人用局部真实共同生产了一个“适合结婚”的版本。 |
| 边界 | 能确认口径被双方修剪；不能确认持续收入、MBA 学费来源和坦白后是否继续。 |
| 最终原话 | “他一直说名校毕业。” / “我只说学校是真的。” / “是不是工资卡也要交出来？” / “婚后工资最好放一起管。” |

诡计分层：误导层为感性诡计——“他太周到 / 她家查太深”；承重层为材料边界诡计——真图缺少决定社会含义的相邻信息。

### 2. A / B 故事与数值账本

| A 故事 | B 故事 | 屏幕运算 |
| --- | --- | --- |
| 资料都真，男方只是准备充分。 | 真实材料被挑成最能过关的一组，长期信息没有出现。 | 覆盖检查：当日余额不能覆盖长期资产；单月到账不能覆盖持续收入。 |
| 流水是母亲临时加码。 | “要不要把流水也问了”由咨询者先发，母亲两分钟后才接到婚后管钱。 | 主语核对：谁先发起动作。 |
| 介绍人偏男方、替男方抬条件。 | 介绍人给两家各报一次好价，利益是把事办成。 | 模式比对：两套话并排。 |
| 团购、积分、停车 AA 说明收入有问题。 | 这些细节只说明他真会算，不能证明收入真假。 | 覆盖检查：消费习惯不覆盖收入来源。 |

硬数字：四次见面；饭局冷场十几秒；存款证明 28.6 万；单月到账 3.1 万；群里两条消息相隔两分钟。数字只由来电人按其审计助理口吻报告，不由主播替她总结。

### 4. 完整剧情

周末两家准备见父母。来电人先告诉母亲，对方名校毕业、收入不错；又提醒对方，饭桌上可能会问学校和工作。第二天，对方一次发来学校、公司和单月收入三张图，晚上又主动补了一张 28.6 万的当日存款证明，说省得饭桌上解释。没人索要这张证明，来电人当时却先觉得省事。

第一次正式饭局由介绍人订在靠窗位。来电人问“名校是本科吗”，对方停了十几秒，答“也算吧，MBA”。服务员加水，来电人顺势把本科问题放下，因为“名校毕业”已经由她报给家里。她随后把学校图转给母亲，只说“学校这边是真的”，没有补上本科、项目性质和学制的差别。

介绍人的两套话进入直播：对女方家说男方学校好、收入稳、家里省心；对男方家说女方稳定、家里不折腾、不太计较学历。假解由“男方单方包装”变成“介绍人偏男方”，再被第二套话推翻——介绍人的利益不是偏谁，而是让双方继续见。

第一夜挂断时，母亲在家里群催见父母日期。白天玩家只能去一处：到周会计的档案室，把 28.6 万当日余额和 3.1 万单月到账分开，得到“不能替他说收入稳”；或去小林老师打烊后的门店，把介绍人的两套报价并排，得到“行规只能解释抬话，不能替具体口径免账”。两个地点、两种动作、两种盲区，不能同日完成。

第二夜回拨必然落到家里群的主语。来电人亲口念出最上面那句“妈，要不要把流水也问了”，承认母亲两分钟后才把话接到“婚后工资最好放一起管”。若玩家走周路线，第一问先撤掉“收入稳”；若走小林路线，第一问先追谁把好价当了真。来电人随后承认自己月薪一万出头，忙季才多一点；她盯着 3.1 万，不只怕被骗，也怕两个人将来都扛不住。

结尾不把团购、积分和 AA 当收入证据。它们只保留“他真会算”这条真半句。主播收麦到三层：图是真的；口径和主语都被修剪；持续收入、学费来源和关系结果今晚不能确认。

## 三、案 4《主责写谁》

### 1. 案件账本

| 槽位 | 重构后内容 |
| --- | --- |
| 表面说法 | 同事拿“审批通过”拖着不还个人垫款，咨询者怀疑有人截住了钱。 |
| 戏剧物件 | 14:05 群流程、14:22 私聊、九天后财务延后通知、审批页、返款行、主责栏。 |
| 假解 | 财务确实延后，审批也确实通过，钱只是慢；咨询者既然主动要主责，垫款是机会成本。 |
| 缺失边缘 | 审批页没有付款状态和收款账户；返款写给对接人；主责、付款对接、供应商确认不在同一人名下。 |
| 利益路径 | 咨询者要主责和能干形象；同事保留供应商与付款入口；领导要结果和季度数据。 |
| 来电人修剪 | 她开场认了想要主责，却压轻自己回过“收到”、又在私聊回了“我来扛”。 |
| 第三压力 | 老板评价、季度复盘、月底信用卡账单、平台要求点名公司。 |
| 实物—言语死锁 | “财务慢”只能覆盖公司报销，覆盖不了供应商返给对接人的另一条路径；“主责写你”与表上两个入口仍写同事互锁。 |
| 反转 | 自认想要机会不等于认下垫款；主责被写成结果责任，钱的两个入口仍留给别人。 |
| 边界 | 能确认流程先被私聊挪开、审批不等于到账、责任与入口分离；不能确认最终账户和老板知情程度。 |
| 最终原话 | “报销审批通过。” / “主责，我确实想要。” / “返款统一打给对接人。” / “先私下办成，复盘再补流程。” |

诡计分层：误导层为感性诡计——新人想表现、同事只是帮她拿机会；承重层为时间诡计加覆盖检查——“来不及”早于财务通知九天，且通知只覆盖报销、不覆盖返款。

### 2. A / B 故事与运算

| A 故事 | B 故事 | 屏幕运算 |
| --- | --- | --- |
| 财务延后导致临时垫款和迟迟未返。 | 私聊绕流程发生在延后通知前九天。 | 日期差。 |
| 审批通过说明款项已在路上。 | 审批、付款、到账是三步，图只到第一步。 | 覆盖检查。 |
| 供应商返款和公司报销是一件事。 | 报销走财务，返款按单据给对接人。 | 路径拆分。 |
| 她拿到主责，所以入口也由她负责。 | 主责写陈，付款对接人与供应商确认人仍是同事。 | 主语核对。 |

### 4. 完整剧情

季度复盘前夜，来电人上麦就承认自己想要主责。对方把“你先顶上”和“复盘写你主责”放在同一句里，她答应得很快。此前她刚向老板表示自己能接活动，这一利益不留到结尾才揭。

第二幕摆出公开流程：14:05，部门助理在群里发预算、对公和个人垫付报备要求；来电人回了“收到”。14:22，对方私聊“先别在大群问预算，来不及，复盘再补”，又用“别让领导觉得你不担事”压住她。来电人回“我来扛”。九天后，财务才发布付款延后通知。玩家在时间线材料板上亲手完成日期差，不能由来电人直接讲结论。

审批页和真实延后通知共同把假解推到最强：审批确实通过，财务也确实慢。缺口是图上没有付款状态和收款账户，对方只是把同一张图发了三遍。第一夜在领导新批注弹出时挂断。

幕间不是顾问排队送答案。赵律师站在控制室门口，周会计开远程共享，小林老师以语音插入。赵要求公司名先遮，证据只能说到垫款事实；周要求付款回单号，拒绝拿审批页当到账；小林拆“主责”这个身份词，同时明确来电人自己先要过这个位置。玩家必须先采一套，另两套保留为终局反证。

第二夜出现供应商报价单：“服务协调费按老规矩返给对接人。”来电人只报告职位和路径，不说“这就是两条钱路”。玩家把它与审批页并排后，才能判断财务延后只覆盖公司报销。领导批注随后出现：“执行主责记陈，流程按老规矩补齐。”两处“老规矩”保持设计性歧义，任何人都不能替玩家确认是否同一套。

最终表格做主语核对：执行主责为陈，付款对接人和供应商确认人仍是同事。主播按“X 归 X，Y 是 Y”收话：她回过“收到”和“我来扛”，不能抹；审批未付款、返款给对接人，也不能拿她的野心抵掉。深问要求她承担行动代价：是否在归档前写入“个人垫款未返”。她选择写，仍保留主责，但不再用沉默换能干形象。

## 四、台词与选项统一标准

- 来电人每句只报告自己看见、听见、做过的事；“这就是两条钱路”“版本共同生产”等结论只留在作者账本和收麦之后。
- 主播问题只使用上一句已经出现的名词、数字或原话，不直接命名角色心理。
- 每幕至少一个核心问题和一个真实可问的外围角度。外围问题可以保面子、查窄一层或暂时接受真借口，不能是故意送分。
- 防备回答变短、少给细节，不提前交出深问自白。
- 最终原话全部来自无门控场景正文；材料路线不同不影响原话公平性。
- 案 3 来电人保留少语气词、报数字、以“我妈”洗主语的指纹；案 4 来电人保留给流程词加引号、害怕时变短的指纹。
- 直播为语音连线。弹幕可以听见停顿和读出的原话，看不见来电人的手、表情或房间。
- 结案只写已确认、被修剪和仍未知，不使用命中率、最佳答案、心理诊断或课程式总结。
