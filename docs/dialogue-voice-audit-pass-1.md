# 第一批台词声纹审计

日期：2026-07-17
范围：Steam 试玩包四案的夜 A、白天、夜 B、回拨首次冲突、深追问和对方留言。

## 结论

案一、案二、案四的承重台词已经能通过“遮名辨人”和“受压变化”测试，不做整案换声。案三原有逻辑闭合，但咨询者、介绍人和男方表姐在若干段落里都使用冷静总结句，听感过近；本批只改案三的表达、防御与句法，不增加学历、收入、学费或资料主导者的新事实。

本批把主要人物的声音从“单张性格卡”升级为可校验的四阶段弧：`nightA / day / nightB / ending`。覆盖林旭阳、四位咨询者和四位主要对方，共 9 人；`PACK-010` 会阻止缺阶段的人物进入内容包。

## 审计方法

1. **承重点抽查**：开场自述、第一次正确追问、白天当面句、回拨首次冲突、深追问、对方留言与结案句。
2. **角色互换测试**：把同案两人的句子遮名互换；若句法、防御动作和利益仍成立，判为声纹碰撞。
3. **压力前后测试**：检查句长、主语、称呼、数字密度或回避目标是否发生可听见的变化。
4. **知识边界测试**：性格只能改变表达，不能让角色知道材料尚未揭示的事实。

## 案三实际修改

- **介绍人**：从作者式总结改为“甩全记录—要求按句追责—拒绝多认”的交易型自保。她承认自己添高“收入稳”、压低“不计较学历”，仍不替任何一方补完整身份。
- **男方表姐**：保留“姑姑、我、他都参与挑资料”的既有事实，增加门口封线的句法；收入与 MBA 学费仍明确拒答，没有分配谁挑了哪张图的新职责。
- **相亲对象**：后台留言改为逐项列真，再用“不够不等于假”反击；持续收入仍不回答。
- **咨询者**：回拨时把“我相信收入稳”和“我把主语全放在他身上”说回第一人称；深追问报出自己一万出头后，句子按声纹骤短。

## 连续性护栏

本批没有改变以下事实：

- 校名与 MBA 项目可核，本科、项目性质、学制不在同一张材料中。
- 存款证明只证明当天余额，持续收入未知。
- 流水先由咨询者提出，两分钟后母亲才跟进。
- 介绍人分别添过“收入稳”和“不计较学历”。
- 男方家多人参与资料整理，但谁主导、收入构成与 MBA 学费来源仍未知。

## 验收口径

- 主要角色四阶段声纹弧由 `content/characters/cast.json` 提供，`content/characters/voice-bible.md` 是人工速查版。
- 导演排演优先看 `docs/generated/steam-demo-01-director-script.md`；逐字段追溯看 `docs/generated/steam-demo-01-full-readable-script.md`。
- 后续台词修改若只增加口癖、没有改变防御动作，不算完成个性化；若角色为了“成长”说出知识边界外事实，视为回归错误。
