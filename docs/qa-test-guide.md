# 开发测试组验收入口

## 平台优先级（2026-09-12 用户确认）

UI 优先适配 PC，日常验证与人工试玩主要在 PC 上完成。先验收 PC 的布局、阅读和操作，再补充移动端兼容检查。

- PC 常规视口：1920×1080、1366×768、1280×800；1280×720 用于检查较矮窗口。记录的是页面可用区域尺寸，不是显示器标称分辨率。
- 重点检查窗口缩放、鼠标／键盘操作、对话框与铭牌完整可见、材料出示、打开／关闭记录后的位置恢复，以及内容本可放下时是否出现多余滚动条。
- PC 截图与实际试玩结果作为主要验收证据；手机和 Steam Deck 保留补充兼容检查，不能代替 PC 验收。
- 响应式修改以 PC 布局为基准，小屏规则通过断点单独处理，不为小屏压缩 PC 的阅读区和操作空间。

## 当前剧情与流程回归重点（2026-09-16）

按[当前方向 S1–S8](../project-skills/case-scriptwriting/references/current-project-direction.md)和[六案复审](review-archive/remaining-cases-review-2026-09-16.md)验证集中问询：本段问清推进，错问本段重问，不强制返回原句或结尾补完成度。材料同页核对并直接选完整问句；普通单项接话直接播放。错问不扣耐心、不限次数，旧挂断存档恢复当前问询；文档不要求圈选。口播任一有效点评推进。重点检查知情提前、材料来源、重复发现和收尾回滚。

四主案和两来电快案已迁移；`--target=six-review` 验证后三主案跨夜、材料误问、重载与全部快案收麦。旧回放或排序烟测只说明兼容行为，不证明符合新设计。`smoke:recorded`、`--target=script-reading`、`--target=quick-detective` 的具体路径先核对脚本；不为适配旧目标恢复取消的玩法。PC 尺寸按上文检查截图与实际点击。

## 一键启动

首次拉取项目后只需执行：

```bash
npm ci
npm start
```

以后启动只需 `npm start`。命令会自动寻找可用端口、清空旧进度并打开浏览器；修改源码或内容后页面自动刷新。

Windows 非开发测试人员可双击 `play-windows.bat`，脚本会在需要时自动构建离线版并打开。

## 一键测试

开发提交前执行：

```bash
npm test
```

Windows 也可双击 `test-windows.bat`。完整测试依次覆盖：

1. 内容索引、内容包结构和脚本语法。
2. 逻辑单测与剧情连续性。
3. 浏览器全部既有路线，包括隔夜、文档、键盘、手柄、逐句推进和 reduced-motion。
4. Electron 桌面 staging 构建与烟测。

只想快速检查内容和逻辑时执行 `npm run test:quick`。

## Windows EXE 验收

Windows 发布候选包还必须通过 `npm run package:win`、`npm run verify:win-package` 和真实打包运行时烟测。验收时应同时检查：

- EXE、SHA-256 文件、打包报告和运行时报告四项产物齐全。
- 禁止联网时仍能从 `file:` 打开标题页，并能完成文件存档的写入、读取、列出、导出和删除。
- `Get-AuthenticodeSignature` 的结果与发布标签一致；未签名包只能标记为内部测试版。
- 应用使用正式图标与元数据，没有 electron-builder 的默认图标、`author` 或 `description` 警告。
- 在干净 Windows 机器上手工复查 SmartScreen、音频设备、窗口状态和崩溃日志。

完整命令及 Steam/Steam Deck 外部发布门槛见 [Desktop and Steam Build Plan](desktop-steam-build-plan.md)。

## 手工完整过案

自动化通过后，从 `npm start` 打开的全新存档至少完成一次案 1 完整夜班：

- 打字中点击只补全当前句，再点击才推进；Space、Enter 行为一致。
- 句尾显示 `▼`；选项出现时自动模式停止。
- 打开和关闭案卷，检查材料、文档、收获、对话记录没有未播内容。
- 检查完整问句、材料阅读、错问回应和继续推进；不应出现材料与原句配对、单项问句菜单、耐心条或圈选额度。
- 切换字速和自动模式，刷新页面后设置仍保留。
- 系统开启“减少动态效果”后重新进入：没有逐字打字、白闪或震动，仍能完成流程。

报告问题时附上：系统和浏览器版本、入口命令、案件/场景、操作步骤、预期结果、实际结果及截图。
