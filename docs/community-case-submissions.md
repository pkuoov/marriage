# 玩家贡献案例入口

## 是否需要

需要，但入口应命名为“贡献案例线索”或“贡献婚恋判断题”，不要叫“爆料”。

每日模式的长期生命力来自新套路、新话术和新反制方式。玩家贡献可以补足短视频平台抓取的盲区，尤其是：

- 新出现的资产边界话术。
- 合理反制方式被曲解成“不爱 / 算计 / 不信任”。
- 朋友之间容易判出分歧的情境。
- 游戏里没有覆盖到的地方习俗或新平台套路。

## 产品原则

- 只收结构，不收原案。
- 只收抽象套路，不收可识别人物。
- 入口强调“不是法律咨询，不处理现实纠纷”。
- 投稿先进入本地/后台待审核池，不直接进入每日案。
- 入库必须改写人物、金额、时间线和材料，不复刻真实事件。

## 当前实现

H5 已实现“贡献案例”页面能力，但标题页入口当前隐藏。等内容审核、后端收集和运营规则准备好后，再用活动入口或灰度入口打开。

玩家填写：

- 冲突类型。
- 第一版说法。
- 你觉得该追问什么。
- 反制方式或争议点。
- 去标识化确认。

提交后：

- H5 保存到 `meta.communityCaseSubmissions`，最多保留 20 条。
- 自动隐藏手机号、邮箱和 `@账号`。
- 通过 `platformRuntime.wechat.postMessage({ type: "case-submission" })` 发给小程序壳。

第一版没有后端，所以它只是本地待审核池。正式上线后，小程序壳或 H5 应把 submission 发到审核接口。

## 入口策略

当前建议隐藏常驻入口，只在这些场景打开：

- 每周热点活动：例如“本周你见过最离谱的房产边界话术”。
- 结算页轻提示：玩家完成今日案后，邀请贡献“类似套路”，但不打断主流程。
- 私域/测试群：先让可信玩家贡献，人工审核质量。

暂不建议在首页常驻开放，因为早期容易收到真实爆料、求助、网暴材料和不可核验争议。

## 后台审核流程

1. 初筛：删除真实姓名、账号、手机号、学校、公司、地址、截图原文。
2. 归类：房产/洗房、恋爱转账、婚前协议、信托保险、情绪话术、平台中介、反诈。
3. 抽象：改成“来访者 A / 对方 B / 家庭账户 / 一笔转账 / 一份协议”。
4. 转写：生成每日案草稿，包括三条追问路线和 3-5 个结果画像。草稿必须改成单人匿名连线：只有咨询者在直播间说话，另一方只能作为转述、聊天截图、录音、账单或合同出现。
5. 风控：确认不构成法律建议、心理诊断、真实爆料或网暴引导。
6. 入库：进入每周情报台，候选进入后续每日案轮换。

## 贡献后的反馈

可以给玩家一个轻量反馈，不承诺采用：

```text
线索已收下。
如果进入每日案，会被改写成虚构人物和虚构材料。
你贡献的是一个判断题，不是一段真实纠纷。
```

后续可以加：

- “本周被采用的玩家线索数”。
- “本周热门争议：房产边界 / 恋爱转账 / 情绪话术”。
- 匿名鸣谢，不展示投稿原文。
