# 对话连贯性审查

审查日期：2026-06-30

## 审查标准

按理发店案重写后的逻辑，所有案件对话都按这条线检查：

```text
开场只给事件钩子，不提前把答案说完。
每一段只新增一个信息。
玩家追问必须承接当前段，而不是凭空跳到结论。
关键材料要分层露出：先看到物件，再看到缺口，再看到用途。
来电人自己的隐藏诉求要放到后半段或满格深问，不放在第一屏。
复盘只能总结玩家已经听到过的事实。
主流程是剧情文本游戏，不是过关提示器；不能实时展示命中数、缺口答案或“应该先看什么”。
```

## 审查结果

### 8 万信用卡周转

原问题：

- 开场同时抛出 8 万、贵餐厅、朋友圈和来电人吃体面，信息太满。
- 后续社保断缴、账单用途和体面压力的递进被削弱。

已调整：

- 开场只保留“信用卡周转，让我先顶一下”。
- 第一段接“奖金晚发”与社保断缴。
- 第二段才揭出 8 万账单和消费用途。
- 第五段再让来电人承认自己吃过体面，也怕承认看走眼。

当前链条：

```text
短期周转
-> 社保早断
-> 8 万账单用途
-> 最低还款递过来
-> 结婚/体面压力
-> 满格追问她怕失去的是钱还是体面
```

审查结果：

### 理发店排班表

原问题：

- 开场就抛出“情绪稳定 / 能投店”，后面重复解释同一张表。
- 来电人自己的利益位置偏弱，容易变成单方受害。

已调整：

- 开场只说发错表、越看越不对。
- 第三段才揭出预约表备注。
- 第五段才揭出“下一次推进”。
- 满格深问追来电人为什么愿意接店里的事。

当前链条：

```text
关系没说死但暧昧很满
-> 情绪求助后接发活动/带客/年卡
-> 发错表，备注不是发型需求
-> 老板娘话术接年卡/投店
-> 下一次推进写着投店/带客
-> 满格追问她也吃了自己人的感觉
```

### 存款证明

审查结果：

- 结构基本成立。
- 开场通过主持人问答逐步展开，虽然较长，但没有直接给最终责任。
- 五段递进清楚：见面前材料尺度、介绍人和来电人共同放大条件、MBA 标签、收入与花销不匹配、工资卡/婚后管钱。
- 来电人隐藏诉求在第五段和满格深问落地。

暂不大改，后续可优化方向：

- 开场可再压缩一句，让首屏更利落。
- 第四段“抠门/会过日子”可以增加一个更具体的可视化物件。

### 职场报销截图

原问题：

- 开场把垫款、署名、审批截图一次说完，后续 scene-1 和 scene-3 的发现感变弱。

已调整：

- 开场只保留垫款和“发了报销截图但钱没回”。
- 主播先问为什么是她垫。
- 第一段再揭“主责署名”和她自己想表现。
- 第三段再看审批截图少了付款状态和收款账户。

当前链条：

```text
先垫款，报销截图后钱没回
-> 主责机会让她先刷卡
-> 不让大群确认预算
-> 审批截图缺付款状态
-> 供应商返款入口在同事手里
-> 主责署名给她，付款入口还在他手里
-> 满格追问她怕被说成抢署名私下垫款
```

## 后续硬规则

新增或修改案件时，人工串读必须能回答：

```text
第一屏有没有提前给答案？
故事集标题页有没有提前讲主题论点、价值判断或结论？
故事集标题页有没有提前暴露总案数、案名列表、章节功能或后续案件物件？
每段新增的信息是不是唯一且明确？
关键追问是不是只问当前段能问到的东西？
如果玩家没问核心追问，下一段还能不能自然继续？
满格深问是不是承接前面至少两个已出现事实？
来电人有没有一句对自己不利但必须说出的隐藏话？
最终原话是不是玩家已经听过或看过？
直播间提示有没有变成重复模板句？
复盘路线能不能让玩家看出自己每一步实际问了什么？
首屏开场有没有停在主播问句上、但来电人还没回答？
选择组提示的路线轴是否和当前问题意图一致？
来电首屏有没有混入案间桥、章节导语或宣传式解释？
主流程按钮/折叠标题有没有误导成“回放、复盘、听录音”，而不是继续对话？
选择区小标题有没有“顺手聊开的地方、询问对话、关键追问、把这一段问实”这类后台设计腔？
当前选择区是不是一个面板，按钮是不是主播真正要问出口的问题？
当前选择区的按钮是不是同一视觉权重？不能用颜色、边框、卡片样式或侧边高亮暗示哪个是核心/正确/推荐。
主流程按钮区有没有“麦上动作 / 麦还连着”这类只解释 UI 的标题或小字？
折叠回看入口有没有“前文对话 / 开场对话 / 上一轮追问后”这类后台整理词？
按钮里有没有“顺着问、按住问、核心追问、普通追问、钱流线、材料线”这类解释玩法的标签？
主播选项有没有直接替来电人贴心理标签，或者像整理后的提纲话，比如“你是不是先心疼 / 你是不是也怕 / 关系一直没说死，你当时怎么接的”？正常主播应该顺着事实问“当时有没有起疑 / 为什么没继续问 / 这句话后面接了什么 / 话当时没说死，你当时怎么回他的”。
背景弹幕/提示有没有“继续追原话、关键原话、下一句原话”这类 AI 工作流腔？
当前选择区有没有直接指导玩家“先看钱流/材料/流程/身份标签”？
深问页有没有“满格追问/关键点都接上了”这类系统评分话？
结论页有没有“更锋利、最佳答案、问题揭示率、满格徽章”这类评分/说教口吻？
主流程 HUD 有没有“抓到 x/y、已问 x/y、还差一句、先看某路线”这类主动帮玩家过关的提示？
如果有听众忍耐度/血量条，它会不会真的耗尽并结束本案，而不是只做装饰？
立绘和表情文字有没有让连线人更像活人在反应，而不是只当静态头像？表情不能泄露正确追问。
话术受过训练、目的不单纯这类钩子有没有来自玩家已经看见的文本？不能偷用后台矛盾或未听到的回答。
结算、满格深问和剧本文档里的代词，是否和当前可见头像、来电人、缺席方一致？如果角色以后可能替换，优先写“咨询者 / 同事 / 对方”。
```

## 2026-06-30 试玩新增问题

- 第一案满格路线完成后，复盘第一页的“本案路线”连续显示五个“钱流结构线”，玩家只能知道路线轴，想不起自己具体问过哪几句。
- 多个普通询问后的兜底提示重复“弹幕顺着这句吵了一轮……”，容易暴露模板感。
- 顶部直播间短评在抓到线索后固定显示“有东西了 / 这句前后对不上 / 继续追原话”，像系统评语，不像直播间状态。
- 第三案“存款证明”开场停在主播问“她问细到哪一步了？”，来电人答案没显示就进入案间说明，通话被菜单打断。
- 第三案第二段问“这个好看的版本，是他一个人说出来的吗？”，分组提示却显示“先看钱从哪来、落到谁手里”，路线轴被“收入”误判。
- 第一案首屏在通话对白下面显示“第一案：体面 / 先从最容易让人心软的体面开始……”，这是故事集导语，不是来电内容，容易让玩家误以为是剧情台词或系统评语。
- 主流程推进按钮写成“继续听原话”，折叠区写“通话回放”，会让玩家以为自己在复盘或听录音；实际这里是继续连线对话。
- 顶部背景弹幕和普通询问反馈仍有“听下一句原话 / 关键原话 / 最硬的原话 / 下一句原话还得继续追”，语感像 AI 流程提示。
- 关键追问区显示“本段只选一句｜先看钱从哪来、落到谁手里”等后台路线轴，等于提前指导玩家怎么解题。
- 深问页显示“满格追问 / 关键点都接上了”，像系统判定，不像主播临场多问一句。
- 结论页出现“结论会更锋利 / 更锋利接法 / 最锋利的那句 / 问题揭示率 / 满格徽章”等评分词，像在讲标准答案。
- 主流程和结果页仍有“抓到/已问/聊开程度/平均揭示率/还差一句/路线已汇总”等过关面板感，不像剧情文本游戏的自然回味。

已处理：

- 路线复盘改为展示每步序号、路线轴和具体追问摘要。
- 顶部直播间短评不再按命中数量报进度，只保留直播间氛围。
- 普通询问兜底反馈按追问语气改写，减少模板句反复出现。
- 第三案开场改为由来电人说完当前关系和家里问细的压力，细节留到第一段原话；验证脚本新增 `OPENING_DANGLING_HOST`，拦截首屏停在未回答主播问句的问题。
- 路线轴推断优先识别“版本/介绍人/标签/条件”等身份话术，再判断收入钱流，减少选择组提示错位。
- 来电首屏移除故事集导语；案间桥只保留在案间过渡和故事集总结这类非通话屏。
- 主流程推进按钮改成“继续”，折叠区改为“上一问”，不要再写“前文对话 / 开场对话”。
- 背景弹幕和普通询问反馈改为“麦里有回声 / 话没说满 / 弹幕压一压”等直播间氛围句。
- 当前选择区不再暴露路线轴；路线倾向只留到复盘页展示。
- 深问页移除系统评分卡，直接显示主播追问和咨询者回答。
- 结论页改成收麦语气：这通收住、你接住的那句、也可以这样收；移除“更锋利/满格徽章/问题揭示率/聊开程度”等前台评分词。
- 主流程 HUD 不再显示命中进度，只保留当前第几段和案件名；结果页去掉百分比进度条、缺口答案和“还差一句”类讲评，改成直播间余波。
- 案件模板里的“先别急/先听/先看”类提示句改为主播自然接话或直播间气氛句。
- 选择区小标题去掉“询问对话 / 关键追问 / 顺手聊开的地方 / 把这一段问实”，后来又去掉“岔开一句 / 盯住一句 / 顺着问 / 按住问”等解释型标签。当前规则：一个选择面板，按钮只写主播要问出口的问题。
- 当前节点按钮去掉按内部类型区分的高亮色条。当前规则：同一组问题同一视觉权重，不让 UI 暗示哪个更优先。

## 2026-07-01 选择区大测准则

这条作为每轮大 test 的固定项：

```text
看到当前节点选择区时，先不要判断按钮是否“有功能区分”，先把它当直播台词读一遍。
如果读出来像 UI 在解释“这是什么选项”，就是错的。
如果读出来像主播现在要问来电人的下一句话，才是对的。
```

必须检查：

- 当前节点只能是一个选择面板，不能上下拆成两个孤立按钮组。
- 面板可以有很短的现场标题，但不能解释玩法。
- 按钮文字只能是主播问题，不能是路线名、难度名、设计名或通关提示。
- 核心问法和外围问法只能在后台路线数据里区分，当前按钮不能有视觉强弱差异，也不能写成“核心/普通/顺着/按住/钱流/材料”等标签。
- 大测试至少抽查三个不同案件的当前节点选择区，复制 DOM 文本确认前台没有解释型标签。

## 2026-07-01 故事集标题页准则

标题页不是收麦总结，也不是目录。不能先说“这几个词不坏，坏的是……”这类主题论点，也不能把总案数、四个案名、章节功能和后续物件一次列出来。玩家还没听电话时，只需要知道热线接进来了。

标题页应该写：

```text
热线已接入。
资料在后台，她已经开口了。
```

标题页不应该写：

```text
四案放在一起说明什么。
一共有几案，每案叫什么。
第一案是什么、第二案是什么、后面会出现哪些物件。
哪些词不坏，谁拿它们省掉责任。
这一集真正要讨论的是……
```

主题论点只能放到故事集收麦、评论墙、复盘页等玩家已经听完之后的页面，而且语气要像回看后浮出来的味道，不要像作者替玩家上课。

进入第一通以后也不能马上把目录补回来。通话眉题和 HUD 只写“热线连线 / 匿名来电 / 今晚收麦”这类直播间话术，不写“故事集 1/4”“第一案：体面”“接入下一案”。案间按钮用“接下一路麦”这类直播间口吻；案间卡片标题要用物件钩子，例如“表格 / 资料图 / 审批截图”，不要退回“下一通来电”。

## 2026-06-30 好玩度试玩补充

第一案“体面”实测路线：每段先点普通询问，再点关键追问。

评价：

- 剧情合理性：链条成立。从“奖金晚发”到社保断缴、8 万账单、催今晚转、最低还款、结婚压力，事实能一层层往下走。
- 反转性：中后段有反转，从“男方隐瞒失业借钱”转到“来电人自己也吃体面、怕承认看走眼”，灰区比单方受害更好看。
- 探索性：仍偏弱。关键追问区只有一个核心按钮，普通询问后还出现“硬点没落地/最要紧的点还没问到”这类系统提示，等于帮玩家找答案。

已处理：

- 增加“听众忍耐度”血量条，额外绕问、重复问和误指材料会消耗直播间耐心；关键追问命中和材料命中不扣，避免压力条变成倒计时。
- 忍耐度耗尽会进入“听众散了”失败页，本案不保证收麦。
- 普通询问反馈去掉“硬点没落地/最要紧的点没问到/往下问”这类答案提示。现场反应要说具体发生了什么，比如“问题被带远”“现场先停了一下”，不要写抽象温度值。
- 立绘前台统一加轻卡通化呈现：提高饱和度和边缘描边，去掉过灰过暗的纪录片滤镜。
- 连线中新增表情层：连眨、停顿、低头翻图、握紧手机、吸气再接等短反应，用来强化追问钩子和来电人的状态。
- 直播间弹幕和表情层加入“话太顺/甜话后面接要求/流程词说得太熟/条件话被托了一层”等钩子，用来提示话术感和目的不单纯，但只根据当前可见文本触发。
