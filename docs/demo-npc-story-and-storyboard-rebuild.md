# 《直播间大侦探》一小时试玩版：NPC 主线剧情与逐幕分镜重构稿

日期：2026-07-10  
性质：剧情与分镜设计稿，先定整晚故事，再拆案件、场景和交互。本稿不直接改运行时 JSON。  
目标时长：首次游玩 58–65 分钟；跳读约 48 分钟；探索支线与回看约 75 分钟。

## 一、剧情总纲

### 1. 一句话故事

一名曾因追随舆论而误伤当事人的深夜主播，为保住即将被平台合并的节目，在四通来电之间走出直播间，向三个立场不同的熟人求助；最后，当三种意见同时压到耳边，他必须决定自己究竟是替观众判人，还是承担起“让事实足够清楚、让选择回到当事人手里”的主持责任。

### 2. 设计原则

每通来电先在夜里制造一个容易站队的版本，白天场景再让玩家主动找人、读材料、承受取舍，第二夜的回拨根据玩家带回来的证据改变。三位 NPC 各自只拥有一部分真相，最后一案必须综合三人的方法，但不能照抄任何一人的答案。

核心循环：

```text
第一夜来电：听见一个好讲、好站队的版本
    ↓
收麦后：赵律师主动来聊，指出主播的情绪或逃避，不提供破案答案
    ↓
第二天白天：玩家主动去周会计或小林老师所在的真实场景求助
    ↓
场景交互：读文档、做比较、遭遇拒绝或立场偏见，得到一块证据并付出机会成本
    ↓
第二夜回拨：玩家用白天获得的东西决定第一问，来电人改变证言
    ↓
收麦：保留一项可确认、一项被修剪、一项今晚仍不能确认
```

### 3. 主角弧

主播的心理弱点是怕再错一次，所以只要证据不够，他就倾向于退回“今晚定不了”。这保护了当事人，也逐渐变成他的免责方式。道德弱点是他把“不替别人决定”误解为“不必表达自己的责任”，来电人得到边界，却常得不到下一步能做什么。

他的外部目标是让深夜档撑过平台本月考核。内部需要是承认：谨慎不是沉默，主持人的责任也不是给答案，而是把材料、利益和代价摆到当事人能够自己决定的位置。

最终变化类型：成人到领导者。开场时，他把事实分开是为了不犯错；结尾时，他把事实分开是为了让别人有能力行动。

### 4. 三位核心 NPC

#### 赵律师：主动找主播聊天的人

- 出场规则：每案收麦后由她主动发消息、打电话或出现在家中。玩家不需要“选择去找她”。
- 个人欲望：确认主播没有把两年前的错误变成新的逃避。
- 方法：盯边界、效力和谁有资格替谁决定。
- 偏差：过度克制，容易让现实中的受损者继续独自承担时间成本。
- 戏剧动作：主动打断、拒绝替玩家背书、在终案要求主播不要公开无法证实的指控。
- 与主播的私人矛盾：她是旧案另一端的人，也是如今最了解主播的人。她不是导师，而是最有资格问“你到底怕什么”的人。

#### 周会计：玩家主动去求助的数字派

- 固定场景：旧工厂改成的财务档案室。白炽灯、铁柜、点阵打印机、午饭盒，空间讲究“每一笔都要能回到入口”。
- 个人欲望：让含糊的钱路重新变成可核对的行。
- 方法：金额加总、时间线、账户路径、流程覆盖。
- 偏差：把人的犹豫视为噪音，容易低估面子、关系和职业机会的真实力量。
- 戏剧动作：第一次求助时拒绝看摘要，要求玩家带原始流水；终案中坚持“钱不到账，别的都先放一边”。

#### 小林老师：玩家主动去求助的人情派

- 固定场景：打烊后的婚介门店。半亮招牌、茶杯、打印资料墙、被反复擦掉的白板条件表。
- 个人欲望：拆穿行业里把人说得过分好听的手法，同时保住“介绍人并非都在骗人”的行业尊严。
- 方法：翻译身份词、识别谁在向谁销售未来、辨认关系中的观众与面子。
- 偏差：容易把证据问题解释成人情与行话问题，有时会替行业找台阶。
- 戏剧动作：拒绝把理发师定性为骗子；逼玩家先承认来电人吃过哪些便利；终案指出“主责”与“老板娘”是同一种先给身份、后收成本的句法。

### 5. 四角人物冲突

| 角色 | 面对不完整真相的主张 | 能救主角的部分 | 会伤害主角的部分 |
| --- | --- | --- | --- |
| 主播 | 证据没到就不下结论 | 守住公平 | 容易把克制变成逃避 |
| 赵律师 | 谁的决定归谁，谁的证据归谁 | 守边界 | 可能过度保守 |
| 周会计 | 钱只认路径 | 拆穿成本转移 | 忽视人为什么愿意配合 |
| 小林老师 | 好听话要翻译成利益关系 | 看见身份诱饵 | 容易过度解释动机 |

平台运营老方不进入核心 NPC 团。他只通过短信、后台数据和改版要求构成系统性对手：观众越快站队，数据越好看；主播越谨慎，节目越可能消失。

### 6. 主题与反题

主题：不替别人做决定，不等于不做决定。负责的主持人不替当事人选，但必须让事实、利益和代价清楚到足以选择。

反题：观众只要一个能马上转发的结论，平台只要一个能马上上涨的数据，顾问只要守住自己的专业边界。每种要求单独看都合理，合在一起却可能让真正承担成本的人继续等下去。

### 7. 世界与视觉母题

- 红灯与日光：夜里 ON AIR 红灯代表被观看；白天冷光和自然光代表没有弹幕可依赖的判断。
- 门与边框：截图裁边、表格列线、直播窗框、办公室门框都在问同一件事：画面外还剩什么。
- “入口”：钱的入口、关系的入口、流程入口、节目入口。每案都有人把入口握在自己手里，把成本留给别人。
- 耳机：序章戴上是躲进职业身份；尾声摘下是愿意用自己的名字承担选择。

## 二、四案剧情

### 第一案：《八万之外》

#### 案件账本

| 项目 | 内容 |
| --- | --- |
| 表面说法 | 男友失业后隐瞒债务，用“怕你离开”让来电人垫八万 |
| 误导答案 | 八万都是为了恋爱体面刷出来的，他只是虚荣又失责 |
| 戏剧物件 | 五个月银行流水、信用卡账单、纪念日会员记录 |
| 材料缺口 | 可见消费不到三万；贷款五万进账后转到尾号 3301；每月 8 号的王姓转账突然停止 |
| 来电人修剪 | 她参与订座、发朋友圈，也收下短视频设备，把共同维持的体面说成“都是他安排” |
| NPC 作用 | 周会计拒绝听摘要，要求玩家用原始流水做加总和交叉；赵律师收麦后提醒主播别替她回答“该不该垫” |
| 反转 | 这不是单纯的约会消费债，八万里有一个早于本段关系的旧洞；关系体面只是把旧洞递到她面前的包装 |
| 今晚边界 | 能确认钱路被修剪，不能确认 3301 属于谁，也不能替她决定是否继续关系 |

#### 完整剧情

第一夜，来电人说男友以奖金晚发为由让她“挡几天”，随后露出早已断缴的社保和八万信用卡账单。弹幕迅速认定对方在吃软饭。通话往下走，来电人却不得不承认：纪念日餐厅由她的会员号预订，朋友圈是她发的，短视频设备也摆在她家。她不是债务责任人，却是这套体面叙事的共同参与者。

主播问到八万与三万的缺口，来电人挂断。赵律师主动来电，没有分析债务，只问主播是不是又想赶在弹幕前面救人。第二天，玩家带原始流水去周会计的档案室。周会计把摘要推回来，要求玩家亲手圈出工资停止、王姓转账、五万信贷和 3301 转出四行。她拒绝回答 3301 是谁，只说：“钱进来三天就出去了，这不是猜人，是先承认你们不知道钱去哪了。”

第二夜，玩家用自己圈出的两行开场。来电人修正证言：八万不能全部算成两人的消费，但她也不能再把设备说成与自己无关。最后她问“我该不该垫”。主播可以替她回答、继续追钱，或把选择还给她。最成熟的路线不是沉默，而是明确告诉她：今晚能确认什么、转钱会承担什么、仍缺什么，然后由她决定。

### 第二案：《自己人名单》

#### 案件账本

| 项目 | 内容 |
| --- | --- |
| 表面说法 | 理发师用暧昧和“自己人”哄来电人办卡、带客 |
| 误导答案 | 所有亲密都是统一销售话术，对方毫无真心 |
| 戏剧物件 | 深夜语音、店长培训模板、会员维护表、“下一次推进”私加列 |
| 材料缺口 | 标准模板有维护备注，却没有“下一次推进”；真实行业惯例只覆盖一部分行为 |
| 来电人修剪 | 她知道关系没说死，也享受插号、免单、朋友折扣和“嫂子”称呼 |
| NPC 作用 | 玩家去打烊后的婚介门店找小林老师。她拒绝把销售话术直接等同于诈骗，要求玩家比较标准模板与私加列 |
| 反转 | 店里的话术和维护表都是真的，但“老板娘—办卡—投店”的私人推进链不属于标准服务 |
| 今晚边界 | 能确认亲密称呼被用于转化，不能确认对方对每个人都没有真实好感 |

#### 完整剧情

来电人放出一段“下班陪你聊”的语音，背景里吹风机始终没停。她说对方只把脆弱讲给自己听，随后却总接办卡、带客或投店。发错的表上有“情绪稳定”“朋友多”“办卡意向强”，弹幕直接把理发师判成海王。

主播没有立即收麦。白天，玩家去找小林老师。门店已经打烊，她正把相亲资料从墙上撕下来。她先承认行业确实会记录熟客偏好，也会教员工维护关系；随后把一张标准表和来电人的表并排，让玩家找出只有后者存在的“下一次推进”。她拒绝说“他一定没有真心”，并逼问玩家：“免费护理、朋友六折、插号，她是不是也都接了？”

第二夜，来电人承认自己享受过这些便利。关键不再是“真心还是话术”二选一，而是对方是否故意让关系保持不明确，从而继续获得办卡、带客与投店机会。结尾保留真心未知，但把“我从来没说只有你一个”与“以后店开起来，你就是老板娘”放在同一张桌上。

### 第三案：《好条件的两面》

#### 案件账本

| 项目 | 内容 |
| --- | --- |
| 表面说法 | 男方把普通本科包装成名校 MBA，又用存款证明制造高收入形象 |
| 误导答案 | 学历和收入都是伪造，来电人只是被条件欺骗 |
| 戏剧物件 | MBA 项目页、当日存款证明、单月收入截图、介绍人双向话术 |
| 材料缺口 | 图是真的，却不能覆盖本科口径、长期收入来源和婚后账户安排 |
| 来电人修剪 | 她把自己对工资、流水与婚后控制权的要求挂在母亲名下 |
| NPC 作用 | 白天只能选去周会计或小林老师处。周会计拆资金持续性，小林老师拆介绍人的双向包装；两条路线各自留下盲区 |
| 反转 | 双方家庭都在销售“未来适合结婚的身份”，男方包装学历收入，女方包装不计较条件，双方都没把真正的钱权要求说出来 |
| 今晚边界 | 能确认资料口径被修剪，不能确认持续收入，也不能确认坦白后两人是否仍愿意继续 |

#### 完整剧情

第三通来电以“名校 MBA”和二十八万存款证明开场。最初证据支持男方主动包装，来电人也把追问解释成母亲怕她吃亏。随着饭局冷场、介绍人的双向说法和单月收入截图出现，案件从真假证明转向谁在把婚姻未来包装成现在可交换的条件。

白天玩家只能找一人。去周会计的档案室，可以发现存款证明是当天开的，收入截图只显示一个月，无法回答持续性；去小林老师的门店，可以拿到介绍人对两家不同的版本，发现男方被说成“收入稳”，女方被说成“家里不折腾、对学历不计较”。选择决定第二夜从钱的持续性还是关系的销售话术切入。

收麦后，赵律师主动指出主播这次一直引用顾问，却没有说自己怎么看。主播第一次意识到，他正在用专家替自己承担主持责任。

### 第四案：《主责写谁》

#### 案件账本

| 项目 | 内容 |
| --- | --- |
| 表面说法 | 同事以财务来不及为由让新人垫款，报销通过却迟迟不还 |
| 误导答案 | 财务流程单纯延迟，同事只是办事混乱 |
| 戏剧物件 | 预算群通知、私聊、审批截图、供应商返款记录、季度复盘主责栏 |
| 材料缺口 | “审批通过”没有付款状态和账户；返款给对接人，而主责署名给来电人 |
| 来电人修剪 | 她主动争取主责，也看见过正常流程，却因怕显得不能扛事而绕开报备 |
| NPC 作用 | 赵律师、周会计和小林老师全部介入，各提出互相冲突的要求；玩家必须决定先保护边界、先追钱路或先拆身份诱饵 |
| 反转 | “主责”不是奖励本身，而是把结果责任给她、把资金入口留给别人的工具 |
| 今晚边界 | 能确认公开流程被绕开，不能确认老板是否知情，也不能确认返款最终进了谁的账户 |

#### 完整剧情

最后一通来电发生在季度复盘前夜。来电人承认自己主动争取主责，也承认看见过个人垫付需报备的群通知。对方随后把预算讨论移到私聊，用“别让领导觉得你不担事”让她刷卡。审批图只显示通过，供应商返款却仍指向对接同事。

平台数据在此时上涨，老方发来短信要求主播直接点名公司。赵律师主动打断，要求不能公开无法证实的指控；周会计在远程共享里只盯付款账户；小林老师从“主责”这个词听出熟悉的身份诱饵。三人都对，但没有任何一人足够。

玩家必须从三种框架中先选一种行动，再在最终材料板上补齐另外两块。若只听赵律师，节目守住边界却可能让来电人继续背款；只听周会计，会忽略来电人主动争取机会的心理链；只听小林老师，容易把职场流程过度解释成话术操控。完成三块拼图后，主播不公开公司名，也不说“今晚定不了”结束。他明确告诉来电人：审批不是到账，主责不是付款入口，绕开报备是她自己的风险，供应商返款路径必须在季度复盘前留下书面问题。决定是否提交复盘、是否继续主责，交还给来电人。

这次收麦证明主播已经改变。他没有替当事人选，也没有躲开自己的责任。

## 三、22 步结构映射

| 步骤 | 试玩中的位置 |
| --- | --- |
| 1. 需要与终点 | 主播必须学会在不替人决定的前提下承担主持责任 |
| 2. 旧伤与世界 | 两年前错误判人；深夜档长期低数据 |
| 3. 弱点 | 把“证据不足”当成免责出口 |
| 4. 激励事件 | 平台通知节目可能并入娱乐组 |
| 5. 欲望 | 用这一晚证明节目值得留下 |
| 6. 盟友 | 赵律师主动陪伴，周会计和小林老师可被求助 |
| 7. 对手 | 平台的数据逻辑与主播自己的恐惧 |
| 8. 假盟友 | “专家意见”看似能替主播承担判断，实际让他更依赖外部权威 |
| 9. 第一揭示 | 第一案八万中有旧洞，单一站队失效 |
| 10. 计划 | 主播决定每案都先找专业人士再收麦 |
| 11. 反击 | 第二案证明专业解释也有行业偏见 |
| 12. 推进 | 主播越来越依赖顾问，自己的声音越来越少 |
| 13. 盟友攻击 | 赵律师问：“你今晚说的是你听见的，还是他们替你说的？” |
| 14. 表面失败 | 第三案两条顾问路线都无法给完整答案，平台数据继续下滑 |
| 15. 第二揭示 | 顾问不是答案，而是不同观察方法 |
| 16. 观众领先 | 玩家已经看出“未来身份换现在成本”的跨案句法，主播仍只逐案处理 |
| 17. 第三揭示 | 第四案“主责”让主播看见四案共同结构 |
| 18. 门槛 | 老方要求点名公司，主播必须选择节目要成为什么 |
| 19. 战斗 | 三位 NPC 同时出场，三种正确但不完整的意见冲突 |
| 20. 自我揭示 | 主播承认谨慎有时只是怕再承担后果 |
| 21. 道德选择 | 不点名、不闭麦，明确证据、风险与可执行下一步，把决定还给来电人 |
| 22. 新平衡 | 节目暂时保住；热线仍开，主播不再独自躲在耳机后面 |

## 四、逐幕分镜

### 幕 01：平台通牒（1 分 20 秒）

- 场景：黑屏与手机冷光。
- 出场：主播、老方短信。
- 镜头 1：全黑，先响一声消息震动。屏幕中央只出现“本月数据再不达标，深夜档并入娱乐组”。
- 镜头 2：玩家按键后，手机光照出半张桌面，旧节目截图压在手机下面，标题被裁掉，只露出“道歉声明”四字。
- 镜头 3：第二条短信出现：“今晚给我一个能剪成短视频的结论。”
- 玩家动作：拿起手机或扣下手机。选择只改变序章语气，不加分。
- 场景转向：生计压力从背景设定变成本晚的具体期限。
- 美术/声音：黑底、手机震动、远处空调声；不出现教程。

### 幕 02：戴上耳机（1 分 40 秒）

- 场景：深夜直播间、走廊、控台。
- 出场：主播、赵律师消息。
- 镜头 1：走廊半根坏灯，人物从暗处进入控台。
- 镜头 2：赵发来“吃饭没有”，紧接一条“我听着”。这句话建立她是主动听直播的人。
- 镜头 3：耳机戴上，画面声音被压窄；ON AIR 灯亮，弹幕才进入。
- 玩家动作：推起直播推子。
- 关键台词：主播：“深夜热线。说得出口的归麦，说不出口的，先留在夜里。”
- 场景转向：主播从私人状态进入职业面具。

### 幕 03：第一通来电，八万（4 分钟）

- 场景：直播控台，账单缩略图在后台边缘。
- 出场：主播、信用卡案来电人、弹幕。
- 镜头 1：只给声音与心象立绘，来电人说“奖金晚发，帮我挡几天”。
- 镜头 2：社保截图进入直播画面，弹幕立刻站队。
- 镜头 3：八万账单展开，玩家先读消费行，再选择追问时间线或感情动机。
- 玩家动作：在两个同等视觉权重的问题中选一问；核心问题均从已见行派生。
- 误判拍：真实的断缴和催款支持“他用恋爱转嫁消费债”。
- 退出钩子：可见消费不足三万，来电人说“剩下那五万多，他从来没提过”。

### 幕 04：轻轻挂断（1 分 40 秒）

- 场景：直播间仍亮，来电人已离线。
- 出场：主播、弹幕、赵律师语音。
- 镜头 1：电话不是摔断，只剩线路空音；弹幕仍在刷“别转”。
- 镜头 2：主播准备给结论，赵的语音条覆盖在发送键旁：“你想说不该转，还是你怕她转了以后怪你没拦？”
- 镜头 3：主播没有回复，先关闭弹幕声音。
- 玩家动作：选择保存哪两份原始材料，决定次日能带给周会计什么。
- 场景转向：第一次明确区分“替她决定”与“提供判断条件”。

### 幕 05：周会计的档案室（3 分 20 秒）

- 场景：第二天下午，旧厂区财务档案室。
- 出场：主播、周会计。
- 镜头 1：从暖暗直播间切到过曝白炽灯；弹幕、耐心和 ON AIR 全部消失。
- 镜头 2：主播递手机摘要，周会计不接：“摘要谁写的？原表呢。”形成 NPC 拒绝。
- 镜头 3：横向铺满的银行流水占据主画面，铁柜与点阵打印机退到背景。
- 玩家动作：从十二行中圈两行，再做一次双行交叉。选错不公布正确答案，只得到周的局限评价。
- 正确发现：工资停止；王姓转账两次；五万信贷进账；49,800 转至 3301。
- NPC 偏差：当主播提起“怕被离开”，周只回：“这句不在流水里。”
- 退出钩子：她把打印页折回去：“晚上别问他爱不爱，先问这五万经过谁的手。”

### 幕 06：第二夜回拨（3 分 40 秒）

- 场景：同一直播间，画面比第一夜更近。
- 出场：主播、来电人、弹幕。
- 镜头 1：玩家从白天圈出的材料中选一块作为第一问。
- 镜头 2：来电人按路线修正证言，承认设备与体面也有自己的份。
- 镜头 3：她问“主播，我该不该垫？”三个回答不判对错，分别体现替答、继续核对、交还决定。
- 玩家动作：选择回应，再完成“确认 / 被修剪 / 未知”三栏归位。
- 收束台词：主播：“八万不是你的债，这句今晚能说。要不要继续这段关系，不归我。钱要不要转，至少等 3301 和那五万说清楚。”
- 场景转向：主播第一次尝试既给边界又不给人生判决。

### 幕 07：赵的第一通私聊（1 分钟）

- 场景：收播后的控制室，屏幕只剩波形。
- 出场：主播、赵律师。
- 镜头 1：赵主动拨来，不问案情结论，先问：“你刚才最后一句，哪半句是说给她，哪半句是说给以前的自己？”
- 镜头 2：玩家选择沉默、承认或岔开；只改变后续两人的语气。
- 退出钩子：下一通热线灯直接亮起，没有完整休息。

### 幕 08：第二通来电，自己人（3 分 30 秒）

- 场景：直播间，背景带理发店玻璃反光的心象层。
- 出场：主播、理发店案来电人、弹幕。
- 镜头 1：先听“下班陪你聊”的语音，吹风机持续作响。
- 镜头 2：来电人说插号、免单、“嫂子”和“老板娘”；弹幕开始把亲密理解为唯一性。
- 镜头 3：发错的表出现，“下一次推进”列被裁在屏幕边缘，玩家必须主动横向展开。
- 玩家动作：选择先听语音背景、看标准表还是追问关系是否说死。不同顺序影响来电人的防备。
- 退出钩子：来电人说：“话术这行都教，表也都有。可我朋友没见过最后那一列。”

### 幕 09：打烊后的婚介店（2 分 40 秒）

- 场景：第二天下午，小林老师的婚介门店。
- 出场：主播、小林老师。
- 镜头 1：半亮招牌，白板上“稳定、顾家、有上进心”被擦过多次。
- 镜头 2：小林先护行：“记偏好不是骗，熟客连水温都得记。”她拒绝把人直接定性。
- 镜头 3：标准维护表与理发店私表并排，玩家拖动两列做差异比较。
- 玩家动作：圈出“下一次推进”，再回答来电人从关系中实际得到过什么。
- NPC 偏差：小林把“老板娘”解释得太像行业行话，玩家可以质疑她在替同行找台阶。
- 退出钩子：她把标准表收回：“表能看出他想推什么，看不出他有没有喜欢过谁。”

### 幕 10：第二案回拨（3 分 20 秒）

- 场景：直播间，人物立绘从受伤转为防备。
- 出场：主播、来电人、弹幕。
- 镜头 1：玩家用标准表或私加列开场。
- 镜头 2：来电人承认自己享受过折扣、插号与朋友羡慕。
- 镜头 3：最终原话并列：“我从来没说只有你一个”与“以后店开起来，你就是老板娘”。
- 玩家动作：从两句之间选择追问“关系边界”或“利益推进”，形成不同但都成立的余味。
- 今晚未知：对方是否有真实好感。
- 收束：关系不明确是真的，利用不明确继续获客也是真的。

### 幕 11：赵的第二次打断（1 分钟）

- 场景：控制室，老方的数据曲线首次明显上涨。
- 出场：主播、赵律师、老方短信。
- 镜头 1：老方发“这案能剪，标题就叫海王理发师”。
- 镜头 2：赵主动发来一句：“你刚才没跟着叫海王，做得对。可别因为怕叫错，就假装没人受伤。”
- 场景转向：克制与行动的矛盾再次加深。

### 幕 12：第三通来电，好条件（3 分 30 秒）

- 场景：直播间，资料截图层层叠入。
- 出场：主播、资料案来电人、弹幕。
- 镜头 1：MBA 项目页先出现，校名真实，给假解提供支撑。
- 镜头 2：当日存款证明和单月收入截图出现，玩家必须判断每张图能证明什么。
- 镜头 3：介绍人的两套说法只露一套，另一套在白天路径中获得。
- 玩家动作：先锁学历口径、收入持续性或介绍链。选择决定白天可去的求助点。
- 退出钩子：来电人第一次承认：“流水不是我妈非要看，是我先问的。”

### 幕 13：白天二选一（3 分 20 秒）

- 场景 A：周会计档案室；场景 B：小林老师门店。
- 出场：主播、被选择的 NPC。
- 周路线镜头：把存款证明、单月收入、公司抬头放在时间轴上；玩家发现真实余额不等于持续收入。
- 小林路线镜头：翻介绍人的双向话术卡；玩家发现两家都收到更好听的版本。
- 玩家动作：只能去一处。另一条信息不会随后自动补发，形成真实信息态差异。
- 代价：周路线缺失介绍人利益链；小林路线缺失资金持续性。
- 退出钩子：未选择的 NPC 在最终案才会带着自己的盲区重新出现。

### 幕 14：第三案回拨（3 分 20 秒）

- 场景：直播间，来电人的资料不再居中，双方原话居中。
- 出场：主播、来电人、弹幕。
- 镜头 1：玩家以白天获得的框架发问。
- 镜头 2：男方“工资卡也要交出来？”与女方母亲“结婚以后钱最好一起管”相互咬住。
- 镜头 3：来电人承认自己并非只验真假，也在试婚后收入是否进入小家。
- 玩家动作：完成一项材料归位，但系统明确保留未走路线的信息缺口。
- 反转：两边都在销售适婚身份，材料真假只是入口。

### 幕 15：赵与主播争执（1 分 30 秒）

- 场景：主播走到直播间外的楼梯间，第一次离开控台与赵通话。
- 出场：主播、赵律师。
- 镜头 1：画面不再有 UI 框，只剩应急灯与楼梯扶手。
- 镜头 2：赵问：“今晚你说了三次‘会计说’和‘小林说’。你自己听见什么了？”
- 镜头 3：主播反击：“我自己说，错了算谁的？”赵答：“本来就算你的。主持不是免责条款。”
- 玩家动作：选择承认害怕或坚持专业距离。两条都进入终案，但赵的入场语气不同。
- 场景转向：主角的旧伤从背景变成公开冲突。

### 幕 16：第四通热线抢入（1 分钟）

- 场景：楼梯间通话被控台警报打断。
- 出场：主播、来电人预录、老方短信。
- 镜头 1：热线自动转入紧急队列，来电人说“下周一季度复盘，主责要写死了”。
- 镜头 2：老方短信：“这通有公司名吗？数据起来了。”
- 玩家动作：回控台接线。没有“继续”过渡，制造终案紧迫感。

### 幕 17：第四案上半场，审批通过（4 分钟）

- 场景：直播间，办公审批流背景。
- 出场：主播、职场案来电人、弹幕。
- 镜头 1：来电人先承认自己主动争取主责，打破前三案“后半才认利益”的固定模式。
- 镜头 2：群公告与私聊并排：公开要求报备，私聊要求“先扛下来”。
- 镜头 3：审批截图出现，付款状态和账户在裁边之外。
- 玩家动作：在时间线、截图边界和主责话术中选一个先追。选择会召来对应 NPC 的第一反应。
- 误导答案：财务延后是真的，看似能覆盖整个拖款问题。
- 退出钩子：供应商记录写着“按老规矩返给对接人”。

### 幕 18：三位 NPC 汇合（3 分钟）

- 场景：直播后台多窗口，不让 NPC 与来电人直接辩论。
- 出场：赵律师在控制室门口；周会计远程共享；小林老师主动发来语音。
- 镜头 1：赵把公司名遮掉：“没证据证明谁拿了钱，不能播名字。”
- 镜头 2：周把共享光标停在付款账户：“审批不是到账。先问账户。”
- 镜头 3：小林的语音插入：“老板娘、投资你、一家人、主责。词不一样，都是先让人站到一个位置上。”
- 玩家动作：选择先采纳谁的框架。另两人不会消失，而是在下一幕成为需要补齐的反证。
- 冲突：赵要收窄，周要追钱，小林要拆身份。三人第一次公开不一致。
- 场景转向：NPC 从答案来源变成互相制约的角色网。

### 幕 19：终局材料台（3 分 20 秒）

- 场景：全屏材料台，三个证据区分别对应边界、钱路、身份。
- 出场：主播、三位 NPC 的短反馈、来电人声音。
- 镜头 1：预算群公告与私聊，证明公开流程被绕开。
- 镜头 2：审批状态、付款账户、供应商返款并排，证明结果责任与钱路分离。
- 镜头 3：季度复盘“执行主责记陈”，与“对接人仍为同事”交叉。
- 玩家动作：先前选择只决定起始区，玩家必须至少完成两个区才能收麦；第三个区可留成终局盲点并反映在结尾。
- NPC 反应规则：三人只评价自己领域的效力，不告诉玩家下一处圈哪里。
- 反转：主责不是单纯奖励，而是成本转移的接口。

### 幕 20：主播的道德选择（3 分钟）

- 场景：直播间，弹幕速度达到整晚最高。
- 出场：主播、来电人、三位 NPC、老方短信。
- 镜头 1：老方要求点名，赵要求守边界，周要求先留书面，林要求把身份诱饵说破。
- 镜头 2：玩家选择节目最后的主持策略：爽点点名、谨慎闭麦、边界内行动。前两条不是死亡选项，但会给出不同后果。
- 镜头 3：成熟路线中，主播按顺序说四句话：审批不等于到账；主责不等于付款入口；绕开报备是她承担的风险；返款路径必须在复盘前书面提出。
- 关键台词：“我不替你决定这份复盘交不交。但这四件事不写进去，交上去的就不只是复盘，是别人替你写好的责任。”
- 自我揭示不直说。主播没有使用惯常的“今晚定不了”结束语，赵在门口听见了。

### 幕 21：整晚收麦（1 分 30 秒）

- 场景：控制台总结，不做评分表。
- 出场：主播、三位 NPC 的余波消息、评论墙。
- 镜头 1：四个物件并排：账单、推进表、资料图、审批截图。
- 镜头 2：四个身份词逐个浮现：投资你、老板娘、一家人、主责；最后只留下各自后面的当下要求。
- 镜头 3：三位 NPC 各留一句不完整评价。赵：“边界守住了。”周：“还有一笔没到账。”林：“词听明白了，人还得继续看。”
- 玩家结果：根据白天求助与终案选择，生成“你如何使用帮助”，不显示正确率。

### 幕 22：摘下耳机（2 分钟）

- 场景：直播间熄灯、清晨街道、家中。
- 出场：主播、赵律师。
- 镜头 1：ON AIR 灯灭。主播摘下耳机，这次没有立即查看数据。
- 镜头 2：老方发来“明天聊改版”。没有胜负结论，节目只暂时活过今晚。
- 镜头 3：回家，赵靠在沙发上睡着，桌上放着那张旧案剪辑账单。主播没有翻旧案，而是把今晚四案的空白便签放在旁边。
- 镜头 4：赵醒了一下：“还开吗？”主播：“开。明晚少替人说一句，多把该摆的摆全。”
- 最后一帧：天亮，手机热线指示灯由灰转亮；字幕“热线每晚都开”。

## 五、制作边界

1. 三位 NPC 不是三个提示按钮。每次出场必须有自己的欲望、拒绝或偏差。
2. 白天切场景时必须整体替换背景、HUD、声音和交互。直播控台元素全部退出，才能让场景切换成立。
3. 每次求助至少改变第二夜的开场问法、可见材料或来电人防备，不能只奖励一段说明文本。
4. 最终案三位 NPC 可以同时出现在后台，但来电人仍是唯一直播连线者，避免变成多人辩论节目。
5. 一小时体量依靠动作种类和场景变化，不靠把每段台词写长。单次对话气泡原则上不超过 90 个汉字。
6. 第一案周会计拒绝、第二案小林老师的行业偏见、终案三人冲突，分别完成 NPC 的“拒绝、偏见、抉择冲突”三种戏剧动作。
7. 四案的最终未知必须保留，NPC 不得以专业身份替代证据闭合未知。
