# 评论区快案：快速侦探模式

## 目标

把“直播间侦探”从剧情主题变成一个十分钟内可以完整体验的动作：听原话、圈疑点、找对照、问回来电人。主播可以漏掉线索，评论区可以群策群力，但任何人都不能凭空得到麦外事实。

## 第一关：《什么都不图》

一位二十四岁的来电人请林旭阳介绍对象。她把条件放到月薪四五千、没房、大十岁都行，却在主播给出符合条件的普通对象时拒绝，只问节目里做生意、家境稳定的男性。玩家只能圈三句话，关卡共有四组成立的破绽，因此至少一组要由评论区继续翻回放补出。

有效破绽不是“她听起来可疑”，而是两句原话改变了彼此的含义：

- 跟着腰不好、家里条件一般的亲生父亲长大，与另一个给她一百万元、同样被叫作“爸爸”的年长男性。
- 主动把话题从钱源带到生育，承认自然怀孕机会较低，又准备等感情稳定再告诉对象。
- 口头接受月薪四五千、没房的男性，实际拒绝符合条件的人，只要求主播介绍条件较好的对象。
- 自称不会撒娇、不会哄人，受压和求介绍时却熟练地叫“哥”、说软话，还承认见面后知道怎样哄人。

能接受十岁年龄差，以及她所说的父母离婚原因，是两个诱饵。前者本身不与其他话冲突；后者只有女儿一方的回忆。圈中后只解释证据为什么不够，不扣成“愚蠢选项”。

结果页不按法庭定案的门槛处理这通电话。四组矛盾都指向同一件事：她先用“什么都不图”进入节目筛过的优质男性范围，再借主播信誉拿到见面机会，重要的钱源和婚育信息准备以后再说。这已经足够让林旭阳拒绝介绍。

评论区还会把更危险的可能性说出来：给钱的年长男性可能并非普通长辈，她也可能在寻找一个能摆到台面上的结婚对象，甚至借此遮住另一段关系。主播不需要等到包养、骗婚或已有伴侣被实锤以后才避雷。未知栏仍保留准确身份、医学原因和现有关系，只用于防止把猜测写成经历事实，不能把风险判断冲淡成五五开。

## 玩家流程

1. 从标题页进入“评论区快案”，不覆盖四幕主线进度。
2. 每页只听一组问题和回答，同时看到不下结论的即时评论。
3. 听完以后回看六句候选原话，最多圈三句。
4. 每次圈句先显示评论如何找对照，再由林旭阳问回当事人。
5. 三次用完，评论区补齐尚未被发现的破绽。
6. 结果页分别列出玩家找到、评论补到、为什么已经足够拒绝，以及哪些背景虽然没查清却不影响避雷。

## 内容与版权边界

本模式受用户提供的公开视频启发，只吸收“观众反复比较同一来电人的公开陈述”这一互动结构。第一关人物、职业、金额、家庭情况、台词、矛盾和结论均为原创虚构，不复刻参考视频中的个人经历或原话。
