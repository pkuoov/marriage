# 直播快案：主播对质模式

## 目标

把一通有所隐瞒的咨询压缩成十几分钟的完整小故事：玩家先整段听完来电人的说法，再把同一段逐句拉回。按住可疑原句以后，林旭阳会把它问成完整的人话；来电人的否认或改口再带出下一段。快案不设置评分、弹幕补线或评论区裁判，冲突只发生在主播和来电人之间。

快案的耐心按陈述段计算。左右浏览和反复听原话不扣耐心，只有确认了一句完全没有可追问线索的话才扣一格；未耗尽时只在原句下显示「耐心 −1」并缩短状态条，不追加弹幕、听众评价或答案讲解。耗尽后才出现直播间开始失去耐心的反馈，并从本段重听；进入下一段时使用新的耐心条。界面不显示数字页码或答对数量。

## 第一关：《什么都不图》

林旭阳直播之外也替登记过的单身听众做少量同城介绍。一位二十四岁的服装销售因此请他介绍对象。她先用工作、收入、名下小两居和父亲的经历证明自己能独立生活，随后把条件放到月薪四五千、没房、年龄大她五岁以内。主播给出符合条件的普通对象时，她不直接拒绝，而是用“不够了解”挡一下，再把安全标准加到主播熟悉、自己经商、家里稳定的男性。

原始连线共十一组对话，分两轮披露。第一轮六组：问候和来意以后，她用一段话介绍工作、旧关系与择偶倾向，再用一段完整家庭经历解释为什么看重患难相守；主播只从她当前住处追到房款来源，不再分别登记年龄、收入、父亲近况和男方房产要求。第一轮只开放钱款来源与异常生育举例两个方向。第二轮五组：她先一次说完口头低条件、结婚节奏和求介绍的原因，主播再用一个符合条件的普通对象检验，随后才追到经商偏好、房贷和背书诉求；本轮只开放实际筛选标准与分手原因两个方向。未来轮次的问题不会提前显示：

- 亲生父亲只能偶尔帮人看店，给她一百万元买房的“爸爸”究竟是不是同一个人。她先坚持“我一直叫他爸爸”，被主播逼着只回答是否亲生以后才承认不是，再用隐私和自愿赠与挡住真实关系。
- 她在讲相互扶持时偏偏拿自己不能生孩子举例；首轮主播不追。玩家选中这个疑点以后，她先反驳，主播短追一句，她才承认做过检查。
- 她口头接受月薪四五千、没有房的对象，也说不会让男方养她；实际又避开符合标准的普通上班族，指定主播熟悉的经商男性，还希望对方减轻总价两百万元房子的贷款压力。
- 她把一段关系散掉归因于不会讲好听话，求主播背书时却立刻恭维、改称呼并让他先替自己说好话；玩家追问的是这究竟是不是分手的根本原因。

每次对质只处理一处矛盾。来电人不完成自我审判：她先淡化、强调隐私，再替自己的双重标准找理由，最后因主播拒绝背书而不耐烦。反差来自她在普通问话里说得从容、被逐项问回时却不断改换理由。

林旭阳拒绝介绍并挂断以后，还要完成两段口头复盘。第一段把两个“爸爸”、口头低条件与实际筛选、不能生育例子的下意识泄露、临场软话重新放在一起。第二段只落行动判断：她没有说清一百万元是谁给的，也没有把自己真正接受的对象条件先说全，却要借主播信誉接触条件更好的对象。主播因此拒绝介绍和背书；出资人身份、双方关系、检查的医学含义和她是否另有伴侣仍然未知，不能由称呼和给款替她补一段人生故事。

## 第二关：《那晚没回消息》

一位二十六岁的985高校在读硕士来问：自己通过婚恋机构认识了一位三十五岁的创业者，两个人相处一个月后，男方突然停止联系。介绍男方时，她先强调家里能支持自己、不是指望对方养，随后又报出男方至少中A8、本地两套平层，自己家为A7；这些资产分档只是她的自述，却让“条件合适”在开场就有了具体含义。她把问题先说成两个人缺少深度交流，又说真正的起点只是自己喝多以后漏回一条消息，想知道是不是男方把这件事看得太重。

这通电话共十三组对话，分三轮。第一轮六组，不再按年龄、学历、双方资产、认识渠道、关系进度逐项填表：她先用一段话说清两个人的基本情况，再完整讲一遍“他会照顾我，却听不懂我”的相处版本，最后自己讲出妹妹小聚和两条消息时间。她说明朋友圈现在三天可见，主播从外面看不到旧内容，再由她自己翻出花那条及前几条并截屏发来。包只作为照片里的新物件，等玩家选中展示需求以后才由主播问出；“还行”时是否已经醉，也留到玩家选中消息状态以后再问。第二轮两组：她用对质后的口径重新讲当晚，主动说到已经发晕、混酒、有人又点了一轮；主播只问这个“有人”是谁，她先含糊成妹妹的朋友，玩家对质后才承认是男性。第三轮五组：她主动再发近两个月的旧动态截图，先用生日和毕业聚会解释六次夜场；主播再短问男方如何发现第三个人、十号照片拍于哪天，以及八号是否也外出。继续对质后，她才承认读研以后聚会一直不少，同行的男男女女也不是固定一拨，其中两三次玩到天亮。事实按“陈述、短问、改口、再问、揭示”逐层出现，而不是听取阶段先预审一遍、玩家再复问：

- 她说自己只想要深度交流，最具体的相处事实却包括主动让男方送花、收下男方送的包，并把花、包和男方的车拍进公开动态。她发来的截图里，朋友点赞、说羡慕，她回复得很开心；前几条也多是漂亮饭和演唱会。主播可以据此判断她同样在意男方的物质条件，以及自己的生活如何被别人看见。
- 她把冲突说成没有看到一条消息。记录显示十一点五十二分她还回了“还行”，六分钟后不再回复；她后来承认，当时已经喝到难受，只是不想让男方知道自己喝多。
- 她先说跟妹妹小聚，谈到酒量时才补出桌上还有妹妹的一名男性朋友。男性在场不能自动证明越界；真正改变判断的是，她为何把三人混酒到断片缩成姐妹俩喝一点。
- 她第二天对男方也先只说妹妹送自己回去。解释时说漏一个“他”，男方问这个“他”是谁，她才把第三个人补上。
- 婚介跟男方说她生活简单，她也说自己很久没出去；后来才承认八号与师姐去 KTV，九号又去酒吧，连续两晚外出。近两个月的截图出现六次夜场，继续问，她又承认读研以后聚会一直不少，同行有不同圈子的男女，其中两三次玩到天亮。她到这时仍把长期状态说成普通聚会。
- 她说十号醒来后一直认真解释和道歉，同一天却仍公开发出八号 KTV 的照片。动态只显示十号发出，男方并不知道照片拍于八号；她刚解释完九号为什么喝断片，转头又发喝酒照片，道歉自然显得乏力。

每轮只显示当时已有依据的方向；年龄差和创业者是否太忙可以暂时存疑，但不再拿“去酒吧本身是否错误”充当一个选项。第三轮的新增方向改为追问男方如何发现第三个人。最大反转仍落在“姐妹俩小聚”被追问出第三个人：主播先问，对方先含糊成“妹妹的朋友”，再被逼着承认是男性；承认出现后才播放一次重击过场，不能在问题刚选中时提前给答案。她肩臂上的大片纹身属于男方初见时已经知道的人物背景，不做玩家质证，也不能单独证明她的生活方式。

结案不靠猜测酒局中是否发生了其他事。主播可以直接判断：男方不是只因为六分钟没回复而退出，而是在连续两晚饮酒、第三人同行、醉酒程度、道歉当天的动态和她分层补充事实的过程中，重新判断两个人是否适合长期关系。她打来想让主播把问题归成男方不理解她，再教她把人追回来；主播拒绝这套说法，也明确男方退出有理由。出轨、把谁当备选或存在供养关系都没有被证明。

## 第三关：《帮我说一句》

一位三十出头的科技创业者打进电话，开口就要林旭阳今晚对着直播间说：对方那句不为钱出卖爱情是假的。入口只交代表面求助，不剧透金额、虚构标注或生育方案。

连线共十一组对话，分三轮。第一轮六组：他先把长文说成故事，文末标了虚构，正文却写了名字、配了照片；同段里他说喜欢她，又说见面她往后躲；谈婚期间三千万打到家里账，一天限额一百万就改成五张卡齐打；最后一笔开口要五千万美元，他说让我想想，对方挂了。本轮开放虚构标签、家里账与五张卡，以及“让我想想之后有没有打出”。第二轮两组：对方回了过去、现在、往后都不会为钱出卖爱情，一句转账数目都没对上；工作室说对碰瓷说不、交给法院，他自己已经起诉，还要直播间先说清楚。第三轮三组：长文里的名字、照片、三千万跟起诉状上的数对得上；生育方案由他自己划出证据边界，不能当今晚的证据。

最大反转落在“标了虚构却点了名”：来电人承认名字、照片都是真的以后，才播放一次重击过场。结案拒绝替他当第二锤，但两边都钉：她催卡、抬价、见面往后躲，公开还谈爱情，高概率是厌这个人、要钱；他用虚构点名和未打出的更大一笔，要节目在判决前砸人。法律上是否彩礼、更大一笔是否发生、生育方案含义和判决结果仍未知。

## 玩家流程

1. 从标题页进入“直播快案”，先看到案件选择页，不覆盖四幕主线进度。
2. 每宗快案只显示稳定的两位案件编号、标题与完成状态；已完成案件保留对勾，也可以重玩。预计时长不放在玩家界面。
3. 每宗按二至三轮推进。每轮先用全屏大字提示「来电人陈述」，把当前版本作为一段完整陈述播放；玩家主动拉回以后，再用全屏大字提示「逐句追问」，才把同一段拆成逐句记录。两张阶段提示只区分节奏，不解释玩法；普通听麦没有实时评论。
4. 玩家可以直接按住任何一句原话。完全没有可追问线索的句子会消耗当前陈述的一格耐心，只在原句下标“这句没有可追问的线索 · 耐心 −1”，不追加解释，也不替玩家排除答案；左右浏览和重听不扣耐心。直播间反应只在耐心耗尽后出现。
5. 每按中一处成立原句，林旭阳用编剧写好的完整问句当面打断，来电人否认、改口或作最小承认；本轮问完后，新的说法自然带出下一段听麦。
6. 最后一轮所有成立方向问完以后，由主播按本案求助作出决定，来电人作最后反应，通话结束。
7. 挂断后继续留在主播视角：先复盘已经成立的矛盾，再说出有完整推导链的高概率故事版本，最后说明哪些部分仍不能实锤。只有最后一页的最后一句显示后，案件选择页才打上完成对勾。

## 舞台呈现

- 整通快案固定在同一间直播间。林旭阳在左，当前来电人在右，背景不变；每宗快案使用自己的匿名像素立绘，不能串角。
- 首次听麦使用宽气泡整段显示，来电人提亮、主播压暗；回放时中央改为逐句记录条，控台 `REC` 亮；打断后恢复窄气泡逐拍攻防，控台 `LINE` 亮。三种表面不依赖页眉也能分辨。
- 舞台层只显示人物姓名与当前状态。不得显示“第 X/Y 屏”“对质 X/Y”“本轮 X/Y”或完成比例；玩家通过来电人的改口和新陈述感受推进。已经问清的原句可做完成标记，但不能标“正确答案”。
- 案件入口遵守观众可知边界：只写“有人来电”和她表面上的求助，不用简介替玩家概括学历、职业、相识渠道、消费、失联导火索或自我归因。所有具体案情从接通后的第一句开始披露。
- 来电人立绘是玩家侧的戏剧化想象，不代表节目获得了摄像头画面；主播和证据系统不得从她的表情、衣着或背景推断事实。

## 内容与版权边界

本模式受用户提供的公开视频启发，使用“把同一来电人的公开陈述前后对照”这一互动结构。第一关的人物、金额、家庭经历、台词和结论均为原创虚构。第二关依据 `BV1iGKG65EJ3` 重新核对原视频的公开因果骨架，保留主动要花、收到男方送的包并发动态，连续两晚 KTV 与酒吧、男性同行者、混酒到断片、六分钟消息差和道歉当天再发旧照等承重节点；人物姓名、具体年龄、婚恋机构、聊天措辞、对质台词和舞台结论均重新创作，不复刻原句，也不把异性在场单独写成越界证据。第三关以公开讨论中常见的点名长文、文末虚构标注与大额婚恋转账争议为结构参考，保留虚构标签与点名配图并置、家里账与赶限额打法、见面往后躲、未打出的更大一笔、公开回复不对账、直播与诉讼双轨等承重节点；真名、可检索标题、原事件地标、性描写和生育操作细节均不进入成稿。结案可以判断她厌人要钱、他借节目砸人，但不把彩礼法律定性或未发生的账写成已证事实。

## 数据与代码

- 内容真源：`content/packs/steam-demo-01/quick-cases/*.json`
- 角色真源：`content/characters/cast.json`
- 纯状态机：`src/runtime/quickDetectiveModel.js`
- 纯界面模块：`src/ui/quickDetectiveView.js`
- 内容入口：`content/packs/steam-demo-01/manifest.json` 的 `quickCases`

案件选择顺序只读取 manifest 的 `quickCases`，不在界面里另写一份列表。每个快案必须提供唯一 `id` 和两位数字 `caseNumber`；编号属于内容身份，不随列表位置临时重排。完成记录独立保存在玩家存档中，重开主线或返回标题页都不会清除。

新增快案至少需要三项 `confrontations`，并用 `disclosureRounds` 分成二至三轮。每轮登记 `turnIds`、`issueOptionIds`、`requiredConfrontationIds` 和正整数 `patience`；未来事实不能提前出现。每项 `issueOptions` 必须用 `sourceAnchor` 逐字绑定本轮来电人陈述中的一句原话，`label` 只供编辑检索，不在回放界面替代原句。每项对质必须有唯一 `id`，并用 `basisTurnIds` 指向当前已经出现的原始话轮。若新事实由对质逼出，应写进 `answerAdds`，并只供后续轮次使用。反驳不限定一问一答：需要否认、追问、改口或再次反驳时使用逐句 `lines`，按实际攻防交替排列。每宗只能有一项 `revealTransition`，必须落在重新解释整案的最大反转上；若答案来自来电人的承认，用 `lineIndex` 把动画放在承认之后。当前段的必要对质完成后，流程必须直接接入下一段听麦；恢复存档时若检测到当前段已经问清，也要自动续播。`summaryPages` 至少分为结束通话、矛盾复盘和高概率判断三段；`confirmed / unknown` 继续约束结案边界，但不上屏替主播说话。
