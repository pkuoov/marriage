# 铺开阶段补充约束（老方干讽 + 加压护栏）

给 `docs/host-voice-rewrite-prompt.md` 的 Phase C（案2-4 铺开）与其配套 `panic-instability-and-siren-prompt.md`。案1竖切经真人评估通过，铺开前补两件:①补上唯一没兑现的签名拍——主播对老方的干讽（全局一次）;②把"加压必须挣来、必须收回暖"写成每案硬清单。

## Part 1|老方干讽（全局一次，兑现"不上进赚钱"人设）

**问题**:序幕有老方通牒，主播从头到尾没接一句，"不是很上进赚钱"这半个人设在台词里看不见。

**位置**:`content/packs/steam-demo-01/manifest.json` → `nightShell.prologue.lines`。现结构:
- [0] 林旭阳 自我介绍
- [1] 运营·老方 通牒「深夜档这个月再不达标，就并进娱乐区。改版方案，下周一前给我。」
- [2] 旁白 推门 …

**在 [1] 之后、[2] 之前新增一条主播私下反应**（此刻还没开播，是他扣下消息的干讽，不是口播）。逐字默认:

```
方案下周一再说。老方这催了小半年了，节目也没黄。
```

要点与边界:
- 只兑现**不上进/不焦虑/懒得迎合**这一层（他听过太多遍、不为数据慌）。**"有正义感"不在这句里硬塞**——那由他整晚不做爽点判决的行为兑现，这句塞进"我偏不教人站队"会变成使命宣言、说教、AI 味。保持干、短、扔一句就走。
- 走同一套去 AI 味风趣约束:不对仗、不漂亮收尾、不抖机灵;念着像个不太在乎数据的人随口嘟囔。若默认句读着仍像宣言/编剧腔，按真人再调，报我。
- **不动 [0]/[1]/[2] 原文**;**不动序幕后面被 smoke pin 的开播句「开播了哈，今天继续连麦。」**（用 assertVisibleText 文本匹配，新增一行不移动 pin，但那句本身一字不能改）。
- 新增行 role/speaker 用「林旭阳」（verify-pack 要求主播行署名林旭阳，不许裸"你"）。
- 序幕一次性,不是每案重复;补这一条即全局生效。

改完 `npm run content:script && npm run check && npm run smoke:browser` 绿。

## Part 2|加压护栏（案2-4 每案硬清单）

案1的加压落在公平那侧,是因为**挣来的**（她正在粉饰处露馅）且**每次收回暖**。铺开时这条最容易滑成"对着难受的人穷追"。每案兑现步步紧逼/抓破绽时，逐条自查:

1. **挣来的**:主播的加压只许开火在来电人**正在粉饰/前后不一/闪躲**的那一处（她藏"自己也有份"的地方）。不许对她的**脆弱、痛处、无助的坦白**加压。判据:被追的那句，是不是她的 spin？不是,就不许凶。
2. **逼逻辑不逼人**:咬的是矛盾本身（"刚说 X 现在 Y，哪个"），不是她这个人、她的处境、她的选择对不对。守阳谋不阴谋。
3. **必收回暖**:每一段加压**必须**以一拍回暖收（撬开→她认/她崩一下→主播软下来给台阶,接 host 设计"钉完回暖"）。**没有回暖的加压不许留**——那就是刻薄。
4. **不在开场凶**:开场接线仍是风趣默认档、先接住;加压只在矛盾露头之后。
5. **急压中的加压要有"护"的动机**:像案1（对方实时监视、她正要被操控着转钱，主播切断混淆是护她别上当），案2-4 的加压也应让人读出"我逼你想清楚是为你好"，不是"我要赢你"。

配额提醒（与两份母单一致，勿降）:每案 默认风趣≥4 / 专业步步紧逼≥4 / 收笑变脸≥1 / 回暖≥1;慌乱失稳≥1段（含跳档）+ 被主播抓到的露馅≥1;夜班弧按案次递进（案2带火气→案4疲累破功→尾声软）。

## 验收（并入 host Phase C 验收）

1. 真人朗读案2-4 逐案确认:①加压都挣来了、都收了回暖、没有一处滑成欺负难受的人;②序幕老方干讽读着像随口嘟囔、不像宣言。
2. 全量校验 + smoke + CI 绿;`git diff -- content/` 不含真相/路线轴/文档行改动。
3. 老方干讽一处、案2/3/4 各一提交。
4. 不确定处停下报告,不自行扩大范围。
