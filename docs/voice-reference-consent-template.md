## 使用范围

参考说话人确认：

1. 本人自愿提供该段录音，并有权授权其用于本项目的语音制作测试。
2. 项目方可以把录音输入语音合成或声音转换工具，生成该角色的内部试听候选。
3. 当前授权范围仅为内部评估、剪辑比较和质量检查，不包含公开传播、宣传展示或商业发行。
4. 未经另行书面授权，生成候选不得作为游戏正式配音，不得用于训练面向其他项目或角色的通用模型，也不得提供给无关第三方。
5. 项目方会把原始录音、逐字稿和生成候选保存在受控制作目录，不提交公共代码仓库。
6. 参考说话人可以通过合同约定的联系人提出停止后续生成或删除尚未发行的内部候选；已经依法归档的合同和审计记录按约定保存。

## 录音核对

- [ ] 录音内容与 `reference.txt` 逐字一致。

- [ ] 说话人已知道使用了语音合成/声音转换技术。
- [ ] 项目方已说明当前使用的模型权重只允许非商用内部评估。
