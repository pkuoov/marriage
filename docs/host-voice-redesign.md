# 主播声音重设计（治"一本正经"，把活人味从外挂变成本性）

日期：2026-08-04
性质：角色设计文档（修正 `docs/host-character-design.md` 的"中性容器"误读，据此立"主播人味法条"入 `project-skills/case-scriptwriting/SKILL.md`，并驱动一次主播台词重写）。
判决来源：用户诊断——主播太一本正经、没活人味，现有的活人感全是手工外填；根在设定。

## 一句话定档

**林旭阳：一个不太上进赚钱、有正义感、有专业知识（前法务）、人缘好的人。平时风趣调侃，但一碰到真相就不马虎，甚至步步紧逼。**

活人味的引擎不是某几拍外挂，是**两个寄存器之间的切换**：默认是"松、暖、爱损两句"的风趣人，一旦案子露出破绽就"啪"地切成"精准、咬住不放"的专业人；把真相钉死之后再软下来。切换本身就是他的签名，缝隙里源源不断漏出活人味。

## 修正容器误读：他是杰洛特，不是白人偶

旧设定用"玩家即主播"的容器模型，把主播台词推成了中性无个性——这是对杰洛特的误读。杰洛特个性极强（毒舌、疲、满腹牢骚），玩家只 steer 他的**抉择**，不 steer 他的**声音**。据此定死：

- **主播有写死的强声音**（风趣 + 步步紧逼），像杰洛特的牢骚一样是作者给的，不靠玩家选。
- **玩家继续 steer 调查立场**（路线轴：先信人／先拆图／先追钱／先反问）——决定他追哪条真相线，不决定他这个人怎么说话。
- 对白框署名林旭阳，玩家此刻是他；但"他"是个有脾气有笑点的人，不是一面白墙。

## 双寄存器：怎么切、切在哪

### 默认寄存器·风趣人（松、暖、损、不端着）

出现在：开场接线、过场、弹幕互动、老方来消息、顾问插话、来电人跑题/生活噪声、白天走访的路上、小尾声。这里他：

- **爱损两句**，包括自损（拿自己不赚钱/节目半死不活开玩笑）。
- **对老方的生计压力是打趣着躲，不是焦虑**——他是真不太在乎数据，"不给爽点判决"不是苦大仇深的原则，是这人就这样、懒得迎合。这让他更可爱，也让老方线不说教。
- **人缘好落到台词上**：顾问愿意半夜帮他、来电人愿意对他掏心窝、弹幕护他，都因为他这人好相处、会把气氛托住。

### 专业寄存器·较真人（准、狠、步步紧逼）

出现在：矛盾露头、来电人闪躲、操控话术出现、文档/流水核对、关键追问、深问、结案。这里他：

- **不马虎**：一个含糊他就咬住不放，"这句你再说一遍""刚才你说的是 A，现在怎么成了 B"。
- **步步紧逼但阳谋不阴谋**：逼的是逻辑不是人，逼出真相不是逼人认罪；对脆弱的来电人，逼的是"别替他圆"，不是打压她。
- 前法务的专业底子在这儿变现：他知道哪句话在法律/事实上站不住，一层层剥。

### 切换即签名（两个招牌动作）

1. **收笑变脸**：正损着呢，破绽一露，笑一收，声音沉下去——这一下要写出来。
2. **钉完回暖**：真相钉死后，他从"狠"软回"暖"，给来电人一个台阶。爱憎分明的"憎"给套路，"爱"给人。

## 现有设定按新镜头重读（是重构不是重启，旧资产全存活）

- **旧伤 A（两年前冤案）**：仍解释"证据锁死才定罪"的纪律——但他不为此苦相，他是个爱开玩笑的人，只在"给人定罪"这一件事上突然不开玩笑。反差本身就是活人。
- **旧伤 B（自己借出没要回的钱）**：案1共鸣点，可以让他失态半句、自嘲一句，而不是庄严独白。
- **签名句式「X 归 X」**：保留，但它属于**专业寄存器**——是他较真时把搅在一起的事掰开的工具，不是他全程的腔调。默认寄存器不许句句 X 归 X。
- **阳谋不阴谋/计策系统**：不变。步步紧逼是在这套框架里的"准和狠"，不越隐私/公权/诱导的线。
- **赵律师（妻子）**：人缘好+风趣有了归属——小尾声里两口子的拌嘴可以更松、更好笑，照顾落在热水和汤上。

## 主播人味法条（补齐缺失的"活人机器"，入 SKILL.md）

来电人有的机器（语言噪声/voiceTics/纹理门控），主播一直没有。补上，且是主播专属版：

1. **寄存器配额律**：每案默认寄存器（风趣/暖/损）至少 N 拍、专业寄存器（步步紧逼）至少 N 拍，且**每案至少一次可见的"收笑变脸"切换**。全程一个腔调（要么全程端着、要么全程贫）都算没做到。
2. **风趣不污染事实层**：玩笑只在交付层（怎么说），不进承重层（判什么）。事实分拣、双源、留白结尾、不预判——一条不松。**对脆弱来电人不许损她本人**（可以损套路、损对方、自损）；玩笑永远站在来电人这边或指向操控者。
3. **步步紧逼律**：来电人/对方一含糊，主播至少追一次"把话说全"，不许放过含糊直接进下一题（这也是他"专业不马虎"的表现）。但逼逻辑不逼人，守阳谋。
4. **主播语言噪声**：不是每句都推进案子。允许主播累、跑题一下、损一句、自嘲、对弹幕翻个白眼——给他和来电人同等的"废话权"。金句配额律照旧（≤3/案），但腾出的空间填**人味**不是填**更短的提问**。
5. **夜班情绪弧（跨案写死）**：第一案精神、话多爱贫 → 中段被案子磨、火气上来一点 → 第四案疲、贫里带累、偶尔破功 → 尾声软。上一案的重量可以渗进下一案开场半句。不许四案都是同一个满血中性主播。
6. **克制是面具不是本性**：默认那个松、有偏见、爱损的人是"真的他"；克制/中立是他戴着的、偶尔滑落的职业面具。滑落的时刻（被案子带偏后认错、被啰嗦问烦了拉回来、对操控真动气）要写出来——活人认错、活人破功，比机器中立可爱。

## 方向示意（示意稿，非最终台词；最终台词走去 AI 味+公平+verify 全流程）

**案1开场——**
- 现状（平）：「八万不是随手帮个忙。你先别怪自己多想。你们在一起多久了，他当时是怎么开口的？」
- 方向（先风趣托住，再切专业）：先一句松的、把她的"是不是我太防着他"接住甚至带点自嘲的暖（默认寄存器），紧接着落到"他原话怎么说的"（专业寄存器起手）——同一段里能看见他从"陪你聊"切到"我要听原话"。

**老方来消息——**
- 现状：主播基本不回应或严肃对待。
- 方向：他打趣着躲（"数据不好看？那也得先把这通听完"这类，松、不焦虑），把"不上进"和"有正义感"一次说清。

**结案钉真相——**
- 现状已较锋利（truth 咬字狠），保留；但钉完后加一拍**回暖**，让"狠"有落点，别停在冷。

## 边界与不做

- 不改事实层公平机制、不改路线轴、不改计策铁律、不改案件真相与收窄阶梯。
- 风趣不许变成综艺插科打诨；他是**有正义感、专业不马虎**的人，贫是底色不是目的，一到真相就收。
- 不许拿脆弱来电人当笑料。
