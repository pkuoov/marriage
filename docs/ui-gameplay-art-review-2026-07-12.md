## 结论

玩法骨架已经成立。玩家需要在有限耐心里追原话、查材料，收麦后再分配调查次数，并把调查结果带回回拨。路线记录、顾问分歧、材料圈点和事实边界回看都能让选择留下后果。当前试玩的主要障碍来自新加的 AVG 表现层，它覆盖了原来的直播布局。玩法数量和插图数量暂时够用。

桌面端主舞台被压进 280 像素宽的左栏；手机端四项 HUD 和长材料说明挤成竖排；材料浮卡会挡住对白与选项。应先修 P0 布局，再接入 V2 立绘和新场景。继续加图只会把遮挡变得更明显。

### P1：布局稳定后处理

1. 让玩家看懂每次提问花的是什么。当前四个问题外观完全一致，只有选完后才知道是否消耗耐心。不要标“正确答案”，但可以在题组标题旁写清“追问会推进一句，绕开关键处可能掉耐心”。自由追问与关键追问继续分组。

2. 把幕间预算改成点数或时钟格。现在“剩余、已做、至少、最多”同时出现，读起来像规则说明。保留“剩余 2 格”，行动卡只显示“耗时 1”或“耗时 2”。

3. 缩短单案回看。当前回看最多七页，放在直播、调查和回拨之后容易拖掉收束感。建议合成三页：

   - 直播成绩、路线和压力放一页。
   - 事实边界摆放独立一页。
   - 回拨结果、麦外来信和下一案入口放一页。

4. 顾问分歧要展示“人在说话”，不能只是一组长文本按钮。赵律师、周会计和小林老师同屏时，至少给头像、姓名、领域和一句立场；玩家选中后再展开完整说法。

5. 材料卡先给类型，再给内容。账单、表格、聊天截图、流程图已经有不同的 CSS 结构，这一点应保留。入口上只写“账单”“排班表”“审批图”，避免把完整摘要当按钮文字。

## 玩法复核

### 游戏性已经存在

核心循环可以概括为：

`听原话 → 选追问 → 圈材料 → 承受耐心变化 → 收麦调查 → 选择顾问或地点 → 带一件东西回拨 → 摆事实边界`

这个循环有三类有效取舍：

- 直播取舍：追事实、追钱路、追身份话术，路线不同，耐心和后续反应不同。
- 调查取舍：次数不够把所有地点走完，部分顾问意见互斥。
- 收束取舍：玩家要决定哪句话值得追，哪些只能留在“已知、推测、未知”。

因此不建议再加新的常驻数值、体力条或小游戏。现有玩法需要的是更清楚的反馈和更短的收束，不是更多系统。

### 仍需防止的玩法问题

- 不要把每组选项做成一道隐藏单选题。每组至少保留一条可成立但代价不同的路线，回看解释代价，不用“答对/答错”替代人物反应。
- 调查地点必须改变回拨开场或可用证据。只换一段对白、不改变回拨的地点，应降为气氛事件。
- 顾问不能成为答案机。赵律师守边界，周会计追钱路，小林老师拆行业话，三人说法应互相缺一块。
- 七页回看若不压缩，会把玩家刚做出的最后选择冲淡。
