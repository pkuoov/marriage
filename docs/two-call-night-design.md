# 两连线之夜·结构改革设计（the two-call night）

日期：2026-07-08
性质：流程层改革设计（playtest 报告驱动，冻结解除的第一项）。
判决来源：真人 playtest 结论——"还是过于线性:每案一段连线,NPC出场解释线索,完事"。

## 病根

十四批改造全部发生在同一条单链上：连线→板→收麦。委托、顾问、留言、快照都是**按时到达的节目单**，玩家的动词只有"接住"。非线性不等于分支对话——**非线性 = 玩家决定接下来做什么，且不同的做法产生不同的信息态**。

## 改革：一夜两连线

每案从"一段连线"改为"一个晚上"，三段结构：

### 第一段连线（约 4 拍）

建立 A 故事＋第一块材料板。以**她挂断**收束——挂断理由每案专设，本身是戏：

- 案 1：说到八万缺口，她说"我缓缓"，挂了。
- 案 2：店里那位突然给她打电话，她慌了，"我先接一下"。
- 案 3：她妈在家里群 @ 她，"我妈叫我，别挂节目，我马上回来"。
- 案 4：活动总结表上多了条新批注，她去截图。

### 幕间调查台（玩家的回合——非线性的心脏）

她不在线。控台亮起 **4-5 个行动位，时间预算只够选 2-3 个**，顺序自定：

| 行动 | 复用资产 |
| --- | --- |
| 送鉴定（选材料×选顾问） | 证据委托（现有） |
| 打给家里人（赵/张/周即时通话，可追一问） | 家人网＋顾问单（升级为对话） |
| 重看材料（多点圈选，第一段没看完的边角） | 材料板＋pityLine |
| 听回放（抓背景音、口误） | 听觉线索＋证言比对 |
| 回后台私信（回流件此刻到达，可回一句） | investigationHooks |

**取舍即表达**：选了送鉴定就来不及听回放；不同玩家带着不同的信息态进入第二段。行动位配置每案在 JSON 里定死（授权内容，不生成事实）。

### 第二段连线（回拨，约 3 拍）

- **开场由玩家决定**：从幕间收获里选一件"带回去的东西"当回拨第一句——委托回单、圈中的边角、回放里的背景音。不同选择触发不同的回拨开场变体（`revisedVersion` 的真正舞台：她的证言修订由玩家亲手引发，不再是圈板后的自动播放）。
- **她的姿态由上半夜决定**：误判快照若显示直播间倒向指责她，她回拨时防御拉满、差点不打回来；倒向同情她，她松。guard 按幕间重算。
- 深问、原话、边界分拣、收麦照旧，但站在"玩家亲手组装的信息态"之上。

## NPC 三动词（从解说员到行动者）

改革后每个包至少各出现一次：

- **拒绝**：张法医嫌截图不够——"给我原件"。玩家必须在回拨里向她要原件（fetch 穿过来电人，NPC 的要求变成对话目标）。
- **打断**：第二段连线中，赵可以突然插一条后台短信「别让她挂」——家人第一次主动出手，而不是等玩家上门。
- **冲突要求抉择**：赵与周的互呛升级为幕间实选——回拨开场采纳谁的框架（法律的"性质"还是会计的"路径"），选择决定回拨第一问的形状并记入路线轴。

## 资产重定位（几乎零浪费）

| 现有资产 | 新位置 |
| --- | --- |
| 证据委托 | 幕间行动位之一 |
| advisorNotes（读后感） | 幕间"打给家里人"的通话体＋收麦残留一条 |
| investigationHooks | 幕间到件（可回一句） |
| revisedVersion | 回拨开场变体 |
| 立场快照 | 回拨姿态开关 |
| 7 场 | 拆为 4＋3 |
| lurker / respondent-note | 保持收麦后（夜的最后一层不动） |

## Skill 立法（随本设计入册）

- **线性禁令**：每案至少一个"决定做什么"的节点（不是"决定说什么"）；至少一段信息必须可乱序获得；砍掉任何"按时到达且无需玩家动作"的新表面提案。
- **NPC 三动词配额**：每包拒绝/打断/冲突各 ≥1。到场→解释→退场的 NPC 不许再写。

## 实施切分

1. **15-engine**：夜结构状态机（段 1／幕间／段 2）、行动位与时间预算、回拨开场变体分发、姿态开关。工程量：中偏大（sceneAdvance 流程重构）。
2. **15a＝案 1 竖切**：完整改制一案（挂断理由／5 个行动位／3 种回拨开场／姿态两态），真人过一遍验"玩家的回合"手感，再铺开。
3. **15b-15d**：案 2-4 按样板改制，每案保留自己的挂断戏与专属行动位。
4. 默认仍是单连线人（幕间通话对象只能是顾问家人，对方不接通）、感知带宽、双源、效力线、授权内容。
5. **案三礼物插麦特许**：只在第二夜、双方都已在场且分别说清公开范围后，允许一次临时双人调解。高额礼物只能制造主播难以拒绝的现场压力，不能购买站队、替另一方授权或扩大材料效力；未获同意的完整流水不上屏。此特许不自动推广到其他案件。
