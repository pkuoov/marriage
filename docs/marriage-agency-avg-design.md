# 《婚恋侦探局》初始设定文档

## 1. 项目定位

《婚恋侦探局》是一款中国式恋爱、相亲、结婚、生子主题的反诈防骗防坑文字对话类游戏。新版本主舞台是“良缘算法”婚恋侦探局，玩家扮演婚恋侦探 / 律师顾问，而不是亲自下场恋爱的主角。每周目由系统后台生成三起婚恋案件：婚前 case、婚后 case、告解模式。玩家通过当事人连线、追问、核验和复盘，在男方、女方或当事人的自我告解中抽丝剥茧找出真相。

游戏重点不是“攻略一个完美对象”，而是在信息不完整、条件被包装、动机不透明、外部环境不断变化的婚恋市场中，识别风险、保护资产、保护情绪、建立边界，并判断一个不完美的人是否值得共同承担十年。

本作不是甜宠恋爱模拟，也不是恐婚劝退模拟，而是婚恋风险管理游戏。玩家的胜利不只有“结婚成功”，也包括及时止损、保住资产、识别骗局、拒绝控制、修复关系、避免把一段关系拖成长期消耗。

核心体验：

- 婚恋市场模拟
- 关系悬疑
- 反诈防骗防坑
- 侦探局连线审案
- 男方 / 女方诉苦与反叙事
- 真受害者、半真半假、恶人先告状的判断
- 长期婚姻经营
- 宏观经济与家庭风险
- 投资、债务和共同财务决策
- 前任、暧昧和出轨风险管理
- 双方父母博弈
- 彩礼、婚房、婚礼、育儿、学区、债务等现实议题
- 同一个 NPC 在不同周目可能有不同真实底色和不良动机

### 1.1 视角重构

旧版本视角：

```text
玩家亲自相亲、恋爱、结婚。
玩家主动给自己的财富、家庭、外貌、学历、情商加点。
```

新版本视角：

```text
玩家是婚恋侦探 / 律师顾问。
系统随机生成本场调查画像，不允许玩家主动加点。
玩家可以选择本局侦探专长：财务审计型、情绪追踪型、证据核查型。
系统后台生成一桩共用案件，所有当事人的言行都服务于同一个隐藏真相。
玩家通过追问、核验、交叉叙事和证据链判断谁在说谎，谁在隐瞒，谁在恶人先告状。
```

玩家不再问“我要不要和 TA 继续”，而是问：

```text
TA 说的版本完整吗？
TA 是真受害者，还是把自己包装成受害者？
对方有没有被反咬？
钱、婚史、孩子、债务、前任、短择和大结果有没有被藏起来？
这个择偶定位是合理美化，还是影响对方知情权的包装？
```

### 1.2 后台共用剧情

每周目开局时，系统先生成三个 `caseBrief`，组成 `caseBriefs`。它们不是屏幕上直接公开的剧情，而是后台真相。三起案件的栏目固定，但具体案型、当事人、隐瞒事实和证据随机。

三案结构：

```text
第一案：婚前 case。关系尚未进入婚姻，重点核验择偶定位、婚史孩子、彩礼房产、债务和承诺包装。
第二案：婚后 case。关系已经进入婚姻或事实共同生活，重点拆共同财务、家务育儿、出轨边界、亲子和双方家庭责任。
第三案：告解模式。随机一个当事人自述自己的经历，玩家贴近 TA 的视角查探婚恋里可能的问题：被坑、自欺、隐瞒、获益和伤害。
```

`caseBrief` 至少包含：

```text
order：第几案
plotId：案件类型
label：对玩家可见的案件标题
truth：后台真实核心
publicHook：侦探局可见的表层冲突
stance：来访者是真受害者、半真半假，还是恶人先告状
premeditated：是否预谋案
premeditatedActorId：预谋角色，有预谋案才存在
caseMode：premarital / married / confession
modeLabel：婚前 case / 婚后 case / 告解模式
modeBrief：本栏目调查重点
complainantId：先连线诉苦的人
respondentId：被诉说的另一方
hiddenFacts：被隐瞒的事实
exaggerations：被夸大或包装的事实
evidence：可追问或可核验的证据
scene：当时场景复盘
testimony：证词、提示、假话、含糊话和追问结果
difficulty：案件难度
budget：本案剩余追问/整理次数
confessionTimeline：告解模式专用时间线节点
threadLink：本周目前后案件的人物牵连或旁证影响
```

后台剧情是公用的意思是：不是男方一套故事、女方一套故事各写各的，而是系统先定一条完整事实链，再让不同当事人从自己的利益位置讲出不同版本。

### 1.3 初始案件库

首批案件类型：

```text
骗婚局：承诺、领证、彩礼、房产加名或资源引荐被用于换取利益。
化债局：婚前债务、家庭欠账、创业亏损或信用卡周转被转嫁给伴侣。
外遇反咬局：诉苦者可能确实被冷落，也可能把情绪外包和外遇包装成受害。
外情生子 / 接盘生子局：孩子、备孕、领证和财产安排被混在一起。
大结果收割局：一方曾通过亲密关系拿过大钱、大资源或关键机会，却选择性不提。
择偶定位包装局：来访者寻求定位，但隐瞒或夸大家境、学历、外貌、婚育史、短择经历。
```

### 1.4 侦探玩法循环

```text
1. 系统生成三起后台案件：婚前 case、婚后 case、告解模式。
2. 第一案开案，先诉苦者连线，重点查承诺前的包装与止损点。
3. 玩家复盘当时场景：饭局、同居屋、婚礼现场、医院走廊、房产中介等。
4. 每案有有限追问/整理配额。比对现场版本、追问证词、整理证据都会消耗配额。
5. 玩家阅读多方证词，追问假话、含糊话和不愿说完整的句子，获得提示。
6. 玩家整理证据卡：转账、聊天、征信、学历、婚育、产检、房产、出行记录。不同整理方式暴露不同线索。
7. 玩家阶段指认：先诉苦者、另一方、双方都有隐瞒，或暂判无预谋。
8. 案间进入侦探局战况页，结算声誉、舆论热度和下一案资源变化。
9. 第二案进入婚后共同生活，重点查责任、账本、家庭边界和长期消耗。
10. 第三案进入告解模式，随机当事人自述经历，玩家站进 TA 的视角查被坑、自欺和可能伤人的部分。
11. 三案结束后进行本周目总复盘。
12. 玩家进入当事人后续片段，系统把三案表现转成止损建议、澄清程度、观察期和后续风险。
```

### 1.4.1 第一批可玩性修正

根据结构 review，当前优先打磨侦探模式主线，旧版恋爱 1-10 章暂时保留但不作为主流程入口。第一批修正目标：

```text
侦探专长：开局选择财务审计型 / 情绪追踪型 / 证据核查型，给随机调查画像叠加明确偏向。
追问配额：每案有限调查资源，避免玩家无成本点完所有追问。
证据卡差异：时间线、钱和资源、动机和收益分别暴露不同线索。
直播证据卡：证据不只是实物证据，也包括当事人前面说过的话、直播录屏、微信截图、社媒图片和消费截图。
结案复盘：展示玩家指认方向、后台更接近的方向、命中的关键矛盾和错过的关键点。
告解模式：不再复用普通版本比对，改为时间线标注“被坑 / 自欺 / 可能伤了别人”。
元进度工具：经验点解锁加班助理、时间线追踪和提前预警。
```

### 1.4.2 第二批周目弧修正

Claude review 指出三案之间缺少叙事弧。第二批修正目标是让每一局不再像三场独立小游戏：

```text
案间战况：每案结算后进入侦探局战况页，展示本案余波，而不是直接跳下一案。
声誉系统：判断准确且调查高效会提高侦探局声誉；声誉高时下一案当事人更愿意配合。
舆论热度：指认失稳会提高旁听席争议；热度过高时下一案更防御，调查配额减少。
案件牵连：上一案当事人会作为下一案旁证、舆论记忆或告解镜像出现。
总复盘：周目结束时汇总每案对声誉和舆论的影响，形成一局内部的因果链。
```

### 1.4.3 第三批侦探转后续桥

Claude review 指出旧 1-10 章恋爱剧情被侦探模式挡住，形成死代码。根据当前方向，主体验更接近《逆转裁判》式连环案件，因此第三批修正不再默认展开长篇恋爱模拟，而是采用“案件主线 + 压缩关系后续”的方式。

```text
双章节表：案件使用 CASE_CHAPTERS，旧恋爱长线 CHAPTERS 暂时保留为素材库。
案卷归档：caseBriefs 保留为 caseArchive，不清空；旧案继续影响后续片段。
后续片段：三案结束后进入 caseAftermath，用短 epilogue 展示当事人关系余波。
后续判断：根据声誉、舆论热度、旧案牵连和指认正确性生成 candidateAccess。
压缩结果：当事人会被归入建议止损、部分澄清、进入观察期或信任基础偏弱。
素材库保留：旧 1-10 章恋爱/婚后内容不作为当前主线展开，后续可抽取为案件回忆、庭审证词和案后短片段。
```

### 1.5 非线性调查与迷惑台词

每个案子不能设计成“读完证词 -> 点答案”的线性流程。玩家必须能在以下界面之间来回跳转：

```text
现场复原
证词交叉追问
证据卡整理
阶段指认
```

当事人的场景复原不等于事实。每个现场至少有三个版本：

```text
先诉苦者版本：通常强调自己被伤害、被逼迫、被误解。
另一方版本：通常指出对方没说完整，但也会回避自己的收益。
第三方 / 材料版本：只证明局部事实，不自动证明谁完整说真话。
```

证词需要包含多种迷惑话术：

```text
假话：与后台事实冲突，但当事人会说得很顺。
迷惑性含糊：听起来没有撒谎，但把钱、领证、房本、孩子等关键诉求混在一起。
不愿意说：当事人知道关键事实，但担心说出来会损害自己利益。
小承认掩护大隐瞒：承认一个轻微包装，让玩家以为 TA 已经坦白。
真话但留白：说了一部分真相，但省略了自己从中获得的利益。
```

玩家追问后会获得“迷惑点 / 矛盾点”。没有抓到足够矛盾点时，即使猜中角色，也不能算稳定破案。

### 1.5.1 直播证据卡

证据卡要更符合直播审案，而不只是传统实物证据。玩家可以把一张卡放到直播台面上，再对某一句证词出示。

证据卡类型：

```text
话术回放：当事人之前在直播里说过的话，适合打前后矛盾。
微信截图：聊天记录、转账前后、撤回和打码截图，适合打时间线和承诺变化。
图片证据：高级服装试穿照、约会照片、朋友圈截图，适合打人设包装和消费能力。
消费截图：高级护肤品、医美、礼物订单、酒店和餐厅消费，适合打“我没包装/我没索取”的说法。
社媒存档：被删动态、共同好友截图、公开视频时间线，适合打关系阶段和公开承诺。
材料卡：征信、病历、产检、合同、房产、学历等硬材料。
```

出示规则：

```text
选中一张证据卡。
对某句证词出示。
如果证据卡 targets 命中证词 kind，形成“出示证据”矛盾点。
如果出示偏了，消耗追问配额，并增加舆论压力。
```

## 2. 世界观背景

游戏主舞台是婚恋侦探局：

**良缘算法婚恋咨询有限公司**

公司表面上仍提供正规婚恋服务：

- 线下相亲
- 背景审核
- 情感咨询
- 婚前财产咨询
- 双方父母见面协调
- 婚礼资源对接
- 育儿、学区和家庭规划课程

但当前主玩法不是玩家亲自相亲，而是“婚恋侦探局”直播审案。公司把婚介资料、律师咨询、情感连线、聊天截图、消费记录和社媒存档汇成案卷，让玩家以婚恋侦探 / 律师顾问身份判断：

- 谁在说完整事实
- 谁在用诉苦占据道德高位
- 谁被反咬或被误伤
- 哪些证据卡能戳破当前台词
- 案后谁该止损，谁只是需要慢速观察

婚介公司的旧功能保留为素材库：客户资料、红娘业绩压力、父母改条件、候选人包装、婚史债务隐瞒、婚礼和育儿压力，都可以被拆成案件回忆、证词、直播证据卡和案后短片段。

玩家每个周目不是婚介客户，而是处理三起案件的侦探局顾问。侦探局也不是完全中立的：声誉、舆论热度、旁听席站队和上一案余波都会影响下一案当事人愿不愿意配合。

## 2.1 视觉与音效模板

当前原型从纯文字升级为类似橙光的互动视觉小说模板。

基础界面结构：

```text
场景背景
人物立绘
底部对话框
说话人名牌
选择按钮
右侧状态面板
音效开关
```

当前没有语音，只有音效。

音效类型：

```text
click：普通点击
confirm：推进章节、确认选择、结算
warning：禁用按钮或风险提示
page：预留翻页音
```

素材结构：

```text
assets/characters/     人物立绘占位 SVG
src/sound.js           WebAudio 音效系统
src/styles.css         VN 舞台、背景、立绘和对话框样式
```

当前立绘为可替换占位资源。后续正式美术可以直接替换为同名 PNG/WebP，或在代码中更新 `CHARACTER_ART` 映射。

## 3. 开局案件与调查画像

旧版“玩家选择性别并给自己加点”的系统取消。新版本中，玩家不是相亲者，而是侦探局调查员。系统会在开局随机生成一份调查画像，用来决定玩家本局更容易看见哪类线索。

调查画像不是玩家主动加点，也不是角色强弱养成，而是本场调查的观察偏向：

```text
财务嗅觉：识别转账、债务、投资、彩礼、房产和大结果。
家庭结构：识别父母介入、原生家庭债务、弟妹压力、老人照护。
形象观察：识别外貌包装、社交展示、人设塑造和照片时间线。
信息核验：识别学历、职业、婚史、孩子、证据链和时间线漏洞。
情绪洞察：识别诉苦表演、情绪勒索、恶人先告状和真受害者创伤反应。
```

系统随机生成这些值，玩家不能手动调整。周目经验会提高后台随机画像的平均质量，但仍保留盲区。

### 3.1 废弃的旧加点规则

以下规则不再作为新版本开局流程，只作为历史设计参考：

长期版本中，玩家开局可以选择性别：

- 男
- 女

然后获得 25 点基础机动点数，自由分配到五项属性。后续周目结算会提供额外永久机动点：

```text
个人财富：0-10
家庭背景：0-10
外貌：0-10
学历：0-10
情商：0-10
```

每项满分 10，初始总和必须等于当前可用机动点。第一周目为 25 点，后续周目会随着经验累积提高。

### 3.2 属性含义

**个人财富**

代表当前可支配资产、收入、存款、车房能力。影响彩礼、嫁妆、约会消费、婚介会员等级、房贷压力，以及是否吸引图钱型 NPC。

**家庭背景**

代表父母资源、城市户口、家庭稳定度、亲戚网络、父母能否出钱出力。影响双方父母态度、婚房支持、孩子上学、老人介入强度。

**外貌**

代表第一印象、性吸引力、社交展示价值、被包装价值。影响初见好感、相亲成功率、朋友圈和短视频事件，也会提高被物化风险。

**学历**

代表教育资本、职业上限、沟通方式、信息判断能力。影响识别骗局、法律意识、职业发展、与高学历 NPC 的共同话题。

**情商**

代表情绪理解、话术识别、冲突沟通和读人能力。影响玩家对 NPC 的魅力值、部分线索是否提前显现、判断对方说话真假和真实动机的能力。情商不是读心术，高情商只能提高识别概率，不能保证永不被骗。

### 3.3 属性段位

```text
0-2：明显短板
3-4：偏弱
5：普通
6-7：优势
8-9：强优势
10：顶配标签
```

强属性不是纯优势：

- 财富高更容易吸引图钱型、资源型对象
- 家庭背景高更容易触发双方父母博弈
- 外貌高更容易被展示化、物化或猎艳
- 学历高更容易识破风险，但也可能被评价“太理性”“不好拿捏”

### 3.4 开局系统评价

分配完成后，系统生成三份评价：

1. 公开资料卡：婚介展示给 NPC 的版本
2. 红娘内部评估：公司如何给玩家定价
3. 隐藏风险画像：玩家容易吸引哪类人

示例：

```text
性别：女
财富 2 / 家庭 3 / 外貌 9 / 学历 6

公开资料：
“形象气质佳，本科以上学历，性格独立，期待稳定关系。”

红娘内部：
“高展示价值，经济承压，中高净值男性转化率高。”

隐藏风险：
更容易吸引控制型、猎艳型、资源交换型 NPC。
```

### 3.5 推荐开局模板

```text
普通城市青年：财富 4 / 家庭 4 / 外貌 4 / 学历 4 / 情商 4
寒门高材生：财富 1 / 家庭 2 / 外貌 4 / 学历 9 / 情商 4
富家低学历：财富 6 / 家庭 8 / 外貌 3 / 学历 1 / 情商 2
漂亮穷人：财富 1 / 家庭 2 / 外貌 9 / 学历 5 / 情商 3
高净值精英：财富 8 / 家庭 4 / 外貌 2 / 学历 3 / 情商 3
家庭托举型：财富 2 / 家庭 9 / 外貌 3 / 学历 2 / 情商 4
独立精英：财富 5 / 家庭 2 / 外貌 3 / 学历 7 / 情商 3
```

### 3.6 肉鸽周目成长

本作的核心结构是婚恋肉鸽。每个周目的 NPC 底色、动机、案例因素和爆发节奏都带有随机性。

每次周目结算后，玩家会获得 2-3 点永久机动点。下一周目创建角色时，可用总点数会增加。

规则：

```text
基础机动点：20
每周目结算：+2 或 +3
永久经验点上限：当前原型为 +24
每项属性上限：10
```

经验点象征玩家经历后的成长，不是单纯数值膨胀。

它代表：

```text
更清楚自己的底线
更熟悉婚恋市场话术
更能识别不舒服的细节
更懂得保护资产和边界
更知道什么时候该继续，什么时候该止损
```

周目经验不会消除随机性，只会让玩家更有能力面对随机性。

## 4. 性别差异反馈

同样属性在男女主身上会获得不同社会反馈。

男主财富低：更容易被质疑“没能力结婚”。

女主财富低：更容易被怀疑“是否图钱”。

男主外貌高：初期加分，但长期仍会被财富和家庭拷问。

女主外貌高：初期优势更明显，但被物化和控制风险更高。

男主学历高：更容易被视为潜力股。

女主学历高：部分 NPC 和父母会觉得“太强势”。

男主家庭高：父母更可能插手房本和彩礼。

女主家庭高：父母更可能审查男方条件和生育安排。

## 5. 婚介匹配系统

婚介公司给玩家生成隐藏婚恋市场画像。

基础推荐等级可以使用：

```text
婚介推荐等级 = 财富 * 0.35 + 家庭 * 0.30 + 外貌 * 0.20 + 学历 * 0.15
```

每个 NPC 对玩家会有三项初始判断：

```text
吸引值：我想不想见 TA
利用值：TA 能不能解决我的问题
风险值：TA 会不会不好拿捏
```

建议公式：

```text
吸引值 = 外貌 * NPC审美权重 + 学历 * 话题权重 + 财富 * 安全感权重
利用值 = 财富 * 图钱权重 + 家庭 * 资源权重 + 外貌 * 展示权重 + 学历 * 跳板权重
风险值 = 学历 * 识破能力 + 家庭 * 保护能力 + 财富 * 退出能力
```

高条件会提高优质匹配概率，也会提高被包装、被计算、被利用的概率。

## 6. NPC 隐藏底色随机

每个新周目开始时，6 个相亲对象会随机生成隐藏底色。

建议概率：

```text
真诚型：50%
现实私心型：25%
道德瑕疵型：15%
高风险控制型：10%
```

系统保底：

```text
每周目至少 3 个 NPC 可以正常发展
每周目至少 1 个 NPC 有明显私心
每周目最多 1 个 NPC 是高风险控制型
```

### 6.1 真诚型

真想进入关系，不代表完美。可能穷、妈宝、逃避、焦虑、事业不稳，但愿意沟通和修复。

行为特征：

- 前后说法基本一致
- 遇到冲突会解释
- 不会强迫玩家快速承诺
- 愿意承担一部分代价

### 6.2 现实私心型

不是纯粹坏人，但结婚目的不纯。

可能目的：

- 解决房子
- 解决户口
- 完成父母任务
- 找人一起还贷
- 找人带娃
- 找阶层跳板
- 找情绪保姆

行为特征：

- 对玩家某项属性特别敏感
- 关系推进快
- 回避自己的短板
- 谈钱谈责任时含糊

### 6.3 道德瑕疵型

存在隐瞒、骑驴找马、前任未断、债务包装、婚史模糊等问题。

行为特征：

- 资料里有小漏洞
- 手机消息频繁
- 对前任问题反应过激
- 遇到核实时转移话题

### 6.4 高风险控制型

不直接写医学诊断，而表现为高控制、高索取、低共情、擅长反咬。

行为特征：

- 初期极度完美
- 快速制造灵魂伴侣感
- 让玩家和朋友家人疏远
- 把边界说成“不够爱”
- 犯错后让玩家内疚

## 7. 初始不良动机随机

如果 NPC 被抽到现实私心型、道德瑕疵型或高风险控制型，就继续抽取初始不良动机。

这让“有问题的 NPC”不是简单坏，而是带着具体目的进入婚恋市场。

### 7.1 不良动机池

**图钱**

看中玩家财富、房产、消费能力。常见行为：主动推进同居、催共同账户、暗示大额礼物、回避 AA。

**图家庭资源**

看中玩家父母、户口、人脉、学区、编制、家族生意。常见行为：很早接近玩家父母，绕过玩家谈条件。

**图外貌展示**

想要一个“拿得出手”的伴侣。常见行为：频繁拍照、公开秀恩爱、在朋友面前塑造完美情侣。

**图生育/照护**

想找人生孩子、照顾父母、做家务、承担家庭隐性劳动。常见行为：很早聊孩子、父母养老、婚后谁辞职。

**图情绪供养**

需要长期被安抚。常见行为：前期卖惨，后期把所有压力倾倒给玩家。

**图阶层跳板**

想借婚姻进入更高圈层。常见行为：对玩家资源圈异常感兴趣，常问“能不能介绍”。

**图避险/遮羞**

有债务、婚史、前任、家庭问题，希望尽快结婚掩盖。常见行为：催进度、害怕背调、对过去含糊。

**图控制感**

享受让伴侣围着自己转。常见行为：初期完美，后期孤立玩家、贬低玩家、制造内疚。

**图婚恋 KPI**

不爱谁，只是年龄到了、父母催了、同事都结了。常见行为：流程感强，像在完成项目。

**图内容/流量**

把恋爱、婚礼、怀孕、育儿当素材。常见行为：任何情绪都想记录，隐私边界模糊。

### 7.2 NPC 高概率动机

```text

图控制感

```

```text

图情绪供养
图阶层跳板

```

许照高概率：

```text
图外貌展示
图控制感
图避险/遮羞
图情绪供养
```

陈默高概率：

```text

图家庭资源
图生育/照护
图避险/遮羞
```

沈知夏高概率：

```text

```

```text

```

### 7.3 动机暴露机制

每个不良动机都有 3 次暴露机会：

```text
轻微信号：让玩家觉得哪里不舒服
明确冲突：玩家可以质问
重大爆雷：进入关系后造成实质损失
```

例：图钱

- 轻微信号：TA 总是忘记转账，但记得玩家收入很高
- 明确冲突：TA 希望玩家先垫婚房装修款，说以后都是一家人
- 重大爆雷：婚后发现 TA 婚前债务被包装成创业亏损

例：图控制感

- 轻微信号：TA 说玩家的朋友不太靠谱
- 明确冲突：TA 要求玩家报备行程，否则就是不尊重关系
- 重大爆雷：玩家发现自己已经很久没有单独见朋友和家人

## 8. 案例事件引擎

为了让后续新增真实感案例时不用硬写进某一章，游戏使用“案例事件引擎”结构。

一个案例不是一整段剧情，而是被拆成若干阶段因素，也就是 `factor`。每个因素标注自己应该进入哪个阶段、影响哪些变量、展示什么文本。

阶段枚举：

```text
screening：婚介初筛
dating：约会观察
preParents：见父母之前
marriageTalk：谈婚论嫁
wedding：婚礼战役
firstYear：婚后第一年
child：孩子上学
```

案例结构示例：

```js
{
  id: "house-parent-funded",
  title: "婚房父母出资与房本名字",
  motiveHints: ["familyResource", "money", "control"],
  factors: [
    {
      stage: "preParents",
      type: "property",
      line: "TA 的父母很早开始问房子首付、贷款和房本名字。",
      internalDelta: 6,
      motiveDelta: 8,
      flags: { parentConflict: 1 }
    },
    {
      stage: "marriageTalk",
      type: "property",
      line: "房本名字被说成安全感，也被说成不信任。",
      internalDelta: 10,
      motiveDelta: 12,
      flags: { assetProtection: 1, parentConflict: 1 }
    }
  ]
}
```

当前代码位置：

```text
src/caseEngine.js
```

新增案例时，只需要加入一个案例对象，并为它拆出不同阶段的 `factors`。系统会根据 NPC 的隐藏动机、隐藏底色和玩家属性，把案例因素分配给合适的 NPC，并在对应章节触发。

## 9. 双爆发值系统

每个 NPC 除了隐藏底色和初始不良动机，还拥有两个隐藏变量。

### 9.1 内在因素爆发值

用途：决定“蛮横”“控制”“冷暴力”“过激反应”“强行站队”等行为的爆发概率。

规则：

```text
internalBurst < 20：视为 0，不触发爆发概率
internalBurst >= 20：开始计算爆发概率
internalBurst 越高，越容易在压力事件中失态
```

它不等于坏人值。真诚型 NPC 也可能在压力下短暂失态，但区别在于事后是否能承认和修复。

初始范围建议：

```text
真诚型：0-16
现实私心型：12-36
道德瑕疵型：18-48
高风险控制型：48-76
```

案例因素、玩家拒绝、父母冲突、财产谈判都会让它累积。

### 9.2 动机爆发值

用途：决定 NPC 不单纯婚恋目的是否会摊牌、行动或明显显形。

规则：

```text
motiveBurst < 70：真实目的不直接摊牌
motiveBurst >= 70：开始以一定概率摊牌或采取行动
```

如果 NPC 是真诚型，没有不良动机，则动机爆发值通常很低。它可能表现为真实恐惧或压力表达，而不是算计摊牌。

初始范围建议：

```text
真诚型：0-16
现实私心型：34-58
道德瑕疵型：42-66
高风险控制型：48-70
```

动机爆发后可能出现：

```text
图钱：要求垫钱、共同账户、提前承担装修婚礼费用
图家庭资源：绕过玩家接触父母或资源圈
图外貌展示：强行公开、展示、包装人设
图生育/照护：提出同住、备孕、照顾老人安排
图情绪供养：用崩溃阻止玩家谈条件
图阶层跳板：索要引荐和资源
图避险/遮羞：要求跳过背调或先订婚
图控制感：要求报备、站队、统一管理
图婚恋 KPI：拿出订婚领证备孕时间表
图内容/流量：把关系和家庭隐私做成内容
```

### 9.3 爆发值与案例因素的关系

每个案例因素可以增加：

```text
internalDelta：内在因素爆发值增量
motiveDelta：动机爆发值增量
flags：外部状态增量，如 parentConflict、assetProtection、suspicion
```

这让案例不是单纯文本，而是能改变 NPC 后续行为概率的事件因子。

## 10. 婚恋避坑核心系统

新定位下，游戏的核心不再是“结婚十年模拟”，而是“在十年关系里持续识别坑”。坑不只来自某个坏人，也来自玩家自己的盲区、父母压力、经济周期、社会比较、情绪饥饿和错误的财务决策。

玩家每一局要同时管理四类安全：

```text
情绪安全：不被长期冷暴力、情绪勒索、控制和外包消耗。
财务安全：不被大额转账、共同债务、投资骗局和房产边界拖垮。
关系安全：不让前任、暧昧、社交软件和情绪替代品侵蚀关系。
家庭安全：不让双方父母、老人照护、育儿分工和教育焦虑压垮小家庭。
```

### 10.1 新增风险变量

建议在 `state.flags` 中保留以下变量：

```text
macroEconomyPressure：宏观经济压力
stockMarketHeat：股市热度与投资诱惑
investmentExposure：家庭投资暴露
scamExposure：诈骗暴露
exReentryRisk：前任回流风险
careDeficit：关心不足
emotionalValueDemand：情绪价值索取
infidelityRisk：出轨或情绪外包风险
```

这些变量不直接等于结局，而是用于改变事件语气、NPC 爆发概率、止损条件和最终结算。

### 10.2 风险识别不等于疑神疑鬼

玩家可以通过三种方式降低风险：

```text
核实：背调、查征信、看合同、问清前任边界、核验投资资质。
谈判：把钱、时间、家务、父母介入和情绪需求说清楚。
退出：当对方持续越界、反咬、隐瞒、转移资产或威胁时及时止损。
```

玩家也可以通过错误方式短期降低不安，但长期升高风险：

```text
监控手机
冷战惩罚
用转账换安全感
用领证解决信任危机
用怀孕或买房绑定关系
把父母拉进每次争吵
```

本作鼓励的是“清醒的亲密”，不是“全面监控的亲密”。

## 11. 大环境系统

每个周目会生成一个外部环境。它影响所有 NPC，而不是只影响某一段剧情。

### 11.1 大环境枚举

```text
经济平稳：默认环境，压力可控。
经济下行：失业、降薪、副业、消费降级和家庭争吵概率上升。
行业裁员：大厂、创业、普通职员等职业线风险上升。
股市向好：投资诱惑增加，家庭备用金更容易被拿去冒险。
股市回撤：亏损、隐瞒、补仓、借钱和相互指责概率上升。
房价上涨：买房紧迫感增强，父母介入和房本争议上升。
房价下跌：已买房家庭压力上升，未买房家庭出现观望分歧。
诈骗高发：杀猪盘、假投资、婚恋诈骗、虚假项目事件权重上升。
社交平台高热：公开展示、攀比、暧昧、情绪价值外包风险上升。
教育成本上升：孩子线压力提前出现，学区和兴趣班变成长期战场。
```

### 11.2 大环境如何影响家庭

大环境不直接宣布“你失败了”，而是提高某类事件的出现概率：

```text
经济下行 + 房贷压力高：更容易触发共同债务、失业隐瞒、亲属借钱。
股市向好 + 图钱/阶层跳板动机：更容易触发家庭备用金投资、假高收益项目。
股市回撤 + 控制型 NPC：更容易把亏损归咎于玩家不支持或不懂投资。
社交平台高热 + 情绪价值索取高：更容易触发暧昧、前任回流、内容流量事件。
诈骗高发 + 学历/情商低：更容易晚发现投资骗局和婚恋诈骗。
教育成本上升 + 父母介入强：更容易触发学区房、老人带娃和教育路线冲突。
```

### 11.3 大环境不是背景板

大环境要体现在玩家选择里：

```text
要不要用家庭备用金投资？
失业后要不要告诉伴侣？
股市赚钱后是否升级消费？
股市亏损后是否隐瞒账户？
房价上涨时是否仓促上车？
经济不好时是否延迟婚礼和生育？
```

每个选择都同时影响关系和资产。比如拒绝高收益项目可能降低短期亲密，但提高资产保护；盲目支持投资可能短期显得“信任”，长期导致共同债务。

## 12. 股市与家庭投资系统

投资系统不是金融模拟器，而是家庭风险偏好测试。

### 12.1 投资事件类型

```text
稳健理财：收益低，争议小，考验共同账户规则。
热门基金/股票：收益和亏损都可能放大情绪。
朋友项目：看似熟人推荐，实则信息不透明。
伴侣创业：亲密关系和商业风险高度绑定。
虚拟币/高收益盘：诈骗暴露和债务风险极高。
父母推荐项目：拒绝会伤面子，接受可能伤资产。
```

### 12.2 风险判断维度

玩家不需要懂复杂金融，只需要练习几个家庭决策问题：

```text
钱从哪里来：闲钱、彩礼、婚房款、备用金、贷款？
谁做决定：一方拍板、共同同意、父母推动、朋友怂恿？
亏损谁承担：个人账户、小家庭共同承担、双方父母兜底？
有没有证据：合同、资质、账户、退出机制、风险揭示？
有没有情绪绑架：你不投就是不信我、错过就怪你、以后都是一家人？
```

### 12.3 投资结局分支

```text
稳健共识：收益不高，但家庭安全垫完整。
短期盈利：亲密和信心上升，但也可能提高下一次冒险概率。
小额亏损：触发复盘，如果能承担责任，关系可修复。
隐瞒亏损：信任下降，后续债务与前任/暧昧风险上升。
共同债务：房贷、育儿、父母养老全部承压。
投资诈骗：进入反诈线，测试玩家是否及时报警、止损和保留证据。
```

## 13. 前任、暧昧与出轨风险系统

出轨不是单纯随机惩罚，而是多个变量叠加后的风险事件。

### 13.1 出轨风险公式

建议使用以下思路计算隐藏风险：

```text
出轨风险 =
  关心不足
  + 情绪价值索取
  + 前任回流
  + 沟通摩擦
  + 长期同住疲惫
  + 社交平台诱惑
  + NPC 道德瑕疵/控制脚本修正
  - 边界感
  - 真实沟通
  - 稳定修复能力
```

也就是说：

```text
关心不足 + 对方情绪价值索取高 + 前任重新出现 = 高风险组合。
经济压力 + 沟通摩擦 + 外部有人愿意倾听 = 情绪外包风险。
高控制型 NPC + 玩家试图设边界 = 反咬、监控、报复性暧昧风险。
真诚型 NPC + 关系疲惫 = 可能短暂动摇，但仍有修复空间。
```

### 13.2 前任事件不只有一种答案

前任出现可能是骗局、搅局、未断联，也可能只是现实中确实需要处理的旧关系。玩家不能只凭“有前任联系”就判死刑，而要看：

```text
TA 是否主动告知？
TA 是否愿意设边界？
TA 是否删除证据或倒打一耙？
TA 是否把旧关系放在现关系之上？
TA 是否用“你太敏感”阻止讨论？
TA 是否让前任介入金钱、工作、家庭或婚礼？
```

### 13.3 关系修复选项

当风险还没变成黑色线索时，玩家可以选择：

```text
明确边界：哪些联系可以，哪些联系必须告知。
补足关心：不是讨好，而是恢复正常陪伴和倾听。
降低索取：对方不能把所有情绪都交给玩家处理。
共同咨询：适合真诚型或稳定修复型 NPC。
暂停推进：不在信任危机里订婚、买房、备孕。
直接退出：适合持续隐瞒、反咬、威胁和多次越界。
```

## 14. 反诈防骗防坑案例池

新增案例应尽量拆成“可复用因素”，不要写成唯一剧情。每个案例至少标注：

```text
触发阶段
关联动机
玩家可观察信号
短期诱惑
长期代价
可核实证据
可止损动作
影响变量
```

### 14.1 新增案例清单

```text
经济周期与家庭承压
股市投资与家庭风险偏好
前任回流与暧昧边界
关心不足与情绪价值外包
杀猪盘式婚恋投资
婚前共同创业
父母推荐理财
朋友高收益项目
婚后隐瞒亏损
失业隐瞒与信用卡周转
旧情人借钱
同事情绪倾诉
社交平台暧昧
私密照片与舆论威胁
```

### 14.2 示例：旧情人借钱

```text
阶段：dating / wedding / firstYear
关联动机：cover / emotionalSupply / control
轻微信号：TA 说只是普通朋友，但回消息很快。
明确冲突：前任遇到困难，希望 TA 借钱或陪同处理。
重大爆雷：小家庭的钱、时间或隐私被旧关系消耗。
可核实证据：转账记录、聊天边界、是否主动告知。
可止损动作：暂停推进、要求明确边界、拒绝共同承担旧关系债务。
```

### 14.3 示例：股市向好

```text
阶段：marriageTalk / firstYear / housingDebt
关联动机：money / classJump / control
轻微信号：TA 频繁谈收益，避谈亏损。
明确冲突：TA 想动用婚房款、彩礼或家庭备用金。
重大爆雷：亏损后要求共同承担，或隐瞒账户继续加仓。
可核实证据：账户归属、资金来源、风险揭示、退出机制。
可止损动作：只用个人闲钱、设置家庭安全垫、拒绝借贷投资。
```

### 14.4 示例：情绪价值外包

```text
阶段：firstYear / housingDebt / child
关联动机：emotionalSupply / control / content
轻微信号：TA 说你不懂 TA，但外面有人很懂。
明确冲突：TA 把争吵后的倾诉固定交给某个异性或前任。
重大爆雷：精神出轨、暧昧、聊天记录、关系公开羞辱。
可核实证据：是否主动告知、是否愿意设边界、是否停止反咬。
可止损动作：恢复沟通、明确外部倾诉边界、暂停推进、必要时退出。
```

## 15. 主要 NPC 资料卡

### 15.1 周砚：稳定体面型

公开资料：

32 岁，体制内或国企，父母退休干部，名下有一套小房，作息规律，不抽烟少喝酒。婚介评价：“适合认真结婚”。

可能底色：

```text
真诚型：慢热、不浪漫，但愿意承担家庭责任。
私心型：想找一个能照顾父母、稳定生育的人。
瑕疵型：前任未彻底断联，仍在比较“谁更适合结婚”。
高风险型：控制欲强，把规则、孝顺、体面当武器。
```

属性诱因：

- 玩家外貌高：更积极推进
- 玩家学历高：既欣赏又防备
- 玩家家庭低：父母会明显试探

危险信号：

- 黄色：“我妈只是嘴直，她没有恶意。”
- 红色：“婚后工资最好统一交给我妈规划。”
- 黑色：“你如果真爱我，就不会让我在父母面前难做。”

婚后爆点：

第 1 年春节去哪家；第 3 年生育安排；第 6 年父母养老。

### 15.2 林鹿：大厂精英型

公开资料：

29 岁，互联网产品或运营，收入高，表达清晰，心理学、沟通术、亲密关系词汇很熟。婚介评价：“高认知伴侣”。

可能底色：

```text
真诚型：工作很累，但愿意学习如何爱人。
私心型：把结婚当人生项目节点，希望快速达标。
瑕疵型：精神出轨边界模糊，习惯保留备选项。
高风险型：擅长话术，用“沟通”压倒玩家真实感受。
```

属性诱因：

- 玩家学历高：触发深度聊天线
- 玩家财富高：触发共同资产规划
- 玩家外貌高：触发社交展示欲

危险信号：

- 黄色：“我不是冷淡，我是在复盘我们的问题。”
- 红色：“你的感受我理解，但你的表达方式不成熟。”
- 黑色：“所有人都觉得你太敏感，只有我还愿意陪你成长。”

婚后爆点：

第 2 年加班与备孕冲突；第 4 年裁员或跳槽；第 7 年精神出轨疑云。

### 15.3 许照：富裕浪漫型

公开资料：

31 岁，创业者或家族生意，消费能力强，会安排惊喜，朋友圈体面。婚介评价：“高净值优质客户”。

可能底色：

```text
真诚型：厌倦家族联姻，想找真正理解自己的人。
私心型：享受恋爱和崇拜，但不想真正绑定。
瑕疵型：债务、股权、前任关系包装得很好。
高风险型：先极度宠爱，再用资源撤回控制玩家。
```

属性诱因：

- 玩家外貌高：高调带入圈子
- 玩家家庭高：考虑资源联合
- 玩家财富低：更容易进入拯救者姿态

危险信号：

- 黄色：“钱的事你不用懂，我来处理。”
- 红色：“房本写谁名这种问题太伤感情。”
- 黑色：“你离开我以后，还能过现在这种生活吗？”

婚后爆点：

第 1 年婚前协议；第 3 年公司债务；第 5 年第三者或商务应酬；第 8 年资产隔离。

### 15.4 陈默：普通踏实型

公开资料：

30 岁，普通职员、工程师或小店经营者，收入一般，性格温和，生活节俭。婚介评价：“稳定过日子型”。

可能底色：

```text
真诚型：能力有限，但真心愿意一起扛。
私心型：想通过婚姻解决房子、户口、父母照护。
瑕疵型：隐瞒家庭债务或亲属负担。
高风险型：低自尊转化成怨气，长期冷暴力和被动攻击。
```

属性诱因：

- 玩家财富高：自卑或依赖
- 玩家学历高：觉得被审判
- 玩家家庭高：可能试图讨好玩家父母

危险信号：

- 黄色：“我没意见，你决定就好。”
- 红色：“我爸妈不容易，你多让一点。”
- 黑色：“反正我没本事，你满意了吧？”

婚后爆点：

第 2 年买房首付；第 4 年亲属借钱；第 6 年职业停滞；第 10 年孩子教育投入。

### 15.5 沈知夏：理性边界型

公开资料：

33 岁，律师或咨询顾问，经济独立，表达克制，婚恋观成熟。婚介评价：“适合高质量伴侣”。

可能底色：

```text
真诚型：外冷内热，愿意慢慢建立信任。
私心型：把婚姻当风险对冲和资源组合。

高风险型：用理性包装冷酷，永远让玩家处于被告席。
```

属性诱因：

- 玩家学历高：触发平等对话
- 玩家财富高：触发婚前协议线
- 玩家家庭低：担心拖累

危险信号：

- 黄色：“我们先把规则说清楚。”
- 红色：“感情不能替代协议。”
- 黑色：“你现在的情绪没有讨论价值。”

婚后爆点：

第 1 年财产协议；第 3 年生育与事业排序；第 7 年离婚冷静期或抚养权预案。

### 15.6 何念：精致内容型

公开资料：

27 岁，生活方式博主、摄影师或自媒体，审美好，情绪价值高，擅长制造浪漫。婚介评价：“高魅力、高社交价值”。

可能底色：

```text
真诚型：表演久了，渴望被真实接住。
私心型：把恋爱、婚礼、孕期、育儿都当内容资产。
瑕疵型：人设与真实收入、情史、消费习惯不符。
高风险型：擅长扮演受害者，用舆论和眼泪操控关系。
```

属性诱因：

- 玩家外貌高：触发情侣账号线
- 玩家财富高：触发消费升级
- 玩家学历高：包装“灵魂共鸣”

危险信号：

- 黄色：“这个瞬间太适合拍下来。”
- 红色：“我们吵架这件事，我想做一期匿名内容。”
- 黑色：“你不让我说，就是怕大家知道你是什么人。”

婚后爆点：

第 1 年婚礼流量；第 3 年孕育内容；第 5 年家庭隐私曝光；第 9 年孩子出镜争议。

## 16. 线索系统

玩家不能直接看到 NPC 的隐藏底色和不良动机，只能通过行为观察。

线索分级：

```text
白色线索：普通性格差异
黄色线索：值得观察
红色线索：重大风险
黑色线索：建议立刻退出
```

例：

- 白色：TA 说自己不太会回消息，但当天确实工作很忙
- 黄色：TA 说不介意 AA，但点菜时默认玩家付钱
- 红色：TA 说房子是自己的，但合同上写的是父母和前任共同出资
- 黑色：玩家提出暂缓领证后，TA 开始威胁公开隐私

## 17. 第一章：《开播，先听谁的版本》

第一章目标：建立新玩法。玩家不是相亲者，而是婚恋侦探局里的调查员 / 律师顾问。系统已经在后台生成完整案件，但玩家只能先听到一方叙事。

开场黑屏文字：

```text
晚上八点，侦探局开案。

标题只有六个字：
婚恋侦探局。

第一位来访者已经在等候区。
TA 说自己是受害者。

但侦探局最危险的地方在于：
每个恶人先告状的人，也会先学会哭。
```

### 17.1 场景一：第一通连线

红娘顾问：孟姐，42 岁，金牌顾问，话术熟练，眼神很准。

律师顾问：程律，38 岁，负责提醒证据边界、财产风险和法律风险。

第一位来访者可能是男方，也可能是女方。TA 的身份由后台 `caseBrief.complainantId` 决定。

开场诉苦可能包括：

```text
“我真的只是想结婚，为什么 TA 家一直逼我拿钱？”
“我对 TA 那么好，现在 TA 说我骗婚。”
“我只是找前任问了几句话，TA 就说我出轨。”
“孩子是无辜的，TA 不能说不认就不认。”
“我只是想知道以我的条件该怎么找对象。”
```

玩家第一轮追问策略：

```text
A. 先让来访者完整陈述
B. 先查硬证据和时间线
C. 先顺着 TA 的说法问下去
D. 让旁听席先投票
```

效果：

- A：边界感 +1，容易发现叙事中的自然断点
- B：证据清晰度 +1，更早触发财务、婚史、孩子和债务线索
- C：来访者可信度暂时上升，但被带节奏概率上升
- D：舆论压力 +1，热度上升，但判断更容易被情绪带偏

### 17.2 场景二：调查清单

导播把调查清单弹到屏幕上。

问题 1：

```text
“第一通连线，你最先核对什么？”
A. 两人真实关系阶段
B. 转账、债务和共同财产
C. 双方父母是否介入
D. 时间线和证据链
E. 婚育史与孩子责任
```

问题 2：

```text
“你最警惕哪种隐瞒？”
A. 家境和债务
B. 外貌包装和照片差异
C. 学历与职业履历
D. 父母强势和家庭负担
E. 情绪勒索与恶人先告状
F. 婚史、孩子、短择经历
```

问题 3：

```text
“如果来访者讲得很委屈，但细节不完整？”
A. 继续听完整版本
B. 直接指出叙事漏洞
C. 要求补证据和时间线
D. 先判断利益诉求
```

这些答案生成本局调查倾向：

- 证据清晰度
- 舆论压力
- 来访者可信度
- 恶人先告状风险
- 财务 / 婚育 / 父母 / 前任等线索权重

### 17.3 场景三：连线池

孟姐：

```text
“真相通常不在一个人的嘴里。”
“现在要决定补充连线谁。”
```

连线池包括：

```text
先诉苦的来访者
被诉说的另一方
双方朋友
父母或亲戚
前任或暧昧对象
婚介顾问
律师 / 财务 / 房产中介等第三方
```

当前原型复用 6 位 NPC 作为当事人与线索对象：

```text
周砚：稳定体面型，容易牵出父母、规则和控制
林鹿：高认知叙事型，容易牵出话术、情绪和反咬
许照：资源浪漫型，容易牵出钱、房产、债务和外遇
陈默：普通踏实型，容易牵出化债、亲属借钱和自卑反击
沈知夏：理性边界型，容易牵出协议、证据和冷处理
何念：内容展示型，容易牵出人设、流量、大结果和舆论压力
```

玩家选择 3 位进入今晚的连线池。

### 17.4 场景四：三轮连线

每轮连线都要看三件事：


```text
“你们关系确认的具体时间是什么？”
“钱、房、债务、孩子、婚史里有没有没说清的部分？”
“你希望侦探局帮你争取什么结果？”
```

玩家每轮连线后选择：

```text
A. 继续听双方版本
B. 申请基础核验
C. 问后台风控意见
D. 暂停连线，整理时间线
E. 直接指出漏洞
```

### 17.5 第一章结尾：旁听席开始站队

旁听席会迅速站队：

```text
“男方太惨了吧。”
“女方明显被套路。”
“这人说话漏洞好多。”
“孩子无辜，但时间线不对。”
“先别骂，转账记录呢？”
```

玩家最终选择：

```text
A. 锁定来访者继续追问
B. 转向另一方当事人
C. 先查证据，不继续听情绪
D. 让第三方补充线索
```

第一章结束文字：

```text
侦探局给了每个人讲故事的机会。
但真相不奖励先开口的人。

你要做的不是替谁出气，
而是在情绪、利益和证据之间，
找出那条最不舒服的事实线。
```

## 18. 第二章：《不是所有温柔都免费》

第二章目标：通过三次约会和第一次压力测试，让 NPC 的隐藏底色与不良动机开始分叉。

结构：

```text
第一次：低成本日常约会
第二次：价值观约会
第三次：压力测试约会
```

### 18.1 第一次约会：低成本日常

场景：咖啡馆、便利店夜宵、公园散步、普通小馆。

目的：看 TA 在没有滤镜、没有高消费、没有红娘时的样子。

关键事件：结账。

选项：

```text
A. 主动买单
B. AA
C. 让对方决定
D. 开玩笑试探：“这顿算谁的投资？”
```

动机反馈：

- 图钱型：对玩家主动买单反应明显变热
- 图控制型：会把买单变成权力展示
- 图 KPI 型：会评价消费观是否适合结婚
- 真诚型：更关注玩家吃得开不开心

### 18.2 第二次约会：价值观

核心问题：

```text
“如果婚后双方父母都需要帮忙，你觉得应该怎么安排？”
```

选项：

```text
A. 优先小家庭，父母问题分开处理
B. 谁家急先帮谁家
C. 结婚就是两个家庭融合
D. 先说清钱和时间，不然以后一定吵
```

动机反馈：

- 图照护型：追问“那我父母和你父母能不能一样？”
- 图资源型：问“你爸妈能接受帮我们带孩子吗？”
- 图控制型：说“夫妻本来就应该统一战线。”
- 真诚型：承认这件事很难，需要慢慢商量

### 18.3 第三次约会：压力测试

系统根据 NPC 动机随机一个压力事件：

```text
图钱型：TA 临时说钱包或账户出问题，让玩家垫一笔不大不小的钱。
图家庭资源型：TA 提出想提前见玩家父母。
图外貌展示型：TA 带玩家见朋友，但明显更在意别人评价。
图生育照护型：TA 带玩家去看望父母，观察玩家是否“懂事”。
图情绪供养型：TA 深夜打电话崩溃，要求玩家立刻陪 TA。
图阶层跳板型：TA 请求玩家帮忙引荐某个人。
图避险遮羞型：TA 拒绝合理背调，表现出被冒犯。
图控制型：TA 对玩家没有及时回复消息表现出明显不满。
图 KPI 型：TA 拿出时间表：多久见父母、多久订婚、多久领证。
图内容流量型：TA 想发布两人的合照或约会内容，哪怕玩家犹豫。
```

玩家选择：

```text
A. 配合
B. 拒绝
C. 提条件
D. 转移话题
E. 直接质问
```

第二章结束文字：

```text
第一次见面，看条件。
第二次见面，看谈吐。
第三次见面，看对方在你说“不”的时候，还是不是那个人。
```

## 19. 第三章：《见父母之前》

第三章目标：玩家从相亲对象进入“准关系”阶段，开始面对双方父母、婚介业绩推进、暧昧排他、资料背调和第一次重大信任选择。

这一章的核心不是见父母，而是“见父母之前，到底要不要先把关系说清楚”。

第三章开始时，玩家已经从第一、二章中选择了一个主要推进对象，或同时观察两人。系统会根据前两章选择生成关系状态：

```text
暧昧观察：双方有好感，但未确认排他。
准恋人：双方默认排他，但没有正式谈承诺。
高压推进：婚介或父母催促见家长。
风险观望：玩家已有红色或黄色线索，但仍想继续了解。
```

### 19.1 开场：孟姐的成交电话

孟姐打来电话：

```text
“我不是催您啊。”
“但按我们的经验，第三次见面以后，如果双方还不错，就要进入下一阶段了。”
“拖太久，真诚的人会累，不真诚的人会换目标。”
```

玩家选择回应：

```text
A. 我想顺其自然
B. 可以推进，但不要太快
C. 先把关系说清楚
D. 我想先做深度背调
E. 我还想再见另一个人
```

效果：

- A：浪漫倾向上升，但婚介控制权上升
- B：稳健推进，双方父母压力稍后触发
- C：触发排他谈判事件
- D：触发背调与信任冲突
- E：触发竞争线或隐瞒线

### 19.2 事件一：排他谈判

如果玩家选择“先把关系说清楚”，进入排他谈判。

NPC 问：

```text
“所以你的意思是，我们现在算什么？”
```

玩家选项：

```text
A. 我希望从现在开始只了解彼此
B. 我还需要一点时间，但会坦诚告诉你
C. 相亲阶段同时了解很正常
D. 你先告诉我，你有没有同时见别人
```

隐藏底色反馈：

真诚型：

```text
会表达自己的边界，也能接受玩家需要时间。
```

现实私心型：

```text
如果玩家条件高，会快速答应排他；如果玩家条件普通，可能保留余地。
```

道德瑕疵型：

```text
容易模糊回答，例如“没有认真了解别人”。
```

高风险控制型：

```text
可能反问：“你连这点确定都给不了我，为什么还要继续？”
```

动机反馈：

- 图钱型：玩家财富高时更愿意排他
- 图外貌展示型：希望尽快公开关系
- 图 KPI 型：把排他视为进入订婚流程
- 图控制型：要求玩家删除婚介 App 或交代全部异性联系人
- 图内容流量型：想用官宣或合照确认关系

### 19.3 事件二：深度背调

深度背调需要付费，也会影响信任。

可查内容：

```text
婚史
债务
房产
学历
工作真实性
重大诉讼
失信记录
部分公开社交账号
```

查不出：

```text
冷暴力倾向
控制欲
真实共情力
父母真实态度
压力下是否变脸
是否会把婚姻当交易
```

玩家选择：

```text
A. 偷偷背调
B. 坦白告诉 TA 我想背调
C. 不背调，选择相信
D. 要求双方都背调
```

后果：

- A：如果被发现，信任下降；但可提前发现硬风险
- B：真诚型会不舒服但能理解；高风险型会把它说成羞辱
- C：亲密上升，风险延后
- D：边界感上升，现实型和理性型更容易接受

背调可能结果：

```text
完全一致：信任上升
小误差：黄色线索，例如收入包装、工作头衔夸大
重大不一致：红色线索，例如债务、婚史、房产归属
无法验证：继续观察
```

### 19.4 事件三：朋友局

玩家或 NPC 提出见朋友。朋友局用于观察一个人在熟人面前如何对待玩家。

场景：

- 火锅店
- 酒吧
- 桌游局
- 同事饭局
- 朋友婚礼

可观察行为：

```text
TA 是否主动介绍玩家
TA 是否尊重玩家的职业和条件
TA 是否在朋友面前开过分玩笑
TA 是否拿玩家外貌、收入、家庭当谈资
TA 是否对服务员、低位者、前任保持基本尊重
```

玩家选项：

```text
A. 大方配合，融入 TA 的圈子
B. 保持礼貌，但观察更多
C. 对不舒服的玩笑当场指出
D. 事后单独谈
E. 直接离场
```

动机反馈：

- 图外貌展示型：朋友局中明显展示玩家
- 图阶层跳板型：不断询问玩家朋友资源
- 图控制型：会评价玩家“不给面子”
- 图内容流量型：拍照、发动态、制造人设
- 真诚型：在朋友面前也会照顾玩家感受

### 19.5 事件四：父母的第一次影子

这一章不正式见父母，但父母会以电话、微信、礼物、红包、问候等方式进入关系。

触发方式：

```text
NPC 父母突然打电话
玩家父母要求看照片
红娘提出安排双方父母线上沟通
节日临近，礼物问题出现
父母询问对方房子、收入、独生子女、是否愿意生育
```

典型事件：母亲的三连问。

```text
“TA 家几套房？”
“父母身体怎么样？”
“以后孩子谁带？”
```

玩家选择：

```text
A. 如实回答
B. 报喜不报忧
C. 告诉父母别太早介入
D. 让对方自己和父母解释
E. 回避问题
```

后果：

- A：父母评估值上升，玩家压力上升
- B：短期平稳，后续爆雷概率上升
- C：边界感上升，父母不满概率上升
- D：关系压力前置，能测试 NPC 承担能力
- E：问题延后，父母私下调查概率上升

### 19.6 事件五：婚介的“成婚套餐”

良缘算法推出阶段性服务：

```text
父母见面礼仪课
婚前财产咨询
彩礼嫁妆地区行情表
婚房方案评估
订婚宴资源包
孕育与学区规划课
```

孟姐：

```text
“感情当然重要。”
“但真要结婚，钱、房、父母、孩子，哪一样不需要提前谈？”
```

玩家选择：

```text
A. 购买婚前财产咨询
B. 购买父母见面协调
C. 购买彩礼婚房行情报告
D. 拒绝购买，自己处理
E. 让 NPC 一起决定
```

后果：

- A：法律意识上升，浪漫氛围下降
- B：父母冲突降低，但婚介介入加深
- C：现实信息增加，NPC 真实动机更容易被诱发
- D：省钱，但后续谈判难度上升
- E：测试 NPC 是否愿意共同承担现实问题

### 19.7 本章压力测试：一次“不方便”的请求

第三章末尾，NPC 会根据不良动机提出一次更接近婚姻的请求。

```text
图钱型：希望玩家帮忙垫一笔“之后会还”的费用。
图家庭资源型：希望玩家安排父母或亲戚见面。
图外貌展示型：希望公开关系，或带玩家参加重要社交场合。
图生育/照护型：询问玩家婚后是否愿意和父母同住、多久要孩子。
图情绪供养型：要求玩家在工作日深夜赶来陪伴。
图阶层跳板型：要求玩家引荐资源，理由是“以后都是一家人”。
图避险/遮羞型：要求跳过背调，直接推进见父母。
图控制型：要求玩家停止同时了解其他对象，并交代近期行程。
图婚恋 KPI 型：提出明确时间表，要求一个月内见父母。
图内容/流量型：要求公开合照或把两人故事做成内容。
```

玩家选择：

```text
A. 答应
B. 拒绝
C. 答应一部分，并设置条件
D. 反问对方能为我做什么
E. 暂停关系
```

### 19.8 第三章结尾选择

玩家根据本章线索做阶段性决定：

```text
A. 确认关系，进入恋爱深水区
B. 暂不确认，但继续观察
C. 要求双方父母先不介入
D. 申请深度背调后再决定
E. 结束关系，换人或暂停婚介
```

第三章结束文字：

```text
相亲最奇怪的地方在于：
你们明明还没确认相爱，
却已经开始讨论两个家庭如何相处。

有些人害怕承诺。
有些人急着承诺。
而真正重要的，可能是：
TA 在承诺之前，有没有尊重你的犹豫。
```

## 20. 第四章：《谈婚论嫁》

第四章目标：把恋爱推进到正式婚事谈判，让彩礼、嫁妆、婚房、房本、婚礼预算、婚前协议和双方父母第一次正面冲突集中出现。NPC 如果带有初始不良动机，会在本章出现第一次重大显影。

这一章的核心不是“谈多少钱”，而是“谁在用钱表达安全感、面子、控制、补偿或逃避”。

### 20.1 开场：谈婚论嫁沟通清单

孟姐拿出《谈婚论嫁沟通清单》：

```text
彩礼
嫁妆
婚房
房本名字
贷款与装修
婚礼预算
订婚宴
婚后住哪
什么时候要孩子
双方父母介入边界
```

孟姐：

```text
“恋爱里可以说以后再看。”
“结婚前，‘以后’会坐到你们对面。”
```

玩家选择：

```text
A. 先和对象说清底线
B. 让婚介安排正式谈判
C. 私下温和推进
D. 暂缓，感觉太快了
```

### 20.2 事件一：彩礼、嫁妆与婚礼预算

第一轮谈的是彩礼、嫁妆和婚礼预算。

冲突点：

```text
彩礼是礼俗、保障、面子，还是交易？
嫁妆是小家庭启动资金，还是女方家庭态度？
婚礼是两个人的仪式，还是两家人的公开汇报？
```

玩家选择：

```text
A. 按地区行情谈，别让父母太难看
B. 彩礼象征化，把钱留给小家庭
C. 坚持高规格，婚礼必须体面
D. 先不谈数字，继续观察态度
```

隐藏反馈：

- 图钱型会特别关注现金和支出顺序
- 图家庭资源型会关注父母愿意给多少
- 图外貌展示型会关注婚礼体面程度
- 图 KPI 型会尽快把金额和日期敲死
- 真诚型会尝试把钱留给未来生活

### 20.3 事件二：婚房与房本名字

第二轮谈婚房。

冲突点：

```text
首付谁出
贷款谁还
装修谁垫
房本写谁
父母出资算赠与谁
婚后共同还贷如何记录
暂时租房是否能被双方父母接受
```

玩家选择：

```text
A. 按出资和还贷贡献写清楚
B. 为了安全感，尽量写双方名字
C. 听父母安排，毕竟他们出钱
D. 暂不买房，先租房独立生活
```

设计重点：房本选择不是单纯道德题。它同时测试玩家资产保护意识、伴侣公平感、父母控制欲和现实压力承受度。

### 20.4 事件三：双方父母第一次正式见面

场景：包间饭局。

桌上出现经典话术：

```text
“我们不是要钱，是要态度。”
“房子写谁名不重要，重要的是两个孩子过得好。”
“以后孩子谁带？”
“你们年轻人不懂，婚姻还是要听父母的。”
“我们家也不是卖女儿。”
“我们也不是娶保姆。”
```

玩家选择：

```text
A. 优先保护小家庭
B. 先安抚父母，别让场面难看
C. 当场暂停，问题太多需要整理
D. 让孟姐介入调停
```

隐藏反馈：

- 高控制型 NPC 会要求玩家站队
- 图生育/照护型会把孩子和老人照护提前打包
- 图家庭资源型会绕过玩家接近父母
- 真诚型会尽量和玩家共同面对父母

### 20.5 事件四：婚前财产协议

婚前财产咨询室里，律师提醒：

```text
感情归感情。
房产、债务、赠与、共同还贷、婚礼支出，最好不要靠记忆保存。
```

玩家选择：

```text
A. 双方都签清楚，保护彼此
B. 不签，谈协议太伤感情
C. 找独立律师再看一遍
D. 先订婚，协议以后再补
```

隐藏反馈：

- 真诚型可能不舒服，但能理解
- 图钱型会反感过于清晰的财产边界
- 图避险/遮羞型会要求跳过细节
- 高风险控制型会把协议说成“不信任”
- 理性型 NPC 会因此好感上升或压力下降

### 20.6 本章压力测试：第一次重大动机显影

如果 NPC 有初始不良动机，本章会出现第一次重大显影。

```text
图钱型：希望玩家先承担装修和婚礼定金。
图家庭资源型：绕过玩家联系父母，试探户口、人脉、学区。
图外貌展示型：把订婚宴当成社交亮相。
图生育/照护型：要求婚后同住、三年内生育、照顾老人。
图情绪供养型：用崩溃和卖惨阻止玩家谈条件。
图阶层跳板型：把订婚宴名单变成资源名单。
图避险/遮羞型：要求先订婚，背调和债务以后再说。
图控制型：要求婚后工资、社交、节假日安排统一管理。
图婚恋 KPI 型：拿出明确订婚、领证、备孕时间表。
图内容/流量型：把订婚、婚礼、父母见面设计成内容。
```

玩家选择：

```text
A. 接受，现实婚姻总要妥协
B. 继续，但必须写清条件
C. 当面质问真实动机
D. 暂停或结束这段关系
```

### 20.7 第四章结尾

第四章可能进入三种状态：

```text
订婚观察期：规则基本谈清，感情仍可推进。
高压推进期：婚事继续，但大量问题被暂时压住。
关系暂停期：玩家发现重大风险，选择暂停或退出。
```

第四章结束文字：

```text
谈婚论嫁不是爱情的反面。
它只是把爱情里所有没说出口的东西，
换成了数字、名字、日期和座次。
```

## 21. 第五章：《婚礼战役》

第五章目标：订婚后，婚礼筹备把关系推到新的压力峰值。婚礼不只是仪式，而是预算、面子、亲戚、前任、公开承诺和双方父母权力的集中爆发。

### 21.1 开场：婚礼待办清单

婚礼事项：

```text
酒店档期
司仪与摄影
伴郎伴娘
婚车
座次
份子钱
朋友圈官宣
婚礼视频
父母致辞
敬酒流程
```

孟姐：

```text
“婚礼最难的不是办得漂亮。”
“是办完以后，两个人还愿意一起回家。”
```

玩家选择：

```text
A. 小型婚礼，优先保住预算和边界
B. 体面大办，不能让双方父母丢脸
C. 让父母主导，他们更懂礼数
D. 先和对象私下定共同原则
```

### 21.2 事件一：宾客名单与座次表

冲突点：

```text
哪些亲戚必须请？
领导和客户要不要请？
前任或暧昧对象是否会出现？
父母的朋友是否占用年轻人的预算？
座次是否体现双方家庭地位？
```

玩家选择：

```text
A. 制定规则：只请真正亲近的人
B. 照顾面子，重要关系都安排上
C. 砍掉超预算名单
D. 交给婚介和婚庆协调
```

### 21.3 事件二：预算失控

婚庆报价升级：

```text
摄影升级
灯光升级
甜品台升级
婚车升级
敬酒服升级
伴手礼升级
```

玩家选择：

```text
A. 费用写清楚，双方按能力分担
B. 先借钱办，婚后慢慢还
C. 降级方案，不为一天掏空几年
D. 要求对象一起面对父母
```

### 21.4 事件三：前任消息

婚礼前两周，玩家收到陌生消息：

```text
“你真的了解 TA 吗？”
“有些事，不该等到婚礼当天才知道。”
```

玩家选择：

```text
A. 直接问清楚
B. 不理会，婚前有人搅局很正常
C. 暂停流程，核实来源和内容
D. 延期婚礼，先处理信任问题
```

隐藏反馈：

- 道德瑕疵型可能暴露前任未断、债务或婚史问题
- 高风险控制型会反咬玩家“不信任”
- 真诚型会不舒服，但愿意解释和核实

### 21.5 事件四：婚礼前夜

婚礼前夜，所有未解决问题都会变得具体。

动机显影：

```text
图钱：计算礼金和回本
图家庭资源：宾客名单变成资源地图
图外貌展示：婚礼成为公开展示
图生育/照护：亲戚提前讨论孩子和老人
图情绪供养：要求玩家先安抚 TA
图阶层跳板：索要引荐机会
图避险/遮羞：要求玩家别再查
图控制感：要求玩家按流程和话术走
图婚恋 KPI：婚礼、领证、备孕不可更改
图内容/流量：婚礼被做成内容项目
```

玩家选择：

```text
A. 继续婚礼，明天以后再说
B. 继续，但把关键条件写下来
C. 延期婚礼，先把问题处理完
D. 取消婚礼，承受代价也要止损
```

### 21.6 第五章结尾

第五章可能进入：

```text
领证婚礼线：婚礼继续，关系进入婚后第一年
延期婚礼线：关系保留，但信任重建
取消婚礼线：重大止损，进入分手或换人路线
高压婚姻线：问题被压住，婚后集中爆发
```

第五章结束文字：

```text
婚礼像一面放大的镜子。
它照见爱情，也照见账单、亲戚、旧事和没说出口的控制。
```

## 22. 第六章：《婚后第一年》

第六章目标：婚礼后的第一年，玩家从仪式进入共同生活。此前压住的问题会以工资卡、家务、春节、父母探访、生育安排和第一次婚后大吵的形式重新出现。

### 22.1 开场：共同生活开始

婚礼过去一个月，鲜花撤掉，滤镜消失。

核心议题：

```text
工资卡
共同账户
私人账户
家务分配
春节去哪家
父母探访
亲密频率
备孕或避孕
第一次婚后危机
```

玩家选择：

```text
A. 共同账户写清规则，各自保留私人账户
B. 工资放一起，先建立一家人的感觉
C. 让父母帮忙规划大额支出
D. 经济先分开，磨合后再谈
```

### 22.2 事件一：家务分配

家务不是小事。它只是太日常，所以更容易被装作没发生。

玩家选择：

```text
A. 列清家务表，谁空谁做不再靠默契
B. 先自然磨合，别太像合租
C. 能外包就外包，用钱换时间
D. 先忍一忍，别刚结婚就吵
```

隐藏反馈：

- 图生育/照护型会默认玩家承担更多
- 图情绪供养型会把家务矛盾转成自己压力大
- 图控制型会用“已婚人士自觉”要求报备和服从
- 真诚型会承认分工不公平并尝试调整

### 22.3 事件二：第一个春节

两边父母都说“你们自己决定”，但每个人都在等答案。

玩家选择：

```text
A. 提前约定轮流，一年一家
B. 今年先去 TA 家，稳住局面
C. 今年回自己家，别委屈父母
D. 两边都不去，旅行过年
```

### 22.4 事件三：父母探访

父母第一次来小家住三天。

冲突点：

```text
冰箱被重新整理
沙发套被换掉
厨房习惯被改变
父母评价家务
父母评价消费
父母评价备孕
```

玩家选择：

```text
A. 定探访规则，住几天、做什么都说清楚
B. 热情接待，老人不容易
C. 要求伴侣出面沟通
D. 如果边界失守，就考虑搬出去
```

### 22.5 事件四：亲密与生育安排

婚后第八个月，孩子议题开始出现。

玩家选择：

```text
A. 先谈职业、身体、钱和谁带娃
B. 顺其自然，有了就要
C. 明确暂缓，至少等关系稳定
D. 回避这个话题，太容易吵
```

### 22.6 事件五：第一次婚后危机

争吵表面上是家务、钱、父母和孩子。真正吵的可能是：

```text
谁的生活被默认牺牲
谁的父母拥有更多发言权
谁的钱更像共同财产
谁的时间更容易被占用
谁的委屈更不被看见
```

玩家选择：

```text
A. 坐下来复盘，重新分工和修复关系
B. 冷处理，等情绪过去
C. 让父母评理
D. 短暂分居，先保住自己
```

### 22.7 第六章结尾

第六章可能进入：

```text
磨合稳定线：问题仍在，但双方愿意修复
家内高压线：婚姻继续，但日常压力持续累积
父母介入线：两家人开始深度参与小家庭
短暂分居线：关系暂停，玩家保住边界
```

第六章结束文字：

```text
婚礼是一日，婚姻是每天。
真正消耗人的，往往不是大事，
而是那些被说成“小事”的重复劳动、重复让步和重复沉默。
```

## 23. 第七章：《买房与债务》

第七章目标：婚后第二年，房子和债务进入小家庭。玩家要在租房、二手房、期房、父母出资、月供压力、装修贷、收入冲击、亲属借钱和共同债务风险中做选择。

### 23.1 开场：真正属于自己的家

核心议题：

```text
继续租房
二手房
期房
首付
共同还贷
装修
父母出资
月供压力
征信和旧债
共同债务边界
```

玩家选择：

```text
A. 继续租房，先保住现金流和自由
B. 买二手房，贵一点但看得见
C. 买期房，赌未来交付和升值
D. 听父母建议，他们出一部分首付
```

```text
首付谁出
```

玩家选择：

### 23.5 事件四：交付、装修或涨租风险


### 23.6 事件五：共同债务谈判

```text
谁承担未来十年的风险
谁的旧债会不会变成共同风险
```

```text
共同风控线：房子成为项目，而不是爱情证明

父母入场线：父母出资换取更多话语权
```

## 25. 结局类型

```text
真爱但贫穷：感情高，经济低，孩子入学困难但家庭稳定。
体面婚姻：外人羡慕，内部低温，十年后像合伙人。
离婚重启：关系失败，但玩家保住自尊、资产或抚养权。
鸡娃同盟：夫妻感情一般，但共同投入孩子教育。
阶层跃迁：通过婚姻、事业或房产改变命运，但代价很高。
反婚结局：玩家在第十年选择不进入婚姻，成为旁观其他 NPC 婚姻的人。
隐藏真结局：边界感、共同决策、冲突修复三项达标。
```

## 26. 设计原则

- 好感度不等于安全
- 条件不是道德
- 真诚型 NPC 也会有缺点
- 有瑕疵的 NPC 不一定不可发展，但必须付出代价
- 高风险控制型不应被浪漫化
- 玩家不是靠攻略判断人，而是靠连续行为、压力测试和边界反馈判断人
- 婚姻不是单人选择，而是两个人、两组家庭、资产、债务、身体和时间共同构成的系统
