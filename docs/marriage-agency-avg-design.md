# 《中国式婚恋：十年一梦》初始设定文档

## 1. 项目定位

《中国式婚恋：十年一梦》是一款中国式恋爱、相亲、结婚、生子主题的日式文字对话类游戏。游戏主舞台是一家婚姻中介公司，玩家以不同性别和属性进入婚恋市场，通过相亲、恋爱、谈婚论嫁、婚后磨合、育儿与孩子上学等长期事件，走到婚姻第十年。

游戏重点不是“攻略一个完美对象”，而是在信息不完整、条件被包装、动机不透明的婚恋市场中，判断一个不完美的人是否值得共同承担十年。

核心体验：

- 婚恋市场模拟
- 关系悬疑
- 长期婚姻经营
- 双方父母博弈
- 彩礼、婚房、婚礼、育儿、学区、债务等现实议题
- 同一个 NPC 在不同周目可能有不同真实底色和不良动机

## 2. 世界观背景

游戏主舞台是婚姻中介公司：

**良缘算法婚恋咨询有限公司**

公司表面上提供正规婚恋服务：

- 线下相亲
- 背景审核
- 情感咨询
- 婚前财产咨询
- 双方父母见面协调
- 婚礼资源对接
- 育儿、学区和家庭规划课程

公司真实运作逻辑更接近婚恋市场的切片：

- 客户资料真假混杂
- 红娘有业绩压力
- 父母会偷偷加钱改匹配条件
- NPC 会隐藏婚史、债务、真实动机或人格问题
- 算法给每个人定价，而不是理解每个人

玩家每个周目都是这家婚介公司的客户。婚介公司不是中立的，它会根据玩家条件把玩家放入不同客户池，例如普通客户池、高净值客户池、催婚客户池、展示型客户池、风险客户池等。

## 2.1 视觉与音效模板

当前原型从纯文字升级为类似橙光的互动视觉小说模板。

基础界面结构：

```text
场景背景
人物立绘
底部对话框
说话人名牌
选择按钮
右侧状态面板
音效开关
```

当前没有语音，只有音效。

音效类型：

```text
click：普通点击
confirm：推进章节、确认选择、结算
warning：禁用按钮或风险提示
page：预留翻页音
```

素材结构：

```text
assets/characters/     人物立绘占位 SVG
src/sound.js           WebAudio 音效系统
src/styles.css         VN 舞台、背景、立绘和对话框样式
```

当前立绘为可替换占位资源。后续正式美术可以直接替换为同名 PNG/WebP，或在代码中更新 `CHARACTER_ART` 映射。

## 3. 开局角色创建

公开首版玩家默认进入男主线。女主线会作为后续大版本单独设计，不沿用男主线候选人、问题库和选择体系。

长期版本中，玩家开局可以选择性别：

- 男
- 女

然后获得 25 点基础机动点数，自由分配到五项属性。后续周目结算会提供额外永久机动点：

```text
个人财富：0-10
家庭背景：0-10
外貌：0-10
学历：0-10
情商：0-10
```

每项满分 10，初始总和必须等于当前可用机动点。第一周目为 25 点，后续周目会随着经验累积提高。

### 3.1 属性含义

**个人财富**

代表当前可支配资产、收入、存款、车房能力。影响彩礼、嫁妆、约会消费、婚介会员等级、房贷压力，以及是否吸引图钱型 NPC。

**家庭背景**

代表父母资源、城市户口、家庭稳定度、亲戚网络、父母能否出钱出力。影响双方父母态度、婚房支持、孩子上学、老人介入强度。

**外貌**

代表第一印象、性吸引力、社交展示价值、被包装价值。影响初见好感、相亲成功率、朋友圈和短视频事件，也会提高被物化风险。

**学历**

代表教育资本、职业上限、沟通方式、信息判断能力。影响识别骗局、法律意识、职业发展、与高学历 NPC 的共同话题。

**情商**

代表情绪理解、话术识别、冲突沟通和读人能力。影响玩家对 NPC 的魅力值、部分线索是否提前显现、判断对方说话真假和真实动机的能力。情商不是读心术，高情商只能提高识别概率，不能保证永不被骗。

### 3.2 属性段位

```text
0-2：明显短板
3-4：偏弱
5：普通
6-7：优势
8-9：强优势
10：顶配标签
```

强属性不是纯优势：

- 财富高更容易吸引图钱型、资源型对象
- 家庭背景高更容易触发双方父母博弈
- 外貌高更容易被展示化、物化或猎艳
- 学历高更容易识破风险，但也可能被评价“太理性”“不好拿捏”

### 3.3 开局系统评价

分配完成后，系统生成三份评价：

1. 公开资料卡：婚介展示给 NPC 的版本
2. 红娘内部评估：公司如何给玩家定价
3. 隐藏风险画像：玩家容易吸引哪类人

示例：

```text
性别：女
财富 2 / 家庭 3 / 外貌 9 / 学历 6

公开资料：
“形象气质佳，本科以上学历，性格独立，期待稳定关系。”

红娘内部：
“高展示价值，经济承压，中高净值男性转化率高。”

隐藏风险：
更容易吸引控制型、猎艳型、资源交换型 NPC。
```

### 3.5 肉鸽周目成长

本作的核心结构是婚恋肉鸽。每个周目的 NPC 底色、动机、案例因素和爆发节奏都带有随机性。

每次周目结算后，玩家会获得 2-3 点永久机动点。下一周目创建角色时，可用总点数会增加。

规则：

```text
基础机动点：20
每周目结算：+2 或 +3
永久经验点上限：当前原型为 +24
每项属性上限：10
```

经验点象征玩家经历后的成长，不是单纯数值膨胀。

它代表：

```text
更清楚自己的底线
更熟悉婚恋市场话术
更能识别不舒服的细节
更懂得保护资产和边界
更知道什么时候该继续，什么时候该止损
```

周目经验不会消除随机性，只会让玩家更有能力面对随机性。

## 4. 性别差异反馈

同样属性在男女主身上会获得不同社会反馈。

男主财富低：更容易被质疑“没能力结婚”。

女主财富低：更容易被怀疑“是否图钱”。

男主外貌高：初期加分，但长期仍会被财富和家庭拷问。

女主外貌高：初期优势更明显，但被物化和控制风险更高。

男主学历高：更容易被视为潜力股。

女主学历高：部分 NPC 和父母会觉得“太强势”。

男主家庭高：父母更可能插手房本和彩礼。

女主家庭高：父母更可能审查男方条件和生育安排。

## 5. 婚介匹配系统

婚介公司给玩家生成隐藏婚恋市场画像。

基础推荐等级可以使用：

```text
婚介推荐等级 = 财富 * 0.35 + 家庭 * 0.30 + 外貌 * 0.20 + 学历 * 0.15
```

每个 NPC 对玩家会有三项初始判断：

```text
吸引值：我想不想见 TA
利用值：TA 能不能解决我的问题
风险值：TA 会不会不好拿捏
```

建议公式：

```text
吸引值 = 外貌 * NPC审美权重 + 学历 * 话题权重 + 财富 * 安全感权重
利用值 = 财富 * 图钱权重 + 家庭 * 资源权重 + 外貌 * 展示权重 + 学历 * 跳板权重
风险值 = 学历 * 识破能力 + 家庭 * 保护能力 + 财富 * 退出能力
```

高条件会提高优质匹配概率，也会提高被包装、被计算、被利用的概率。

## 6. NPC 隐藏底色随机

每个新周目开始时，6 个相亲对象会随机生成隐藏底色。

建议概率：

```text
真诚型：50%
现实私心型：25%
道德瑕疵型：15%
高风险控制型：10%
```

系统保底：

```text
每周目至少 3 个 NPC 可以正常发展
每周目至少 1 个 NPC 有明显私心
每周目最多 1 个 NPC 是高风险控制型
```

### 6.1 真诚型

真想进入关系，不代表完美。可能穷、妈宝、逃避、焦虑、事业不稳，但愿意沟通和修复。

行为特征：

- 前后说法基本一致
- 遇到冲突会解释
- 不会强迫玩家快速承诺
- 愿意承担一部分代价

### 6.2 现实私心型

不是纯粹坏人，但结婚目的不纯。

可能目的：

- 解决房子
- 解决户口
- 完成父母任务
- 找人一起还贷
- 找人带娃
- 找阶层跳板
- 找情绪保姆

行为特征：

- 对玩家某项属性特别敏感
- 关系推进快
- 回避自己的短板
- 谈钱谈责任时含糊

### 6.3 道德瑕疵型

存在隐瞒、骑驴找马、前任未断、债务包装、婚史模糊等问题。

行为特征：

- 资料里有小漏洞
- 手机消息频繁
- 对前任问题反应过激
- 遇到核实时转移话题

### 6.4 高风险控制型

不直接写医学诊断，而表现为高控制、高索取、低共情、擅长反咬。

行为特征：

- 初期极度完美
- 快速制造灵魂伴侣感
- 让玩家和朋友家人疏远
- 把边界说成“不够爱”
- 犯错后让玩家内疚

## 7. 初始不良动机随机

如果 NPC 被抽到现实私心型、道德瑕疵型或高风险控制型，就继续抽取初始不良动机。

这让“有问题的 NPC”不是简单坏，而是带着具体目的进入婚恋市场。

### 7.1 不良动机池

**图钱**

看中玩家财富、房产、消费能力。常见行为：主动推进同居、催共同账户、暗示大额礼物、回避 AA。

**图家庭资源**

看中玩家父母、户口、人脉、学区、编制、家族生意。常见行为：很早接近玩家父母，绕过玩家谈条件。

**图外貌展示**

想要一个“拿得出手”的伴侣。常见行为：频繁拍照、公开秀恩爱、在朋友面前塑造完美情侣。

**图生育/照护**

想找人生孩子、照顾父母、做家务、承担家庭隐性劳动。常见行为：很早聊孩子、父母养老、婚后谁辞职。

**图情绪供养**

需要长期被安抚。常见行为：前期卖惨，后期把所有压力倾倒给玩家。

**图阶层跳板**

想借婚姻进入更高圈层。常见行为：对玩家资源圈异常感兴趣，常问“能不能介绍”。

**图避险/遮羞**

有债务、婚史、前任、家庭问题，希望尽快结婚掩盖。常见行为：催进度、害怕背调、对过去含糊。

**图控制感**

享受让伴侣围着自己转。常见行为：初期完美，后期孤立玩家、贬低玩家、制造内疚。

**图婚恋 KPI**

不爱谁，只是年龄到了、父母催了、同事都结了。常见行为：流程感强，像在完成项目。

**图内容/流量**

把恋爱、婚礼、怀孕、育儿当素材。常见行为：任何情绪都想记录，隐私边界模糊。

### 7.3 动机暴露机制

每个不良动机都有 3 次暴露机会：

```text
轻微信号：让玩家觉得哪里不舒服
明确冲突：玩家可以质问
重大爆雷：进入关系后造成实质损失
```

例：图钱

- 轻微信号：TA 总是忘记转账，但记得玩家收入很高
- 明确冲突：TA 希望玩家先垫婚房装修款，说以后都是一家人
- 重大爆雷：婚后发现 TA 婚前债务被包装成创业亏损

例：图控制感

- 轻微信号：TA 说玩家的朋友不太靠谱
- 明确冲突：TA 要求玩家报备行程，否则就是不尊重关系
- 重大爆雷：玩家发现自己已经很久没有单独见朋友和家人

## 8. 案例事件引擎

为了让后续新增真实感案例时不用硬写进某一章，游戏使用“案例事件引擎”结构。

一个案例不是一整段剧情，而是被拆成若干阶段因素，也就是 `factor`。每个因素标注自己应该进入哪个阶段、影响哪些变量、展示什么文本。

阶段枚举：

```text
screening：婚介初筛
dating：约会观察
preParents：见父母之前
marriageTalk：谈婚论嫁
wedding：婚礼战役
firstYear：婚后第一年
child：孩子上学
```

案例结构示例：

```js
{
  id: "house-parent-funded",
  title: "婚房父母出资与房本名字",
  motiveHints: ["familyResource", "money", "control"],
  factors: [
    {
      stage: "preParents",
      type: "property",
      line: "TA 的父母很早开始问房子首付、贷款和房本名字。",
      internalDelta: 6,
      motiveDelta: 8,
      flags: { parentConflict: 1 }
    },
    {
      stage: "marriageTalk",
      type: "property",
      line: "房本名字被说成安全感，也被说成不信任。",
      internalDelta: 10,
      motiveDelta: 12,
      flags: { assetProtection: 1, parentConflict: 1 }
    }
  ]
}
```

当前代码位置：

```text
src/caseEngine.js
```

新增案例时，只需要加入一个案例对象，并为它拆出不同阶段的 `factors`。系统会根据 NPC 的隐藏动机、隐藏底色和玩家属性，把案例因素分配给合适的 NPC，并在对应章节触发。

## 9. 双爆发值系统

每个 NPC 除了隐藏底色和初始不良动机，还拥有两个隐藏变量。

### 9.1 内在因素爆发值

用途：决定“蛮横”“控制”“冷暴力”“过激反应”“强行站队”等行为的爆发概率。

规则：

```text
internalBurst < 20：视为 0，不触发爆发概率
internalBurst >= 20：开始计算爆发概率
internalBurst 越高，越容易在压力事件中失态
```

它不等于坏人值。真诚型 NPC 也可能在压力下短暂失态，但区别在于事后是否能承认和修复。

初始范围建议：

```text
真诚型：0-16
现实私心型：12-36
道德瑕疵型：18-48
高风险控制型：48-76
```

案例因素、玩家拒绝、父母冲突、财产谈判都会让它累积。

### 9.2 动机爆发值

用途：决定 NPC 不单纯婚恋目的是否会摊牌、行动或明显显形。

规则：

```text
motiveBurst < 70：真实目的不直接摊牌
motiveBurst >= 70：开始以一定概率摊牌或采取行动
```

如果 NPC 是真诚型，没有不良动机，则动机爆发值通常很低。它可能表现为真实恐惧或压力表达，而不是算计摊牌。

初始范围建议：

```text
真诚型：0-16
现实私心型：34-58
道德瑕疵型：42-66
高风险控制型：48-70
```

动机爆发后可能出现：

```text
图钱：要求垫钱、共同账户、提前承担装修婚礼费用
图家庭资源：绕过玩家接触父母或资源圈
图外貌展示：强行公开、展示、包装人设
图生育/照护：提出同住、备孕、照顾老人安排
图情绪供养：用崩溃阻止玩家谈条件
图阶层跳板：索要引荐和资源
图避险/遮羞：要求跳过背调或先订婚
图控制感：要求报备、站队、统一管理
图婚恋 KPI：拿出订婚领证备孕时间表
图内容/流量：把关系和家庭隐私做成内容
```

### 9.3 爆发值与案例因素的关系

每个案例因素可以增加：

```text
internalDelta：内在因素爆发值增量
motiveDelta：动机爆发值增量
flags：外部状态增量，如 parentConflict、assetProtection、suspicion
```

这让案例不是单纯文本，而是能改变 NPC 后续行为概率的事件因子。

## 12. 第一章：《你的条件很好，只是需要包装》

第一章目标：让玩家意识到婚介公司展示的不是爱情，而是被包装后的条件。

开场黑屏文字：

```text

人生不是没有选项。
是每个选项都像在催你签字。
```

### 12.1 场景一：婚介面谈

效果：

- A：边界感 +1，真诚型 NPC 初始好感略升
- B：婚介推荐等级 +1，私心型 NPC 注意力上升
- C：短期吸引上升，后续信任危机概率上升
- D：红娘控制权上升，后续被安排高成交对象概率上升

## 13. 第二章：《不是所有温柔都免费》

第二章目标：通过三次约会和第一次压力测试，让 NPC 的隐藏底色与不良动机开始分叉。

结构：

```text
第一次：低成本日常约会
第二次：价值观约会
第三次：压力测试约会
```

### 13.1 第一次约会：低成本日常

场景：咖啡馆、便利店夜宵、公园散步、普通小馆。

目的：看 TA 在没有滤镜、没有高消费、没有红娘时的样子。

关键事件：结账。

选项：

```text
A. 主动买单
B. AA
C. 让对方决定
D. 开玩笑试探：“这顿算谁的投资？”
```

动机反馈：

- 图钱型：对玩家主动买单反应明显变热
- 图控制型：会把买单变成权力展示
- 图 KPI 型：会评价消费观是否适合结婚
- 真诚型：更关注玩家吃得开不开心

### 13.2 第二次约会：价值观

核心问题：

```text
“如果婚后双方父母都需要帮忙，你觉得应该怎么安排？”
```

选项：

```text
A. 优先小家庭，父母问题分开处理
B. 谁家急先帮谁家
C. 结婚就是两个家庭融合
D. 先说清钱和时间，不然以后一定吵
```

动机反馈：

- 图照护型：追问“那我父母和你父母能不能一样？”
- 图资源型：问“你爸妈能接受帮我们带孩子吗？”
- 图控制型：说“夫妻本来就应该统一战线。”
- 真诚型：承认这件事很难，需要慢慢商量

### 13.3 第三次约会：压力测试

系统根据 NPC 动机随机一个压力事件：

```text
图钱型：TA 临时说钱包或账户出问题，让玩家垫一笔不大不小的钱。
图家庭资源型：TA 提出想提前见玩家父母。
图外貌展示型：TA 带玩家见朋友，但明显更在意别人评价。
图生育照护型：TA 带玩家去看望父母，观察玩家是否“懂事”。
图情绪供养型：TA 深夜打电话崩溃，要求玩家立刻陪 TA。
图阶层跳板型：TA 请求玩家帮忙引荐某个人。
图避险遮羞型：TA 拒绝合理背调，表现出被冒犯。
图控制型：TA 对玩家没有及时回复消息表现出明显不满。
图 KPI 型：TA 拿出时间表：多久见父母、多久订婚、多久领证。
图内容流量型：TA 想发布两人的合照或约会内容，哪怕玩家犹豫。
```

玩家选择：

```text
A. 配合
B. 拒绝
C. 提条件
D. 转移话题
E. 直接质问
```

第二章结束文字：

```text
第一次见面，看条件。
第二次见面，看谈吐。
第三次见面，看对方在你说“不”的时候，还是不是那个人。
```

## 14. 第三章：《见父母之前》

第三章目标：玩家从相亲对象进入“准关系”阶段，开始面对双方父母、婚介业绩推进、暧昧排他、资料背调和第一次重大信任选择。

这一章的核心不是见父母，而是“见父母之前，到底要不要先把关系说清楚”。

第三章开始时，玩家已经从第一、二章中选择了一个主要推进对象，或同时观察两人。系统会根据前两章选择生成关系状态：

```text
暧昧观察：双方有好感，但未确认排他。
准恋人：双方默认排他，但没有正式谈承诺。
高压推进：婚介或父母催促见家长。
风险观望：玩家已有红色或黄色线索，但仍想继续了解。
```

### 14.1 开场：孟姐的成交电话

孟姐打来电话：

```text
“我不是催您啊。”
“但按我们的经验，第三次见面以后，如果双方还不错，就要进入下一阶段了。”
“拖太久，真诚的人会累，不真诚的人会换目标。”
```

玩家选择回应：

```text
A. 我想顺其自然
B. 可以推进，但不要太快
C. 先把关系说清楚
D. 我想先做深度背调
E. 我还想再见另一个人
```

效果：

- A：浪漫倾向上升，但婚介控制权上升
- B：稳健推进，双方父母压力稍后触发
- C：触发排他谈判事件
- D：触发背调与信任冲突
- E：触发竞争线或隐瞒线

### 14.2 事件一：排他谈判

如果玩家选择“先把关系说清楚”，进入排他谈判。

NPC 问：

```text
“所以你的意思是，我们现在算什么？”
```

玩家选项：

```text
A. 我希望从现在开始只了解彼此
B. 我还需要一点时间，但会坦诚告诉你
C. 相亲阶段同时了解很正常
D. 你先告诉我，你有没有同时见别人
```

隐藏底色反馈：

真诚型：

```text
会表达自己的边界，也能接受玩家需要时间。
```

现实私心型：

```text
如果玩家条件高，会快速答应排他；如果玩家条件普通，可能保留余地。
```

道德瑕疵型：

```text
容易模糊回答，例如“没有认真了解别人”。
```

高风险控制型：

```text
可能反问：“你连这点确定都给不了我，为什么还要继续？”
```

动机反馈：

- 图钱型：玩家财富高时更愿意排他
- 图外貌展示型：希望尽快公开关系
- 图 KPI 型：把排他视为进入订婚流程
- 图控制型：要求玩家删除婚介 App 或交代全部异性联系人
- 图内容流量型：想用官宣或合照确认关系

### 14.3 事件二：深度背调

深度背调需要付费，也会影响信任。

可查内容：

```text
婚史
债务
房产
学历
工作真实性
重大诉讼
失信记录
部分公开社交账号
```

查不出：

```text
冷暴力倾向
控制欲
真实共情力
父母真实态度
压力下是否变脸
是否会把婚姻当交易
```

玩家选择：

```text
A. 偷偷背调
B. 坦白告诉 TA 我想背调
C. 不背调，选择相信
D. 要求双方都背调
```

后果：

- A：如果被发现，信任下降；但可提前发现硬风险
- B：真诚型会不舒服但能理解；高风险型会把它说成羞辱
- C：亲密上升，风险延后
- D：边界感上升，现实型和理性型更容易接受

背调可能结果：

```text
完全一致：信任上升
小误差：黄色线索，例如收入包装、工作头衔夸大
重大不一致：红色线索，例如债务、婚史、房产归属
无法验证：继续观察
```

### 14.4 事件三：朋友局

玩家或 NPC 提出见朋友。朋友局用于观察一个人在熟人面前如何对待玩家。

场景：

- 火锅店
- 酒吧
- 桌游局
- 同事饭局
- 朋友婚礼

可观察行为：

```text
TA 是否主动介绍玩家
TA 是否尊重玩家的职业和条件
TA 是否在朋友面前开过分玩笑
TA 是否拿玩家外貌、收入、家庭当谈资
TA 是否对服务员、低位者、前任保持基本尊重
```

玩家选项：

```text
A. 大方配合，融入 TA 的圈子
B. 保持礼貌，但观察更多
C. 对不舒服的玩笑当场指出
D. 事后单独谈
E. 直接离场
```

动机反馈：

- 图外貌展示型：朋友局中明显展示玩家
- 图阶层跳板型：不断询问玩家朋友资源
- 图控制型：会评价玩家“不给面子”
- 图内容流量型：拍照、发动态、制造人设
- 真诚型：在朋友面前也会照顾玩家感受

### 14.5 事件四：父母的第一次影子

这一章不正式见父母，但父母会以电话、微信、礼物、红包、问候等方式进入关系。

触发方式：

```text
NPC 父母突然打电话
玩家父母要求看照片
红娘提出安排双方父母线上沟通
节日临近，礼物问题出现
父母询问对方房子、收入、独生子女、是否愿意生育
```

典型事件：母亲的三连问。

```text
“TA 家几套房？”
“父母身体怎么样？”
“以后孩子谁带？”
```

玩家选择：

```text
A. 如实回答
B. 报喜不报忧
C. 告诉父母别太早介入
D. 让对方自己和父母解释
E. 回避问题
```

后果：

- A：父母评估值上升，玩家压力上升
- B：短期平稳，后续爆雷概率上升
- C：边界感上升，父母不满概率上升
- D：关系压力前置，能测试 NPC 承担能力
- E：问题延后，父母私下调查概率上升

### 14.6 事件五：婚介的“成婚套餐”

良缘算法推出阶段性服务：

```text
父母见面礼仪课
婚前财产咨询
彩礼嫁妆地区行情表
婚房方案评估
订婚宴资源包
孕育与学区规划课
```

孟姐：

```text
“感情当然重要。”
“但真要结婚，钱、房、父母、孩子，哪一样不需要提前谈？”
```

玩家选择：

```text
A. 购买婚前财产咨询
B. 购买父母见面协调
C. 购买彩礼婚房行情报告
D. 拒绝购买，自己处理
E. 让 NPC 一起决定
```

后果：

- A：法律意识上升，浪漫氛围下降
- B：父母冲突降低，但婚介介入加深
- C：现实信息增加，NPC 真实动机更容易被诱发
- D：省钱，但后续谈判难度上升
- E：测试 NPC 是否愿意共同承担现实问题

### 14.7 本章压力测试：一次“不方便”的请求

第三章末尾，NPC 会根据不良动机提出一次更接近婚姻的请求。

```text
图钱型：希望玩家帮忙垫一笔“之后会还”的费用。
图家庭资源型：希望玩家安排父母或亲戚见面。
图外貌展示型：希望公开关系，或带玩家参加重要社交场合。
图生育/照护型：询问玩家婚后是否愿意和父母同住、多久要孩子。
图情绪供养型：要求玩家在工作日深夜赶来陪伴。
图阶层跳板型：要求玩家引荐资源，理由是“以后都是一家人”。
图避险/遮羞型：要求跳过背调，直接推进见父母。
图控制型：要求玩家停止同时了解其他对象，并交代近期行程。
图婚恋 KPI 型：提出明确时间表，要求一个月内见父母。
图内容/流量型：要求公开合照或把两人故事做成内容。
```

玩家选择：

```text
A. 答应
B. 拒绝
C. 答应一部分，并设置条件
D. 反问对方能为我做什么
E. 暂停关系
```

### 14.8 第三章结尾选择

玩家根据本章线索做阶段性决定：

```text
A. 确认关系，进入恋爱深水区
B. 暂不确认，但继续观察
C. 要求双方父母先不介入
D. 申请深度背调后再决定
E. 结束关系，换人或暂停婚介
```

第三章结束文字：

```text
相亲最奇怪的地方在于：
你们明明还没确认相爱，
却已经开始讨论两个家庭如何相处。

有些人害怕承诺。
有些人急着承诺。
而真正重要的，可能是：
TA 在承诺之前，有没有尊重你的犹豫。
```

## 15. 第四章：《谈婚论嫁》

第四章目标：把恋爱推进到正式婚事谈判，让彩礼、嫁妆、婚房、房本、婚礼预算、婚前协议和双方父母第一次正面冲突集中出现。NPC 如果带有初始不良动机，会在本章出现第一次重大显影。

这一章的核心不是“谈多少钱”，而是“谁在用钱表达安全感、面子、控制、补偿或逃避”。

### 15.1 开场：谈婚论嫁沟通清单

孟姐拿出《谈婚论嫁沟通清单》：

```text
彩礼
嫁妆
婚房
房本名字
贷款与装修
婚礼预算
订婚宴
婚后住哪
什么时候要孩子
双方父母介入边界
```

孟姐：

```text
“恋爱里可以说以后再看。”
“结婚前，‘以后’会坐到你们对面。”
```

玩家选择：

```text
A. 先和对象说清底线
B. 让婚介安排正式谈判
C. 私下温和推进
D. 暂缓，感觉太快了
```

### 15.2 事件一：彩礼、嫁妆与婚礼预算

第一轮谈的是彩礼、嫁妆和婚礼预算。

冲突点：

```text
彩礼是礼俗、保障、面子，还是交易？
嫁妆是小家庭启动资金，还是女方家庭态度？
婚礼是两个人的仪式，还是两家人的公开汇报？
```

玩家选择：

```text
A. 按地区行情谈，别让父母太难看
B. 彩礼象征化，把钱留给小家庭
C. 坚持高规格，婚礼必须体面
D. 先不谈数字，继续观察态度
```

隐藏反馈：

- 图钱型会特别关注现金和支出顺序
- 图家庭资源型会关注父母愿意给多少
- 图外貌展示型会关注婚礼体面程度
- 图 KPI 型会尽快把金额和日期敲死
- 真诚型会尝试把钱留给未来生活

### 15.3 事件二：婚房与房本名字

第二轮谈婚房。

冲突点：

```text
首付谁出
贷款谁还
装修谁垫
房本写谁
父母出资算赠与谁
婚后共同还贷如何记录
暂时租房是否能被双方父母接受
```

玩家选择：

```text
A. 按出资和还贷贡献写清楚
B. 为了安全感，尽量写双方名字
C. 听父母安排，毕竟他们出钱
D. 暂不买房，先租房独立生活
```

设计重点：房本选择不是单纯道德题。它同时测试玩家资产保护意识、伴侣公平感、父母控制欲和现实压力承受度。

### 15.4 事件三：双方父母第一次正式见面

场景：包间饭局。

桌上出现经典话术：

```text
“我们不是要钱，是要态度。”
“房子写谁名不重要，重要的是两个孩子过得好。”
“以后孩子谁带？”
“你们年轻人不懂，婚姻还是要听父母的。”
“我们家也不是卖女儿。”
“我们也不是娶保姆。”
```

玩家选择：

```text
A. 优先保护小家庭
B. 先安抚父母，别让场面难看
C. 当场暂停，问题太多需要整理
D. 让孟姐介入调停
```

隐藏反馈：

- 高控制型 NPC 会要求玩家站队
- 图生育/照护型会把孩子和老人照护提前打包
- 图家庭资源型会绕过玩家接近父母
- 真诚型会尽量和玩家共同面对父母

### 15.5 事件四：婚前财产协议

婚前财产咨询室里，律师提醒：

```text
感情归感情。
房产、债务、赠与、共同还贷、婚礼支出，最好不要靠记忆保存。
```

玩家选择：

```text
A. 双方都签清楚，保护彼此
B. 不签，谈协议太伤感情
C. 找独立律师再看一遍
D. 先订婚，协议以后再补
```

隐藏反馈：

- 真诚型可能不舒服，但能理解
- 图钱型会反感过于清晰的财产边界
- 图避险/遮羞型会要求跳过细节
- 高风险控制型会把协议说成“不信任”
- 理性型 NPC 会因此好感上升或压力下降

### 15.6 本章压力测试：第一次重大动机显影

如果 NPC 有初始不良动机，本章会出现第一次重大显影。

```text
图钱型：希望玩家先承担装修和婚礼定金。
图家庭资源型：绕过玩家联系父母，试探户口、人脉、学区。
图外貌展示型：把订婚宴当成社交亮相。
图生育/照护型：要求婚后同住、三年内生育、照顾老人。
图情绪供养型：用崩溃和卖惨阻止玩家谈条件。
图阶层跳板型：把订婚宴名单变成资源名单。
图避险/遮羞型：要求先订婚，背调和债务以后再说。
图控制型：要求婚后工资、社交、节假日安排统一管理。
图婚恋 KPI 型：拿出明确订婚、领证、备孕时间表。
图内容/流量型：把订婚、婚礼、父母见面设计成内容。
```

玩家选择：

```text
A. 接受，现实婚姻总要妥协
B. 继续，但必须写清条件
C. 当面质问真实动机
D. 暂停或结束这段关系
```

### 15.7 第四章结尾

第四章可能进入三种状态：

```text
订婚观察期：规则基本谈清，感情仍可推进。
高压推进期：婚事继续，但大量问题被暂时压住。
关系暂停期：玩家发现重大风险，选择暂停或退出。
```

第四章结束文字：

```text
谈婚论嫁不是爱情的反面。
它只是把爱情里所有没说出口的东西，
换成了数字、名字、日期和座次。
```

## 16. 第五章：《婚礼战役》

第五章目标：订婚后，婚礼筹备把关系推到新的压力峰值。婚礼不只是仪式，而是预算、面子、亲戚、前任、公开承诺和双方父母权力的集中爆发。

### 16.1 开场：婚礼待办清单

婚礼事项：

```text
酒店档期
司仪与摄影
伴郎伴娘
婚车
座次
份子钱
朋友圈官宣
婚礼视频
父母致辞
敬酒流程
```

孟姐：

```text
“婚礼最难的不是办得漂亮。”
“是办完以后，两个人还愿意一起回家。”
```

玩家选择：

```text
A. 小型婚礼，优先保住预算和边界
B. 体面大办，不能让双方父母丢脸
C. 让父母主导，他们更懂礼数
D. 先和对象私下定共同原则
```

### 16.2 事件一：宾客名单与座次表

冲突点：

```text
哪些亲戚必须请？
领导和客户要不要请？
前任或暧昧对象是否会出现？
父母的朋友是否占用年轻人的预算？
座次是否体现双方家庭地位？
```

玩家选择：

```text
A. 制定规则：只请真正亲近的人
B. 照顾面子，重要关系都安排上
C. 砍掉超预算名单
D. 交给婚介和婚庆协调
```

### 16.3 事件二：预算失控

婚庆报价升级：

```text
摄影升级
灯光升级
甜品台升级
婚车升级
敬酒服升级
伴手礼升级
```

玩家选择：

```text
A. 费用写清楚，双方按能力分担
B. 先借钱办，婚后慢慢还
C. 降级方案，不为一天掏空几年
D. 要求对象一起面对父母
```

### 16.4 事件三：前任消息

婚礼前两周，玩家收到陌生消息：

```text
“你真的了解 TA 吗？”
“有些事，不该等到婚礼当天才知道。”
```

玩家选择：

```text
A. 直接问清楚
B. 不理会，婚前有人搅局很正常
C. 暂停流程，核实来源和内容
D. 延期婚礼，先处理信任问题
```

隐藏反馈：

- 道德瑕疵型可能暴露前任未断、债务或婚史问题
- 高风险控制型会反咬玩家“不信任”
- 真诚型会不舒服，但愿意解释和核实

### 16.5 事件四：婚礼前夜

婚礼前夜，所有未解决问题都会变得具体。

动机显影：

```text
图钱：计算礼金和回本
图家庭资源：宾客名单变成资源地图
图外貌展示：婚礼成为公开展示
图生育/照护：亲戚提前讨论孩子和老人
图情绪供养：要求玩家先安抚 TA
图阶层跳板：索要引荐机会
图避险/遮羞：要求玩家别再查
图控制感：要求玩家按流程和话术走
图婚恋 KPI：婚礼、领证、备孕不可更改
图内容/流量：婚礼被做成内容项目
```

玩家选择：

```text
A. 继续婚礼，明天以后再说
B. 继续，但把关键条件写下来
C. 延期婚礼，先把问题处理完
D. 取消婚礼，承受代价也要止损
```

### 16.6 第五章结尾

第五章可能进入：

```text
领证婚礼线：婚礼继续，关系进入婚后第一年
延期婚礼线：关系保留，但信任重建
取消婚礼线：重大止损，进入分手或换人路线
高压婚姻线：问题被压住，婚后集中爆发
```

第五章结束文字：

```text
婚礼像一面放大的镜子。
它照见爱情，也照见账单、亲戚、旧事和没说出口的控制。
```

## 17. 第六章：《婚后第一年》

第六章目标：婚礼后的第一年，玩家从仪式进入共同生活。此前压住的问题会以工资卡、家务、春节、父母探访、生育安排和第一次婚后大吵的形式重新出现。

### 17.1 开场：共同生活开始

婚礼过去一个月，鲜花撤掉，滤镜消失。

核心议题：

```text
工资卡
共同账户
私人账户
家务分配
春节去哪家
父母探访
亲密频率
备孕或避孕
第一次婚后危机
```

玩家选择：

```text
A. 共同账户写清规则，各自保留私人账户
B. 工资放一起，先建立一家人的感觉
C. 让父母帮忙规划大额支出
D. 经济先分开，磨合后再谈
```

### 17.2 事件一：家务分配

家务不是小事。它只是太日常，所以更容易被装作没发生。

玩家选择：

```text
A. 列清家务表，谁空谁做不再靠默契
B. 先自然磨合，别太像合租
C. 能外包就外包，用钱换时间
D. 先忍一忍，别刚结婚就吵
```

隐藏反馈：

- 图生育/照护型会默认玩家承担更多
- 图情绪供养型会把家务矛盾转成自己压力大
- 图控制型会用“已婚人士自觉”要求报备和服从
- 真诚型会承认分工不公平并尝试调整

### 17.3 事件二：第一个春节

两边父母都说“你们自己决定”，但每个人都在等答案。

玩家选择：

```text
A. 提前约定轮流，一年一家
B. 今年先去 TA 家，稳住局面
C. 今年回自己家，别委屈父母
D. 两边都不去，旅行过年
```

### 17.4 事件三：父母探访

父母第一次来小家住三天。

冲突点：

```text
冰箱被重新整理
沙发套被换掉
厨房习惯被改变
父母评价家务
父母评价消费
父母评价备孕
```

玩家选择：

```text
A. 定探访规则，住几天、做什么都说清楚
B. 热情接待，老人不容易
C. 要求伴侣出面沟通
D. 如果边界失守，就考虑搬出去
```

### 17.5 事件四：亲密与生育安排

婚后第八个月，孩子议题开始出现。

玩家选择：

```text
A. 先谈职业、身体、钱和谁带娃

C. 明确暂缓，至少等关系稳定

```

### 17.6 事件五：第一次婚后危机

争吵表面上是家务、钱、父母和孩子。真正吵的可能是：

```text
谁的生活被默认牺牲

谁的钱更像共同财产
谁的时间更容易被占用
谁的委屈更不被看见
```

玩家选择：

```text
A. 坐下来复盘，重新分工和修复关系

```

### 17.7 第六章结尾

```text
磨合稳定线：问题仍在，但双方愿意修复
```

```text
婚礼是一日，婚姻是每天。
```

## 18. 第七章：《买房与债务》

第七章目标：婚后第二年，房子和债务进入小家庭。玩家要在租房、二手房、期房、父母出资、月供压力、装修贷、收入冲击、亲属借钱和共同债务风险中做选择。

### 18.1 开场：真正属于自己的家

核心议题：

```text
继续租房
二手房
期房
首付
共同还贷
装修
父母出资
月供压力
征信和旧债
共同债务边界
```

玩家选择：

```text
A. 继续租房，先保住现金流和自由
B. 买二手房，贵一点但看得见
C. 买期房，赌未来交付和升值
D. 听父母建议，他们出一部分首付
```

### 18.2 事件一：首付、装修与房本

冲突点：

```text
首付谁出
装修谁垫
贷款谁还
父母出资如何记录
房本名字是否和贡献匹配
婚前协议是否覆盖新资产
```

玩家选择：

```text
A. 所有出资、还贷、装修都写清楚
B. 别算太细，夫妻还是要互相信任
C. 父母出钱，就接受父母意见
D. 先暂停，压力超出预期
```

### 18.3 事件二：收入冲击

贷款批下来后，公司降薪或收入不稳。

玩家选择：

```text
A. 立刻削减预算，重做现金流
B. 先向父母借钱缓一缓
C. 暂时不说，自己扛过去
D. 考虑止损，卖掉或退掉
```

### 18.4 事件三：亲属借钱

买房后，亲戚开口借钱。

玩家选择：

```text
A. 拒绝，房贷期不做人情贷款
B. 借一部分，保住亲戚关系
C. 可以借，但必须写借条和期限
D. 让伴侣一起出面处理
```

### 18.5 事件四：交付、装修或涨租风险

不同路线触发不同压力：

```text
期房：延期交付、停工、维权
二手房：装修超支、邻里问题、隐性维修
租房：涨租、搬家、无法落户或学区不稳
```

玩家选择：

```text
A. 收集证据，走维权或合同流程
B. 继续忍耐，先别把事情闹大
C. 让双方父母加入处理
D. 准备退出方案，减少沉没成本
```

### 18.6 事件五：共同债务谈判

本章最终问题：

```text
谁签字
谁还钱
谁承担未来十年的风险
谁的旧债会不会变成共同风险
```

玩家选择：

```text
A. 明确债务边界，不清楚就不签字
B. 共同承担，婚姻就是一起扛
C. 先别谈太细，压力太大
D. 分开资产和债务，必要时分居止损
```

### 18.7 第七章结尾

第七章可能进入：

```text
共同风控线：房子成为项目，而不是爱情证明
债务高压线：债务成为婚姻里的第三个成员
父母入场线：父母出资换取更多话语权
止损分居线：玩家保住资产和边界
```

第七章结束文字：

```text
房子可以是家，也可以是债。
真正可怕的不是月供，
而是你不知道自己到底签下了谁的未来。
```


## 20. 结局类型

```text
真爱但贫穷：感情高，经济低，孩子入学困难但家庭稳定。
体面婚姻：外人羡慕，内部低温，十年后像合伙人。
离婚重启：关系失败，但玩家保住自尊、资产或抚养权。
鸡娃同盟：夫妻感情一般，但共同投入孩子教育。
阶层跃迁：通过婚姻、事业或房产改变命运，但代价很高。
反婚结局：玩家在第十年选择不进入婚姻，成为旁观其他 NPC 婚姻的人。
隐藏真结局：边界感、共同决策、冲突修复三项达标。
```

## 21. 设计原则

- 好感度不等于安全
- 条件不是道德
- 真诚型 NPC 也会有缺点
- 有瑕疵的 NPC 不一定不可发展，但必须付出代价
- 高风险控制型不应被浪漫化
- 玩家不是靠攻略判断人，而是靠连续行为、压力测试和边界反馈判断人
- 婚姻不是单人选择，而是两个人、两组家庭、资产、债务、身体和时间共同构成的系统
