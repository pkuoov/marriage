# 《婚恋侦探局》游戏宗旨

## 一句话

人生不是肉鸽游戏，人生也不能重来。

大多数人并不是完美无限或是十恶不赦，他们都有他们的利益考量，他们也有他们的诉求。你不能改变随机的事和随机的人，只能关注自己的每一次选择。

游戏里可以有周目，现实里没有重开。每一局开始时，你带着有限的条件、有限的经验和有限的判断力进入一段关系。你会遇到形形色色的人和事：好的，坏的，不好不坏的；真诚但软弱的，现实但不恶的，温柔但自私的，体面但控制的。

你不能预读全部剧本，也不能保证自己一定遇见“正确的人”。你只能在一次次选择里，逐渐学会看人、看事、看自己。

## 游戏想表达什么

《婚恋侦探局》不是一个鼓励恐婚、反婚或拜金的游戏。它也不是一个用“好人坏人”粗暴划分婚恋关系的游戏。

它想表达的是：婚恋不是童话里的固定路线，而是一套包含欲望、利益、家庭、风险、误解、真心、诈骗、诱惑、宏观环境和代价的复杂系统。

大多数人都是利己的。人会优先考虑自己，保护自己，替自己打算。这并不天然等于邪恶，但如果一个人只允许自己利己，却要求伴侣无条件牺牲，那么关系就会开始失衡。

剧情编排上，除非角色就是纯粹的职业骗子，否则不要把任何一方写成完全透明、完全无辜、完全可靠的叙述者。每个人都会为了自己的利益、面子、恐惧或关系位置修剪事实：隐瞒不利时间点，放大自己受伤的部分，淡化自己获益或失责的部分，把真实事实说成更有利于自己的版本。相对受害者也可能是真受害者，但 TA 的自述仍然可能漏掉自己的拖延、默认、索取、反击、试探或逃避。

因此，每一案的真相不应该只问“谁在骗谁”，还要问：

```text
谁先修剪了事实？
谁从这个版本里获益？
谁淡化了自己的责任？
谁说的是真话，但只说了对自己有利的一半？
```

每一条被隐藏、被裁切、被改口或被装糊涂的信息，都必须有目的性。它不能只是为了让玩家有线索可找。要先回答：

```text
TA 为什么要在这个时间点隐藏？
TA 想换取什么：见父母、领证、借钱、加名、同居、面子、退路、资源、情绪优势？
TA 不说完整，对谁有利？
TA 如果说完整，会立刻失去什么？
```

如果一个人的行为看起来没有明确利益目的，也不能直接写成“坏”。它可能是任性、惯坏、逃避冲突、装不懂、不愿承担、低能力沟通、被原生家庭推着走，或故意使坏。这样的案子要单独作为“动机不清 / 责任能力不清”的专题来分析，而不是硬塞进诈骗或包装案里。

## 每日案的戏剧原则

每日案不能只是一条线索核验题。它必须像直播间里真正会吵起来的一口瓜：有一个具体物件或一句具体原话，把几个人的面子、利益和误会拧在一起。

后续情节生成必须遵守三条：

```text
戏剧化：每案至少有一个能让弹幕立刻有画面的物件、原话或动作。
灰区化：不要只写“对方主动骗 / 咨询者单纯受害”，至少让一方相对受害者也有面子、默认、试探或转述失真。
动机不明确化：关键材料或关键要求最好不是单方凭空出现，而是由父母、朋友、前任、平台、现实压力或双方含糊转述共同推出来。
```

例如，“对方发截图”本身不够有戏。更好的写法是：见父母前多出一张存款证明，但这张证明到底是对方主动秀资产、咨询者暗示、还是父母借咨询者的嘴要来的，说不清。玩家要听出的不是“证明真假”，而是这张证明如何被双方拿来维护体面、换取饭局继续、或避免被父母追问。

每个每日案生成时，都要先回答：

```text
这案的戏剧物件是什么？
它为什么现在出现？
是谁先把它推到台面上的，是否说得清？
谁可以借它保全面子？
谁可以借它推进下一步？
如果它被完整说清，谁会立刻难看？
```

如果这些问题答不出来，案子会变成平铺的“核验练习”，缺少玩点和爽点。

## 主播追问的逻辑

连线客户的叙述可以跳跃、含糊、前后矛盾，因为这正是直播间要听出来的东西。客户可能把证明、说服、抱怨、催促、辩解混在一起讲，也可能先讲对自己有利的半句。

但主播的问题不能跳。主播每一句追问都必须从客户刚说出的内容自然推出，像一层一层往下剥：

```text
上一句出现了什么？
这句话试图证明什么？
它想说服谁？
对方为什么这样说？
如果说服成功，下一步才可能发生什么？
```

例如，对方发截图的直接目的不是“推进某件事”，而是“证明自己条件够稳”或“说服咨询者/父母先放心”。饭局、借钱、见面、领证、加名这些是被说服之后可能发生的后续结果，不能在主播第一句追问里直接跳过去。

正确的追问链应该是：

```text
他为什么发图？
-> 他想证明什么？
-> 他想先说服谁？
-> 你或家里被说服以后，他希望哪件事更容易被答应？
```

这条规则是后续所有关卡的基础：玩家可以从客户混乱的表达里找问题，但系统给玩家的选项必须逻辑环环相扣，不能替剧情跳步。

主播还必须听见客户已经说过的信息。客户如果已经说“我们是相亲认识的”，主播下一句不能再问“你们怎么认识”，而应该承接：“相亲认识的，那他一开始怎么介绍自己？”重复询问已给事实会让主播显得没有在听，也会破坏玩家对直播间的信任。

主播的问句和客户下一句回答也必须能接上。如果主播问“他一开始怎么介绍自己条件”，客户下一句却说“他听说以后发了几张截图”，中间就缺了“谁听说了什么”的桥。更好的接法是问“你妈具体问了什么，你又怎么跟他说的”，客户再回答“我跟他说我妈想确认学校、工作和收入”，然后发图才有来源。

UI 氛围文案不能替玩家下指令。不要写“先听对面怎么开口”“先别急”“你要判断”这类系统教学句。过渡页、浮动弹幕和提示条只负责制造直播间气氛，例如“直播间安静了一下”“麦里有点东西”“弹幕别吵”。真正的追问和节奏交给主播台词与玩家选项完成。

每个每日案生成完以后，都要把文本串起来读，而不是只看单独字段。至少要串读：

```text
开场三句
每段咨询者原话 + 每个可选追问 + 该追问反馈
每条后续原话 + 每个 follow-up + 该 follow-up 反馈
最后回看
```

如果串读时出现“主播问 A，咨询者答 B”“突然多出一份图/账单/录音”“选项已经知道玩家还没听到的信息”“反馈直接替玩家总结答案”，这条分支就要重写。

玩家要做的不是替任何一方当辩护人，而是在多个人各自修剪过的叙述之间，听出事实如何被折叠。

所以本作的第一性出发点是：

```text
尊重自己。
保护自己。
提高自己。
不要把人生托管给任何人的承诺。
```

在一个信息不透明、压力很真实、话术很熟练的社会里，能够存活下去的核心能力，不是永远相信爱，也不是永远不信爱，而是：

```text
看见事实。
承认欲望。
识别风险。
建立边界。
为自己的选择负责。
```

本作的“避坑”不是让玩家永远怀疑所有人，而是让玩家知道哪些信号必须核实，哪些让步需要边界，哪些承诺不能替代证据，哪些甜蜜背后可能是情绪勒索、财务绑定、关系围猎或长期消耗。

## 为什么使用周目和随机事件

婚恋天然带有随机性。

同一个相亲对象，在不同周目里可能是真诚的，也可能带着现实私心；可能只是有缺点，也可能隐藏债务、前任、控制欲、投资风险、情绪依赖或婚恋目的。

同一个选择，在不同人身上也会产生不同后果。

你主动买单，可能被真诚的人记住，也可能被图钱的人标记为“好拿捏”。

你提出婚前协议，可能换来成熟沟通，也可能引爆对方的控制欲。

你选择相信，可能收获关系，也可能延后风险。

这就是游戏里“类肉鸽”结构的来源：不是为了暗示人生可以重来，也不是为了把婚恋简化成抽卡，而是用可重复的虚构周目，帮助玩家看见现实关系中的不确定性、利益考量和人性惯性。

## 周目经验

每一周目结束后，玩家会根据本周目遇到的事件获得永久能力成长。前几轮成长更快，之后回到更慢的积累节奏。

这些点数不是让玩家变成“完美的人”，而是象征经验的积累：

```text
你更知道自己要什么。
你更能识别熟悉的话术。
你更能在甜蜜时保持清醒。
你更能在压力下保住边界。
```

下一周目，你仍然会遇到随机的人和随机的事。但你不再完全是上一局那个自己。

这也是本作的底层态度：人生不会因为你变强就停止出题，但你可以因为经历过而更有能力答题。

## 新增属性：情商

情商不是“会哄人”，也不是“圆滑”。

在本作中，情商代表：

```text
读懂对方情绪的能力
识别话术和谎言的能力
判断对方真实动机的能力
让对方感到被理解的能力
在冲突中不被情绪完全带走的能力
```

情商会影响：

- 玩家对 NPC 的初始吸引力
- 玩家识别对方话术和真假表达的能力
- 部分黄色线索是否提前显现
- 高控制/高伪装 NPC 的行动是否更容易暴露
- 冲突中是否能用更低代价获得信息

但情商不是读心术。

高情商可以提高判断概率，不能保证永不被骗。低情商也不是失败标签，只是意味着你需要更多事实、更多边界和更慢的节奏。

## 本作不鼓励什么

本作不鼓励玩家把所有人都当敌人。

本作也不鼓励玩家用“现实”包装剥削，用“爱”包装牺牲，用“孝顺”包装控制，用“安全感”包装占有。

如果玩家每一局都只追求收益最大化，也可能进入体面但冷漠的关系。

如果玩家每一局都只相信甜蜜，也可能进入高压婚姻。

真正的隐藏胜利，不是赢过所有人，而是在复杂的人和事里，依然没有弄丢自己。

## 面向公开发布的说明

《婚恋侦探局》包含大量现实婚恋议题：相亲、彩礼、婚房、双方父母、婚前协议、婚礼、婚后家庭矛盾、生育和孩子教育，也包含经济下行、投资亏损、股市诱惑、前任回流、情绪价值外包、暧昧边界和情感诈骗。

游戏中的 NPC、事件和案例均为现实议题的综合改编与虚构，不指向具体真实个人。

本作不是法律建议、心理诊断、投资建议或婚恋指导。它是一款互动叙事游戏，目标是让玩家在选择中体验不确定性、风险识别和自我成长。
