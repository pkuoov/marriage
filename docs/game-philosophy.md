# 《中国式婚恋：十年一梦》游戏宗旨

## 一句话

人生不是肉鸽游戏，人生也不能重来。

大多数人并不是完美无限或是十恶不赦，他们都有他们的利益考量，他们也有他们的诉求。你不能改变随机的事和随机的人，只能关注自己的每一次选择。

游戏里可以有周目，现实里没有重开。每一局开始时，你带着有限的条件、有限的经验和有限的判断力进入一段关系。你会遇到形形色色的人和事：好的，坏的，不好不坏的；真诚但软弱的，现实但不恶的，温柔但自私的，体面但控制的。

你不能预读全部剧本，也不能保证自己一定遇见“正确的人”。你只能在一次次选择里，逐渐学会看人、看事、看自己。

## 游戏想表达什么

《中国式婚恋：十年一梦》不是一个鼓励恐婚、反婚或拜金的游戏。它也不是一个用“好人坏人”粗暴划分婚恋关系的游戏。

它想表达的是：婚恋不是童话里的固定路线，而是一套包含欲望、利益、家庭、风险、误解、真心和代价的复杂系统。

大多数人都是利己的。人会优先考虑自己，保护自己，替自己打算。这并不天然等于邪恶，但如果一个人只允许自己利己，却要求伴侣无条件牺牲，那么关系就会开始失衡。

所以本作的第一性出发点是：

```text
尊重自己。
保护自己。
提高自己。
不要把人生托管给任何人的承诺。
```

在一个信息不透明、压力很真实、话术很熟练的社会里，能够存活下去的核心能力，不是永远相信爱，也不是永远不信爱，而是：

```text
看见事实。
承认欲望。
识别风险。
建立边界。
为自己的选择负责。
```

## 为什么使用周目和随机事件

婚恋天然带有随机性。

同一个相亲对象，在不同周目里可能是真诚的，也可能带着现实私心；可能只是有缺点，也可能隐藏债务、前任、控制欲或婚恋目的。

同一个选择，在不同人身上也会产生不同后果。

你主动买单，可能被真诚的人记住，也可能被图钱的人标记为“好拿捏”。

你提出婚前协议，可能换来成熟沟通，也可能引爆对方的控制欲。

你选择相信，可能收获关系，也可能延后风险。

这就是游戏里“类肉鸽”结构的来源：不是为了暗示人生可以重来，也不是为了把婚恋简化成抽卡，而是用可重复的虚构周目，帮助玩家看见现实关系中的不确定性、利益考量和人性惯性。

## 周目经验

每一周目结束后，玩家会根据本周目遇到的事件获得永久能力成长。前几轮成长更快，之后回到更慢的积累节奏。

这些点数不是让玩家变成“完美的人”，而是象征经验的积累：

```text
你更知道自己要什么。
你更能识别熟悉的话术。
你更能在甜蜜时保持清醒。
你更能在压力下保住边界。
```

下一周目，你仍然会遇到随机的人和随机的事。但你不再完全是上一局那个自己。

这也是本作的底层态度：人生不会因为你变强就停止出题，但你可以因为经历过而更有能力答题。

## 新增属性：情商

情商不是“会哄人”，也不是“圆滑”。

在本作中，情商代表：

```text
读懂对方情绪的能力
识别话术和谎言的能力
判断对方真实动机的能力
让对方感到被理解的能力
在冲突中不被情绪完全带走的能力
```

情商会影响：

- 玩家对 NPC 的初始吸引力
- 玩家识别对方话术和真假表达的能力
- 部分黄色线索是否提前显现
- 高控制/高伪装 NPC 的行动是否更容易暴露
- 冲突中是否能用更低代价获得信息

但情商不是读心术。

高情商可以提高判断概率，不能保证永不被骗。低情商也不是失败标签，只是意味着你需要更多事实、更多边界和更慢的节奏。

## 本作不鼓励什么

本作不鼓励玩家把所有人都当敌人。

本作也不鼓励玩家用“现实”包装剥削，用“爱”包装牺牲，用“孝顺”包装控制，用“安全感”包装占有。

如果玩家每一局都只追求收益最大化，也可能进入体面但冷漠的关系。

如果玩家每一局都只相信甜蜜，也可能进入高压婚姻。

真正的隐藏胜利，不是赢过所有人，而是在复杂的人和事里，依然没有弄丢自己。

## 面向公开发布的说明

《中国式婚恋：十年一梦》包含大量现实婚恋议题：相亲、彩礼、婚房、双方父母、婚前协议、婚礼、婚后家庭矛盾、生育和孩子教育。

游戏中的 NPC、事件和案例均为现实议题的综合改编与虚构，不指向具体真实个人。

本作不是法律建议、心理诊断或婚恋指导。它是一款互动叙事游戏，目标是让玩家在选择中体验不确定性、风险识别和自我成长。
