# 游戏宗旨

更新：2026-09-16。当前产品是以个人直播为舞台的剧情推理游戏，玩家扮演林旭阳，听出说法中的问题，选择怎么问，并看材料与当事人如何回应。具体规则统一维护在[当前项目方向](../project-skills/case-scriptwriting/references/current-project-direction.md)。

乐趣来自具体的人、具体的诉求和当场接得上的攻防。主播可以直说、有脾气、接梗；来电人可以认了事实仍然坚持自己的要求。真实照顾、熟人交流和喜剧节奏也属于剧情，不必都换算成证据。

本段集中问清，没问清就本段重问，问清后向前。材料帮助发问，操作应直接。取消强制逐句回放循环、复杂材料组合、弹幕插话、重复收麦和为完成度补出的深问。口播快案读材料后任选一个成立的点评。

现有四主案、三快案及顺序以 manifest 为准，不以随机周目、永久属性成长或固定案件时长约束本轮设计。这些旧方案不再是当前宗旨。内部记录用于事实和存档，不强制变成评分、责任报告或额外结案页面。
