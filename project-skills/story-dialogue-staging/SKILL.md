# Story Dialogue Staging

遵循 [当前项目方向](../case-scriptwriting/references/current-project-direction.md)。本技能处理人物从哪里来、上一场做了什么、下一场怎样接上，以及这些内容如何呈现；不另规定每案结构和结案仪式。

## 工作范围

整案改造先连读剧情，再安排场景与对白。局部改一句只检查相关交换及前后接缝，不必重做完整分镜和预计时长。按需使用 [case-scriptwriting](../case-scriptwriting/SKILL.md) 写对白、[detective-plot-coupling-review](../detective-plot-coupling-review/SKILL.md) 查发现链；不默认整套加载。

读取实际源案、相关人物卡、当前连续台本与运行时消费者，区分已有事实、待验证设计和本次提案。历史方案里的场景数量、二选一预算、NPC出场次数和下一案钩子不是现行实现要求。

## NPC 出场与关系

核对这个人跟主播的关系、此时正在做什么、为什么会参与、能知道哪些事。妻子、好友和业务伙伴首次出场先有符合关系的招呼或接话，再谈眼前问题。后续见面接上约定和旧话，不重复陌生人介绍。

专业人物可以拒绝、误读、开玩笑或护短，按当时利益写，不强制六项人物模板、三类动作配额和公开冲突。寒暄可以只建立关系；不必奖励一份材料。求助工具与剧情 NPC 不是同一种系统，不能以“新增好友”为由自动新增解题提示。

林旭阳是个人主播；身份与生计沿当前人物卡，开场不逐夜复读履历。收线、静音、开播由本人操作，不凭空增加导播、耳返指令、节目组档案室或全知后台。运营消息来自业务伙伴，不等于控制室实时指挥。

## 跨场与跨夜

检查挂断缘由、白天行动的来源、得到什么、第二夜怎样承接。若所有叙事行动已改顺序，取消虚构的机会成本，不恢复“只能查两处”。可选材料仍根据当前实际路径检查，不假定玩家一定看过。

被明确用于中断通话或改变决定的声响、物件和来访要有后果；普通生活细节不都登记成悬疑承诺。新增地点要符合个人主播的接触渠道，不能因为案子需要文件就突然获得调查权。

同一事实只首次揭露一次：动态开头说过归属，正文追用途或责任；删掉原支线后，独有证人和授权也随之检查。世界新闻和具体个人损失属于不同事实，不能靠案间字幕把两者合并。

## 场景与阅读舞台

- 真正换地点时同步背景、时间、角色、HUD和操作。离播后不残留 ON AIR、上一场名牌或“开播前”标签。
- 对白按当前阅读页呈现，姓名、角色 ID、立绘、亮暗和存档阅读进度一致；舞台动作不冒充说话人。
- 一屏可读不靠压缩人物语言实现；需要时在自然停顿分页，不能按逗号数或“最多一问一答”裁掉攻防。
- 主播保存名用于显示，默认名仍是内容真源；改名不能改人物关系或履历。
- 语音立绘是演出，主播和弹幕不能据此看见来电人表情、衣着或房间。
- 动画跟随实际阶段或剧情变化，重载、返回和下一句不重复播放。重放开头要醒目，尊重减少动态效果设置，不显示答案字幕。
- 长问句、材料按钮、已标注气泡和继续按钮优先检查 PC 遮挡，再补窄屏。集中问询页让玩家看懂问什么、用什么材料；本段问清推进，不贴关键选择标签，不强制返回原句。长材料可展开，结果对白与操作不得互相遮挡。
- 自动播放、配对接话和手动下一句共用可取消时序；材料弹层暂停下层阅读，关闭后恢复焦点和位置。

匿名立绘的身份一致性、暖色侧脸、三态和实际输出尺寸以 [立绘制作方向](../../docs/pixel-art-transition-and-portrait-direction.md) 为准。更换素材先验证同一角色与 UI 实际尺寸，不能引用不存在的差分、常驻遮眼黑条或用滤镜批量替代审核。没有图片改动时不强制重新生成立绘。

## 案尾与片尾

按当前路由检查收麦、可选案件记录、生活尾声、下一通及最终片尾。内部 `caseClosing` 字段不意味着必须显示六项结案报告；不得把已经撤销的总结页当成剧情完整性的门槛。

生活尾声承接刚才说过的话，可以保留熟人约定与旧伏笔，不重讲责任、补发未收到的材料或替玩家命名主题。最后一案进入已批准的电影字幕，具体文字见当前项目方向，不能因一般规则删去用户锁定句。

新案标题不提前披露原件、矛盾答案和全案总结。若改变案尾路由，核对最后一案、存档继续与回看，不只验证中间案件。

## 接入与验收

字段、稳定 ID、顺序进度、存档刷新及生成稿见 [运行时内容接入](../case-scriptwriting/references/runtime-content-integration.md)。改动后运行内容生成、`npm run check`，再构建并走受影响浏览器路径。

整案跨夜重排需实际走到第二夜或收麦；只改一个名牌则检查相应场景和尺寸。报告具体覆盖，不把定点载入验证说成从头通关，也不为局部修改要求全案新增分镜、NPC冲突或路线。
