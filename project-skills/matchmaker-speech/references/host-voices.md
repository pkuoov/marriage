# 说媒语料的使用方式

既有样本来自 `tools/matchmaker-corpus/`，包含对谈、剪辑、标题与热评。采样时的账号和流量信息不能当成实时事实，标题未有字幕佐证时不算真人原话。

可观察的方式有直接追条件、顺着抱怨听细节、对比同一人对不同对象的标准，以及冷静接住荒诞要求。选用局部交流方式即可，不必把一案归入某种“店型”，也不把样本里的外貌打分、阶层评价和性别观点当作作者规则。

虚构媒人有自己的工作压力、偏见、熟人关系与诉求；主播沿当前人物卡，可以讽刺、判断、接梗。不能按“标题即判决”“判决不让步”“林旭阳不能点破”限制对白。来电人的解释可能成立，人物也可能改变想法。

使用案例前核对实际来源；不复制真实姓名、联系方式和可识别的完整事件。人物可以表达刻薄或偏见，游戏材料与系统结算不替他认证这些观点。
