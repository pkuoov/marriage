# 相亲来电人的可选反应

既有样本中的标题、热评与字幕代表不同来源，不把网友概括当成来电人自述。遵循 [当前项目方向](../../case-scriptwriting/references/current-project-direction.md)。

来电人可以先谈择偶条件、家人意见、见面经历或一件刚发生的不满，不要求开口报盘、只说半句，也不按前三十秒分配声口。

想得到的可能是介绍、认可、替自己传话或让对方退让。被点中后，她可以挑标准、缩小承诺、说是家里要求，或怪对方不肯继续谈；具体理由接当前事实，不复制语料中的群体标签。

主动分享可能来自得意、委屈或觉得主播懂自己，不等于主动供述全部秘密。主播顺着听见新细节，再问不一致之处。相同角色贯穿整案，不因进入相亲话题就突然切成报价机器。
