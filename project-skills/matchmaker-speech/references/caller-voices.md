# 说媒连线当事人语言（只抄形状）

来自每人婚恋相关播放量前 20 的标题轴和热评「中译中」。杰哥只用对谈现场。陈楠补桌号标题 + 天书会诊。当事人本人仍只说半句。

## 报盘，不叙事

合格开口像报菜，不合格开口像小说。

- 硬件起：「我 29，本科，在这边上班，房子还没有。」
- 家里起：「我妈说至少得有……」
- 假谦虚：「要求真不高」，下一句就是城市、学历、身高、车。
- 展览场开口更短：报岁数和学校，等场子打分。
- 现场高频：「凭什么找比我差」「普通的就行」「结了会不会降低生活质量」。

不要让当事人第一句就分析自己的依恋类型。

## 高频轴（按实际热片，不是想象）

| 轴 | 当事人形状 | 场子/弹幕怎么译 |
|---|---|---|
| 岁数 vs 档 | 「年龄不重要，心态年轻」 | 有钱人很少吃这岁数；被更高档短择过后回不去 |
| 软件预期 | 「我要安全感、共情」 | 安全感=有钱；共情=舍得花钱 |
| 颜值错位 | 「路上好多都顺眼」 | 走路标准和上床/领证标准不是同一把尺 |
| 短择棘轮 | 「处着挺好，后来不回了」 | 消费和档位上去就下不来 |
| 富养报价 | 「我自己也有收入」 | 婚前家里养，婚后要对方养 |
| 看得上/养得起 | 「条件好的看不上我」 | 把一笔具体开销问死 |
| 恋爱/结婚上限 | 「处着甜，没法领证」 | 问谁先提证、卡在哪张纸 |
| 向上择 / 比我差 | 「我凭什么要找一个比我差的」 | 把婚介当许愿机，以为辩赢就分配配偶 |

## 被追问时的闪躲

- 用好态度挡硬件：「他对我挺好的。」
- 用别人挡自己：「朋友都说我可以再等等。」
- 用未来挡现在：「他过两年项目结束就稳定。」
- 数字抖动：「一个月差不多两万……到手没有那么多。」
- 用软件词挡报价：「我要的是情绪价值。」弹幕负责译成钱。

## 被打分后的三路

1. **急眼**：用同等粗鲁顶回去，坐实性格短板。高光是下麦大骂，不是冷静复盘。
2. **改口**：当场降一档需求，下一句又加回来。
3. **推家**：越界要求说成父母的，自己只是传话。

游戏里这三路都要能听出来，不能写成立刻认栽的自我审计。

## 评论区会替当事人「中译中」

写弹幕用这个形状，不要写成作者判词，也不要让林旭阳说：

- 原话「我抵触高收入」，译成「谈过的都是高收入」。
- 原话「要求不高」，直接报盘：岁数、身高、税前、房、车、要不要孩子。
- 原话「普通就行」，译成「前 10% 以外他看不见」。
- 原话「帮我看看几分」，译成场子比主播更早报分。
- 原话「家里节俭」，履历里出现对不上的大额礼物时，译成「谎不用脑子」。
- 找对象的正确比法：先跟同性竞争对手比，不是跟对面比。
- 互联网闺蜜对客户卖鸡汤，对自己「只做不碰」。
- 杰哥现场像防火墙：来的人越神，观众越安心。

## 和热线咨询者的差别

热线咨询者绕、铺垫、车轱辘。说媒连线者更快进入报价。若一案是热线里的相亲求助，前三十秒可以热线，进入「帮我看看我配谁」之后切到本表。
