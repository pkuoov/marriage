# 口播模版（说媒切片是标准，不是文稿）

这些连麦标题、热评、弹幕就是台词的口语标准。写完先按这个表朗读，再过 `case-scriptwriting` 的口语门禁。本表管「像不像口播」；那张表管「像不像这个人」。

只抄形状。禁止把原片标题、真名、课程微信号写进游戏。

## 一口气

- 一句能喊完。超过两个逗号，拆开或删解释。
- 换气只在标点。书面长句（「在……的情况下」「基于……」）一律重写。
- 主播金句必须能当切片标题：问句、对仗、带数字，或重复催一句。

## 人称

- 只用我 / 你 / 他 / 我妈。禁止「该当事人」「女方母亲」「咨询者」。
- 物件用口语名：卡、房、彩礼、流水，不用「给付安排」「保障条款」。

## 标题即口播

对照采集到的标题形状写，不要对照已有案文：

- 问句：「还能不能爱我哦？」
- 判决：「相亲是筛选，不是许愿机。」
- 对仗：一句只一对。看得上的养不起。
- 数字带单位：二十八万八、没挣两万、一年八个月。
- 重复催：「你能找！你能找！」

删掉案件专名后，这句仍应像连麦，不像材料板。

## 先物件，后解释

- 坏：「保障是为了降低风险。」
- 好：「二十八万八，领证前打进我的卡。」

数字可以说错再改。解释不能先于物件。

## 半句原则

- 当事人只说半句，下一刀留给主播或弹幕。
- 弹幕可以「中译中」，林旭阳不能。
- 主播一案金句 ≤2。说完停，不要补第二组对仗。

## 禁写（口播指纹）

- 然而 / 因此 / 综上所述 / 换言之 / 值得注意的是。
- 一段里两组对仗、每句都有信息量、所有人语气词相同。
- 当场剖析自己的依恋类型或「我其实是在……」。
- 结尾落在漂亮短句上还要再解释一遍。

## 朗读验收

1. 用说话速度读这一句和前后各两句。
2. 上一句的词必须能接到这一句；接不上就重写，不另起摘要。
3. 读完还能当切片标题，或还能当当事人半句报盘。两样都不是，再改。
