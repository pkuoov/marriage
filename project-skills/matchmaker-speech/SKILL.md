# Matchmaker Speech

写说媒、相亲、择偶定位连线时用。律师场用 `lawyer-speech`，不要把打分腔套到法律顾问嘴上。

语料：`tools/matchmaker-corpus/`。B 站 `order=click` → 必须谈婚恋 → 按播放量取前 20。杰哥**只收对谈现场**，不收社会博弈课。陈楠没有真正的高播官号，桌号是短搬运，用标题形状 + 天书会诊补。只抄**形状**，不抄真名、可检索标题、课程微信。玩家仍是主播林旭阳。

口播标准见 [oral-broadcast.md](references/oral-broadcast.md)。这些切片的标题、热评、弹幕就是台词模版，不是文稿。声纹见 [host-voices.md](references/host-voices.md) 和 [caller-voices.md](references/caller-voices.md)。流量池与分栏报告见 `tools/matchmaker-corpus/out/patterns.md`，覆盖与缺口见 `out/coverage-report.md`。话轮池只认字幕；没有字幕不得用标题冒充真实台词。

## 口播模版（先过这关）

连麦视频是标准口播。写任何媒人/当事人句，先当切片标题读出来。

- 一口气喊完，超过两个逗号就拆。
- 只用我/你/他/我妈。物件叫卡、房、彩礼，不叫保障条款。
- 标题形状：问句、一句一对仗、数字带单位、重复催。
- 先物件后解释。当事人半句，弹幕可以中译中，林旭阳不能。
- 禁：然而、因此、综上所述。禁一段两组对仗。
- 和 `case-scriptwriting` 口语门禁同时过：本表管像不像口播，那张表管像不像这个人。

## 一场连线的骨架

1. **货架店（鳌烨）**：先展览人，再让场子报分，偶尔听出一句谎。
2. **判决店（金大王 / 陈楠金句）**：标题先判，连麦打幻想，对方破防或改口。
3. **审讯店（天书；陈楠会诊）**：先听完整故事，再拆谎、命名关系。
4. **门槛局（大超）**：先报名门槛和城市场次。
5. **挡神人现场（杰哥对谈）**：冷静陪聊，让对方自己出丑。点破向上择、普通姑娘不普通、辩赢红娘不发配偶。

林旭阳只追问物件，不改打分老师，不替媒人完成判决。

## 主播话术（媒人角色）

- 先要可数条件，再谈性格。
- 「要求不高」译成门槛：岁数、学历、房子、孩子、谁出钱。
- 判决用市场句：只能找这类 / 相亲是筛选不是许愿机。不用「你值得被爱」。
- 金句短、可切片。一案媒人金句 ≤2。
- 禁止上嫁步骤、验资流程、话术包。

## 连线当事人语言

- 开口先堆硬件，或先堆「我妈说」。
- 杰哥现场高频：「凭什么找比我差」「普通的就行」「没两万没房不能结」「交工资」。
- 陈楠桌号高频：看得上/养得起，恋爱上限/结婚上限，钱颜性格占两样，仪式感/恐婚。
- 被点破后急眼、改口、或把锅推给家里。把婚介当许愿机。

## 验收

- 杰哥写成现场冷静，不成博弈课老师。
- 陈楠不写成「人人都听过的大号」；金句可用，流量不能装。
- 没有真名、原片标题、课程引流。林旭阳不教上嫁。
- 每句能当口播：朗读像连麦，不像材料板。
