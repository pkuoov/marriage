# 无赖来电：谎盖谎

更新：2026-09-20。写或改主案、快案动机时必读。总规则仍以[当前项目方向](current-project-direction.md)为准；具体写法按[二次改稿](second-revision-dialogue.md)，可玩路径按[内容接入](runtime-content-integration.md)。旧改稿 prompt 只保留接入记录。

## 什么时候用

来电人提出显得不讲理的要求：要别人出钱、要主播背书、要对方先认错、要换一个更好听的理由。先判断她属于哪一类，再决定挖多深。

## 两类无赖

**妄人。** 就是不讲理，底下没有第二层可挖。可以在快案四写一个。不要给妄人硬编一套难言之隐。

**藏真实目的 / 难言之隐。** 现有主案和多数快案走这条。通常不是一个谎，而是用一个谎盖另一个谎。行为上的说法有掩盖，心里那套目的还有修饰。核心问题往往是一团糟。

两种收法：

- **她自己知道。** 例如案一：很清楚不给钱的原因，不想给，也没钱。
- **她开头不知道有多大。** 例如公司案：挖下去发现整个公司就是个庞氏骗局。

## 怎么挖

先让她把面上的要求讲完，再挖她用来盖住的那句话，最后落到今晚真正要保护的东西。后一层可以用前一层已经认下的事实，不能开场把底谎和乱局讲完。这里的目的供作者理解人物，不要求角色自己说破，也不要求主播作心理定论；层数随冲突展开，不按每场一个谎分配。

对面可以是真的有过感情、真的垫过钱、真的被瞒过。真的那部分留下；现在要钱、要面子、要主播帮腔，另算一层。

## 本案怎么套

**案一。** 核心是不想把之前给的钱拿出去。还要挖出来说是替他俩存着。实际还要补：因为消费高早花了，不剩什么钱了。至少女的不说剩多少。

**Tony 案。** 因为钱没了所以想办法要。她也确实和 Tony 谈恋爱了，享受情绪价值，但是现在就是要钱。信息还不是 Tony 给她的，她只是借着 Tony 的渠道去买。

**其余案件**也要有类似桥段：面上一个说法，底下另有目的，再用更好听的话修饰。不要写成一个干净秘密、一次招认结束。
