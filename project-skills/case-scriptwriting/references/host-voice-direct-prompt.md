# 主播台词：直来直去 Prompt

日期：2026-09-19。声线规则仍看本文「怎么说」。**未改的原句和结构收口已并入 [未改项完整 Prompt](remaining-edits-prompt.md)**，开改用那份，不要按本文「各案必改」再开一轮。案三饭桌两连问已经改过。

先读本案可玩路径上的 `openingDialogue`、`entryQuestion`、`lines` 里的 host、`hostLine`、`hostHoldLine`、场尾、收麦。连线人别改文雅。不要恢复旧系统，不要重置存档。改完跑 `npm run content:index`、`npm run content:script`、`npm run check`。生成稿不能手改。

## 怎么说

钉事实，接着问。别宣判，别立法，别声明「今晚不算」「我没法判断」。

发现不对以后，可以对质里的主播追问做两连问：先钉已经露出来的错，再把一层显而易见能推出来的可能性问出来，逼对方沉默或反驳。第二问必须是听众现在就能想到的下一层，不能另开秘密。话要说全，别压成「按本科听」这种谁也听不懂的半句。

两连问写在 `lines` 里的 host。不要写进 `entryQuestion`、`question`、`hostLine`——那些字段同一话轮只能一个问号。

像跟人说话：短、具体、有脾气也可以。不要选择题论文，不要排比收束，不要评论区小编口吻。

收麦可以硬拒（不转、不介绍、不圆道歉）。那是办事，不是写作文。

## 不要写成这样

**生硬下判：** 事情摊开了，还替观众总结一课。\
反例：「你可以不喜欢他瞒着工作，但不能把自己享受的全略过去。」「你再补一张单，也补不出公司要付的钱。」「这就对了。」「这不叫再商量。」「补不上这六分钟。」

**怕过线就收：** 材料在眼前，先宣布这题今晚不许碰。\
反例：「今晚不能算到谁头上。」「先不说门口的人。」「不能拿一张卡的余额替他回答。」「不用在这里交检查。」「现在不想聊的，我们先不聊。」「我现在说不准……也没法替你判断。」「不替任何一边把结论补齐。」

**文绉绉：** 「是想证明 A，还是想把自己花过的先放下？」两个论文题。改成一句人话接着问。

## 各案必改

**案一。**\
- 「但不能把自己享受的全略过去」→ 接着问她自己花了多少，别下判。\
- 「今晚不能算到谁头上」→ 「用途没说，这笔先搁着。云栖接着说。」停问可以，别立法。\
- 「你拿这张停缴记录，是想证明……还是想把自己花过的先放下？」→ 「你拿停缴出来，是不想转，还是先不提你花过的？」\
不动：明白钱反正已经花出去了；你有什么话当着直播间直接跟他说吧；就想在我这讨个说辞糊弄人家；主动赠与是你现在的说法；转给你的钱，除了用于共同生活，你房租也不用出，剩下的钱呢。

**案二。**\
- 「这就对了」删掉，直接问合同和退钱。\
- 「先不说门口的人」→ 「门口的事先带过。十二万怎么给他的？」\
- 「他还欠你个交代」能留在场尾，前面问句别先宣判。\
修刘海场尾保留。

**案三。**\
- 「饭桌上查不清，回家就可以让家里按本科听」这类半句话不要。两连问写清楚：「他当面都说本科不是了，你怎么不接着问？回家还跟家里说他是那所学校本科毕业？」\
- 「这不叫再商量」可改成直接要求：条件不改，你自己跟父母说。\
- 「不能拿一张卡的余额替他回答」「他愿意给多少，你还没问清」→ 问她：「共同账户你不接受。那他怎么给，你打算听到什么才算数？」\
- 「那今天就到这儿吧」不要问着付法突然收工。该挂断用挂断词，别像怕得罪人。

**案四。**\
- 「旧的等新收款，新的一场又要你们先垫……」整段别讲庞氏课。主管原话已经在，问：「报销为什么要等下一场的钱？」\
- 「你再补一张单，也补不出公司要付的钱」→ 「你再交一张，钱就能下来？」\
不再垫款、群里问付款日保留。四千不要再当新秘密审（结构问题归另一份 prompt）。

**快案一。**\
- 「不用在这里交检查」「现在不想聊的，我们先不聊」删。生育不当通关，问一句「这事你打算什么时候跟对方说」就走。\
- 「今天我了解的还不够，先不替你介绍」删。留硬的：「介绍我不做。可靠我也不说。」

**快案二。**\
- 「补不上这六分钟」→ 「你当时已经难受，为什么回还行？」\
- 「只肯讲对自己有利的那半段，我没法替你把这话圆过去」→ 收到「这道歉我不替你圆」。\
- 「说不准他为什么不联系，也没法替你判断还要不要继续」删。

**快案三。**\
- 口播就说人话：名字照片都点了，末尾写虚构，这谁信。\
- 「合作方可不会陪她慢慢等」「热度是他主动要的」这类小编句改直。\
- 「不替任何一边把结论补齐」删。虚构你已经不信，别最后缩回去。\
第一段只钉虚构，代孕/热搜不必中。

## 不要做

- 不要改连线人文雅。\
- 不要为「直白」加骂人或讲大道理。\
- 不要只改 `whyTonight`。\
- 不要动案一你定过的那几句。\
- 快案四、序章亲子环、案四夜二审四千，不在本单。
