# 当前项目方向

更新：2026-09-17。适用于《深夜热线：直播间侦探》的主案、来电快案与口播快案。这里是跨技能创作规则的唯一维护入口；用户当前要求优先。历史评审、既有实现和示例不能覆盖新决定。规则归属见[标准索引](../../../docs/standards-index.md)。

## 从最近人工修改提炼的标准

### S1 本段问清，向前推进

围绕眼前争议集中问询，问题之间只保留听众理解所需的直接承接。没问清就留在当前段重新问；问清即推进。不得通过后段回滚、整段重听、重复原句轮询、收麦补问或完成度解锁来补同一问题。不为凑因果链添加中间人、材料和多轮反转。返回查阅已听内容可以保留，不成为必经循环。

先让来电人讲清本场诉求、理由与经历，再围绕其中的争议集中追问。陈述、问询、情绪反应按故事需要衔接，不设每夜场次、出示次数或信息峰值配额。

首次进入才播放整段开场；错问后直接恢复当前材料和问法，保存退出后也不重播。

普通问询只有一个有效接话时直接播放主播问题和回应，不再让玩家确认唯一问句；按阅读速度翻页仍保留。主案和来电快案按此方向改稿。口播快案没有在线当事人：读完当前材料，选择任一有依据的点评即可推进，未选观点不算错，不要求点完。集中问询也不等于取消思考、把所有问题变成自动成功，或强制每段只剩一问一答。

### S2 先收到，再使用

关键材料出现时交代谁发来、通过什么渠道、为何此时发。主播只能据已听到的原话、已收到的材料或亲历见闻发问；后台不是全知人物。可跳过的信息不能成为固定续文的唯一前提。一个自然的收件交代足够，不为证明来源增加转发链和授权口播。

材料能支持多少就问到哪里。相邻转账不自动是同一笔钱，历史消费不是现有余额，提交页面不是成交回单，转述不是本人确认。需要核实就对具体的人问具体内容，不用“还要另外确认”替代行动，也不反复用免责声明撤回已经成立的判断。

### S3 谁提供不利信息，要符合人物目的

被质疑的一方可直接发截图、原话或本人说明反驳。是否上麦服从本案设定和已发生的接入，不统一规定性别或通话人数。来电人也可以交出对自己不利的材料，但要有说得通的目的，如证明自己的遭遇、解释争议或被追问后补交；不能主动念完对方整套指控，替主播完成发现。

### S4 已经承认的事实不能重新成为秘密

按实际播放顺序连读上一句、问题、回答和下一步。角色说“你刚才说”或用引号引用，须与已播原话吻合。已经承认金额、来源、用途或日期，后面只能问尚未回答的部分、实际变化或另一人的说法。不要为了再次出示材料让人物失忆、重新否认，或把作者知道但玩家没听见的话算作已知。

人物可认事实而不认评价，继续保护钱、关系、面子或诉求，也可拒答、反击、谈崩或挂断。解释成立时主播调整判断，不以认错、道歉、完整自白作为通关条件；不为对称灰区给另一方编造过错。

### S5 台词是人对人说的

主播先问具体行为、金额、用途和意愿，语气可以直接、有脾气、好奇或讽刺。删掉为了不冒犯而绕圈的修饰、抽象审判、自己回答自己的问题和无对象的核验旁白。接话要针对刚听到的内容，不固定套“共情—核实—边界—结论”。

区分语音、文字、截图、录音与演出。只有收到文字或图片，才谈截图、裁切、那一行；语音立绘不等于主播看见房间或衣着。对方正在看直播，就不能无缘无故让来电人回头转发整段回放。按钮说明眼前动作，不用“追问这句”“材料试问”等含糊标签，也不标“关键选择”推荐答案。

### S6 材料操作直接，选项有实际区别

在当前问询中查材料、发问、听回答。相关材料与被问的话同页可核对，必要时保留原件展开。直接选择可说出口的完整问句；取消材料下拉框、原句配对、PRESS 隐藏解锁、试问／正式出示两套入口及跨行乘法式操作；比较多份材料本身可以有用，但不做多层操作迷宫。

序章沿用同一套操作，不额外教原句与材料配对。材料问询选中后，实际播放完整问句及对应人物回应，包括错误方向；不以旧的评题反馈替代交流。收麦后只读已收原件，必要的现场问答移到挂断前。

选项各自指向当前可疑处，错误方向应来自已知材料引出的合理怀疑或尚未回答当前争议的相邻问题，不拿显然无关或荒谬结论凑数量，不把答案先写进提示。有依据且能推进争议的问法可以同时成立；有用补问回答后留在本组，记录已问，不用纠错口吻。问错给简短、能接话的回应，然后本段再问；不扣耐心、不限制尝试次数、不挂断后罚重听。材料原件只读，删除无作用的行标注、额度与确认页。HUD 保留当前夜次与已收材料，删除耐心、空材料提示及伪进度。必要存档状态可保留，完成度、揭示率和最终原话打分不作为补剧情的门槛。

### S7 删除重复，保留有价值的生活交流

删除弹幕插话、替玩家裁判的评论、拖长的表情包描述、无意义喝水／盯尾号，以及重复确认同一件事的单线问答。问答已经完成任务时，不再用材料题、回拨开场、结尾点评重复问一遍。

熟人寒暄、真实照顾、接梗和人物习惯可承担关系与节奏，不要求每句增加证据，也不设段数、时长、说辞层数、金句、噪声、独立来源或最低字数配额。短不等于好；是否保留取决于这段交流实际做了什么。

### S8 收在当前结果，内部记录不变成报表

主要争议问清、态度明确或对方拒绝继续后自然收麦。短收麦不省略挂断前的判断和人物反应；已经成立的问题当面点明，允许对方抵抗或翻脸，不要求认错。必要的新问题提前放进对应问询段，不放进满格奖励深问。取消重复问“转不转”、重新概括全案和长篇责任口播。标题反映当前动作，不沿用已经取消的回拨、回放或调查。

内部事实、未知、来源和连续性记录保留，但不强制变成玩家页面。角色猜测与作者确认分开；没有确认的事不能在内部结案记录里悄悄升格为事实。口播案最后一段点评已经收住，就不另加同义总结。

## 案一的具体决定，不推广为其他案件事实

- 男友不上麦：看见直播说法不对，直接向后台发对话截图、流水和本人文字。匿名观众另发女方两年前去同一家餐厅的朋友圈，替代前同事支线。
- 先问酒水与高消费，再问支出来源、共同生活和剩余钱款；没有必要转述男友到闺蜜电话的绕路。
- 用户指定的口吻与落点：“明白，钱反正已经花出去了，什么时候能见回头钱咱也不知道。”“转给你的钱，除了用于共同生活，你房租也不用出，剩下的钱呢？”“你有什么话当着直播间直接跟他说吧。”
- 结束争执的态度：“就想在我这讨个说辞糊弄人家。你其实心里门清这些钱都花哪了。”“反正八万我不转，之前给我的就是主动赠与。”这些是本案台词要求，不是所有案件的结论或法律认定。

## 人物、世界与已批准片尾

玩家是林旭阳。身份、亲属关系和知情范围核对 `content/characters/cast.json`、`voice-bible.md`、`offmic-voices.md`；过时口吻随用户决定修正。妻子、好友、业务伙伴按关系接话，不重复初识，不因职业吞掉私人关系。案件亲友不自动成为主播朋友；个人直播不凭空增加导播班组和档案室。

保留已批准片尾：“故事未完待续”；“维护基本的道德底线是每个人都应该做的”；“主播将在正式版归来继续主持公道！”案内去说教不授权删除这些特定字幕。

## 现状与验收

四主案已接入 `focusedInquiry: true`、`compactClosing: true`，七幕证据问询使用 `acts[].inquiry` 的直接问句；两来电快案也已改为直接选择本段问法、错问本段重问。第三快案 `solo-commentary` 的任一有效点评推进继续保留。不能只加模式标志就宣称改稿完成，须同步台词顺序、材料来源、消费者和存档。

局部修句检查相关交换，整案审读检查当前实际路径；不为填账本扩大因果链。只记录、只审查、接入修改按用户授权区分。报告分清源码审读、自动结构检查和真实试玩。测试保留稳定 ID、有效引用、来源、顺序与恢复，不以旧配额、旧句子或已取消页面反向约束新设计。
