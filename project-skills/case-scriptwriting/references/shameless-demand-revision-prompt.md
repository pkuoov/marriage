## 总目的

让听众顺着「她今晚要什么」往下听，而不是顺着材料清单往下听。每一通最后剥开的，应是她真正要保住的东西，或她自己也没料到的乱局。

下面的逻辑链是发现顺序，不是每项都要新建一场。先按实际夜次和消费者核对必经对白；已听得到的保留或调整位置，不再补一次招认。过场只在需要新材料时带材料，不为每层另造凭据。妄人不硬挖隐情，口播案不套连线人的招认。

## 案一 信用卡

**目的。** 核心改成：不想把之前给的钱拿出去。不是审他乱花，也不是审他理财。

**逻辑链。**

1. 面上：八万是他的卡、他乱花、还瞒失业，我不该出。
2. 真要的：以前转到我这儿的钱，我不吐。
3. 盖着的说法：当初说「替咱俩存着」。现在改口「自愿给的」。
4. 再底下的乱：日子过得高，钱早花了。剩多少她不说。她门清：不想给，也没钱。
5. 他瞒失业、借款、信托，只解释他为什么开口要八万，不是本案高潮。

**现稿差在哪。** 夜二已经有「替我们存着」的聊天，也逼她报出「一万一千六百多」。和「至少女的不说剩多少」相反。`credit-bank-flow` 先认花掉半薪，再到 `credit-loyalty-test` 问代存约定，发现顺序倒了；后者第二幕还把已认过的个人消费重新全盘否认。开场和社保段仍容易把戏抢到他头上。三万五用途未明；一万二设备已在账单和她的陈述中出现，不能一起当作没有材料。

**要改。**

- 可玩顺序对准：不想吐旧钱 → 挖出「替他俩存着」→ 补出基本花完。把代存约定放到集中追问半薪去向之前；后面让她争「也是为了两个人」，不要再否认已经认下的个人消费。余额她可以含糊、可以拒报，但「没存下」要由已认下的花销和她拿不出钱的回应撑住，不能仅凭拒报余额断定。作者记录可以留精确数，她嘴里不要报。
- 「一万一千六百多」从她的台词、收麦、分享文案里拿掉或改成她不说，同时检查 `publicHook`、`storyInterludeRecap` 等玩家可见摘要。内部可以留真实余额，但不能再记成「她已承认精确数」。男方可以仍以为她有十五万。
- 三万五：收在用途没说明，不拿它认定花在谁身上，别再许明天对。设备：保留已认的一万二和她受益的事实，不另审分期、赠与或收益承诺；不要把归档的设备场整段捞回来。
- 失业、流水、信托放在「她不吐钱」之后，当他的线，不当收口。

## 案二 名单 / Tony

**目的。** 她现在是要钱。恋爱是真的，但盖不住「钱没了才急」。

**逻辑链。**

1. 面上：一排女人，恋爱诈骗，把十二万要回来。
2. 真的一层：她跟 Tony 谈过，也吃留晚档、叫自己人这些好脸色。
3. 现在：钱没了，就是要钱。
4. 再底下的谎：高息不是 Tony 先推销的。她听来的，不够门槛，借他的户去买。用「他骗我」盖「我自己要买、现在拿不回来」。
5. Tony 收钱不交合同，仍要交代。她裁图、她先开口，不能变成没人帮她追凭据。

**现稿差在哪。** 夜一已经提到小姐妹与高息，夜二 `tony-caller-benefits` 已经说「我先问能不能跟着买」「并进他的户」，不是只有作者记录。问题在于夜一主播仍说「他没答应过在谈」，与本轮恋爱是真的冲突；夜二先问警察与借款，冲淡了主动代投。她听说赎回拖延才翻手机的先后，仍留在 `tony-next-push-column.questionOptions`，不能当作当前 `acts[].inquiry` 已经播到。

**要改。**

- 夜一：完整图和她的回答证明名单在记钱；裁图本身证明她隐去了钱的部分。保留确实谈过恋爱、约会和情绪价值，把「他没答应过在谈」这一否定关系的判断改掉。不能从恋爱是真的跳到名单上其他人也都是女友。
- 夜二尽快落到：十二万怎么走他户、谁先说要买、她何时听说可能拿不回。警察敲门当过场，不要长成主问题。她自己那笔借款点到为止。
- 沿用已播的「小姐妹那儿听来的、借 Tony 的手买」，集中打她为什么省掉主动代投；把「转钱后听说赎回在拖，才翻名单」接进必经交流，不重复审已经认下的消息来源。「钱没了」是她拿不回钱的处境，不提前确认十二万已经亏光或实际买成。
- 修刘海留在收尾，不另开一层。

## 案三 彩礼

**目的。** 学历是开门的谎。底下是加价，再底下是钱怎么给、进谁卡。取消见面还要他去说忙，是另一层修饰。

**逻辑链。**

1. 面上：名校本科，我们被资料骗了。
2. 盖着的：介绍人/他自己说的，我只是转述。
3. 真要的：查完普通家境，彩礼往上加；她知道，也觉得该多拿。
4. 再底下：二十八万八领证前入她个人卡，婚宴首饰另算。她自己的钱不对等。
5. 谈崩后：条件不改，要一个更好听的取消理由（说忙）。
6. 一团乱：两边数字都是真的，却不是一笔已经谈拢的共同安排。

**现稿差在哪。** 夜一 `profile-caller-repeats-label:questionOptions:0` 已在必经顺序里说「我当时也觉得他该多拿一点」，不缺这句。夜二还用学费解释她为什么不信男方，随后又围着「只差两千」问。付法、共同账户拒绝和「说忙」已经存在；要加强的是从她赞成加价到她坚持付法的承接，不是再补一次承认。

**要改。**

- 保留夜一她也觉得该多拿的现有回答，后续不能又退回「都是我妈定的、我不知道」。
- 再用「他只给一张工资卡、没诚意」去盖「条件我不肯改」。她可以嘴上说不能改，剧情要保留这是她也赞成的条件。
- 夜二不要再审学历。对准付法：进谁卡、何时给、另算什么、她那边出什么。「共同账户她不接受」先落地，一团乱才听得见。
- 「只差两千」不能盖过「他拒绝的是这套付法」。
- 收麦停在条件不改、要他去圆，不要停在学费那句。
- 说忙保留。宸直三十万只当她家里的未知，不当本通暴雷。
- 别补：介绍人再反水、第三套彩礼数字、本通宸直暴雷。

## 案四 职场垫款

**目的。** 催六万八是面。四千分成是第一层底。再挖下去，不是他一个人手续没办好，是公司本身在空转，像庞氏。

**逻辑链。**

1. 面上：我垫了六万八，怕群里一问就没活动。
2. 盖着的：我想争这场，临时被叫去垫。
3. 真要的（开头）：业绩，还有那四千。
4. 她/他开头未必知道有多大。白天或夜二才看到：别的部门也在等钱，单子齐了也不付。
5. 乱局：整个公司就是个庞氏骗局。本通能挖到「不是我这一笔、钱从后面补前面」，案后的宸直/押金不要开场讲。

**现稿差在哪。** 谁让垫、四千、审批原页已经能打。跨部门待付有。第二夜先打待付，最后却又回到四千与外部协调，容易把最大问题收回个人多报费用。「上回有人结了、现在各部门待付」还没有交代新钱怎样接旧缺口，不能单凭这两件事就认定后钱补前钱。案后经营数字仍像关灯补课。

**要改。**

- 四千认下之后，先问他准备怎么催、是否还想接下周的活动。这里可以仍抱希望；最终「不再垫」留到乱局揭开以后，不提前完成再让他无故反口。
- 四千与费用草单的遮掩要收住，再打穿他下一句盖法：「会优先办我的 / 下周还能垫」。沿用上回到账让他敢垫、现在各部门齐件也不付款这条线，不在揭开公司问题之后又把四千当新秘密审一遍。
- 再集中处理待付：材料齐了为什么还不打钱。沿现有主管消息、前主办或财务受理线补一条具体联系，例如旧款明确要等下一场收款才能付；这是待补剧情，不是现有材料已证明。先交代谁收到、为什么现在拿出来，再让他发现公司依赖后续进款顶旧缺口，不能把先后发生的两笔账直接当成同一笔钱。
- 公司庞氏方向保留，本通让「后面补前面」有可听见的依据。他开头可以真的不知道有这么大，也不必突然懂集团账目。口头信息若只能支持怀疑，就让主播追问这个滚动填缺口的做法；不要凭待付直接宣布已经查清全部骗局。不新开资金链讲座，不把押金归集提前口播。
- 不再垫款、群里问付款日保留。
- 别补：新反派、押金课、开场讲暴雷。

## 快案一 什么都不图

**目的。** 「什么都不图」盖「要介绍」，再盖「还要你说她可靠」。

**逻辑链。** 患难、穷爸爸是面 → 两个爸爸不是一个人 → 登记表上的普通人她先不要 → 今晚要介绍，还要主播背书。生育顾虑是旁支，不当通关。

**现稿差在哪。** 链在，自动对质和旁支仍可能抢「先说可靠」。身世拆穿后，她还要介绍这句容易被带过去。

**要改。** 可玩路径按：身世对不上 → 她还是要介绍 → 口头低要求不当真 → 不介绍、不背书。不要并成开场一次讲完。生育别抬成主线。

**逻辑链。** 漏消息是面 → 「还行」的时候人已经不好了 → 桌上还有别人、后来也不是一次 → 她漏说，却要对方先低头。

**现稿差在哪。** 三环清楚。听歌、包、花不要回到核心。

**要改。** 只检查第一轮是不是打「还行」。旁支保持能问、不必中。
