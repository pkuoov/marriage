## 二、Tony：警察收成过场

文件：`cases/02-tony.json` 的 `tony-who-messaged`，以及夜一挂断、回拨开场。

**目的。** 夜二尽快落到十二万怎么走他户、谁先要买、何时听说拿不回。门口来人只带过。

**现稿。** version 已经能一句带到警察和自己那笔借款。闲问还全是警察、搬家、催债。`helperHint` 仍写「先问昨晚来人是谁」。夜一挂断「先不说门口的人」，回拨「昨晚门口的事交代一下」——过场占了主位。

- 必经问不要再审警察。闲问若还留警察，最多一条，不要三条占满。
- `helperHint` 改成追十二万和谁先要买，不要先追门口是谁。
- 回拨不要先追「门口是谁」。
