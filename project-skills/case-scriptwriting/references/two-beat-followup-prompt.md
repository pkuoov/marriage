## 怎么问

发现不对以后，对质 `lines` 里的 host 可以两连问：

1. 先钉已经露出来的错。
2. 再问一层听众**现在**就能想到的可能性，逼对方沉默或反驳。

第二问还是这一层，不能另开秘密，不能把夜二的词提前问出来。话要说全，别压成半句。不要写成「是 A，还是 B」论文题。不是每个对质都两连问。

两连问只写在 `lines` 的 host。`entryQuestion` / `question` / `hostLine` 仍只一个问号。
