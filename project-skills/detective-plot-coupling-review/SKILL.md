# Detective Plot Coupling Review

遵循 [当前项目方向](../case-scriptwriting/references/current-project-direction.md)。侦探技法用于当前故事需要的发现，不要求所有来电都有多层骗局、反转、非线性调查或双方过错。

## 核对当前发现所需的承接

读取目标案、相关时间线、人物知识、材料来源、实际路线与连续台本。区分作者实际发生的 B 故事、来电人想让人相信的 A 说法，以及目前玩家听到的部分。

对承重发现记录：前文痕迹、可见来源、玩家动作、人物回应、后续变化。未知也要具体，但不用安排角色逐项说出来。没有依据的外部事实不能在结尾突然补出；有依据的怀疑可以先问，再根据找补或解释调整。

可选技巧：
- False solution：真实细节支持一个不完整解释，后来的发现改变理解。
- Missing edge：截图、称呼或承诺缺少一项会影响当前判断的信息。
- Quote payoff：旧原话在新语境中显出另一层意思，引用须来自实际已播内容。
- 实物-言语死锁：材料与说法冲突，玩家选择原话和材料出示。
- 压力访谈：对方为维护原诉求而收窄承诺、改换用途或继续抵赖。

按需要选用，不凑层数，也不强迫每个承重点同时有文书和两个独立来源。原话和改口能证明说辞变化，不能因此证明外部资金已入某账户。其他模型见 [detective-patterns.md](references/detective-patterns.md)，只作选用参考。

## 检查具体断点

- 玩家发现之前是否已由材料标题、NPC、弹幕或提示说出答案。
- 同一事实是否被回拨开头和后续场景重复当作首次揭露。
- 引用有没有扩大原话，角色有没有知道后面才会收到的消息。
- 删除或跳过调查后，后续是否仍假定得到那条信息。
- 两次材料是不是同一来源的重复，而非独立佐证；相邻流水是不是被拼成未经证明的钱路。
- 反转是否抹掉已经真实发生的帮助，或为“灰区”强给一方增加过错。
- 被点中后的否认有没有具体利益和新理由；不以完整招认、认同主播或道歉作为揭露验收。

人物关系、幽默与日常停顿可以保留。删掉后没有损失一条证据，并不意味着这段没有价值。集中问询与材料核对让玩家参与，不需要必经回放循环；不恢复“线性禁令”、地点数量或 NPC 拒绝／打断／冲突配额。

## 伏笔与包级接续

对明确影响剧情的悬念记录铺垫与回收位置、此时证明的事及尚未证明的事。普通被注意的喝水、关窗或闲聊不自动升级为必须回收的谜题。警笛、敲门若导致突然挂断，后续应交代实际后果；不能当纯背景音遗忘。

已设计的熟人约定、夫妻互动、业务压力和跨案机构线继续保留。跨案新闻晚于其种子与时间点，不替旧案追认账户、损失或主观故意。尾声可让物件和人物自己呼应，不必用总结墙宣布主题。

原同席场景已撤销时，连同其独有证人、授权和回声一起撤销；不再以旧“同席特许”给凭空目击者续命。保留的回声须有现在仍可走到的来源。

## 接入与验证

先修导致断点的来源或顺序，再改相关对白；同步人物知识、作者合同和引用。不要为补一条因果而强造一份文件、一名证人或一次调查。

运行内容生成、现有合同校验和受影响路线。涉及模式或存档时按 [运行时内容接入](../case-scriptwriting/references/runtime-content-integration.md) 验证。报告实际发现及证据，不把“满足多少种反转技巧”作为质量成绩。
