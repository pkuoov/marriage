# 可选推理写法

遵循[当前方向](../../case-scriptwriting/references/current-project-direction.md)。这些方法只在现有事实需要时使用，不是每案工序，也不要求借鉴特定作品或增加因果链。

- 省略范围：截图裁掉了一列，先问原图。材料完整并不意味着一定还藏另一层秘密。
- 同一事实的不同用途：承认收钱后仍争赠与还是共同支出；继续问用途，不重新证明收过。
- 已知照顾与当前争议并存：曾经帮忙是真的，不能据此推定现在的收款已履约，也不必把帮助改成全是假。
- 口述与材料不符：保留可见原话，再问具体差别。角色可以解释成功，不能每次强制揭穿。
- 新来源带来新问题：本人后台回应可以直接进入问询，不为多层调查绕经朋友、同事和陌生证人。
- 未解决的行动：合同没交、条件没谈拢、付款没到，可以收在这里，不用额外揭秘或责任报告。

避免材料重复已问清内容、角色忘记前话、点评先给答案、每案同样的反转和固定双方过错。证据无需反复出现才算有价值，纯关系与生活交流无需伪装成线索。公开口播没有现场当事人，不凭空安排质询回答；任一成立点评可结束本段。
