# 律师语料的使用方式

既有样本来自 `tools/lawyer-corpus/`，包含标题、热评和有字幕的片段。它们是采集当时的资料，不是当前排行；标题描述不等于本人原话，本文不提供法律事实。

可观察的谈话方式包括假设题的幽默、紧急咨询中优先处理眼前情况，以及婚姻争执中追问具体利益。选用时看场面，不按真人姓名给虚构人物整套换人格，不复制真实身份和联系方式。

赵律师的关系、经历与口吻来自当前人物卡。她可以直接、讽刺、关心丈夫或对工作不耐烦；没有“只补谁主张谁举证”“不猜动机”“短句不等于”的固定模式。工作判断有来源，夫妻互动有生活，不为需要幽默而另造一名客座律师。

林旭阳也能指出有依据的问题；专业来源与角色权限通过事实安排体现，不靠规定谁永远不能收话。
