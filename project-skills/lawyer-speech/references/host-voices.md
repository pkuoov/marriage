# 律师主播声纹（只抄形状）

来源：每人 B 站播放量前 30 的标题和热评。禁止把原片标题、真名、咨询微信号写进游戏。

## 冯予希：假设题店

Top30 流量王不是连麦，是把法条问成脑筋急转弯，夹人设整活。

- 假设题：执行完才抓到真凶还能不能救；缓着的不想再缓；续命像不像能卡 bug；一种时长违法、拉长了呢；没有国籍的人在公海上；能不能告到最上面那一层、谁收案。
- 对照题：同样是造假摆拍，为什么一个罚钱、一个进刑事。时事只当对照，不复述事件细节。
- 荒诞案当段子：捡到别人扔的东西、做出怀孕、回头要钱；关系称谓套叠（他的他来告我）。
- 人设整活占了多条头部：跳舞、擦不擦边、美颜、被封、客户问干这行多久、像不像假律师。这是开场，不是法律结论。
- 收句用构成/管辖/不构成，不教怎么做那个荒唐前提。
- 不要写成婚姻撕人，也不要写成赵律师的短句阀门。

## 郭庆梓：先救人，再定罪名

Top30 是刑案连麦和罪名课。观众记得的是「人都昏迷了还先连麦」和「只听一面就能打出疑点」。

- 第一句打断操作欲：先救人 / 先送医 / 先停手。再谈报警、自首、谅解。
- 只听家属或当事人一面，也先问程序漏洞，不先承诺无罪。
- 争点写成选择：这个行为定 A 还是定 B；判得重不重；这种自首算夯还是拉。
- 现场金句形状：在线等很急；这心态太强；律师求你先救人。
- 程序感：办案机关那句暗示你听懂了没有；看守所里的身体变化当时间锚，不当教程。
- 性、暴力、未成年人只保留罪名和程序，不写怎么实施。
- 适合当「刑案顾问」或错误来电里的狠问题，不适合当红娘。

## 郭延娇：听坑，不背锅

高播几乎全是婚姻连麦切片。观众夸的是每句无法被选中、免疫性别攻击、把遮羞布撕开。

- 先听坑：绕过语言陷阱，不当她的背锅侠。
- 听完可以直接恶心：这十五分钟我都难受，对方离得好。
- 性别攻击回弹：对方喊「我是女的啊」，回「我也是」。男律师说同一句会被打，女律师这句是绝杀——游戏里赵律师可用更短的「性别不是论据」。
- 译价三层：她以为抚养费是养我和孩子；普通人以为是养孩子；纸上往往是养孩子、两边分。
- 点破哭和钱不是同一套声线：前面一直哭，谈到利益语气就变。
- 收场可以劝离，但不写财产怎么分、怎么藏、怎么告。
- 扎心现实句可以有：「别再自我安慰优秀了」；下一句仍要落回本案物件，不能变鸡汤或教程。

## 和赵律师的边界

赵律师固定：短句、明确、不等于；不猜动机、不许诺判决；私下先问吃饭。

- 需要假设题幽默 → 另上场客，不要让赵律师玩卡 bug。
- 需要听坑撕遮羞布 → 另上场客，赵律师只补「谁主张谁举证」。
- 需要先救人 → 赵律师可以短喝止，不展开罪名课。

## 禁写

- 真名、律所城市、微信号、委托价。
- 会见、取证、转移财产、卡缓刑的步骤。
- 复述伤害或性犯罪过程。
- 林旭阳用律师金句收案。
