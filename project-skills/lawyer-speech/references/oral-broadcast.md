# 口播模版（律师切片是标准，不是诉状）

这些普法假设题、刑案连麦、婚姻听坑的标题和热评就是台词的口语标准。写完先按这个表朗读，再过 `case-scriptwriting` 的口语门禁。本表管「像不像口播」；那张表管「像不像这个人」。赵律师默认仍是短句、不等于；客座才换店。

只抄形状。禁止原片标题、真名、咨询微信、办案步骤。

## 一口气

- 一句能喊完。超过两个逗号就拆。
- 「在符合……的前提下」「根据相关规定」是诉状，不是口播。
- 律师金句必须能当切片：先救人 / 不构成 / 不等于 / 谁主张谁举证。

## 人称

- 我 / 你 / 他 / 你老公。禁止「原告」「被告」「该行为人」出现在连麦里。
- 纸用口语名：回单、流水、那张单，不用「举证材料包」。

## 标题即口播

- 假设题：「还能不能救？」「能不能立刻执行？」
- 急问：「报警前能再……吗？」第一句先停手。
- 听坑：「我聊这十五分钟都难受。」
- 三层译：「她以为养我和娃；纸上往往是养娃、两边分。」一句一层，不要写成定义表。

删掉案件专名后，仍应像连麦，不像法律意见书。

## 先动作，后名目

- 坏：「亲子异议的构成要件尚未满足。」
- 好：「谁提出，谁先拿依据。现在连能送检的东西都没有。」

可以残酷。不能把构成要件念成清单。

## 半句原则

- 当事人先要一个许可：「能不能再」「有没有机会」。
- 顾问回一句程序，不停下来讲课。
- 一案律师金句 ≤2。

## 禁写（口播指纹）

- 然而 / 因此 / 综上所述 / 依法应当。
- 会见话术、取证步骤、怎么藏、怎么告。
- 复述伤害或性犯罪过程。
- 赵律师玩卡 bug，或改成「你离得好」。

## 朗读验收

1. 说话速度读这一句和前后各两句。
2. 上一句的词能接到这一句。
3. 读完要么是能切片的程序句，要么是当事人要许可的半句。两样都不是，再改。
