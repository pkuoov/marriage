# 律师连线当事人语言（只抄形状）

来自三人播放量前 30 的标题轴和热评。当事人本人仍只说半句。

## 开口就要许可，不叙事

合格开口像要一个开关，不合格开口像小说。

- 刑案急：「他还在流血，我能不能再……」「二审有没有机会无罪。」
- 婚姻急：「我要离，孩子我带走。」「他特别好，就这一点。」
- 假设玩：「这样算不算违法。」把生活过成选择题。

不要让当事人第一句就分析自己的依恋类型或背诵法条。

## 高频轴

| 轴 | 当事人形状 | 律师下一刀 |
|---|---|---|
| 先动手再问 | 「我先做完再问你合不合法」 | 打断：先停手 / 先救人 |
| 只要结果 | 「有没有机会无罪 / 能不能轻一点」 | 只听一面也先打疑点，不承诺 |
| 性别挡箭 | 「我是女的啊」 | 性别不是论据 |
| 哭和钱 | 前面哭，谈到卡、房、抚养费就换声 | 把两套声线当众对照 |
| 抚养费 | 「养我和孩子都该他出」 | 译成她以为的 / 纸上会写的 |
| 工资卡 | 「为什么要上交」 | 问上次钱实际进了谁的口袋 |
| 好儿媳 / 好丈夫 | 自我标榜一套，物件对不上 | 别祸害对方了，先看这一张纸 |
| 优越感破防 | 「你说话真难听」 | 「你花钱买的是这个」——游戏里留给顾问，不给林旭阳 |
| 许愿机 | 辩赢律师就该分配结果 | 咨询不是发配偶、也不是发判决 |

## 被追问时的闪躲

- 用委屈挡物件：「我都记不清为什么吵了，都是鸡毛蒜皮。」
- 用身份挡责任：「我是女的 / 我还是硕士。」
- 用未来挡现在：「他退役以后就好了。」
- 数字抖动：月花、回家天数、次数，先报一个整的再改。

## 被点破后的三路

1. **急眼**：嫌律师难听，坐实优越感。
2. **改口**：当场降需求，下一句加回来。
3. **推家**：越界要求说成父母的。

不写立刻认栽的自我审计。

## 评论区中译中

写弹幕用这个形状，不要让林旭阳说：

- 人都昏迷了还先连麦，这心态太强。
- 女人的钱是自己的，男人的钱是全家的。
- 挣得再多也是 ta 自己的，不是家里的。
- 吃不饱只有一个烦恼，吃太饱烦恼无穷。
- 正常过日子的人往往不花钱来连麦。

## 和热线咨询者的差别

热线咨询者绕。律师连线者更快要一个许可或一个结果。若一案从热线转律师，前三十秒可以热线，进入「这算不算 / 我能不能」之后切到本表。
