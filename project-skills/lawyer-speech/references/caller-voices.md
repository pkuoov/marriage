# 法律咨询来电人的可选反应

既有样本来自标题、热评及部分字幕，不能把标题轴当真人完整对白。遵循 [当前项目方向](../../case-scriptwriting/references/current-project-direction.md)。

来电人可能先问能不能做某件事，也可能先讲经过；不限制为半句话或前三十秒切换某种声口。他可能想获得许可、挽回损失、替家人辩解、让顾问认可自己的理解。

被追问时，可以抓住一个对自己有利的细节重复、争某个词、搬出家人意见，或只认已经无法否认的动作。原因来自本案，不从语料给每个人添加哭腔、身份口号或统一推责方式。

事实清楚不等于当事人愿意接受评价；相对受损的人也可能确实没有隐瞒。按前后交换判断，不能让每个来电人都变成等待律师点醒的人。
