# 有意思的情节 / 对话（只抄形状）

来自三人 B 站播放量前 30。写进游戏时换本案物件，删掉可检索原题。不复述伤害过程，不写成操作手册。

## 冯予希：把法条问成段子

- **执行完才反转**：处罚已经做完，真相反过来了，还能不能撤回。收在管辖和程序，不写怎么执行。
- **缓着的人不想再缓**：当事人嫌等待，问能不能立刻走完。律师只答程序开不开这扇门。
- **对照处罚**：两段看起来像同一种假，一个罚钱、一个进刑事。让观众自己问「差在哪一层」，主播只追问材料，不给标准答案讲义。
- **称谓套叠**：来告的人跟当事人的关系叠了两层（他的他）。先把关系图画清，再问诉因。
- **捡到遗弃物之后的主张**：从别人扔掉的东西推出一个人身结果，回头要钱。争点是同意、因果、证据，不是教怎么做。
- **客户问干了多久**：经验梗当开场，下一句必须回到本案纸。
- **假律师恐慌**：有人被爆执照是假的，弹幕来问「会不会是你」。适合人设压力，不适合当法律结论。

不要把整活（跳舞、擦边、美颜、封禁）写成案件真相。

## 郭庆梓：人还没稳住，先来要许可

- **流血还在线等**：人已经倒了，来电先问「我能不能再补两下」。律师第一句是救人，观众笑的是心态，不是招数。游戏里只保留「先停手」。
- **家属上麦问无罪**：只讲对自己有利的一面。律师不承诺结果，只把疑点一条条问出来。弹幕比律师更早看见破绽。
- **同一个结果，两个罪名**：人已经不在了，争的是定轻还是定重。只写争点名，不写怎么造成这个结果。
- **花式自首排行**：有人来问自己算不算主动。律师用「夯还是拉」收，不教怎么补自首。
- **送回去之后被反告**：好心或冲动送人，自己进了看守所。锚点用时间（待了多久、瘦了多少），不当教程。
- **机关那句暗示**：来电人觉得对方在暗示。律师问「你听懂的是哪一句」，不替他翻译成对策。

## 郭延娇：十五分钟听出两套人

- **听坑不背锅**：对方每句都像要把责任塞给律师。律师绕开，不当选中项。
- **聊恶心了**：还没听完案，顾问已经受不了。收句是「对方离得好」，不是财产方案。
- **我是女的啊 / 我也是**：性别当挡箭牌。回弹要短。赵律师用「性别不是论据」，客座才用更损的那句。
- **老实声音**：同一类来电声线重复到能认。用来写「又是这套」，不要写成歧视。
- **哭完谈钱变声**：前半段委屈，问到卡、房、抚养费，语气干净了。把两段原话并排。
- **抚养费三层**：她要养我和孩子的全部；普通人听成养孩子；纸上往往是养孩子、两边分。只译名目，不写怎么要到最多。
- **产后第一战**：记不清为什么吵，记得都是小事；物件对上的是到单位闹、路断了。
- **你说话难听 / 你花钱买的**：破防句。留给顾问，不给林旭阳。
- **别祸害人家了**：自我标榜好儿媳 / 好丈夫，认知和物件对不上。劝离可以，夺产步骤不行。

## 怎么用在《深夜热线》

- 一案挑 **一个** 情节形状，换成本案账单、短信、鉴定、钥匙。
- 林旭阳负责把荒唐前提按回物件：「谁在流血」「哪一张纸」「上一句原话」。
- 错误选项可以是「教他下一步怎么做」；正确方向是停手、保全、分开已知与未知。
