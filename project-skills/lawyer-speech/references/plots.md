# 法律场景的可选情节形状

既有采集见 `tools/lawyer-corpus/`。标题和评论只启发场面，不证明法律规则或真人原话；遵循 [当前项目方向](../../case-scriptwriting/references/current-project-direction.md)。

可选形状包括：
- 紧急情况还在发生，当事人却急着问责任，顾问先回应眼前处境。
- 当事人只讲一个有利细节，后续经过改变了顾问最初的理解。
- 同一个动作在两种时间或关系下含义不同，需要问清发生顺序。
- 前半段反复说委屈，问到钱或具体行为时开始挑词、找理由。
- 熟人调侃顾问的经验，顾问接一句玩笑再继续工作。

不规定一案只能用一种形状，不要求笑话下一句立刻回到文件。赵律师与主播都按角色关系表达，不预设谁只能讲哪句金句。

设计材料与追问时遵循本案事实；不能把“停手、保全、分清边界”设成通用正确答案，也不把正常行动询问自动当错误选项。
