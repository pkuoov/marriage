# Lawyer Speech

遵循 [当前项目方向](../case-scriptwriting/references/current-project-direction.md) 和角色卡。赵律师先是具体的人和主播的妻子；工作中直接、熟人间有生活感，不固定说“不等于”，也不在每次交锋后补一句程序或证据边界。

## 使用语料

`tools/lawyer-corpus/` 是既有采集资料。字幕可用于观察真实话轮；标题、热评和剪辑只说明传播方式，不能当作原话、事实、法律来源或口语验收标准。采样范围和账号数据仅代表采集当时，不作为实时排行。

按需读 [host-voices.md](references/host-voices.md)、[caller-voices.md](references/caller-voices.md) 与 [plots.md](references/plots.md)。形状可以借鉴，不能复制真人身份、联系方式或完整切片，也不把既有角色换成语料中的某位律师。

## 写眼前问题

顾问回应当前事实、争执或行动障碍，不照着法律意见书报完整流程。可以直说、反问、打断，也可以寒暄或不接话；不限逗号数，不要求每句能切片。

职业词是否保留看对象与场合。讲法庭里的原告被告可以用原称，谈夫妻之间的事用自然人称。不要为了口语化把法律含义改错，也不要为了准确每次朗读免责声明。

区分角色威胁、法律推测与确定规则。涉及具体法律结果时按故事所在地和时间核实可靠法律来源；语料和用户描述都不是法源。核实结果写进作者事实记录，只把影响眼前对话的一点写进对白，不许诺必胜或把拒绝一项行动自动当作所有事实成立。

私人建议、公开争执和受托工作按人物实际关系安排；不能为了显得公允把妻子写成桌边公证人，也不能为了表明身份强行自报代理权限。正常材料询问不因旧 skill 的“禁止办案步骤”而被一概删除，具体内容按任务、现实准确性和场景需要判断。

## 验收

连读前后交换，看顾问是否接住问题、保持知识来源、人格与关系，是否用一句无关程序总结冲淡了刚才的冲突。受损来电人可以真实受损，被戳中者仍可争责任；不强求哭腔、性别口号或自白。
