# Lawyer Speech

写律师顾问、连麦咨询或法律边界台词时用。说媒场用 `matchmaker-speech`，不要把打分腔和本表混用。

语料：`tools/lawyer-corpus/`。采集是 B 站 `order=click` 后再按播放量取每人前 30，**不限婚恋**。只抄**形状**，不抄真名、可检索标题、咨询微信、办案步骤。玩家仍是主播林旭阳。赵律师是他妻子，默认声口仍是短句、不等于、不猜动机、不许诺判决；顾问上场才换下表某一种声纹。

口播标准见 [oral-broadcast.md](references/oral-broadcast.md)。这些切片就是口播模版，不是诉状。声纹见 [host-voices.md](references/host-voices.md)、[caller-voices.md](references/caller-voices.md)、[plots.md](references/plots.md)。流量池与分栏报告见 `tools/lawyer-corpus/out/patterns.md`，覆盖与缺口见 `out/coverage-report.md`。话轮池只认字幕；没有字幕不得用标题冒充真实台词。

## 口播模版（先过这关）

普法假设题、刑案连麦、婚姻听坑是标准口播。

- 一口气喊完。禁止「根据相关规定」「在符合……的前提下」。
- 连麦里用我/你/他，不用原告被告。
- 先动作后名目：「谁提出，谁先拿依据。」不要念构成要件表。
- 当事人先要许可。顾问回一句程序就停。
- 赵律师仍是短句、不等于；不玩卡 bug，不说「你离得好」。
- 赵律师受一方委托时必须让人听出她在替谁办事，不能为了显得公允把她写成桌边公证人。亲子问题在公开现场吵起来时，她先压住争吵，只说「你俩先别吵，这里也掰扯不明白」这一类现场话；不要替任何一方拿孩子训人。检测、诉讼或下一步，等公开争吵结束，再对委托人私下说一条最可行的方向。
- 和 `case-scriptwriting` 口语门禁同时过。

## 覆盖缺口

| 人 | B 站 Top30 实际是什么 |
|---|---|
| 冯予希 | 官号，单条 240 万–640 万。假设题 + 时事对照 + 人设整活。不是连麦撕人。 |
| 郭庆梓 | 官号，单条约 100 万–137 万。刑案连麦 / 罪名争点 / 先救人。 |
| 郭延娇 | 官号粉丝少；高播在切片号，18 万–71 万。婚姻连麦撕遮羞布，听坑不背锅。 |

一案只用一种律师声纹。不要把赵律师改成郭延娇撕逼，也不要改成冯予希抽象整活。

## 三种骨架

1. **假设题店（冯予希）**：把法条问成「能不能卡 bug」。先给一个荒唐前提，再收成一句管辖/构成/不构成。人设整活可以当开场，不能当结案。
2. **刑案连麦（郭庆梓）**：人还在出事，先打断操作欲。只听一面就打出疑点。争点是罪名和程序，不是道德宣判。
3. **婚姻听坑（郭延娇）**：15 分钟听完坑，不背锅。哭的时候一套，谈到钱语气变了。抚养费、工资卡、谁离得好，当场译成三层：她以为的 / 普通人以为的 / 法院会怎么写。

林旭阳只追问物件和原话，不替律师完成判决，不教观众怎么告、怎么藏、怎么夺产。

## 律师话术（顾问角色）

- 先要可核的动作、时间、纸，再谈感受。
- 判决用程序句：不构成 / 不等于 / 谁主张谁举证 / 先救人再说话。不用「你值得被爱」。
- 金句短、可切片。一案律师金句 ≤2。
- 可以残酷，操作手册不能出货：不写会见话术、取证清单、转移财产步骤、怎样卡缓刑。
- 伤害、性、未成年人只写争点（定什么罪、先做什么），不复述过程。

## 连线当事人

- 开口先要一个动作许可：「能不能再……」「二审有没有机会」。
- 婚姻连麦：哭、委屈、我是女的啊；钱一到，语气换档。
- 把咨询当许愿机：辩赢律师就该得到想要的结果。
- 被点破后急眼「你说话难听」，或改口，或把锅推给家里。

## 验收

- 删掉案件名词后，律师句仍像该店声纹，不像媒人打分。
- 赵律师没改人格；林旭阳没替律师收案。
- 没有真名、原片标题、微信号、可执行的办案/夺产步骤。
- 每句能当口播：朗读像连麦，不像法律意见书。
