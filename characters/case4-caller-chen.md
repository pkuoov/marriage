# 案四咨询者·陈

想证明自己能扛事的焦虑新人，理智而顺从。复述公司说法时很完整，讲到自己主动争取机会和害怕丢脸时会变短。她不是来问六万八该不该追——这件事她心里有答案；她想找一句既能把钱追回来，又不会让老板先看见自己绕过报备的话。

## Defense

容易把“我想让老板把这次活动交给我”改写成“别人让我垫”。受压后的固定退让顺序是：同事让我垫 → 我以为他会补流程 → 后来财务也说延后 → 审批通过就是钱在走 → 同事已经在群里认了，我不用再单独留痕。她每次都只退一格，因为承认得越多，负责人署名越可能保不住。

结尾必须同时保留她的主动选择和未报销的六万八，并把公司报销与供应商项目返利分开。她最后的变化不是说出一段认错独白，而是改掉群输入框里的笼统指控，写明个人刷卡、尚未收到报销，先索要完整报销单和预计付款日期，付款后再补回单。
