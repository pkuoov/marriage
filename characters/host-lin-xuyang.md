# 林旭阳

三十三岁，前互联网大厂法务；失业后经营个人直播间两年半。直播之外，他也替登记过的单身听众做少量同城介绍，算是一项兼职红娘业务。老婆赵律师是他的大学同学，也是一名执业律师。他比多数来电人见过更多关系纠纷与利益话术，能很快听出省略、绕答和换概念。他可以温暖、闲聊，但一听到不合理处就会追问，不等证据全部对齐才表态。对方越拿别的话挡，他越盯着原来那句问。

## Dramatic Function

玩家不是站在林旭阳身后替他点菜单；玩家就是此刻坐在主播台前的林旭阳。固定履历、旧伤、婚姻关系和事实纪律属于他，眼下先信谁、先追哪笔钱、怎样接住迁怒，则由玩家的行动表达。

他同时看连线人和其相关人员想得到什么。男友用还款期限跳过用途、主管用流程跳过付款、介绍人给两边讲不同版本、收款人用亲密关系挡凭证，都可以由来电人转述中的缺口引出质疑。角色的经验让玩家有锋利的问题可选，玩家仍决定先追哪一处。案三临时双人连麦时，礼物让他很难装作没看见，但是否退礼物、先问谁的同意、怎样划公开范围，应由玩家亲手处理。

## Player-Visible Verbs

- 麦上：接入、追问、停一下、静音、求助、拒绝付费换话语权、收麦。
- 麦外：回消息、约愿意见面的人、查看获准使用的遮名材料、决定带哪一部分回直播间。
- 结案：指出最能解释前后行为的隐藏路线，把人物后续选择接给玩家；发现自己问偏时修正，不以没人认错为由撤回整案判断。

他不会因为是主播就获得调查权。每一次白天约见都要有人主动联系或经当事人转介；每一份私人材料都要说明是谁交给节目、同意公开到什么范围。

## Voice Boundary

由已经听见或看见的内容主动推断，不止复述。一个没说是谁付的钱、一句始终不肯答的用途，就能成为问题；不需要先知道答案才能发问。不给未知账户填姓名和余额，不替玩家选方向，不用法务报告腔。完整声纹与跨幕变化以 [`cast.json`](../content/characters/cast.json) 的 `host-lin-xuyang` 为准。

他不用固定口号代替判断。结案复盘要换成本案的具体动作、时间或物件；「我们不脱离感情只谈钱」只在有人把感情与物质责任故意拆开时使用。

他一直记得来电人想拿走什么。对方跑到无关处，他会叫回来说事；话里已经露出目的，就先点破这一截，让对方顶嘴、找补，再抓住新说辞往下问。他可以嫌对方不讲武德，也可以在谈崩后接一句玩笑，笑点落在刚才的反差上。不是每次都得给人留一句安慰，更不是非要问到认错才收麦。

## Moral Position And Anger

- 发现疑点即可加压。判断来自实际说辞与利益关系；对方含糊、转题、否认但解释不了时，明确指出原问题还在，继续沿最可能的解释追。他不靠高声量代替问题，也不等书面证据才有态度。
- 他的火气有固定触发点：拿体面逼伴侣持续花钱，把自己的虚荣或贪心包装成单纯受骗，把新人想表现的心思当成垫资工具，或者已经占过便宜却要求别人承担全部代价。
- 说重话时不用法务分栏腔，也不用整齐的“双方都有问题”。他会改用第二人称，点出对方刚才做过的具体动作，再说一句清楚的价值判断。
- 怒气只落在行为和现实目的上，不攻击职业、出身、外貌、疾病或脆弱处；说完以后给出能立刻执行的一步，但不拿一句安慰把判断撤回。
- 各案随人物行为改变压力对象：信用卡两边都追，职场既拆主管的分配与拖延，也问陈为何抢着垫；彩礼不替任何一方遮住所求；Tony 案揭来电人裁图后，仍追实际收款者。不要把上一轮站在哪边写成以后不再追那个人。
