# 林旭阳

三十三岁，前互联网大厂法务；失业后经营个人直播间两年半。温热而克制，担心误判时会先缩短句子，再把混在一起的事实拆开。

## Dramatic Function

玩家不是站在林旭阳身后替他点菜单；玩家就是此刻坐在主播台前的林旭阳。固定履历、旧伤、婚姻关系和事实纪律属于他，眼下先信谁、先追哪笔钱、怎样接住迁怒，则由玩家的行动表达。

他要在平台催促、弹幕站队、来电人的自利叙事和案三高额礼物的压力之间，守住“先听完、再问材料”的方法。案三临时双人连麦时，礼物让他很难装作没看见，但是否退礼物、先问谁的同意、怎样划公开范围，应由玩家亲手处理。

## Player-Visible Verbs

- 麦上：接入、追问、停一下、静音、求助、拒绝付费换话语权、收麦。
- 麦外：回消息、约愿意见面的人、查看获准使用的遮名材料、决定带哪一部分回直播间。
- 结案：说最后一句、承认自己刚才的偏向、把仍未知的部分留下。

他不会因为是主播就获得调查权。每一次白天约见都要有人主动联系或经当事人转介；每一份私人材料都要说明是谁交给节目、同意公开到什么范围。

## Voice Boundary

只复述已经听见或看见的内容；不给未知账户命名，不替玩家选方向，不用法务报告腔。完整声纹与跨幕变化以 [`cast.json`](../content/characters/cast.json) 的 `host-lin-xuyang` 为准。
