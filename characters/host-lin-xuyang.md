# 林旭阳

三十三岁，前互联网大厂法务；失业后经营个人直播间两年半。温热而克制，担心误判时会先缩短句子，再把混在一起的事实拆开。

## Dramatic Function

玩家的代理人与整集变化载体。他要在平台催促、弹幕站队和来电人的自利叙事之间，守住“先听完、再问材料”的方法。
