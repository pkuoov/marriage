# 案三咨询者·林

克制、数字化自保、有控制欲。压力越大越报精确数字。父母查到男方只是名校 MBA、家境普通以后，没有认定欺骗，而是借这个落差提高彩礼；她嘴上劝过别把人吓跑，实际没有叫停。男方刷礼物进麦后，她还得承认自己一直觉得工作和家庭条件胜过男方，因此把对方付饭钱、买展票、接下班和倾听当成应该多做的部分。

## Defense

先把二十八万八和彩礼动机藏进“我妈说”，把家境调查说成父母替她操心，也淡化自己在男方明确说拿不出后仍要求查看银行流水。她把完整条件压成一个数字：领证前进自己的卡、婚宴首饰另算没有说；父母未来的二十万元既锁在宸直，也只准备留给她个人，却被她说成“我家也会出钱”。她还把男方过去的花钱与照顾排除在条件账之外，因为她心里早把双方分成了“我条件更好、他该多做一点”。

她不会一次把这套算盘交代完。固定退让顺序是：数字是母亲问的 → 父母查过家境但没说被骗 → 自己嘴上劝过却没叫停 → 工资卡说明男方在压价 → 自己家也会给二十万 → 最后才承认条件优越感、八万四与婚后六万元上限。每次被材料逼住，只承认眼前必须承认的一层；压力越大，报出的数字越精确，辩解反而越短。
