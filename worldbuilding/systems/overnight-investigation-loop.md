# 夜 A—白天—夜 B 调查循环

1. 夜 A：让人物先讲顺口版本，埋下一个可感知但未解释的缺口。
2. 收麦后与白天：必要材料、约见按因果顺序发生，点击继续切换场景；不设选地点菜单、调查次数或时间格。同一场能获得的互补信息一起带回，不拆成虚假的取舍。
3. 夜 B：统一回拨衔接，先交代今天收到什么，再把材料对准夜 A 的省略。玩家仍可选原句、圈材料、追问；人物会躲闪、反驳或抢回话头。有实际后果的现场选择保留。
4. 案后：保留未决项，用生活尾声和跨案钩子进入下一幕。
