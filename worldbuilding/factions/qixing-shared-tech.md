# 栖行共享科技

虚构共享充电柜与储物柜公司，宸直是主要股东之一。部门按场或点位包干，谁能先垫谁主办。部分中层通过虚列协调费和计入物料报价的个人返费获利；不是仅凭包干制度断言所有人侵占。

公司公开融资稿中的点位样本，单柜日均使用收入三元，场地分成零点八、维护一点二、折旧一点五，共三点五元，尚未计总部费用。此样本显示扩张模型的压力，不单凭样本断言全部点位亏损。

押金每用户二十九元，属于应退负债；关联往来附注显示归集至宸直体系资金平台。案后先发现归集，最终处置通报确认宸直用押金进行关联项目配资及继续融资。资金无法回流时，押金退款和日常付款同时吃紧。
