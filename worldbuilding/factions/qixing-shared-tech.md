# 栖行共享科技

虚构共享硬件公司，主营共享充电柜和储物柜，宸直信托是主要股东之一。公开融资稿长期用新增点位和下一轮估值讲增长：押金二十九元，单次使用费一元五角，押金属于需退还款项；柜机采购、铺设、维护和场地方分成持续发生。按公司披露的使用率，单个点位已经难以覆盖维护与分成。

供应商返费表把点位协调、渠道维护、采购配合分别挂在招商主管、区域经理、采购经办三层。它能证明层层返费是业务规则，不能在没有支付记录时指认具体个人入账。案后出现的两家公子奢靡八卦只塑造资本与公司文化，不是财务证据。
