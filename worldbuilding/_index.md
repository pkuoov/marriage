# Worldbuilding

## World Overview

故事发生在当代中国城市的一档个人直播里。城市不是背景板：餐厅会员、理发店客情、婚恋资料、公司审批与信托产品共同构成一套“好听身份如何换成现实成本”的社会系统。

绝大多数案情通过匿名连麦、白天走访、截图、录音和文件进入直播间。节目不具备警方或司法权力，因此“能确认什么”与“仍然不知道什么”本身就是世界规则。
